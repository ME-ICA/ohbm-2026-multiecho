Introduction

Quantifying voxelwise associations of neuroimaging measures with non‑imaging phenotypes is fundamental to mapping brain–behavior relationships and uncovering links between brain and -omics. However, conducting such analyses at scale while ensuring reproducibility in a framework that is accessible to researchers without neuroimage analysis expertise remains a challenge. We developed NeuroVoxel, a Python framework designed for mass‑univariate voxelwise regression using imaging derivatives organized according to the Brain Imaging Data Structure (BIDS)1, to allow users to conduct association analyses in settings where they may not necessarily have direct access to the underlying dataset. NeuroVoxel provides a user-friendly interface for analyzing associations between neuroimaging measures such as morphometry, white matter microstructure integrity, or proteinopathy maps and non‑imaging variables such as demographics, genomics, proteomics, and cognitive measures.

Methods

NeuroVoxel (https://github.com/bilgelm/neurovoxel) is implemented in Python 3.13 and integrates pybids2 for loading in BIDS datasets, nilearn3 for neuroimage manipulation and regression modeling, formulaic for parsing Wilkinson formulas, and nanslice for visualization of statistical maps. The graphical user interface, built with streamlit, provides modules for data import, parameter tuning, and model specification (Figure 1). NeuroVoxel is fully compatible with imaging derivatives organized according to BIDS, allowing automatic detection and ingestion of derivative files such as preprocessed and spatially normalized structural and diffusion MRI and PET images. Statistical analyses follow a mass-univariate general linear model structure based on a user-provided formula, e.g., FA ~ age + sex, where the outcome variable is examined at each voxel. Each voxel’s regression coefficient and statistical significance are estimated, corrected for multiple comparisons (permutation-based familywise error correction), and rendered as brain overlays. In addition to statistical maps, NeuroVoxel performs basic variable checks and displays descriptive statistics for the variables used in the analysis. A configuration file and downloadable output package ensure reproducibility. We demonstrated NeuroVoxel using the Baltimore Longitudinal Study of Aging (BLSA) Open dataset comprising 119 participants and 313 neuroimaging visits, including imaging derivatives computed from structural MRI (RAVENS maps for GM, WM, and ventricles), DTI (FA, MD, AD, RD), and [11C]PiB PET (PiB DVR reflecting amyloid-β plaque burden).

Results

On a MacBook Pro with 40-core Apple M3 Max and 128 GB memory, it took 9 minutes, including image data loading, to run a mass-univariate analysis examining the association of fractional anisotropy in the white matter with age, adjusting for sex (i.e., FA ~ age + sex). The analysis was based on 259 observations in a 1 mm isotropic space restricted to a white matter mask consisting of 521,499 voxels, with 10,000 permutation tests applied to the age term. The voxelwise regression coefficient maps are displayed using dual-coded visualization4 (color for effect magnitude, opacity for significance) in Figure 2. Findings indicate that older individuals have lower FA in the white matter.

Conclusion

NeuroVoxel advances reproducible voxelwise neuroimaging analyses by combining open-source transparency, BIDS-compatible data handling, and a simple user interface to allow researchers without neuroimage analysis expertise to conduct mass‑univariate regression studies. NeuroVoxel supports variable interactions, powers, and other mathematical transformations that can be specified using Wilkinson notation. Quick exploratory analyses on the order of a minute can be conducted by setting the resolution of the template space to be coarser (for example, 2 mm rather than 1 mm isotropic) or reducing the number of permutation tests, directly in the app. NeuroVoxel provides a practical tool for quantifying neuroimaging–phenotype associations in large-scale studies, aligning with reproducible neuroscience principles. NeuroVoxel is amenable to extension to a cloud-based federated learning framework to facilitate analysis in multisite settings.
