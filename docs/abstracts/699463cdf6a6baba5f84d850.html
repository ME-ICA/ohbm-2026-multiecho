Introduction

Since the discovery that neural activity can be organized into large-scale intrinsic networks, analyses focusing on the role of such networks has taken on ever increasing importance in a wide array of applications. However, the quantification of how networks relate to phenomenology of interest remains challenging, often requiring significant tradeoffs between validity, complexity, and interpretability. Here we introduce the functional MRI Connectome Omnibus Network Testing (fCOuNT) package for R that provides a flexible framework for easily interpretable network-level inference that is optimal for detecting rare and weak effects commonly observed in brain-behavior associations1.

Methods

The fCOuNT package leverages Higher Criticism2,3 (HC) to test for network effects using a 2-level approach. In order to do this, the whole connectome is subjected to mass univariate testing, providing a sufficient number of “observations” within and between networks to perform omnibus testing with HC. The primary inputs to the package are subject-level functional connectivity (FC) matrices, the desired statistical test, and data required to perform the tests (Figure 1A). First level statistical tests are performed for each node-pair in the FC matrices (Figure 1B). Nodes are grouped by pre-defined network affiliation so each node-pair is associated with a specific network-pair (Figure 1C). Second level tests employ HC to make inference at the network-pair level by comparing the empirical distribution of first level p-values with the expected null distribution using a modified Kolmogrov-Smirnov statistic (Figure 1D). Intuitively, HC arises from a simple observation: in the absence of any true effect, mass univariate testing on random data would yield a uniform distribution of p-values. HC quantifies the difference of the observed values from the theoretical uniform distribution. The primary output of the package is the HC statistic and associated p-value for each intra- and inter-network pair. Additional outputs include a graphical summary of the results and quality control plots to ensure that the basic distributional assumptions underlying HC are met.

Results

The fCOuNT package is currently available via Github at https://github.com/andrew-gerlach/fCOuNT and will be available through CRAN in early 2026. The package allows for a wide range of user control from fully automated to step-by-step completion. Data and FC matrices can be flexibly read from file or existing R environment variables. The package currently supports t-tests, ANOVA, and linear regression at the first level, though this selection will be continually expanded to accommodate requested user functionality. Users are also free to implement their own first level tests and provide the p-values for second level testing. This approach allows for a high degree of flexibility in the first level tests as it only requires the p-values for the second level test. Network assignments for common parcellations (e.g., Schaefer, Shen, etc.) to the Yeo 7 and 17 network atlases4 are provided, though users may also provide a simple node-wise list of network assignments for a more flexible implementation. For m networks, the output includes m intranetwork connectivities and m * (m – 1) / 2 internetwork connectivities. Note that this constitutes a family of m * (m + 1) / 2 primary tests, so multiple comparisons correction should generally be implemented at this level. False discovery rate (FDR) correction is implemented by default, but Bonferonni and no correction options are also available.

            The computational demands for this approach are moderate–a typical analysis may require 10-30 minutes to run on a standard single-core computer. The mass univariate testing and p-value calculation for the HC statistic steps comprise the major computations, but both processes are highly amenable to parallel computing. Enabling the parallel option within the package typically reduces run times to <5 minutes.

            Example input and output are provided in Figure 2 based off previous work employing this methodology to test for differences between healthy controls and an elderly depressed population5. (Note: the Study Data displayed is fictitious and only for illustrative purposes.) The results in Figure 2 reflect the t-test defined in the input and show greater connectivity in the depressed group between the default mode network (DMN) and executive control network (ECN) and lower connectivity within the somatomotor network (SMN). In this example, there are 28 primary tests for network connectivity differences between the group (7 intranetwork connectivities and 21 internetwork connectivities); the output is FDR-corrected for this family of tests.

Conclusion

We have developed an R package for testing network-level connectivity that is powerful, flexible, interpretable, computationally efficient, and now convenient. The optimal power for detecting rare and weak effects derives from the multiple observations afforded by connectomes approaches. Meanwhile, the reliance on only p-values at the second level creates a common space for unifying a wide array of first-level statistical tests, providing excellent analytical flexibility. The deterministic framework is computationally efficient for connectomes of typical size (~hundreds of nodes) and parallelizable. Finally, since connectome-level processed data in the form of FC matrices are widely available or easily produced via extant pipelines, this R package makes the two-level testing framework easy and accessible for a plethora of applications.
