Introduction

The Naturalistic Stimuli (NS) paradigm provides a unique and ecologically valid context for studying complex brain function. While Inter-Subject Correlation (ISC) is commonly used to delineate group-shared neural responses driven by external stimuli[1], reliance on group-averaged synchrony fails to capture widespread individual differences. Inter-Subject Representational Similarity Analysis (IS-RSA) offers a solution by mapping time-locked neural responses to individual behavioral or physiological phenotypes, translating shared activity into structured, explainable patterns of individual variability[2].

A critical, yet underexplored, dimension in this context is the dynamic fluctuation of individual attention. Real-time attentional engagement, indexed by pupil dilation, is significantly modulated by both state and stable traits, fundamentally influencing the neural response time series and serving as an essential factor for explaining individual synchrony differences. Furthermore, the attentional network itself exhibits stable hemispheric lateralization, notably the right-hemisphere dominance of the Ventral Attention Network (VAN). Thus, simultaneously integrating two critical dimensions—individual dynamic changes in attention and hemispheric lateralization—under NS conditions is crucial for establishing the mechanisms and sources of brain synchrony. This study aims to systematically reveal the lateralization patterns of brain synchrony and their commonalities and specificities across multiple film stimuli. We first assess the static hemispheric lateralization of IS-RSA between attention synchrony and ISC. Subsequently, a sliding-window approach is employed to test whether static ROI lateralization aligns with, or deviates from, its real-time dynamic lateralization, thereby clarifying how attention shapes individualized synchrony features in naturalistic settings.

Methods

The study utilized 7T fMRI data from the Human Connectome Project (HCP) S1200 release, specifically 184 participants who completed four naturalistic movie runs. Synchronous eye-tracking provided pupillometry-based indices of attentional engagement[3]. After rigorous quality control (eye-closure < 75%, mean framewise displacement < 0.2 mm), between 128 and 141 participants remained per movie.

fMRI data underwent the HCP minimal preprocessing pipeline with custom post-processing, with six additional low-level visual and auditory features regressed to control for audiovisual differences between movies. Vertex-level functional data were mapped onto 400 homotopic ROIs[4]. Pairwise temporal ISC (tISC) was calculated per ROI (Fig. 1A). Eye-tracking data were similarly cleaned (blink interpolation, filtering, detrending, and low-level feature regression) and downsampled to 1 Hz. ISC of cleaned pupil data (eyeISC) quantified cross-subject attentional synchrony (Fig. 1A)[5].

For each movie, static IS-RSA was performed: Spearman correlations between tISC and eyeISC were computed separately for left and right homotopic ROIs (Fig. 1B). The difference (R - L) quantified the static lateralization of brain–attention coupling. To capture dynamics, a tapered sliding-window IS-RSA (30 TR window, 1 TR step) generated a dynamic lateralization time series (Fig. 1C).

To test if static patterns modulate dynamic coupling, 200 ROIs were divided into static right- (R - L > 0) and left- (R - L < 0) lateralized groups. At each time window, Mann–Whitney U tests (FDR-corrected) compared dynamic coupling between groups to identify significant time windows. Dynamic lateralization patterns were classified into four types based on whether their dynamic sign was consistent with the static pattern (R1: consistency) or represented other scenarios (R2, R3, L3). Nonparametric permutation tests (5,000 repetitions) assessed the significance and non-randomness of these dynamic patterns (Fig. 2C).

Results

Static analysis revealed lateralization patterns that exhibited both commonalities and context-specific features across movies. Notably, regions within the Ventral Attention Network (VAN), Dorsal Attention Network (DAN), and Default Mode Network (DMN) consistently showed right-lateralization in cross-subject synchrony, suggesting a stable organizational feature across stimuli, while left-lateralized ROIs were more diffusely distributed (Fig 2A).

Mann–Whitney U tests comparing dynamic coupling values confirmed a strong link between static structure and dynamic events. The R1 category—where dynamic lateralization matched the static pattern (transient amplification)—was the predominant dynamic type across all movies (Fig. 2C). Crucially, the R1 dynamic maps correlated strongly with their corresponding static lateralization maps (r = 0.56–0.79), indicating that these transient events represent a selective amplification of the underlying static lateralization architecture. Nonparametric permutation tests confirmed the statistical significance of the R1 pattern (p < 0.05 across three movies), suggesting these high-contribution windows are non-random and tightly coupled to stimulus-driven temporal events.

By contrast, other dynamic lateralization categories failed to reach significance, implying their limited contribution to the overall static structure. Furthermore, analysis within a mask of ROIs stable across all four movies (Fig. 2B) confirmed high consistency of the R1 pattern across contexts, supporting R1 as a robust, cross-stimulus dynamic lateralization feature (Fig. 2D, E). These findings collectively suggest that attention-modulated brain synchrony lateralization is not uniformly sustained but is shaped by temporally specific, high-contribution dynamic windows that transiently amplify the brain’s intrinsic static lateralization structure.

Conclusion

This study systematically compared static and dynamic patterns of attentional modulation on cross-subject brain activity synchrony during naturalistic viewing. Our findings reveal that the "static" lateralization structure derived from full-time correlation analyses is disproportionately influenced by a limited number of critical time windows. These transient neural coupling events effectively and transiently amplify the intrinsic lateralization structure, thus determining the overall observed static lateralization pattern. These key dynamic events demonstrate both temporal specificity and robust generalizability across different movie stimuli. This observation motivates a new conceptual framework: functional lateralization should be viewed not merely as a fixed anatomical attribute but as a context-dependent transient state shaped by specific dynamic event ensembles.
