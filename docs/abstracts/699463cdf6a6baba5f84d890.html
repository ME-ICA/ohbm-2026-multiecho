Introduction

Traditionally, neural markers have been derived by comparing group averages using purely discriminative feature-selection approaches, such as mass-univariate t-tests, which aim to maximize group separation. However, it is well established that individuals exhibit substantial interindividual variability, which these approaches typically overlook. 

Functional connectivity patterns estimated from resting-state functional magnetic resonance imaging (fMRI)– represented as functional connectomes (FCs) – are unique to each individual 1. These so-called brain-fingerprints allow to identify individuals from a population, have been linked to cognitive traits 2 and the features driving identifiability are altered in neurodegenerative diseases, including Alzheimer’s Disease 3 and Parkinson’ Disease (PD) 4.  

In neuroimaging, intra-class correlation (ICC) is commonly used to identify connections that are reliable within an individual across different time points while preserving between-subject variability. Accordingly, ICC has been employed to identify features underlying individual brain fingerprints, namely stable connectivity patterns that support identifiability.

Here, we systematically investigate whether incorporating feature stability via ICC into the feature-selection pipeline improves generalization performance relative to standard discriminative methods in distinguishing patients with Parkinson’s disease from healthy controls across two independent cohorts. Furthermore, we assess whether stable connectivity features exhibit enhanced clinical relevance by predicting individual clinical measures of motor symptom severity and cognitive functioning.

Methods

We analyzed resting-state fMRI data from patients with PD and healthy elderly age-matched controls (HC) across two independent cohorts. The Newcastle cohort initially comprised 63 HC and 45 PD patients. To obtain a balanced training and validation dataset, 18 HC were held out, yielding a balanced sample (N=90; PD: n=45; HC: n=45). The Geneva cohort (N=55; PD: n=55) was used for holdout testing and consisted exclusively of PD patients. The 18 held-out Newcastle healthy controls were used for comparison with PD patients in the Geneva cohort.  A schematic overview of the analyses pipeline is shown in Figure 1. 

First, FC matrices were computed in each subject's native space using Pearson correlations between 278 brain regions (Shen parcellation plus subcortical and cerebellar regions). In the training Newcastle dataset, we then assessed the reliability of each FC edge using edgewise ICC, which quantifies the stability of connectivity between repeated measurements within subjects. Higher ICC values indicate more stable within-subject connectivity patterns and greater between-subjects variability in the group3. We evaluated multiple ICC computation strategies (PD-only, HC-only, and across all subjects) and retained the PD-only formulation – where reliability is assessed strictly within the patient group – as it yielded the highest downstream classification AUC. Next, we conducted a parameter sweep to determine the optimal number of features by repeating the classification while varying the number of top-ranked ICC edges retained (k) and selecting the k that maximized cross-validated AUC, identifying a peak classification performance at k = 11,000 edges. To further isolate the most robust connections within this feature space, we applied bootstrap resampling (1000 iterations) to the PD cohort by repeatedly drawing a new PD sample with replacement and re-running the ICC feature-ranking/selection each time, and retained only edges selected in more than 60% of resamples, yielding a final consensus set of 7’821 stable features.

For direct comparison, we selected an equal number (7’821) of features using conventional independent two-sample t-tests between PD patients and healthy controls. Both feature sets were tested for (i) binary classification to test accuracy in distinguishing PD patients vs. HC and (ii) prediction of clinical motor symptoms severity and cognitive functioning. For motor symptoms severity, we used the Unified Parkinson's Disease Rating Scale (UPDRS) total score in the Newcastle dataset, and motor score (part III) in the Geneva dataset. For cognitive functions, we used the Cambridge Cognitive Examination (CAMCOG) total score in the Newcastle cohort and the Montreal Cognitive Assessment (MoCA) and Parkinson’s Disease Cognitive Rating Scale (PD-CRS) in the Geneva cohort. 

For task (i), we extracted each individual’s connectivity value corresponding to the ICC-selected or t-test-selected features and trained a logistic regression classifier with 5-fold cross validation, computing balanced accuracy and AUC for PD vs. HC discrimination. 

For task (ii), we predicted clinical severity using only PD patients and the fixed set of connectivity edges. We compared two predefined feature sets: (1) ICC-stable edges (k=7’821) and (2) an equal number of top t-test edges (k=7’821). For each subject, we extracted the connectivity values of the selected edges (ICC-stable or t-test top-K) and used them as predictors in a Ridge regression model (linear regression with L2 regularization, used to prevent overfitting when the number of edges is large compared to the number of subjects). We standardized the predictors and tuned the Ridge regularization strength using nested 5-fold cross-validation, making sure that the test data was never used in training sets. Prediction accuracy was then evaluated as  and p-value (from the correlation between predicted and observed scores).

Results

Stable (ICC-selected) and discriminative (t-test-selected) feature sets performed similarly on binary classification. ICC-selected features achieved high AUC in both the Newcastle training set (AUC = 0.790 ± 0.077, Balanced Accuracy = 0.722 ± 0.111) and the independent Geneva holdout test set (AUC= 0.954, Balanced Accuracy = 0.825). Classification was comparable using t-test-selected features (Newcastle training set: AUC = 0.992 ± 0.045, Balanced Accuracy = 0.900 ± 0.091; holdout test set:  AUC = 0.970, Balanced Accuracy = 0.926). These results demonstrate strong cross-site generalization.

ICC-stable features showed better clinical predictive utility than t-test-selected features in the training dataset, but did not generalize to the testing dataset. Using fixed-mask Ridge regression on PD subjects only, ICC-stable features significantly predicted motor symptoms severity (UPDRS Total score) in Newcastle (R² = 0.182, p = 0.003), whereas the matched t-test feature set did not reach significance (R² = 0.074, p = 0.054). Neither ICC-stable nor t-test features significantly predicted cognitive functions in the Newcastle cohort (CAMGOC, p > 0.32). In the external Geneva PD cohort, neither ICC-stable nor t-test features significantly predicted UPDRS-III, MoCA, or Total PD-CRS (all p > 0.17).

Conclusion

Incorporating feature stability, as quantified by ICC, into the connectomic feature-selection pipeline yields a robust set of Parkinson’s disease–related functional connections that is largely distinct from those identified using purely discriminative criteria, with only ~25% feature overlap. Despite this divergence, both selection strategies achieve good classification performance and excellent cross-cohort generalization.

Importantly, ICC-selected features show superior clinical predictive utility compared with discriminative features within the training dataset; however, this advantage does not generalize to an independent cohort, potentially due to the relatively small sample size (N=45) of the cohort used for feature derivation. Larger cohorts may be necessary to better understand the factors limiting cross-dataset transferability.

Overall, these findings suggest that reliability-based feature selection may enhance clinical relevance within a given dataset, but also call for caution when applying fingerprinting-based approaches. Features optimized for high intra-subject stability at the group level may still be sensitive to inter-individual variability, limiting their ability to generalize across cohorts or to capture subject-specific effects consistently. This highlights a key challenge for functional connectome fingerprinting when translated across independent datasets.
