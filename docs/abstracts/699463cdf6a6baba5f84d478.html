Introduction

In daily life, reading different sentences evokes different feelings and thoughts. Recent work has shown that large language models (LLMs) share many aspects of language processing with the human brain. Although LLMs can be used to predict neural responses to linguistic inputs, the interpretability of such predictive power remains limited. Specifically, it is still unclear which features or dimensions of sentence meaning are used by humans and LLMs to encode semantic information. In this study, we first developed and validated an encoding model capable of effectively predicting brain responses to sentences. We then showed that affective properties of sentences, i.e., valence and arousal, are systematically related to patterns of brain activation.

Methods

We built and tested the encoding model with reference to the methods described in Tuckute et al. (2024).1 First, we constructed Chinese Sentence Corpus with Semantic Variety (CSCSV),2 which contains 1,000 semantically diverse sentences that span a broad semantic space via limited pairwise cosine similarities (Mean = 0.4; STD = 0.086; Fig. 1a). 

With this corpus, we collected participants’ brain responses to these sentences using a silent-reading fMRI task (Fig. 1b). In each trial, a sentence was presented at the center of the screen, and whole-brain activity was recorded with a 3T scanner. Each run contains 50 unique sentences. Each participant completed 24 runs, resulting in 1200 sentence presentations in total, with 200 sentences repeated once. In the end, 8 participants (4 female) completed the experiment involving 1,000 baseline sentences. fMRI data were preprocessed following the standard pipeline implemented in the CONN toolbox, and first-level analyses were performed using GLMsingle, a state-of-the-art toolbox optimized for rapid, event-related designs.3 

We computed a vector representation for each sentence using text2vec-base-chinese (https://huggingface.co/shibing624/text2vec-base-chinese). To develop the encoding model, sentence embeddings were treated as independent variables and ROI-wise BOLD values as dependent variables. Data from five participants were averaged to train the model, and data from the remaining three were used for model evaluation. We fit the encoding model using ridge regression. 

Next, with the obtained model, we screened a large text corpus (~200M sentences) and computed predicted brain responses for each sentence. Sentences were then ranked by their predicted activation strength, and we selected the top 250 and bottom 250 sentences. These sentences were predicted to maximally activate or deactivate the language network. Another 5 (3 female) participants subsequently read these 500 sentences in the fMRI scanner following the same procedure. 

In addition, valence and arousal scores for the sentence were obtained using a fine-tuned multilingual language model (XLM-RoBERTa-large), which has demonstrated reliable performance in previous work.4

Results

We first trained models using data from multiple ROIs independently, including both language-selective regions and control regions (Fig. 2a). These ROIs were functionally defined.5 As expected, most control ROIs—such as those in the Multiple Demand Network and the Default Mode Network—showed little to no response to linguistic stimuli (Fig. 2b). We chose BOLD values from one particular ROI (Posterior Temporal, PostTemp) to train the encoding model we needed, given that previous studies have shown that PostTemp plays a more important role in language comprehension than other ROIs. The model performed well on both datasets. For the three left-over participants in training stage (Fig. 2c, grey line), the model trained on 1,000 baseline sentences achieved a correlation of r = .298 (p < .0001). For the five participants who read newly selected sentences (Fig. 2c, purple line), using 500 selected sentences, performance reached r = .485 (p < .0001). These high and significant correlations indicate that the model effectively captures the mapping between sentence features and neural responses, and can therefore be used to predict the brain’s response to a given sentence. 

In addition, we examined how affective dimensions correlated with reading-related neural responses (Fig. 2d). Consistent with prior one-to-one mapping theories, the orbitofrontal cortex tracked valence, wheras the amygdala tracked arousal. More importantly, we also observed widespread associations within the language network, indicating that the predicted neural activation in this language network was partly driven by affective variance in the sentences. Taken together, these results highlight the complexity of affective processing and challenge the traditional view of a strict one-to-one mapping between affective dimensions and specific brain areas. 

Conclusion

Our findings demonstrate that brain responses to sentences can be reliably predicted using an encoding model grounded in sentence embeddings. Moreover, emotional dimensions such as valence and arousal systematically modulate neural activity within the language network, suggesting that the brain’s representation of sentence meaning is shaped by rich affective information rather than isolated, category-specific mechanisms.
