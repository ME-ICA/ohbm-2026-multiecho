Introduction

Age-related episodic memory decline represents a major risk factor for Alzheimer’s disease and poses a central challenge in cognitive aging research. While traditional models emphasize the roles of the medial temporal lobe and prefrontal cortex, growing evidence underscores the contribution of the cerebellum and its functional interactions with cerebral cortical networks to episodic memory.^1 In aging, this cerebello-cerebral circuitry is critical for supporting high-fidelity memory, yet its topological organization and efficiency are frequently disrupted, leading to alterations in large-scale brain networks that subserve memory processes.^2 Such network-level alterations may account more powerfully for individual differences in memory performance among older adults than focal brain changes alone. However, the specific role of cerebellar-functional networks in explaining this variability remains poorly understood.^3 To address this gap, we employed a network-based approach on task-based fMRI data to investigate how cerebello-cerebral connectivity shapes individual differences in visual episodic memory encoding and retrieval in older adults. We hypothesize that the functional integration of the cerebellum with key cerebral networks constitutes a principal neural substrate predicting memory abilities in the aging brain.

Methods

We analyzed data from 997 older adults (age ≥50 years; 112 with ≥2 follow-ups) from the Beijing Aging Brain Rejuvenation Initiative (BABRI) cohort, who underwent structural and task-based MRI.^4 An episodic memory task employing an encoding-retrieval block design was administered, and memory accuracy was derived from participant responses. fMRI data was preprocessed using DeepPrep.^5 Age, gender, and education were included as covariates in all analyses.

Whole-brain activation maps were generated using a general linear model (GLM) at both individual and group levels, with button-press responses regressed out. Multiple comparisons were controlled using the false discovery rate correction (p<0.05). Significantly activated cerebellar regions were parcellated into functional networks via a Dictionary Learning algorithm, applied within a voxel-based activation mask and a cerebellar mask in MNI space. Model selection was performed using grid search and the elbow method. Activation within each cerebellar network was estimated via GLM, and its relationship with memory accuracy was assessed after controlling for demographic covariates. Bonferroni correction (p<0.05) was applied to correct for multiple comparisons.

Dynamic functional connectivity (dFC) between cerebellar networks and cerebral regions (Schaefer atlas) was computed using a sliding window approach. Inter-individual differences in dFC were quantified using Dynamic Time Warping (DTW) distance. Participants were stratified into high-, medium-, and low-performance groups based on memory accuracy quartiles. Between-group differences in dFC were assessed using two-sided tests (p<0.01), identifying connections with DTW distances exceeding 2.58 standard deviations.

Results

Voxel-wise analysis revealed significant activation across the cerebellar cortex, particularly in lobules VI–X of the posterior lobe. Similar patterns were observed in encoding and retrieval phase. Positive activation was observed in lobules VI, Crus I (superior), VIIB, VIIIA, X, and the vermis, while deactivation occurred in Crus I (inferior), Crus II, and lobule IX. However, no significant correlations were found between voxel-wise activation and memory performance.

Dictionary Learning identified 30 distinct cerebellar functional networks, with Crus I and Crus II exhibiting lateralized organizational patterns. One key network in the right Crus I/II showed significant differences in activation (old-item condition) among performance groups after Bonferroni correction. Activation in this network was negatively correlated with retrieval accuracy for old items.

dFC analysis revealed distinct, memory-phase-dependent interactions between the key cerebellar network and cerebral regions across performance groups. During encoding, high- versus low-performance groups exhibited differential connectivity with the Temporo-Parietal region, whereas high-medium differences involved the Control Network B (intra-parietal lobule), and medium-low differences were observed in the Dorsal Attention Network B. During retrieval, high- and low-performance groups diverged in connectivity with Default Mode Network A (prefrontal medial); high-medium differences were identified in Default Mode Network B (prefrontal dorsal); and medium-low differences involved Default Mode Network A (temporal) alongside Control Network B (prefrontal medial) (see Figure 2 for details). These patterns suggest that efficient episodic memory relies on phased, large-scale cerebello-cerebral coordination, with encoding engaging attention and control networks, and retrieval recruiting default mode and medial prefrontal regions. Notably, in a follow-up analysis of participants exhibiting memory decline at the second follow-up, significant dFC differences were observed between the same key cerebellar network and both Default Mode Network A and the Temporo-Parietal region.

Conclusion

Our findings elucidate the cerebellum’s role in episodic memory by characterizing its functional topography and dynamic interactions with the cerebrum. We identified a lateralized network in the right Crus I/II whose activation correlates with memory performance and distinguishes between proficiency groups. Group differences in dFC between this cerebellar network and key cerebral networks (e.g., Default Mode Network, Temporo-Parietal region) during both encoding and retrieval suggest that memory ability is supported by distinct, large-scale brain-cerebellar dynamic configurations. This study provides novel evidence that cerebellar functional specialization and its dynamic integration with the cerebrum are critical neural correlates of episodic memory performance in older adults, offering new avenues for exploring cerebellar mechanisms in memory aging and identifying potential interventional targets.
