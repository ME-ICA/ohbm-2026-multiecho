Introduction

Transcranial focused ultrasound stimulation (TUS) is a promising tool to safely stimulate deep brain regions. To ensure subject safety and accurate stimulation of the desired location, dedicated simulation and neuronavigation are required for accurate targeting. The acoustic wave simulations and offline neuronavigation method can provide a useful reference standard for transducer positioning and TUS targeting1, however, those do not account for skin-transducer coupling, and it is challenging to precisely position the transducer. The only way to map the focal point in situ is to perform MR-Acoustic Radiation Force Imaging (MR-ARFI)2. In brief, MR-ARFI uses a Pulsed Gradient Spin Echo (PGSE) experiment to detect bulk displacement of the tissue. The sonication is performed during one of the diffusion encoding gradients, thereby induced displacements along the gradient direction are encoded as phase changes.

To leverage the use of MR-ARFI outcome for online TUS-fMRI neuronavigation, the TUS focal point map needs to be created immediately after the scan to map on the atomical reference for verification and calibration. In this work, we implemented a MR-ARFI sequence with non-distorted Half-Fourier Acquisition Single-shot Turbo spin Echo (HASTE) readout using a pulseq3 to minimize post-processing and developed an online reconstruction pipeline using OpenRecon4. This work demonstrates the pipeline in the phantom MR-ARFI acquisition and investigates the feasibility in vivo.

Methods

A Diffusion Weighted (DW)-AHSTE sequence using a pair of bipolar gradients having flow-compensation was prepared using pulseq for MR-ARFI experiment (Figure1). The sequence parameters are following; FOV = 192 x 192 mm2, number of slices=3, slice thickness = 3mm, TR = 2s, TE = 58ms, matrix size = 64 x 64, center out encoding, 40 volumes (alternating TUS ‘on’ and ‘off’). The diffusion direction was aligned with TUS direction to encode tissue displacements as phase changes.

The experiment was performed at 3T (Magnetom Prisma, Siemens Healthineers, Germany) using a gelatin phantom with a 300kHz annular array transducer (IMASONIC, France) driven using the IGT 32 channel system (Image Guided Therapy, France) (Figure 1).  Two MR-ARFI experiments were performed, TUS focal point 55 and 35 mm with 1.0 MPa input using the same MR-ARFI sequence.

The data were reconstructed on the scanner computer using OpenRecon with ‘raw to complex image’ feature to output mean phase difference map (i.e. MR-ARFI focal point map) with a home-built python script (Figure 1). In each volume, when coils are combined, the first volume was used as a reference to compute phase offsets for individual coils. The phase offsets were then summed across all coils, with magnitude weighting to account for the coil sensitivity. In the end of MR-ARFI acquisition, mean phase difference was computed and output (Figure 1)

To demonstrate the sequence robustness to the physiological noise, a healthy volunteer was scanned with a written informed consent at the same scanner with the same coil. Note that, no TUS was applied in this in vivo experiment as we currently have no ethical approval for ARFI in vivo. The sequence parameters for DW-AHSE sequence are following; voxel size 2x2x4 mm3, b-value of 200s/mm2 in L-R direction assuming a transducer will be placed in temporal lobe, 60 volumes, slice TR = 0.8 s, GRAPPA = 3, TE = 65ms. For comparison, identical sequence without diffusion gradients (b = 0s/mm2) was acquired. To correct the background field artifacts in phase images, a linear fitting was performed slice by slice and volume by volume in vivo. The code was adopted from SEPIA toolbox5.

Results

Using a DW-HASTE sequence, TUS induced phase changes were successfully encoded. Figure 2a is a screenshot of scanner console showing mean phase difference maps from TUS focal point 55 mm and 35 mm experiments. Clearly TUS induced phase changes are observed, and the focal distance was measured using scanner GUI (Figure 2a orange rectangles). The MR-ARFI focal point map can be exported as DICOM immediately after the scan for TUS repositioning. 

Figure 2b shows phase standard deviation maps in whole brain with and without a post-processing from b= 0 and 200 s/mm2 data. Without diffusion gradients, clean phase standard deviation maps were acquired as no flow was encoded. With diffusion gradients, motions were encoded, resulting large phase standard deviations in deep brain structures where physiological motions are expected. The large phase deviations were successfully suppressed using a linear background field correction. After the background field removal, the standard deviation decreased to less than 0.15 radian at most of the brain region, promising the high detectability of TUS induced phase change. 

Conclusion

We have demonstrated that the DW-HASTE sequence can be used to encode TUS induced phase change, and the focal point map is immediately available after the scan using OpenRecon. Leveraging the HASTE readout, the distortion-free focal point map can be directly mapped on anatomical reference without further post-processing such as distortion correction. The computationally efficient linear fitting method can be also implemented into OepnRecon framework as it does not require additional scans. Although, sequence sensitivity to ARFI contrast and optimal TUS timing need to be further investigated, this framework, pulseq MR-ARFI sequence with OpenRecon, will enable closed-loop online TUS repositioning based on the acquired MR-ARFI focal point map. Furthermore, this sharable, open-source development provides a plug-and-play framework, unloading hurdles of MR-ARFI implementation and the reconstruction, allowing neuroscientists conducting TUS experiments with robust neuronavigation.
