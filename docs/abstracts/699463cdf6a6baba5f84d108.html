Introduction

Much of our everyday memory formation occurs incidentally as we engage in goal-directed behaviors1. These goal-directed behaviors are modulated by cognitive control, which refers to the ability to regulate behaviors and thoughts in response to changing circumstances and internal states while keeping goals in mind2. According to the dual mechanisms of control theory, cognitive control operates through two distinct modes: proactive and reactive control2. However, how different cognitive control modes impact incidental memory formation and what’s the underlying neural mechanism remain poorly understood.

Neuroscience studies indicate that the formation of memory traces or engrams left by information processing in the brain is the neural substrate of incidental memory3. Critically, the two control modes may differentially shape these traces. Under proactive control, information processing is guided by top-down modulation established before the arrival of a target stimulus, enabling early selection of task-relevant information. In contrast, reactive control is characterized by bottom-up regulation of information processing, with task-relevant features selected from the stream of information driven by the current stimuli.

Grounded in memory engram theory3, we hypothesized that distinct control modes modulate the fidelity4 and competition of neural representations during encoding, thus influencing subsequent incidental memory performance. To test this, we combined functional magnetic resonance imaging (fMRI) in healthy adults with stereo-electroencephalography (sEEG) in clinical participants to probe both spatial representational mechanisms and temporal neural dynamics.

Methods

Participants and Behaviour Tasks

Eighty-eight healthy adults (age = 23.02 ± 2.41 years; 40 females) participated in the fMRI study, and six clinical patients (age = 30.16 ± 8.39 years; 3 females) undergoing sEEG monitoring performed the same behavioral paradigm. All procedures were approved by the institutional review board, and written informed consent was obtained from all participants.

Our behavioral paradigm was designed to manipulate cognitive control modes (proactive vs. reactive) during stimulus encoding, enabling subsequent assessment of their impact on incidental memory performance. Adapted from previous studies5, this computer-based paradigm consisted of two phases: an item classification task during encoding and a surprise recognition memory test.

During the item classification task, cognitive control modes were manipulated by varying the temporal interval between the cue (a colored border indicating the classification rule) and the target stimulus (the picture to be classified). In the proactive condition, the colored border appeared before target onset, allowing participants to prepare the relevant rule in advance. In the reactive condition, the colored border appeared simultaneously with the target, requiring participants to process the rule and respond on the fly. After completing the classification task, participants performed a surprise recognition memory test, with recognition sensitivity (d′) serving as the primary measure of incidental memory.

To support subsequent neural analyses, an additional 15 participants (age = 22.53 ± 3.11 years; 7 females) completed a target localizer task in which the same pictorial stimuli were presented multiple times. The resulting activation patterns were averaged to generate item-specific neural templates, which served as reference patterns for the representational fidelity analysis.

fMRI Acquisition and Analysis

Whole-brain fMRI data were acquired on a Siemens 3.0T scanner. Preprocessing included slice-timing correction, motion correction, and normalization to MNI space. Two regions of interest (ROIs) were defined: a Visual–Temporal Region identified from localizer activation, and a Frontal Region derived from Neurosynth meta-analytic maps associated with "memory."

Within each ROI, we employed multivariate pattern analysis (MVPA) to characterize task-relevant neural representations. Target representational fidelity was quantified as the cosine similarity between each trial's encoding pattern and its corresponding item-specific template derived from the localizer task. To characterize cue representations, we first regressed out target-related activity from each trial's activation pattern and then applied a linear support vector machine (SVM) classifier to decode cue identity from the residual patterns. Trial-level linear mixed-effects models and mediation analyses were used to examine the pathways linking control mode, neural representations, and memory performance.

sEEG Acquisition and Analysis

Intracranial sEEG signals were recorded at 2000 Hz and localized to MNI space via CT–MRI co-registration. Preprocessing included down-sampling, band-pass filtering (1–200 Hz), line-noise removal, artifact rejection, and common-average referencing. Analyses focused on electrodes within the fMRI-defined Visual–Temporal Region, specifically the hippocampus (16 contacts) and fusiform gyrus (10 contacts).

Time–frequency power (2–120 Hz) was computed using complex Morlet wavelets and analyzed with mixed-effects models to characterize neural dynamics associated with control mode and memory outcome. To assess the aperiodic 1/f component—an index of excitation–inhibition balance—the FOOOF algorithm was applied to sliding windows (500-ms width, 50-ms step) to estimate trial-level aperiodic exponents. Statistical significance for both time–frequency and aperiodic analyses was evaluated using cluster-based permutation testing (1,000 permutations; cluster-level p < .05).

Results

Using a large fMRI sample (N = 88), we first found that proactive control led to significantly better incidental memory performance than reactive control (t(87) = 5.553, p < .001), with performance in both conditions well above chance (proactive: t(87) = 26.981, p < .001; reactive: t(87) = 28.269, p < .001). Remarkably, we observed the same behavioral pattern in a small but independent sEEG cohort (N = 6), where proactive control again yielded better memory performance (t(5) = 2.824, p = .037).

To uncover the neural mechanisms underlying this robust behavioral effect, we defined two fMRI regions of interest: a Visual–Temporal Region identified from a target localizer task and a Frontal Region derived from Neurosynth meta-analytic maps of memory. Multivariate pattern analyses revealed a partial mediation effect of target representational fidelity (RF) on the relationship between cognitive control modes and subsequent memory performance. The indirect effect through target RF was small but significant in both regions (Frontal: a × b = 0.004, 95% CI [0.001, 0.008]; Visual–Temporal: a × b = 0.007, 95% CI [0.003, 0.012]), as determined through bootstrap confidence intervals. Specifically, the a-path (control → target RF) was significant (Frontal: a = 0.010, p < .001; Visual–Temporal: a = 0.012, p < .001), as was the b-path (target RF → memory; Frontal: b = 0.423, p = .007; Visual–Temporal: b = 0.597, p < .001). The direct effect (c′-path) also remained significant (Frontal: c′ = 0.211, 95% CI [0.144, 0.278]; Visual–Temporal: c′ = 0.208, 95% CI [0.141, 0.275]).

We further tested a serial mediation model in the Visual–Temporal Region to examine whether cue representation decodability (CRD) and target RF jointly mediate the control–memory relationship. Results supported a significant serial indirect pathway: reactive control induced higher CRD relative to proactive control (a₁ = −0.005, t(14077) = −3.800, p < .001), higher CRD was associated with lower target RF (d = −0.025, t(14076) = −2.351, p = .019), and lower target RF predicted poorer memory (b₂ = 0.595, Z = 3.516, p < .001). The serial mediation effect through both CRD and target RF was significant (effect = 0.0001, 95% CI [0.0000, 0.0002]), as was the indirect pathway through target RF alone (effect = 0.007, 95% CI [0.003, 0.012]). However, the pathway through CRD alone did not reach significance (effect = 0.001, 95% CI [−0.001, 0.003]).

To address the limited temporal resolution of fMRI, we analyzed intracranial sEEG recordings from six clinical participants who performed a similar item-classification and subsequent memory task. In the hippocampus, proactive control elicited stronger theta power following cue onset (400–1600 ms, p = .029), whereas reactive control evoked stronger theta after target onset (700–1200 ms, p = .011). High-gamma power following the target predicted subsequent memory (1050–1300 ms, p = .049). The aperiodic exponent—an index of excitation–inhibition balance—was significantly lower for remembered than forgotten items (300–1600 ms after target onset, p < .001), indicating greater synaptic excitability during successful encoding. In the fusiform gyrus, proactive and reactive control induced distinct temporal–spectral dynamics, with their aperiodic exponents following opposite trajectories: proactive trials showed an increase-then-decrease pattern, whereas reactive trials exhibited a decrease-then-increase pattern (750–950 ms after target onset, p < .001). These exploratory temporal findings converge with the fMRI results, suggesting that proactive control establishes a more stable preparatory neural state, while reactive control triggers late, stimulus-driven processing.

Conclusion

Together, our findings demonstrate that proactive control enhances incidental memory primarily by strengthening target representational fidelity during encoding—a mechanism observed consistently across both the Visual–Temporal and Frontal regions. In the Visual–Temporal Region, we further identified a serial mediation pathway whereby proactive control reduces competition of target and cue representations, which in turn preserves target fidelity and supports memory formation. These spatially resolved fMRI results are complemented by exploratory sEEG evidence suggesting that proactive control engages a preparatory neural state characterized by coordinated theta activity and a more favorable excitatory–inhibitory balance conducive to memory encoding. In contrast, reactive control elicits late, stimulus-driven processing that contributes to weaker memory formation.

Based on our findings, we propose a representational framework that conceptualizes cognitive control and memory not as separate systems, but as integrated components of information processing. Within this framework, cognitive control actively regulates neural representations, while memory emerges as a downstream consequence of these representational states.
