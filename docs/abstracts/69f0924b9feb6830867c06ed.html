Introduction

White matter (WM) functional connectivity (FC) has emerged as an important yet methodologically challenging extension of conventional gray matter (GM) fMRI analyses. Despite growing interest, the lack of standardized, accessible, and well-validated software has limited the broader adoption of WM functional network analysis. To address this need, we present White Matter Functional Networks (WhiFuN), a GUI-based MATLAB toolbox designed to provide a fully automated, reproducible, and user-friendly framework for investigating FC in both WM and GM.

WhiFuN integrates all essential preprocessing steps required to extract WM and GM BOLD signals and construct functional networks, significantly reducing the technical burden on users. WhiFuN Version 3 (v3) introduces major software advancements focused on usability, transparency, and quality assurance. Preprocessing can now be executed using a single function (whifun_preproc), while WM and GM functional networks can be generated using a single function (whifun_create_FN_kmeans), enabling streamlined scripting and large-scale analyses. All functions are fully self-documented within MATLAB, promoting reproducibility and ease of adoption. Another major new feature of WhiFuN is the enhanced Quality Control (QC) Viewer, designed to systematically identify participants with poor data quality. The QC module includes seed-based correlation maps for canonical GM networks, including the default mode, auditory, and visual networks, further strengthening the QC. Additional updates include DARTEL-based MNI registration, improving the alignment in the MNI space for better analysis of participants with wide age range. Finally WhiFuN now can support externally preprocessed datasets and users can directly create the WM and GM Functional networks without the need to preprocess the data with WhiFuN.  Collectively, WhiFuN provides a comprehensive and accessible software solution for robust WM and GM FC analysis.

Methods

WhiFuN v3 was updated using MATLAB 2025a and integrates custom-written code with established routines from the SPM toolbox for preprocessing, normalization (optional DARTEL algorithm (Ashburner J. 2007)), and quality control. The toolbox is designed to provide a transparent, automated, and reproducible workflow for WM and GM functional connectivity analysis, while offering extensive tools for data quality assessment and participant-level decision making.

WhiFuN v3 substantially improves support for script-based analyses, enabling efficient and reproducible processing of large datasets. Core functionalities are consolidated into a small set of high-level functions, including whifun_preproc for fully automated preprocessing, whifun_qc for generating and organizing quality control outputs, and whifun_create_FN_kmeans for constructing WM and GM functional networks using k-means clustering. This design allows complete analyses to be executed with only a few lines of code, reducing scripting complexity while maintaining flexibility through user-defined parameters. The streamlined scripting interface facilitates batch processing, promotes reproducibility, and enables seamless integration of WhiFuN into existing neuroimaging workflows.

In addition to standard preprocessing outputs, WhiFuN v3 introduces a comprehensive suite of new Quality Control (QC) plots aimed at facilitating the identification of artifacts, noise, and preprocessing failures. These QC measures are generated automatically for each participant and are designed to support objective exclusion decisions prior to functional network analysis.

First, WhiFuN now generates voxel-wise BOLD time series plots for GM, superficial WM, deep WM, and CSF compartments, alongside framewise displacement (FD) measures. These plots are provided both before and after nuisance regression, following best practices recommended by Power et al. (2013). Visual inspection of these plots allows users to assess the effectiveness of nuisance regression, identify motion-related artifacts, and detect abnormal signal fluctuations across tissue types.

Second, WhiFuN generates seed-based FC maps to enable rapid, biologically interpretable validation of preprocessing quality. Specifically, spherical regions of interest (ROIs; radius = 6 mm) are defined in MNI space for canonical GM networks, including the default mode network (MNI seed: 5, −49, 40), auditory network (64, −12, 2), and visual network (−4, −91, −3). The average BOLD time series extracted from each ROI is correlated with the voxel-wise time series across the entire brain, producing whole-brain correlation maps that reflect the expected spatial organization of these networks. These seed-based connectivity patterns, adapted from Taylor et al. (2024), allow users to quickly identify unusual or implausible network configurations that may arise from artifacts, excessive motion, or preprocessing errors.

To streamline and standardize the QC process, WhiFuN v3 includes a newly developed QC Viewer, implemented using MATLAB App Designer. The QC Viewer provides an interactive interface that allows users to browse all QC plots for an individual participant within a single environment. Users can visually inspect motion metrics, tissue-specific time series, and seed-based FC maps, and then accept or reject participant data directly within the interface. The QC Viewer also allows users to add comments documenting the rationale for exclusion or inclusion decisions, promoting transparency and reproducibility in large-scale studies.

Collectively, these additions establish QC as a central component of the WhiFuN workflow, providing both automated and visual tools to ensure data integrity. By integrating established best practices with intuitive visualization and interactive decision-making, WhiFuN v3 enables robust and reproducible WM and GM functional connectivity analyses across diverse datasets.

Results

WhiFuN v3 incorporates DARTEL based segmentation and normalization as an optional preprocessing feature (See Figure 2A Segmentation drop down ,the default is no DARTEL), providing improved inter-subject alignment, particularly in studies spanning a wide age range. Compared to conventional normalization approaches, DARTEL employs high-dimensional nonlinear registration to better account for age-related variability in brain morphology, including differences in cortical thickness, tissue contrast, and white matter organization. Visual inspection (Using QC viewer) of normalized images revealed improved anatomical correspondence across participants when DARTEL was enabled, especially in deep white matter regions and along tissue boundaries that are critical for white matter functional analyses. This enhanced alignment supports more accurate voxel-wise comparisons and network construction across heterogeneous populations, making WhiFuN particularly well suited for developmental, aging, and lifespan fMRI studies.

WhiFuN v3 introduces an interactive Quality Control (QC) Viewer that enables efficient, participant-level assessment of data quality within a unified graphical interface. The QC Viewer integrates multiple QC outputs generated during preprocessing, allowing users to rapidly inspect motion, signal characteristics, anatomical to functional alignment, functional to MNI template alignment and seed based functional organization without leaving the GUI. As shown in Figure 2B, voxel-wise BOLD time series from GM, superficial WM, deep WM, and CSF are displayed alongside framewise displacement, facilitating identification of motion-related artifacts and abnormal signal fluctuations across tissue types. In addition, the QC Viewer provides seed-based FC maps for canonical GM networks, including the default mode, visual, and auditory networks (Figure 2C). These maps enable rapid detection of atypical or biologically implausible connectivity patterns indicative of noise or preprocessing failure. Importantly, the QC Viewer allows users to accept or reject participant data directly within the interface, with the option to record comments documenting exclusion decisions. Together, these features streamline quality assessment, promote reproducibility, and establish QC as an integral component of the WhiFuN analysis workflow.

Conclusion

WhiFuN v3 provides a comprehensive, accessible, and reproducible software framework for investigating functional connectivity in WM and GM using fMRI. By integrating fully automated preprocessing, data-driven network construction, and interactive quality control within a single toolbox, WhiFuN addresses key methodological barriers that have limited the broader adoption of WM FC analysis. The GUI-based design lowers the entry barrier for new users, while the streamlined scripting interface enables efficient batch processing and reproducible large-scale analyses.

A central contribution of WhiFuN v3 is the emphasis on quality control as an integral component of the analysis workflow rather than a post-hoc step. The newly introduced QC Viewer provides intuitive visualization of motion metrics, tissue-specific BOLD time series, and seed-based functional connectivity maps for canonical networks, allowing rapid identification of artifacts and preprocessing failures. The ability to accept or reject participants and document decisions directly within the QC interface promotes transparency, consistency, and reproducibility across studies.

Methodological advances in WhiFuN v3 further enhance anatomical precision and flexibility. The inclusion of optional DARTEL-based normalization improves inter-subject alignment, particularly in cohorts spanning wide age ranges where anatomical variability is pronounced. Support for externally preprocessed datasets allows WhiFuN to be seamlessly integrated with existing pipelines, expanding its applicability across diverse neuroimaging studies.

From a software perspective, WhiFuN v3 emphasizes simplicity without sacrificing methodological rigor. High-level functions such as whifun_preproc, whifun_qc, and whifun_create_FN_kmeans enable complete analyses to be executed with minimal scripting, facilitating reproducible research and efficient deployment on large datasets. Comprehensive self-documentation within MATLAB further enhances usability and transparency.

Collectively, WhiFuN v3 represents a robust and scalable platform for WM and GM functional connectivity analysis, bridging methodological advances with practical usability. By combining automation, rigorous quality control, and flexible deployment, WhiFuN enables more reliable investigation of WM functional organization and supports its broader adoption in developmental, clinical, and lifespan neuroimaging research.
