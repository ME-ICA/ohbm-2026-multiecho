Introduction

The ModelArray R package1, together with the ModelArrayIO Python package, enables mass-univariate analyses of large NIfTI, CIfTI, and MRtrix3 fixel data on modest hardware. While initial releases were benchmarked on ~1,600 sessions, support for larger-scale datasets and the breadth of R's modeling ecosystem were limited. Specifically, only linear and generalized additive models (GAMs) were supported. Here we report updates to the ModelArray ecosystem that broaden modeling flexibility, improve storage efficiency for larger samples, and streamlines data import and export across neuroimaging formats.

Methods

We created a new general execution pathway, ModelArray.wrap, which applies any user-defined R function using ModelArray's framework for parallelization and collating results. Rather than being constrained to linear models or GAMs, this new pathway effectively provides the opportunity for the user to call or define any function, and run it on each data element (e.g., voxel, vertex, fixel, etc.) as long as it returns a single-row data frame of scalar values. To assist function development, we added analyseOneElement.wrap and exampleElementData, which expose the per-element data frame for testing during parallel processing.

The companion Python package formerly known as ConFixel was refactored and renamed as ModelArrayIO. We optimized ModelArrayIO for conversion from neuroimaging file formats to the DelayedArray backends used by ModelArray. We introduced two key storage features: direct access to data from AWS S3 without downloading entire datasets, and support for both HDF5 and TileDB backends. We also implemented stripe-based writes to improve throughput. Finally, we added features so models can include multiple element-wise variables (i.e. multiple vertex-, voxel- or fixel-wise brain maps can be included as dependent or independent variables).

To demonstrate these newly added functionalities, we analyzed cortical thickness and curvature CIfTI files from the Reproducible Brain Charts2 FreeSurfer data. These CIfTI files are in FSLR 164k, including 327,684 surface vertices for 7,193 scans. We wrote a function that first applied CovBat3 to thickness and curvature to harmonize values across scanning sites at each vertex, and second, evaluated the correlation between cortical thickness and mean curvature, which are known to be related4.  

Results

ModelArray.wrap enables virtually any R model to be efficiently fit at each element (voxel, vertex, fixel), with model outputs such as diagnostics and predictions saved for downstream analysis and visualization. For example, users can harmonize data across batches, fit penalized splines to model age-related changes, and convert predictions to CIfTI time series (dtseries) of age trajectories or spatial maps (dscalar) of estimated degrees of freedom. The framework is supported by comprehensive tests, realistic vignettes, and enhanced documentation. Quality of life improvements, such as progress bars, verbosity controls and R debugger entry points are also now available.

Our example analysis revealed a near cortex-wide negative correlation between cortical thickness and curvature. Positive correlations were found in the crowns of the gyri bordering the central and calcarine sulci along with portions of cingulate cortex (Figure 1). The entire analysis took less than 2 hours on an Apple silicon M4 chip using 8 CPUs, with the HDF5 file containing all input data less than 13GB.

Conclusion

These enhancements, released as version 0.2, increase scalability of the ModelArray analysis framework to large-scale samples, broaden modeling to arbitrary user-defined element-wise functions, and strengthen interoperability via dual HDF5/TileDB backends with S3 support. Together, they improve throughput, accessibility and reproducibility for high-dimensional neuroimaging studies. All features are available for immediate use with accompanying documentation, tests, and example workflows.
