Introduction

The classical model of the language circuit has evolved into a more complex network-based framework through advances in neuroimaging and cognitive neuroscience. In parallel, novel neuromodulation techniques, such as focal transcranial magnetic stimulation (TMS) targeting language-network regions, have been developed to restore language function in patients with aphasia. To better understand the functional roles of individual language-related regions, it is necessary to adopt not only a topological perspective but also a hodological, network-theoretical approach. The present study aimed to characterize the functional connectivity profiles of key language-processing regions using a novel resting-state network analysis method, the functional connectivity overlap ratio (FCOR). We focused on region-specific connectivity features and hemispheric lateralization within the language network.

Methods

Resting-state fMRI data were obtained from 120 healthy adults aged 20–70 years. Functional connectivity was quantified using FCOR, which measures the degree of coupling between a predefined seed region and intrinsic functional networks. Language-related regions of interest included Brodmann areas (BA) 44 (opercular inferior frontal gyrus), 45 (triangular inferior frontal gyrus), 22 (superior temporal gyrus), 39 (angular gyrus), and 40 (supramarginal gyrus). FCOR values were calculated between each seed region and 14 canonical resting-state networks: auditory, sensorimotor, primary visual, higher visual, visuospatial, language, dorsal default mode network (DMN), ventral DMN, left executive control network (ECN), right ECN, anterior salience network (SN), posterior SN, precuneus, and basal ganglia networks. Group-level statistical comparisons were performed using the Mann–Whitney U test.

Results

All language-related regions demonstrated strong functional connectivity with the language network and higher-order cognitive networks, including the DMN, ECN, and SN; however, each region exhibited a distinct connectivity profile. BA45 showed stronger coupling with the language network than BA44, whereas BA44 exhibited stronger connectivity with the salience network. BA22 demonstrated strong connectivity with the auditory and language networks without hemispheric lateralization. BA39 showed robust connectivity with the DMN and ECN in addition to the language network and exhibited the most prominent lateralization. BA40 showed the strongest connectivity with the salience network among all regions examined.

Conclusion

The functional connectivity profiles identified in this study are consistent with known clinical and cognitive roles of language-related regions. Bilateral connectivity of the superior temporal gyrus supports early-stage speech sound processing (1). Prominent lateralization and strong DMN and ECN coupling in the angular gyrus reflect its involvement in higher-order semantic and contextual processing (2,3), as well as its clinical association with acalculia and agraphia. The supramarginal gyrus showed preferential involvement in salience and attentional networks (4), consistent with its role in ventral attention processing and hemispatial neglect. Furthermore, connectivity patterns between inferior frontal and parietal language regions mirrored known anatomical connections (5). These findings demonstrate that FCOR analysis effectively captures region-specific connectome profiles and provides a hodological framework for understanding functional specialization within the language network. The present study may contribute to identify optimal target sites in neuromodulation therapies, as exemplified by language rehabilitation using transcranial magnetic stimulation (TMS).
