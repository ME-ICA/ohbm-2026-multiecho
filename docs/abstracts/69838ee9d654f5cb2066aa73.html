Introduction

Emotion plays a central role in human cognition and social behavior, yet its assessment still relies heavily on subjective reports or facial cues, which are susceptible to bias, suppression, or ambiguity. Neuroimaging offers a promising alternative by capturing distributed neural representations of affective processing across large-scale brain networks. Prior fMRI research using block-design paradigms has shown that emotional states can be decoded using multivariate pattern analysis and dynamic functional connectivity; however, these tightly controlled paradigms fail to reflect the continuously varying emotional experience of real-world settings. Naturalistic stimuli, such as movies, evoke richer and more ecologically valid emotional and sentiment responses, but also introduce methodological challenges due to the absence of predefined stimulus boundaries and the coexistence of multiple affective dimensions at each moment. To address this, we developed a naturalistic emotion-decoding framework that integrates transformer-based emotion inference from movie subtitles, hemodynamic delay modelling, and a purpose-built deep learning architecture (fMRINet).1 Our goal was to decode multi-class emotion categories from fMRI data collected during full-length movie viewing. 

Methods

We used a naturalistic fMRI movie-watching dataset consisting of 20 participants (TR=1s; 5315 TRs), watching the movie ‘500 days of Summer’.2 We generated automatic labels for seven emotions (anger, disgust, fear, joy, neutral, sadness, surprise) signifying seven classes using pretrained Bidirectional Encoder Representations from Transformers (BERT) model fine-tuned with emotion label for text from TV dialogues’ utterance.3 We validated emotion extraction performance by comparing generated labels with MELD database that contains 13,000 utterances with emotional labels.4 

We temporally aligned the sentence-level emotion predictions with the BOLD signal by convolving each emotion probability with an HRF model, implemented using Nilearn’s design-matrix generator. We applied a sliding window with a window length equal to HRF width (20 seconds) and a step size of 1 second to both HRF-convolved labels and fMRI time series for analysis. Final labels for each window were the maximum of averaged emotional labels within the window. For each window, we extracted spatiotemporal activity from 400 Schaefer atlas ROIs grouped into seven resting-state networks (DMN, salience/ventral attention, dorsal attention, frontoparietal, somatomotor, limbic, visual). 

 We classified the emotions from fMRI activity using automatic emotional labels in two ways; 1) using dynamic functional connectivity (dFC) and machine learning classifiers such as SVM and Naïve Bayes, 2) using fMRINet, which is a modified deep learning architecture inspired by EEGNet, incorporating multiple temporal convolution kernels (sizes 3, 5, 7). We used leave-one-subject-out cross-validation (LOSOCV) for generalization testing. 

Results

Transformer-based label generation outperformed lexicon-based methods when validated on the MELD dataset (61% accuracy vs. ~43% for TextBlob/VADER). These findings demonstrated that pretrained BERT models more effectively capture emotion-related linguistic features in naturalistic settings, owing to the transformer's advanced contextual understanding and fine-tunning on emotion extraction tasks in movie dialogue. This superior performance highlights the rationale for employing BERT-based approaches in the present study.

In multi-class emotion decoding, the proposed fMRINet model achieved an accuracy of 31.18% for 7-class classification and 32.08% for 6-class classification (with the neutral class excluded), both substantially surpassing random chance levels (14.29% and 16.67%, respectively). Furthermore, the 7-class performance exceeded the 28.16% accuracy reported in a prior multivariate pattern analysis study that utilized dFC features with traditional machine learning classifiers in a controlled block-design paradigm. 5 These results demonstrate that fMRINet effectively captures complex spatiotemporal patterns underlying naturalistic emotion processing, outperforming conventional dFC-based approaches even when benchmarked against outcomes from more structured block-design experimental paradigms.

To further validate the performance of the proposed approach, we applied the gold-standard dFC feature extraction followed by traditional machine learning classifiers to the same naturalistic fMRI dataset. The classification achieved near-chance performance for 7-class emotion decoding (SVM=16.3%, NB=19.9%, RFC=17.4%). Taken together, these findings underscore the proposed deep learning architecture’s superior capability to capture complex spatiotemporal dynamics of emotion in fMRI data under naturalistic conditions, thereby providing strong justification for its adoption over conventional dFC-based pipelines with machine learning classifiers.

Conclusion

This study presents a scalable framework for decoding emotional states from naturalistic fMRI that combines modern NLP transformers, HRF-aware temporal alignment, and a compact deep neural architecture. Our findings demonstrate that multi-class emotion decoding is feasible from fully naturalistic stimuli, achieving above-chance accuracy despite the lack of discrete stimulus blocks. fMRINet provides improved decoding performance compared with classical machine-learning approaches.

The results highlight the potential of naturalistic neuroimaging paradigms for studying complex, real-world emotional dynamics and illustrate how automated linguistic models can generate meaningful affective labels for fMRI research at scale. This framework provides a foundation for future work incorporating multimodal cues (audio-visual features), cross-movie generalization, and multi-participant shared-response modelling. It also advances the development of clinically relevant emotion-decoding tools for disorders characterized by impaired affective processing.
