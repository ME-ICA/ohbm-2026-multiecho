Introduction

Neuroimaging research and clinical practice increasingly combine heterogeneous data types, including high-resolution structural and functional MRI, diffusion-weighted imaging with tractography, and electrophysiological or stimulation-related information such as electrode reconstructions and activation volumes. Integrating these modalities into a coherent spatial framework is essential for understanding brain structure–function relationships and combine translational methods and findings between multidisciplinary teams.

Although many specialized software tools exist for neuroimaging visualization, users often face a trade-off between accessibility and flexibility. Tools designed for ease of use may lack the extensibility required for novel research applications, while highly customizable platforms often demand significant programming expertise. Furthermore, adapting existing viewers to emerging visualization paradigms, such as virtual reality or integration with 3D graphics software, can require substantial development effort.

These challenges are particularly pronounced in translational contexts such as deep brain stimulation research, where clinicians and researchers must jointly interpret multimodal imaging data alongside electrode placement and stimulation parameters. Similarly, ultra-high-field (f)MRI at 7 Tesla produces datasets of exceptional spatial resolution that benefit from specialized visualization approaches not readily available in general-purpose viewers.

We present BrainDeer, an open-source, Python-based neuroimaging viewer designed to address these challenges. BrainDeer aims to lower the barrier to advanced multimodal visualization while providing a flexible plugin architecture that enables straightforward extension for domain-specific workflows, novel interaction paradigms, and integration with external rendering environments.

Methods

BrainDeer is built around a modular architecture and a unified Python API that exposes data loading, rendering, interaction, and measurement functionality programmatically. Volumetric MRI data, tractography streamlines, and electrode models are integrated within a shared spatial coordinate system based on image affine transformations, ensuring accurate anatomical alignment across modalities.

All functionality is accessible through the public API, allowing new features to be implemented as lightweight plugins without modifying the core application. Plugins can register custom data loaders, visualization modes, analysis tools, or export functions. Visualizations can be extended into immersive virtual-reality environments via a Unity-based interface¹, enabling exploration of complex three-dimensional anatomical relationships. Additionally, a dedicated plugin allows to stream 3D scene content directly into Blender², providing access to advanced rendering, lighting, animation, and publication-quality figure production.

We demonstrate extensibility through two example workflows implemented as BrainDeer plugins. The Lead-DBS workflow³ integrates structural imaging data, electrode reconstructions, target region atlases, stimulation volumes, and fiber tracts derived from normative or patient-specific connectomes for interactive 3D inspection of deep brain stimulation cases. The 7T MRI workflow provides optimized visualization of ultra-high-resolution anatomical data, including layer-specific analysis tools.

Results

BrainDeer provides a unified environment in which users can load multimodal datasets, define regions of interest, perform quantitative measurements, and generate publication-ready visualizations without switching between applications. The same data representation and coordinate system persist across 2D slice views, 3D renderings, VR exploration, and Blender export, ensuring spatial consistency and eliminating the need for repeated manual alignment or data conversion throughout the analysis and visualization pipeline.

The Lead-DBS workflow enables interactive inspection of electrode placement relative to subcortical target structures, neighboring anatomical regions, and reconstructed fiber pathways within a single coordinated view. Users can visualize stimulation volumes, query distances from active contacts to anatomical landmarks, and compare electrode positions across patients in template space.

The 7T workflow demonstrates that BrainDeer handles ultra-high-resolution datasets exceeding 500 million voxels while maintaining interactive frame rates during navigation and rendering. Optimized data loading and GPU-accelerated rendering enable fluid exploration of submillimeter anatomical detail without downsampling.

Both workflows illustrate how domain-specific visualization needs can be addressed through the plugin system without requiring modifications to the core application, preserving a consistent user experience across heterogeneous datasets and analysis contexts.

Conclusion

BrainDeer combines a flexible plugin architecture with low technical barriers, providing a practical foundation for exploratory data analysis and translational communication across neuroimaging domains. By exposing all core functionality through a documented Python API, BrainDeer enables researchers to develop and share custom visualization workflows tailored to specific research questions or clinical applications. Integration with Unity and Blender extends visualization possibilities beyond traditional desktop environments into immersive and cinematic rendering contexts.
