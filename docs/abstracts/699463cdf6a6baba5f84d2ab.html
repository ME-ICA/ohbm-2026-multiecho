Introduction

The relationship, or coupling, between structural connectivity and functional connectivity is complex and necessitates further exploration. Previous work has shown that structure-function coupling (SFC) differs among individuals, and these differences can be leveraged for studying cognitive and neurodevelopmental differences and outcomes.^1 Much of the work in this field often relies on a single measure of functional connectivity, which is typically “defined by the correlation or coherence...[between nodes’ or regions' Blood-oxygenation-level–dependent imaging (BOLD) time series and] does not provide directionality or causality.”^2 While this is a straightforward approach, it is unclear if a single measure is sufficient for capturing the complex dynamics of functional connectivity in the brain, and how structure-function coupling depends on the definition of functional connectivity. Motivated by this question, we assessed the prediction of individual differences in general intelligence using SFC patterns across 14 different functional connectivity measures from multiple domains,^3 and tested whether their combination into a single model could boost the prediction of these individual differences. 

Methods

We used neuroimaging and behavioral data from the Human Connectome Project Young-Adult S1200 release. We filtered subjects based on the following criteria of available data: diffusion MRI, resting state MRI (rsMRI), behavioral measures (PicVocab_Unadj, ReadEng_Unadj, PicSeq_Unadj, Flanker_Unadj, CardSort_Unadj, ProcSpeed_Unadj, PMAT24_A_CR, VSPLOT_TC, IWRD_TOT, and ListSort_Unadj). Selected subjects were also restricted to unrelated subjects and with the same reconstruction algorithm (r227). After accounting for all of these criteria, we were left with 329 subjects. Structural connectivity (SC) and functional connectivity (FC) matrices were computed for each subject using the Shen k=268 whole-brain parcellation^4. For SC, we used the already preprocessed diffusion data and applied an in-house reconstruction pipeline for probabilistic tractography based on MRtrix3, which, among others, included B1 field inhomogeneity correction, response function estimation with the dhollander algorithm, fiber orientation distributions estimation, fiber tracking, pruning and connectome generation.  

For FC, we first parcellated the  ICA-FIX denoised fMRI for each of our selected subjects and the resulting BOLD time series were fed into the pyspi library ^3 to compute 268 x 268 connectivity matrices for 14 statistics of pairwise interactions (SPIs) from the sonnet subset, which were shown to be minimally redundant in terms of behavior. These SPIs included: 

  • Spearman and covariance from the basic statistics domain 
  • Itakura dynamic time warping and barycenter dynamic time warping (DTW) from the distance similarity domain
  • Additive noise from the causal inference domain 
  • Directed and integrated information from the information theory domain; 
  • Phase lag and phase slope indices, coherence magnitude, and non-parametric spectral Granger causality from the spectral analysis domain; 
  • Cointegration and power envelope correlation as miscellaneous statistics 

To note, since some of these SPIs were directed measures, their FC matrices were symmetrized by taking the averaged of the upper and lower triangular terms. 

Once SC and FC matrices were obtained for each subject, we computed the structural connectivity-functional connectivity coupling (SFC) for each node, which was operationalized as the Spearman’s rank correlation between the SC vector and the FC vector for each corresponding node. This results in a feature vector of length 268, where each value is the Spearman’s rank correlation coefficient. This was repeated for all 14 SPIs. Figure 1a shows the averaged coupling across subjects for each SPI, and Figure 1b shows the correlation between average couplings ordered according to hierarchical clustering. 

Next, we computed the general factor of intelligence, g, following the methodology and implementation described in. ^5 We then predicted individual differences in g using the whole-brain SFC profiles from the SPIs. 

Specifically, we first created a train (80%)/test (20%) split that was stratified using a 5-quantile discretization of the outcome variable. Then, a Random Forest model was tuned and tested separately for each SPI. Importantly, to assess whether the combination of SFC profiles across SPIs boosted the prediction of g, we ran the same predictive framework with fused inputs based on concatenating (i) the 14 SPIs and (ii) those SPIs that significantly predicted g. Model performance was assessed using the Pearson correlation between predicted and true test set values. We also examined functional brain network feature importance using post-hoc permutation importance. 

Results

Initial modeling results showed significant (p<0.05) Pearson correlation coefficients between predicted and true g values for 5 of the 14 SPIs: covariance (r=0.2844, p=0.0103), directed information (r=0.2675, p=0.0150), integrated information (r=0.2685, p=0.0146), Itakura dynamic time warping (r=0.3552, p=0.017), and Spearman (r=0.4234, p=0.0002). 

For the model that used all SPIs concatenated into one feature vector, the “All-SPI model,” the Pearson correlation between true and predicted g values for the held-out test set was 0.3167, p=0.0096. For the model that used only the 5 significant SPIs from above, the “Top 5 model,” the Pearson correlation between true and predicted g values for the held-out test set was r=0.3603, p=0.0030, outperforming the All-SPI model and all single SPI models except the Spearman model.  

We also stacked predictions from each single SPI model and used those predictions as features in a second stage meta-learner, but this did not show any improvement over using the single best SPI model or the Top 5 model. 

We performed post-hoc permutation feature importance to examine how network-level coupling affected predictions and how this varied across SPIs and models. Figure 2 shows an overlay of the network-level permutation importance for the 5 best tuned single SPI models and the Top 5 model. Most models show high importance for the Default Mode network. Some notable differences are that Spearman shows even higher importance for the Visual 2 network and almost as high for the Medial Frontal network, while integrated information shows high importance for Visual 1 and Visual 2, and Itakura has higher values for the Frontoparietal and Motor networks than other models. The Top 5 model shows nearly uniform importance for all networks, which can be contextualized by the greater number of features; since each node is represented by 6 different SFC values, this model is integrating information across multiple domains. In turn, these permutation importance results show that different SPIs, and therefore different domains of SFC, use diverse patterns of coupling across functional brain networks to predict general intelligence, which is line with the distributed nature of general intelligence.^5 

Conclusion

There are many underexplored metrics from domains such as spectral analysis, distance similarity, information theory, and causal inference, that can be used to compute functional connectivity from fMRI data. This work is a step towards better understanding both their individual and complementary roles in shaping individual differences of cognitive ability through their coupling with the underlying brain structure. 

Our results show that the 3 best predictors of cognitive ability were, in order of performance, SFC derived from the Spearman rank correlation (a measure of monotonicity), the Top 5 model that integrates 5 different measures of SFC, and SFC derived from Itakura dynamic time warping (a distance measure). This highlights the observation that measures from different domains contribute different and complementary information, underscoring the need to better understand when and how to apply different measures of SFC. 

Furthermore, integrating different domains of functional connectivity into SFC revealed differential network feature importance patterns. This finding points to the distributed nature of general intelligence and highlights how using multi-domain functional connectivity metrics can lead to new insights about cognitive ability and brain structure-function coupling.  

This sets up further experimentation and refinement of a multi-domain functional connectivity and SFC methodology. Future steps include expanding the subset of SPIs used, testing different model types (such as gradient boosting and support vector regression), exploring new methods to fuse predictions from single SPI models beyond stacking, and using different metrics to compute the coupling instead of Spearman’s rank correlation (for example, cosine similarity). This multi-domain SFC approach presents a data-driven way to investigate individual differences in cognitive outcomes from SFC.
