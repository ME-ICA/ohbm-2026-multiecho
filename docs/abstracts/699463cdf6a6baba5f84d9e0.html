Introduction

While the spatially dynamic properties of large-scale functional brain networks have been previously recognized and investigated^1, existing methods have not been explicitly designed to identify dynamic states of network expansion and contraction that capture trends in brain region recruitment over time, resulting in a knowledge gap concerning how these states are altered in psychiatric conditions such as schizophrenia. Here, we introduce a novel spatially dynamic data-driven warping algorithm to identify these states in resting-state fMRI data. We report that large-scale brain networks exhibit transient states of contraction and expansion revealing the ebb and flow brain area recruitment. Furthermore, we demonstrate that the statistics for these states are altered in schizophrenia, revealing the potential of our approach to serve as a valuable biomarker construction tool.

Methods

We analyzed resting-state fMRI data collected from n = 148 subjects (n = 60 individuals with schizophrenia; n = 36 female) as part of the Functional Imaging Biomedical Informatics Research Network (FBIRN) initiative^2. Scans were selected for analysis using stringent quality control criteria. Preprocessing steps included motion and slice timing correction, warping to Montreal Neurological Institute 152 space, spatial resampling and smoothing with a 6 mm full-width at half-maximum Gaussian kernel, motion regression, detrending, despiking, low-pass filtering, and voxel time series normalization. To extract functional brain networks from the fMRI data, we first utilized static group-level independent component analysis (ICA) with model order = 20 to capture large-scale networks. We then used the static network template as input to a sliding window group information guided ICA (GIG-ICA) approach in order to identify time varying network maps from the fMRI data^3. Thereafter, we used a spatially dynamic warping approach to align time adjacent network maps. To accomplish this, we first flattened maps at each pair of windows t and t + 1 by ranking voxels according to voxel connectivity intensity at time t. Flattened maps were then aligned using the dynamic time warping (DTW) algorithm^4, yielding a set of dynamic warping maps for each network and subject. Given our connectivity intensity ranking approach, regions that exhibit positive warping values within the warping maps are expanding into peripheral regions, while regions that exhibit negative warping values are contracting into the network core. Finally, for each network, we clustered warping maps across subjects using k-means clustering (k = 4) to identify salient states of regional expansion and contraction, and we assessed differences in the state vector statistics of these clusters between healthy controls and individuals with schizophrenia with a general linear model while accounting for confounders commonly reported in psychosis studies (age, sex, race, site, and motion).

Results

We identified recurring patterns of network expansion and contraction for every analyzed brain network. For example, we identified primary visual network states with both negative and positive patterning, indicating the presence of alternating periods of network expansion toward peripheral voxels and contraction toward core voxels. Furthermore, results for the dorsal attention network revealed states with striking similarities to secondary visual and posterior default mode network patterns. As a further case in point, the salience network exhibited patterns of expansion resembling the default mode network and patterns of contraction within the temporal lobes.

With respect to group differences, our GLM analysis revealed that individuals with schizophrenia exhibit altered warping state statistics with respect to controls. For example, we detected significant differences in fraction time for a primary visual network expansion state (p = .0002), for dorsal attention contraction (p = .0008) and expansion (p = .00002) states, and for salience network contraction (p = .003) and expansion (p = .0001) states. We also detected significant differences in mean dwell time for three primary visual network contraction states (p = .008, p = .001, and p = .0004), a dorsal attention network expansion state (p = .0005), and a salience network expansion state (p = .00005). Finally, we found differences in the number state transitions for the primary visual (p = .001) and salience (p = .009) networks.

Conclusion

Overall, our spatially dynamic warping algorithm reveals that large-scale brain ensembles exhibit transient patterns of localized stretching and shrinking. Moreover, the presence of warping states which bear similarity to other brain networks is consistent with previous observations that functional brain ensembles engage with one another in a manner that influences the evolution of fMRI connectivity over time^5. Notably, the fact that we found significant differences in the warping state statistics between healthy controls and individuals with schizophrenia also suggests that psychosis impacts the ability of some brain networks to maintain spatially dynamic regimes. In conclusion, our approach reveals explicit states of brain network expansion and contraction that can be used to develop biomarkers for psychiatric conditions such as schizophrenia.
