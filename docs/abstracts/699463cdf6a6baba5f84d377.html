Introduction

Tractography approaches can often utilise predefined anatomy-driven protocols to localise and reconstruct specific white matter bundles from diffusion Magnetic Resonance Imaging (dMRI) data.1 However, such tractography protocols are not always straightforward to build and often represent a finite number of tracts that do not necessarily capture the full extent of white matter (WM) connections.2 In addition, their application is challenging for connectivity studies where diverse brain geometries exist, such as in pathological states were anatomy maybe different,1 different stages of life or even comparative studies across species.3 Data-driven methods, such as Non-negative Matrix Factorization (NMF) decomposition of whole-brain tractography, have been shown as an alternative approach to address these challenges.2 Despite the NMF promise in estimating components that capture sets of grey matter (GM) regions and their underlying WM connections, currently there is no automated, reliable and flexible process to perform NMF on dMRI data. Here we present an end-to-end toolbox for performing NMF decompositions at both the group and individual level. 

The Non-negative matrix FActorisation of traCTography (NFACT) toolbox is a flexible open-source pipeline, fully compatible with the FSL neuroimaging environment, that can handle a multitude of neuroimaging filetypes (volumetric, surface and combined) and can perform data-driven decompositions for human and non-human tractography. NFACT utilizes a unique iterative NMF approach so that outputs are stable across runs, and can project group components to individuals enabling statistical comparisons of these components in both GM and WM. Here we present the toolbox and demonstrate its capabilities in several scenarios.

Methods

Non-negative matrix factorisation is a blind source separation technique that decomposes an NxM data matrix to a NxC source matrix (C the number of components) and a CxM weights matrix.2 In the context of dMRI whole-brain tractography data, if N corresponds to seeds, e.g. WM/GM surface and M to targets, e.g. the rest of the brain/white matter, components that link sets of GM to WM patterns can be estimated. Because tractography data are non-negative, NMF ensures that the decomposition will return non-negative source and weight matrices. 

NFACT implements such NMF decomposition concept in a flexible manner. It supports a range of seed/target definitions as volumes (e.g. NIFTI), surfaces (e.g. GIFTI) or a combination of the two (e.g. CIFTI format), in cortex, subcortex and white matter. Users can provide inputs directly, or by using a file-tree. A file-tree is an efficient and customisable file to define user inputs, implemented in FSL file-tree (https://open.oxcin.ox.ac.uk/pages/fsl/file-tree). NFACT contains several prebuilt file-trees for Human Connectome Project (HCP) data, however, users can provide their own custom file-tree. NFACT decomposition can be used for individual data or group-level data projected all the way to individuals, enabling statistical comparisons. It allows component thresholding and component uncertainty mapping using run-rerun stability evaluations. NFACT can also run for non-human data, enabling comparative studies.3 It consists of multiple modules which can be ran sequentially or standalone (Figure 1A). 

The input for NFACT is a set of seeds (e.g. GM regions) and targets (e.g. whole of WM) and dMRI data that have had fibre orientations estimated (in our case via FSL-BEDPOSTX).  With this input, a seeds-to-targets tractography matrix is obtained at every subject level. In the case of multiple subjects, these matrices are averaged across subjects. On this group average matrix, NMF decomposition is conducted for a given number of components, to produce a components x targets (white matter) matrix (H) and a (grey matter) seeds x components matrix (W). To ensure reliable NMF estimates, multiple NMF iterations, with random starting conditions are initiated. The output is clustered by determining the optimum cluster number and the centroids used to initiate a final NMF 4 (please see figure 1b). 

To project back to individual space a dual regression approach, using the group level decomposition output and the individual tractography matrix, is utilized. A non-negative least squares approach is used to maintain the non-negativity of the back-projections.2 Outputs can then be used for calculating subject level component loadings and further statistical testing, such as permutation-based inference in PALM (https://fsl.fmrib.ox.ac.uk/fsl/docs/statistics/palm).

To demonstrate the capabilities of NFACT, both data from the HCP,5 and macaque data1 were run through the toolbox, as described below. 

Results

To illustrate the reliability of the iterative NMF process, iterative NMF and single NMF were repeated twice at 75 components using human whole brain tractography and two analytical strategies were used to assess run-rerun variability. The first strategy involved correlating components across runs to determine which components were most similar. The correlation values of most similar components were statistically significantly different between iterative NMF and single NMF (U = 4155, p = <0.01), with iterative NMF having higher similarity (mean = 0.96, std = 0.01) across runs than single NMF (mean = 0.92, 0.13 std). Secondly, the percentage overlap between tracts taken from the XTRACT tractography atlas1 to both single NMF and iterative NMF was calculated across two runs. Chi squared tests indicated a statistically significant difference in the tract overlap with the XTRACT atlas, between single NMF runs (Χ²: 84.78, p <0.01), but not for the iterative NMF (Χ²: 49.07, p 0.17); showing that the agreement of the derived components with manually reconstructed tracts was more consistent with the iterative NMF. Figure 1c shows the disagreement between runs for both the single NMF and iterative NMF, demonstrating that the latter return substantially more consistent components across runs. Spatial maps of the NMF values for components that had the highest overlap with the anterior radiation (left), inferior (middle) and middle (right) longitudinal Fasciculus are shown. 

Figure 2A shows HCP group decomposition results with seeds of bilateral NIFTI thalamic volume, and the target the whole brain. The radiations shown are the bilateral anterior (right: red, left: red-yellow), central (right: brown and blue, left: pink and yellow), posterior (right: green, left: blue-green) and inferior (right: copper, left: red-white) thalamic radiations. The corresponding volume seeds are shown overlayed over thalamic volumes. 

Figure 2B shows decomposition results using HCP data, with CIFTI seeds, comprising of the left and right white-grey matter surface GIFTIs as well as subcortical NIFTI volumes. Columns one and two shows group decomposition Z score maps for the grey and white matter, consisting of the middle longitudinal fasciculus (top), forceps major (middle) and the cingulum (bottom). Columns three and four show the dual-regressed individual level results corresponding tracts, demonstrating how group components project to individual subject tractography data. The left and right white-grey matter GIFTI surfaces were used as seeds, with the whole brain as a target. For comparisons with the HCP data similar tracts of the middle longitudinal fasciculus (top), forceps major (middle) and the cingulum (bottom) are shown.

To explore the optimal number of components for human and macaque, decompositions were run for 25, 50, 75, 100, 125, 150, 175 & 200 components and plotted as demonstrated in figure 2D. For each dimensionality, the explained variance was calculated after thresholding the output. The elbow point was calculated by finding the point of the line with maximum curvature as an indicating the optimum number of components. The optimum number of components for whole brain human decomposition was at 75 components, while for the macaque data it was between 50-75 components for the data we used. Figure 2D also demonstrates the run-rerun correlation values between similar components across iterative NMF (white matter: green, grey matter: yellow) and single run NMF (white matter: purple, grey matter: red). 

Conclusion

NFACT is an open-source, FSL compatible end to end pipeline to perform NMF data-driven decompositions of tractography. NFACT can handle multiple different file types (surfaces, volumes or combined) and using an iterative NMF process, components were shown to be more stable than using a single NMF run. Optimum number of components for whole brain decomposition for humans and macaque has been demonstrated, and users can utilize this method for their own data. NFACT is currently available on GitHub (https://github.com/SPMIC-UoN/NFACT).
