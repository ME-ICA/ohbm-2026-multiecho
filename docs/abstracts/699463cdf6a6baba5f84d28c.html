Introduction

Ultra-high field MRI (UHF MRI, e.g. magnetic fields at or above 7 T) delivers images with increased signal to noise ratio (SNR). This can be used to shorten scan time or increase spatial resolution compared to 3 T MRI, both for basic and applied research, as well as for clinical practice. However, common neuroimaging analysis tools such as FreeSurfer are not optimized for features of ultra-high field MRI like sub-millimetric voxel sizes and non-standard sequences. Notably, more pronounced radiofrequency field inhomogeneity (RFih) at ultra-high field necessitates the use of tailored methods including the MP2RAGE sequence1 for acquisition of T1-weighted images. The detection of small, subtle epilepsy-causing lesions, namely focal cortical dysplasias (FCDs), is a promising clinical use case for UHF MRI. MELD-graph2, a widely used software for the detection of FCDs, was developed with clinical 1.5 T and 3 T MRI data, and uses cortical surface features extracted with FreeSurfer as inputs to a graph-based convolutional neural network. It has not been tested or validated on UHF MRI data. Here, we study the performance of MELD-graph on 9.4T MRI data and propose adaptations to the surface reconstruction and feature extraction pipeline to improve downstream performance in epilepsy lesion detection.

Methods

9.4 T UHF MRI (MP2RAGE, 0.8 mm isotropic voxel size (corrected for RFih3) and paired 3 T MRI (MPRAGE, 1.0 mm) T1-weighted data from 20 healthy controls and 2 focal epilepsy patients with histopathologically verified focal cortical dysplasia (FCD) type 2b were analyzed. FreeSurfer (version 7.2.0) was used for segmentation, surface reconstruction and extraction of vertex-wise cortical features. These vertex-wise cortical features were used as inputs for MELD-graph2. In an adapted pipeline, UHF MP2RAGE data was preprocessed as follows: 1) Removal of background noise by a ‘robust’ combination of MP2RAGE inversion time 1 and 2 images4, 2) correction of re-introduced bias field artefacts using SPM, 3) scaling of MP2RAGE uniform intensities to positive values, 4) skullstripping using SynthStrip, before 5) running the FreeSurfer pipeline with support for sub-millimetric voxel space segmentation. MELD-graph lesion prediction sensitivity was assessed with respect to manually defined ground-truth labels for the FCDs. In healthy controls, the presence and number of false-positive clusters was recorded and compared.

Results

Two histologically verified FCDs were detected by the MELD-graph algorithm invariably using both the unmodified and the adapted pipeline for 9.4T data as well as using 3T MRI data (see fig. 2 A-F). However, using the unmodified pipeline on 9.4 T data resulted in a higher number of false positives per subject in controls (mean 1.2) compared to using it on 3T MRI data (mean 0.4, Wilcoxon signed-rank test p < 0.01) and consequently lower specificity. The modified pipeline restored specificity, as shown in figure 2 G, with a mean number of false positive clusters per control of 0.4 (Wilcoxon p < 0.01). Most false-positive clusters were located in the basal temporal lobes and at the frontal pole (fig. 2 H-J), where RFih was particularly severe, resulting in strongly hypo (hyper) intense signals in the inversion time 1 and 2 images (fig. 1B). Moreover, without the adapted preprocessing, FreeSurfer reconstruction failed with errors in 1/23 subjects as opposed to no failed reconstructions using the adapted pipeline and using 3T MRI data. Qualitatively, the adapted processing pipeline resulted in fewer errors of skullstripping and cortical surface placement especially in the lower temporal regions (see fig. 1).

Conclusion

UHF adaptations improve FreeSurfer cortical segmentations and differentiation between healthy and altered cortical structure. For epileptogenic lesion detection as a downstream task, adapted preprocessing and surface reconstruction of 9.4 T UHF data resulted in performance parallel to what is achieved using 3T MRI data. In this small sample, there is no evidence of improved diagnostic performance of UHF MRI in terms of specificity. As there were no epilepsy patients with a confirmed FCD but negative 3 T MRI in this cohort, the assessment of sensitivity and possible improvements using UHF MRI is limited. UHF MRI requires dedicated adaptations to effectively apply FreeSurfer and subsequent software for detection of epileptogenic lesions. We are planning to extend this evaluation to 7T data and to a larger sample size.
