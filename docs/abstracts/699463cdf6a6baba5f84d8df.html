Introduction

Lead-DBS is a streamlined and dedicated pipeline for deep brain stimulation (DBS) imaging analysis, visualization, and connectomic mapping. It is a widely used and well-established toolbox for this purpose and has empowered ~1,000 peer-reviewed publications to date. This has led to a democratization of methods to analyze DBS imaging datasets and may have increased the speed of advances made in this field. Since the release of its previous version1, the software has significantly expanded, with multiple novel tools, atlases, and workflows developed in parallel. This rapid growth reflects a fast pace of the community but also motivates documentation of these new features to support transparency, and continued community-driven progress. While numerous different tools and resources were introduced, one common feature across them may be seen in establishing unified and more standardized workflows.

While numerous minor additions and refinements have been carried out, a few major features are highlighted and tested in the Methods section. Together, these new features advance Lead-DBS from a collection of powerful, independently evolving tools toward a more cohesive and reproducible platform for DBS imaging research.

Methods

Data Format and Database

First, v4.0 implements an organized data format that introduces a structured machine- and human-readable standard for DBS imaging, stimulation parameters, and clinical variables, which are compliant with the Brain Imaging Dataset Storage (BIDS) format. A novel tool to store DBS programming parameters and clinical outcomes ensures that parameters are compliant with the implanted DBS hardware and stores these meta data in such a way that they can be used by the entire Lead-DBS ecosystem as well as by other BIDS applications.

Unified Workflow

Second, v3.0 had introduced three separate tools: the DBS Sweet Spot Mapping, DBS Fiber Filtering, and DBS Network Mapping Explorer, which analyzed DBS effects on a local, tract- or network-level, respectively. In v4.0, we harmonize these three tools into a single interface. All three modalities now follow a streamlined workflow and shared statistical methods, ensuring that the exact same tests are run on a voxel- or tract-wise basis.

Atlases

Third, the high-resolution flexible open atlas for clinical use in the subcortex (FOCUS) atlas introduces unprecedented detail of subcortical gray and white-matter structures. The atlas, which has been meticulously assembled based on numerous high-resolution resources may offer next-level analyses of precise DBS mappings, especially when paired with advanced concepts described below.

Other Tools

Fourth, v4.0 integrates several major technical advances: The advanced biophysical modeling toolbox OSS-DBS v22 was seamlessly integrated and allows next-generation electric field, as well as the recently introduced probabilistic Pathway Activation Mapping3. The Lead Connectome tool was made BIDS-compliant, now again allowing the seamless analysis of patient-specific diffusion MRI and resting-state fMRI data. We integrated a conda environment, which allows direct integration of python tools. For example, machine learning tools from the Freesurfer library (https://surfer.nmr.mgh.harvard.edu/), such as EasyReg, SynthMorph, and SynthSeg, as well as DBSSegment,4 have already been integrated and can be used out-of-the-box. The integrated Lead-Tutor platform facilitates self-teaching Lead-DBS for novel users, who can directly evaluate their electrode localization results while training.

Analysis

We demonstrate some of these new features of Lead-DBS v4.0 workflow in a previously published cohort of 51 patients with Parkinson’s disease who underwent bilateral subthalamic nucleus DBS (STN-DBS). Preoperative MRI and postoperative CT were used for lead reconstruction using the standard Lead-DBS reconstruction pipeline1. Stimulation settings and clinical UPDRS-III scores were stored using the novel database. Stimulation volumes (E-fields) were computed using OSS-DBS v22. 

All analyses were performed within the novel Unified DBS Mapping Explorer, enabling seamless transitions between modalities:

Sweet Spot Mapping: Voxel-wise correlations between E-field magnitude and clinical improvement on the Unified Parkinson’s Disease Scale III (UPDRS-III) were computed, generating an optimal stimulation profile.

Fiber Filtering: E-fields were used as seeds for DBS Fiber Filtering analysis using the new FOCUS atlas, and streamline-wise correlations were computed to derive an optimal tract profile associated with UPDRS-III clinical outcomes.

Network Mapping: Using resting-state functional MRI from 1,087 scans in the Human Connectome Project5, voxel-level functional network associations were computed between each stimulation volume and UPDRS-III clinical outcomes.

Results

Across the 51 STN-DBS patients, the Unified Explorer successfully produced a coherent set of modality-specific optimal stimulation profiles and replicated the results we observed in our previous studies. The sweet spot analysis identified a focal dorsal-lateral STN region associated with maximal UPDRS-III improvement. Fiber Filtering revealed a consistent streamline profile connecting the STN with premotor and supplementary motor areas. Network Mapping highlighted a distributed functional network centered on motor and premotor regions.

For the first time, all three methods were computed within a single unified GUI environment and using the exact same statistical scripts for each modality. The new programming tool enabled transparent stimulation parameter management and immediate volume visualization, with the novel database allowing for reproducible, and machine- and human-readable data storage.

Conclusion

Lead-DBS v4.0 builds on the strengths of earlier versions by standardizing data handling, integrating parallel analysis tools into a single interface, and enabling seamless exploration of sweet spots, fiber pathways, and functional networks. The release further develops and extends previously established components, including OSS-DBS v2, Lead Connectome, Lead-Tutor, and state-of-the-art FOCUS atlas. When applied to a 51-patient STN-DBS cohort, the framework demonstrated its ability to generate multi-modal models of stimulation efficacy.
