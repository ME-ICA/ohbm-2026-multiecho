Introduction

The ability to predict inter-individual variability in cognitive performance (such as memory performance) from neuroimaging data is a central goal in translational neuroscience and biomarker discovery. Prior studies have shown that neuroimaging features can be used to estimate cognitive performance across individuals1. However, most predictive studies rely on a single imaging modality. This is limiting because different MRI modalities capture complementary aspects of brain organisation, and although each modality can individually predict aspects of cognition, integrating them in the same model may better capture the distributed neural architecture underlying memory2. However, integrating these diverse, high-dimensional modalities presents a major machine learning challenge. Standard concatenation methods suffer severely from the high dimensionality of data, and summarising data risks losing fine-grained predictive information. 

In this project, we address these challenges by predicting memory performance across 3 tasks (free-recall, working memory, and recognition). The prediction models considered demographic variables, voxel-wise grey-matter maps (GM), diffusion-derived functional anisotropy (FA) and mean diffusivity (MD) maps, and seven condition-specific task-fMRI contrasts from the corresponding tasks. We further take into account the role of emotional valence by separating both behavioural performance and task-fMRI features into positive, negative, and neutral conditions in recognition and free-recall performance. Our modelling compares standard Kernel Ridge Regression using concatenated features with a Multiple Kernel Learning framework, elastic-net constrained KRR (ENMKL-KRR)3, which assigns separate kernels to each modality and produces interpretable modality-specific weights. This approach enables both accurate prediction and estimation of the relative contribution of the different neuroimaging modalities for predicting different aspects of memory.

Methods

We analysed multimodal neuroimaging and behavioural data from 1174 healthy young adults (62.3% female; mean age ± SD = 22.4 ± 3.3 years). All participants were free of lifetime neuropsychiatric diagnoses and medications (except hormonal contraceptives). Detailed information about data can be found in previous publications4.

Study procedure and behavioural targets

Participants completed two fMRI sessions. The first session comprised a picture-rating encoding task (24 neutral, 24 positive and 24 negative pictures) and a verbal working memory n-back task (0- and 2-back). An unannounced picture free-recall test followed the first session (outside the scanner). The second session comprised a picture recognition task (old/new/familiar judgments) and acquisition of structural (T1) and diffusion imaging modalities. Primary prediction targets were: (1) free-recall performance (total correctly recalled pictures), (2) recognition performance (false-alarm corrected d-prime), and (3) working memory performance (2-back d-prime). 

MRI acquisition and feature extraction

Structural (MPRAGE 1 mm³) and functional images were acquired on a Siemens Magnetom Verio 3T with a 12-channel coil. T1 preprocessing used SPM12 (MATLAB R2016b) with DARTEL normalisation to a study template, and resulting grey-matter (GM) probability maps were used as structural features.

Diffusion data (64 directions, b=900 s/mm²) were preprocessed following the ENIGMA-DTI pipeline, with region-specific mean skeletonised FA and MD maps as outputs (FSL JHU atlas). 

fMRI preprocessing (SPM12) included slice timing, realignment, co-registration, DARTEL normalisation, and 8 mm smoothing. First-level GLMs produced voxel-wise beta maps for encoding (negative, neutral, or positive picture presentation), recognition (old, or new picture), and n-back (0-back, 2-back). 

Beta maps for each fMRI condition, GM, FA, and MD maps constituted the imaging modalities.

Demographic variables (i.e., sex, age, weight, height, smoking habits, alcohol and cannabis consumption) were included as an additional modality to the models.

Pattern-recognition models

All machine learning analysis was implemented in PRoNTo5 v3.1 within MATLAB R2021b. We evaluated two modelling strategies:

1. Standard Kernel Ridge Regression (KRR): linear KRR was applied to concatenated features. In PRoNTo, this is implemented by summing the linear kernels Ki, where each modality’s kernel is computed as Ki = Xi*XiT, and Xi is a data matrix for modality i (subject x feature). The prediction function was learned by solving the regularised kernel ridge objective with L2 regularisation. The regularisation hyperparameter was selected via nested cross-validation (see below).

2. Elastic‑Net Multiple Kernel Learning – Kernel Ridge Regression (ENMKL-KRR): a separate kernel was used for each modality and, for GM and fMRI, for each anatomical region (98 regions from a custom atlas). Each kernel was mean-centred and normalised before combination. During training, ENMKL-KRR estimates two sets of weights: feature-level weights for each modality and kernel-level weights that determine the relative contribution of each modality for the predictive model. Kernel weights were learned jointly under an elastic‑net penalty that mixes L1 (sparsity) and L2 (grouping) regularisation. The elastic‑net mixing parameter and the overall regularisation strength were selected via nested cross-validation. The relative contribution of a modality was obtained by summing the weights of its associated kernels. Similarity of weight contribution across modalities was quantified using cosine similarity.

For all models, we used 5-fold nested cross-validation, with both the inner and outer loops employing five folds. Model performance metrics included Pearson’s correlation (r) between predicted and observed targets, as well as normalised mean squared error (nMSE = MSE / range(target)).

Results

In our models, ENMKL-KRR substantially outperformed the standard KRR model. Accuracy averaged across all models for ENMKL-KRR was r = 0.32 ± 0.01, nMSE = 0.90 ± 0.07, compared to standard KRR with r = 0.07 ± 0.11, nMSE = 1.00 ± 0.02. Hence, hereafter, only ENMKL-KRR models will be discussed.

Among the three target groups, recognition performance was predicted most accurately, followed by free-recall, while working memory showed the lowest prediction accuracy (Figure 1A). Within recognition performance, neutral-item recognition achieved the highest accuracy (r = 0.44 ± 0.06, nMSE = 0.81 ± 0.04), followed by positive (r = 0.42 ± 0.06, nMSE = 0.83 ± 0.04) and negative (r = 0.36 ± 0.07, nMSE = 0.87 ± 0.04) items. Within free-recall, the best prediction was obtained for positive pictures (r = 0.31 ± 0.02, nMSE = 0.90 ± 0.01), followed by neutral pictures (r = 0.28 ± 0.10, nMSE = 0.95 ± 0.05) and negative pictures (r = 0.25 ± 0.04, nMSE = 0.94 ± 0.01). The weakest predictive performance was observed for working memory (r = 0.19 ± 0.02, nMSE = 0.99 ± 0.02).

For the recognition and working memory models, the largest modality weights were assigned to the task-related fMRI modalities. Specifically, in recognition models, the “old” fMRI modality had the highest weight (0.41 ± 0.14, averaged over folds and models), and in working memory models, the “2-back” fMRI modality showed the highest weight (0.56 ± 0.39, averaged across folds). In contrast, free-recall showed a more evenly distributed modality-weight pattern (Figure 2A). Across all analyses, DTI-derived modalities (FA and MD) and demographic variables contributed minimally to the final models.

Using the multiple-kernel approach applied to each atlas-defined brain region, we also estimated the relative regional weight contribution within each modality. For the best-performing model (neutral-item recognition), we compared the similarity of region-level weight patterns across modalities (i.e. “GM” and all fMRI modalities) to assess whether shared regional patterns underlie prediction performance. Overall, the modalities were not highly similar, but the highest similarities were found between modalities associated with similar tasks (e.g., pictorial recognition and encoding fMRI sessions showed mutual similarity; likewise, “0-back” and “2-back” fMRI conditions resembled each other) (Figure 2B).

Conclusion

In this study, we integrated multiple brain imaging modalities—including DTI-derived measures, structural MRI, and several task-related fMRI sessions—into single models to predict memory-related phenotypes: recognition performance, free-recall, and working memory. Overall, predictive performance was modest, with recognition models performing best, followed by free-recall, and working memory showing the lowest accuracy.

The higher accuracy for recognition compared to free-recall likely reflects differences in data acquisition: free-recall was measured outside the scanner, so predictions relied solely on brain activity during the encoding phase and subsequent recognition of previously viewed items. In contrast, recognition models directly incorporated task-related brain activity, which likely improved predictive power. Surprisingly, working memory could not be predicted effectively, despite prior studies on the same data identifying related fMRI activity4. This may reflect the inclusion of multiple unrelated modalities, which could have introduced noise and overwhelmed the models. Testing this hypothesis by selectively removing unrelated modalities is a potential direction for future work.

A key challenge in multimodal machine learning is effectively combining data from different sources. Here, we compared multiple-kernel elastic net kernel ridge regression (ENMKL-KRR) with the standard kernel ridge regression (trained with the unweighted sum of the kernels) and observed superior performance for ENMKL-KRR. In standard KRR, the model does not learn the relative contribution of each modality during training, which may explain its lower performance. In contrast, ENMKL-KRR learns the relative contribution of each modality, selecting relevant modalities with correlated information.  This is particularly important in neuroimaging, where brain regions (treated as separate kernels in this case) are functionally or structurally correlated.

Recognition performance predictions were driven mainly by fMRI data from the recognition “old” condition, while working memory performance was driven primarily by fMRI data from the 2-back task. In contrast, free-recall predictions did not rely strongly on a single modality, likely because brain activity was not measured during the recall period itself, and predictive information comes from activity before (fMRI modalities during encoding) and after (fMRI modalities during recognition) the task. However, these results should be interpreted with caution, as weight patterns are unreliable when predictive performance is low.

Interestingly, weight patterns across modalities in the best-performing model were generally dissimilar, indicating that each modality contributes unique information. Nevertheless, higher similarity was observed among modalities derived from related tasks, suggesting correlated signals and corresponding weight distribution.

In summary, ENMKL-KRR provides a promising framework for multimodal predictive modelling in neuroimaging, outperforming standard KRR. While these models can capture meaningful memory-related signals, interpretation of weights requires caution, as not all contributions necessarily reflect underlying physiological mechanisms. Nonetheless, with careful interpretation, these findings have potential implications for cognitive neuroscience and biomarker development.
