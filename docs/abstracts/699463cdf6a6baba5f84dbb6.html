Introduction

The neuroimaging community has developed a rich ecosystem of tools for brain data analysis such as NiBabel for format handling or PySurfer1 for surface visualization, yet researchers face significant challenges due to the heterogeneous nature of these resources. Current workflows require switching between multiple software packages for different tasks: one tool for parcellation manipulation, another for surface visualization, and yet another for connectivity analysis. This fragmentation forces researchers to repeatedly implement basic operations that should be straightforward, such as modifying brain parcellations to add, group or remove regions, color mapping or surfaces and tractograms manipulations.

The lack of standardized, unified approaches for these fundamental tasks creates several problems. First, researchers waste valuable time writing custom scripts for operations that are conceptually simple but, in some cases, technically demanding. Second, these ad-hoc implementations are prone to errors and difficult to validate, potentially affecting the reproducibility of neuroimaging studies. Third, the steep learning curve associated with mastering multiple tools and their idiosyncrasies creates barriers for newcomers to the field and slows scientific progress.

While excellent tools exist to tackle individual needs such as PySurfer or FURY2, there is a need for a comprehensive toolkit that consolidates essential functionality for parcellation manipulation, surface processing, and visualization within a single, coherent framework. Such a solution would streamline workflows, reduce redundant coding efforts, and improve the accessibility of advanced neuroimaging techniques. Here, we present CLABTOOLKIT, an open source Python package designed to address these challenges by providing an integrated, user-friendly interface for common neuroimaging operations, enabling researchers to focus on scientific questions rather than technical implementation details.

Methods

Main architectural design

CLABTOOLKIT implements a layered and modular software architecture inspired by established neuroimaging frameworks such as Nipype, NiBabel, and Nilearn, while integrating modern GPU-accelerated visualization capabilities through PyVista3 (Figure 1). The architecture comprises 19 python modules organized in 6 hierarchical layers: (1) The data management layer provides support for BIDS4 and DICOM standards and implements robust image input/output functionality, including data organization and format interoperability. In addition, it includes a limited set of basic morphological operations intended for preliminary image manipulation rather than full analytical processing. (2) The utility and infrastructure layer comprises three foundational modules that provide core functionality for data management, visualization support (including color handling), and general-purpose utilities such as index handling, file operations, and progress tracking within neuroimaging analysis pipelines.  (3)  The geometric and anatomical primitives layer provides tools for defining and processing fundamental neuroimaging objects including surfaces, white matter tracts, anatomical parcellations, region centroids and connectomes. (4) The specialized analysis layer comprises five modules designed to complement existing neuroimaging pipelines. It provides methods for applying FreeSurfer processing methods across subjects, generating morphometry tables suitable for statistical analysis, and computing spatial probabilistic and maximum probability maps from previously derived parcellations, among other advanced functionalities. (5)  The pipelines and quality control layer  include modules to control the status and summary outputs from different processing pipelines such as Freesurfer. It can also leverage the BIDs organization of the data to create an interactive web for fast quality assessment and curation of neuroimaging data. (6) The visualization layer employs PyVista for GPU-accelerated rendering to compose multi-panel figures with configurable anatomical views, data map overlays, and layout grids for cortical surfaces and tractography. In this construction each panel is treated as a multi-layer scene in which individual objects are added as separate PyVista actors, enabling fine-grained control over rendering order, visual properties, and interaction.

Configuration Management

The framework employs a modular configuration architecture utilizing five external JSON files, enabling flexible parameter customization without code modification. Three primary configuration files govern the toolkit behavior: (1) bids.json defines BIDS nomenclature mappings (e.g., "sub" → "Participant"), standardizing file naming conventions throughout the morphometrytools and parcellationtools modules; (2) config.json specifies metric units and computational parameters, utilized extensively by both morphometrytools and visualization components; and (3) viz_views.json controls rendering parameters including camera positions, predefined viewing layouts as well as  lighting and reflection properties of the objects.

 Core Components

The toolkit comprises three primary data structures. The Surface class encapsulates mesh geometry, including vertices, faces, and associated scalar data (e.g., cortical thickness, sulcal depth), with support for FreeSurfer, OBJ, GIFTI, STL, VTK, and TEX formats. The Tractogram class manages white matter streamlines in TCK or TRK formats, utilizing efficient ArraySequence representations for streamline coordinates, per-point scalar data, and per-streamline scalar data. Both the Surface and Tractogram classes integrate seamlessly with the Parcellation class, which provides automated color table management, label-to-region mapping, masking, grouping, volume computation, and structure centroid computation.

Results

CLABTOOLKIT follows modern Python packaging standards with modular imports and comprehensive docstrings following NumPy documentation conventions. Dependencies are carefully managed, requiring only stable releases of scientific Python libraries (numpy, scipy, nibabel, pyvista, dipy, pandas or nilearn). The toolkit is compatible with Python 3.9+, ensuring accessibility across computing environments. 

It comprises 19 Python modules that contain 11 classes with 211 methods and 252 standalone functions, totaling 463 callable functions. The toolkit's architecture centers around core data structures including Surface (37 methods), Parcellation (34 methods), and Tractogram (24 methods) classes for representing neuroanatomical entities, complemented by specialized visualization classes such as BrainPlotter (23 methods) for multi-view rendering.

Following FAIR5 data principles, the toolkit provides BIDS support through dedicated entity manipulation functions. The bidstools module mirrors the BIDS-Apps specification and enables bidirectional conversion between BIDS filenames and structured dictionaries, recursive dataset navigation, automated entity extraction, and batch operations across subjects and sessions. Functions support entity insertion, deletion, key/value replacement, and recursive folder operations, facilitating programmatic dataset curation and derivative generation (See Figure 2A.1). 

The parcellationtools module facilitates parcellation manipulation through methods for region filtering by name or code, hierarchical grouping of anatomical structures, and spatial masking operations. Additionally, it supports quantitative analysis through automated volume calculations, morphometric measurements, boundary extraction (See Figure 2A.4), and region-wise time series extraction from 4D functional data, with interoperable export capabilities across FreeSurfer, FSL, and Nilearn formats. 

The surfacetools module allows surface manipulation through methods for loading triangular meshes, managing vertex-wise parcellations and scalar overlays, computing mesh properties (normals, edges, boundaries), and extracting region-specific vertex data. Additionally, it supports volume-to-surface mapping for integrating volumetric measurements onto cortical meshes, mesh component separation for topological analysis, and export capabilities across multiple mesh formats.

The tracttools module enables tractograms manipulation through methods for streamline filtering, smoothing and resampling (See Figure 2A.5) and clustering-based segmentation. Additionally, it supports quantitative fiber analysis through automated streamline length calculations, centroid computation, tract-based interpolation of volumetric measures onto fiber pathways, and pointwise/streamline-wise scalar mapping for visualization and statistical analysis.

The networktools module implements graph-theoretical measures through efficient sparse matrix operations, including connected components detection via union-find algorithms, enabling rapid analysis of structural and functional connectomes.

The BrainPlotter class, included in the visualizationtools module, employs PyVista for interactive 3D rendering with hardware acceleration. The visualization system supports simultaneous display of surfaces, tractograms and point clouds within a unified coordinate system. Surfaces can be colored by region-wise or vertex-wise scalar maps, discrete parcellations with custom color tables, or continuous statistical maps with configurable colorbars (Figure 2B, panels 1 and 4). Tractograms support tube rendering with diameter modulation, local orientation coloring, and scalar-based filtering (Figure 2B, panels 2, 3 and 4). The visualizationtools module enables multi-panel arrangements (e.g., lateral/medial hemispheric views) with synchronized camera controls. Integration with matplotlib through plottools facilitates publication-ready composite figures combining 3D renderings.

Conclusion

CLABTOOLKIT addresses a critical gap in the neuroimaging software ecosystem by providing a unified Python framework for common data manipulation and visualization tasks that previously required disparate tools or custom implementations. While specialized packages excel in specific domains CLABTOOLKIT provides a set of useful tools to work with neuroimaging data.

The parcellationtools, surfacetools, and tracttools modules enable researchers to perform operations on brain structures that would otherwise require switching between multiple software packages and file format conversions. It allows to load a volumetric parcellation (e.g., Desikan-Killiany atlas), filter it to retain only frontal lobe regions using anatomical labels, calculate volumes for each region, extract mean fMRI signal from 4D data for each area, and export the results to HDF5 file—all within the same environment using consistent syntax. The surfacetools and tracttools modules allow direct projection of volumetric data (such as myelin maps or subcortical measurements) onto surface meshes or tractograms for multi-modal visualization. The tracttools module enables fiber-specific quantification by allowing users to cluster streamlines into anatomically meaningful bundles and interpolate microstructure maps onto each streamline to compute tract profiles to how these metrics vary along fiber pathways. These capabilities eliminate the typical workflow of exporting data from one tool, reformatting it, importing to another tool, and manually combining results—instead providing direct programmatic access to complex operations through simple method calls.

The toolkit employs several optimization strategies for large-scale analyses. For example, network analyses exploit CSR sparse matrix representations, reducing memory footprint by orders of magnitude for connectomes with a high number of nodes. 

A key strength of CLABTOOLKIT is its sophisticated visualization framework, which enables the creation of multi-panel figures with multiple anatomical views, data map overlays, and layout grids for surfaces, tractograms, or pointclouds within a flexible layout configuration. This capability addresses a missing link in neuroimaging research where creating comprehensive visual representations often requires manual composition across multiple software packages.

Limitations

However, several limitations warrant consideration. First, the toolkit focuses on structural neuroimaging and tractography, with limited support for functional connectivity analyses or preprocessing operations—domains well-served by existing packages like Nilearn and fMRIPrep. Second, while PyVista provides hardware acceleration, rendering performance for large tractograms (>100,000 streamlines) may still benefit from further optimization. Third, the current implementation prioritizes ease of use over computational efficiency for certain operations, which may necessitate refactoring for high-throughput processing scenarios.

Availability

This toolkit is released under the Apache 2.0 license, available via GitHub (github.com/connectomicslab/clabtoolkit). Documentation includes API references, tutorials, and example workflows. The modular design enables researchers to adopt individual components or construct complete end-to-end analyses within a consistent framework, accelerating method development and enhancing reproducibility in neuroimaging research. It enables both exploratory data analysis and generation of publication-quality figures, serving as the critical interface between computational results and scientific interpretation.
