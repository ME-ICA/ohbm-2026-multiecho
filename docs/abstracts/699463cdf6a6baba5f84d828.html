Introduction

Parametric neural population encoding models like population receptive field models characterize the response functions of recording sites like fMRI voxels. These describe a response function of continuous stimulus parameters like visual field position, auditory frequency, somatosensory position, or motor effector position. The interpretable parameters of these response functions allow researchers to reveal detailed neurophysiological properties including how response function extents and positions change within responsive brain areas and computational interactions and nonlinearities in neural processing. However, many stimuli and tasks differ in complex, high-dimensional ways, making it difficult to hypothesize which parameter(s) neural response functions might follow and develop suitable encoding models.

                  When the parameters underlying neural response functions are not clear (or parametric response functions are not expected) researchers can use Representational Similarity Analysis (RSA) to characterize neural response properties. Since representational similarity disregards parameters of the stimulus or task, it needs no a priori hypothesis of which parameters underlie the resulting response pattern. However, RSA’s analysis of response patterns across many voxels does not reveal how individual voxels respond within that pattern, obscuring how neural response properties change within the ROI that was used to calculate the RDM. Furthermore, RSA does not reveal parametric response functions, so the many analyses enabled by parametric encoding models become impossible or less interpretable.

Here, we develop representational tuning models to unite these approaches, yielding parametric response models in representational spaces derived from responses to any arbitrary set of stimuli or tasks. We hypothesized that in an ROI’s two-dimensional representational space, a parametric response function for each voxel could capture much of the voxel’s response to all conditions.

Methods

Specifically, we define each voxel’s response function as a circular Gaussian function fit to the voxel’s response amplitudes to all conditions, where the positions of the conditions are taken from the two-dimensional representational space of the ROI containing the voxel. 

This approach can be applied to any arbitrary set of conditions and any ROI containing recording sites of any type. Here we used the Natural Scene Dataset (NSD) (Allen et al., 2022) as it fulfils important requirements and preferences. First, as a 7T fMRI dataset, the recording sites involved (voxels) are small neural populations that may have specific response functions. Second, the conditions are a set of naturalistic image stimuli, which vary in complex ways and so do not allow an a priori low-dimensional parameterization. Third, the NSD also includes visual field mapping data, allowing us to define a set of small, well-understood ROIs (i.e. visual field maps) that constitute distinct image representations and are defined independently from conditions whose responses we analyze (i.e. natural images). Fourth, most of the stimulus conditions (those we analyze) are each presented more than once, allowing representational tuning models to be fit on one set of responses and evaluated on an independent set of responses to the same conditions. Finally, several thousand conditions are included, covering the representational space exceptionally thoroughly.

We used the NSD’s visual field mapping models to define borders of visual field maps (V1, V2, V3, hV4, LO-1, LO-2, VO-1, VO-2, PHC-1, PHC-2, TO-1 and TO-2) based on reversals in cortical progressions of polar angle. These visual field maps were regions of interest for subsequent analyses.

We assigned the response amplitude of the natural image’s last presentation to our test set and the mean response amplitude of the other presentations to our training set. In each visual field map, we computed the representational dissimilarity matrices of the pairwise dissimilarities (1-correlation) between response patterns to each image pair (Fig. 1A). We then used classical multidimensional scaling to project these dissimilarities to pairwise distances in a two-dimensional representational space (Fig 1B). We optimally aligned these two-dimensional representational spaces by rotating them to a common reference space (that of visual field map VO-1 of Subject 1) using the Kabsch optimal rotation algorithm.

For each voxel, we fit a two-dimensional circular Gaussian function to the images’ response amplitudes, with the images located at their positions in the two-dimensional representational spaces for each visual field map. This gave the preferred position and extent of the voxel’s response function in the two-dimensional representational space, i.e. the voxel’s representation tuning function (Fig 1C). 

We repeated this using the representational space of every visual field map to give the images’ positions for models in every voxel but focused on two specific visual field maps. First, we asked which part of representational space of the voxel’s own visual field map did the voxel respond to, a ‘Within ROI’ model. Second, we ask which part of another source visual field map’s representational space did the voxel respond to, a ‘Between ROI’ model to characterize sampling and connectivity between brain areas.

We then tested how closely the fit response function predicted the response amplitudes for the same images in the test set. We computed the model’s performance as a proportion of the noise ceiling (i.e. the correlation between the training and test sets). We tested how the statistical significance of these model fits using Wilcoxon signed-rank tests and tested how fits differed between visual field maps using two-factor ANOVAs (factors: visual field map and participant). We also tested whether the extent (standard deviation) of the representation tuning functions differed between visual field maps using a two-factor ANOVA.

Results

Our Within ROI response model explained significantly above zero variance, under cross-validation, in higher-level visual field maps LO-2, PHC-2 and TO-1, as well as V1 (Fig 2A). As variance explained measures do not consider the low repeatability of responses in the single image presentations in the test set, we computed the proportion of the noise ceiling that was captured by the model (“Model Performance”) to take this into account. This revealed a low Model Performance in V1 and showed that the Within ROI model explained over 50% of the explainable response in the test set in some visual field maps (Fig 2B). Only LO-2, PHC-2 and TO-1 showed Model Performance significantly above zero: V1’s effect depended on the high between-measure repeatability here. A two-factor ANOVA demonstrated significant differences in variance explained (F11,173 = 12.39, p = 4.5298e-17) and Model Performance (F11,173 = 4.63, p = 3.59209e−06), with increases from earlier to later visual field maps. This differs considerably from visual spatial tuning models (i.e. pRF models) from the same participants, whose variance explained also differed between visual field maps (F11,173 = 105, p = 1.67322e−70) but decreased from earlier to later visual field maps.

                  Our Between ROI model aimed to characterize sampling and connectivity between a source and a target ROI. We chose the source visual field map for each target visual field map using the fit in the training set responses, so that this Between ROI model doesn’t necessarily fit the test set responses better than any other model. This Between ROI representational tuning model explained significantly above zero variance, under cross-validation, in many visual field maps: V1, V2, VO-1, VO-2, PHC-1, PHC-2, TO-1 and TO-2 (Fig 2C). Again, evaluating Model Performance as a proportion of each voxel’s noise ceiling, this was significantly above zero in VO-1, VO-2, PHC-1, PHC-2, TO-1 and TO-2, exceeding 60% of the explainable response in the test set in some ROIs (Fig 2D). As in the Within ROI model, a two-factor ANOVA demonstrated significant differences in variance explained (F11,173 = 25.48, p = 8.85731e-31) and Model Performance (F11,173 = 11.92, p = 1.79988e−16), with increases from earlier to later visual field maps. Wilcoxon signed-rank tests revealed the variance explained and Model Performance of the Between ROI model were significantly higher than that of the Within ROI in many visual field maps.

We next investigated whether the visual field maps differed in the specificity of the parts of the representational space, i.e. subsets of images, to which their voxels responded to. We therefore looked at the extent (standard deviation) of the fit response function: a smaller response function shows that a voxel’s response amplitude varied more, or across specific subset of images. For both Within ROI and Between ROI response models (Fig. 2E-F), we found response function extents systematically decreased from earlier to later visual field maps. Wilcoxon signed-rank tests revealed significantly smaller response functions in the Between ROI model than the Within ROI model only in later visual field maps: VO-1, VO-2, PHC-1, PHC-2, TO-1 and TO-2.

We finally asked whether the voxels’ preferred representational space positions were systematically organized on the cortical surface. For each visual field map, we computed the Spearman correlation (ρ) between the cortical surface distances and the distance between the preferred representational space positions of each voxel pair. All visual field maps had a medial correlation significantly above zero (Fig 2G-H). The correlation between preferred representational space distances and cortical surface distances were highest in early visual field maps V2 and V3, lowest in lateral pathway maps LO-1, LO-2, TO-1 and TO-2, and intermediate in ventral pathways maps VO-2, PHC-1 and PHC-2. Correlations were typically higher in Between ROI models than Within ROI models.

Conclusion

Here, we evaluated a novel approach to describe a voxel’s response function without the need for a continuous stimulus parameter such as visual field position, auditory frequency, numerosity or event duration. This approach combines two common neural data analysis approaches. First is dimensionality reduction (RSA), which we use to position arbitrary conditions in a continuous representational space. Second is encoding modelling (like pRF modelling), which we use to fit response functions in the resulting space, allowing analysis of response function parameters.

We demonstrate that representational tuning models predict the responses in an independent test set significantly better than chance in mid-level visual field maps of the lateral and ventral visual steams, but not early visual field maps. This demonstrates that many voxels preferentially respond to a sub-set of images in a continuous region of the representational space described by the response function. The extent of the response functions systematically decreases from earlier to later visual field maps, reveling responses to increasing specific image sub-sets. 

Even though we chose the simplest possible representational space geometry and response function, the goodness of fit of these models approaches the noise ceiling. Between ROI response models fit significantly better than Within ROI models in many visual field maps, suggesting that each voxel’s response can be better described by a sampling of the representational space of another visual field map, rather than representing part of the representational space of the visual field map that the voxel itself lies in. Finally, voxel’s preferred positions in the representational spaces gradually varied across each visual field map’s cortical surface. This suggests that the principal components of high-dimensional representational spaces may reflect the fine-scale organization of the cortical surface.
