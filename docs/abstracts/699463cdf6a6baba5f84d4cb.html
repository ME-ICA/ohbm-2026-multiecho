Introduction

MRI generates images with millimeter-scale spatial resolution, while many important biological features occur at much smaller (microscopic) scales. Over the past several decades, MRI practitioners have used the information derived from biophysical parameters (like relaxation and diffusion) to indirectly probe microscopic tissue compartments using millimeter-scale data. While these approaches have been somewhat successful, a new paradigm has recently emerged1 that leverages multiparametric MRI data (e.g., using relaxation and diffusion jointly in a higher-dimensional experiment) to probe tissue microstructure with an unprecedented level of detail.

We developed the open-source Diffusion-Relaxation Suite (DRSuite) software package, which provides novel analysis methods to identify and separate multiple microstructural tissue compartments from MRI data using advanced constrained estimation techniques. These form the central component of an end-to-end package that includes novel tools for multicontrast image registration, spectroscopic image estimation from multicontrast MRI data, and spectroscopic image visualization. This package also provides tools to quantify the expected spectral information produced by a multiparametric acquisition, which can be used for quality assessment and protocol optimization.

Methods

We implemented Diffusion-Relaxation Suite as a set of command-line tools (using MATLAB and Python) and as a graphical interface (using C++, GLSL, and Qt). The architecture of DRSuite is depicted in Fig. `A. We distribute versions of the software compiled for Linux, Mac, and Windows; the compiled MATLAB components can be run using the MATLAB runtime, available as a free download.

The functionality we developed in DRSuite includes the following:

  • Spatially-regularized spectrum estimation. We implemented the spatially-regularized multiparametric spectrum estimation techniques described in Refs. 2-4. Spatial regularization enables major improvements, both theoretically and empirically, relative to earlier methods for estimating diffusion/relaxation spectra. DRSuite currently supports 1D spectrum estimation from one-dimensional contrast encoding (a common, relatively-easy experiment to implement) and 2D spectrum estimation from higher-dimensional diffusion-relaxation or relaxation-relaxation contrast encoding (a more advanced experiment that offers substantially better microstructure resolving power).
  • Multicontrast image registration. Image alignment is important for the accurate estimation of microstructural tissue compartments. We developed registration tools that are designed to correct motion and distortion artifacts and ensure spatial consistency across a series of multicontrast MR images. These tools use a multi-stage registration approach combining center alignment, affine registration, and nonlinear deformable registration. Our nonlinear registration software uses a U-Net as a regularizer and is implemented using PyTorch to achieve improved performance on computers with GPUs.
  • Visualization. We implemented command-line visualization tools that allow users to plot spatial-spectral images, and obtain spatial maps of different microstructural features by integrating over different regions of the spectral dimension.
  • Phantom Data. We developed tools for generating synthetic multidimensional phantom datasets with known ground-truth spectra. These datasets can be used to evaluate and compare different acquisition schemes and spectrum estimation methods.
  • Estimation-theoretic characterization. We created a tool to evaluate estimation-theoretic Cramér-Rao bounds for this type of spectrum estimation. This provides a quantitative measure that can be used for evaluating the quality of estimated spectra, and can also be used to prospectively assess the estimation-theoretic characteristics of different experimental acquisition paradigms. This can be very useful for designing and optimizing experiments, as described in Refs. 3,5.
  • Interactive visualization. We developed the Diffusion-Relaxation Suite Viewer (DRViewer) for exploring the spectroscopic images output by the command-line tools (see Fig. 1B). DRViewer provides views of the data in spatial and spectral dimensions, which enable the user to navigate the multi-dimensional data.

Results

Figure 2 depicts typical ways that Diffusion-Relaxation Suite can be used.  Figure 2A depicts taking multidimensional diffusion-relaxation data from a mouse spinal cord with traumatic injury,2  using Diffusion-Relaxation Suite to estimate a 2D spectroscopic image that depicts the distribution of diffusion and relaxation decays within each image voxel, and then visualizing different microstructural tissue compartments (including distinct white matter, gray matter, and injury-specific compartments) by spectrally-integrating the spectral peaks of the spectroscopic image.  Figure 2B depicts taking human brain images with different T2 weightings,3 using Diffusion-Relaxation Suite to estimate a 1D spectroscopic image that depicts the distribution of relaxation decays within each image voxel, and then visualizing different microstructural tissue compartments (such as myelin water, intra-/extra-cellular water, and cerebrospinal fluid).

Conclusion

Diffusion-Relaxation Suite provides open-source implementations of novel tools that are useful for characterizing tissue microstructure in health and disease from multiparametric MRI data.  Source code, compiled packages (for Linux, Mac, and Windows), documentation, and tutorials are provided online (https://drsuite.org/). The software is freely available under an open-source (LGPLv2) license.
