Introduction

Individuals with long COVID often experience impaired memory, difficulty concentrating, fatigue, and malaise that can last months or even years after initial SARS-CoV-2 infection1. Despite the substantial personal and societal burden of long COVID, the brain mechanisms and risk factors underlying symptoms remain to be determined. This gap represents a critical public health concern impacting the quality of life for millions of individuals worldwide. Prior work has largely focused on activity patterns and stationary network features, but growing evidence suggests that brain network dynamics explain more variance in cognition and behavior than traditional, time-invariant models2. Building on these observations, we applied a data-driven model of time-varying brain connectivity that flexibly estimates transitions between latent states3. Using this approach, we identified brain network dynamics linked to the experience of cognitive fog in an individual with long COVID, offering a potential pathway for advancing long COVID diagnostics and treatment.

Methods

Dataset.

As part of an ongoing data collection effort, we conducted a longitudinal, densely-sampled case study of an individual patient (N=1) with long COVID who underwent 80 resting- and task-state fMRI sessions over 14 months. In each study session, intrinsic (resting-state) scans bookended task-evoked scans, allowing us to investigate the persistent impacts of cognitive fog provocation on intrinsic brain network dynamics. The analyses reported here focused on 18 sessions in which the participant performed a rapid instructed task learning (RITL)4 task (Fig. 1A), and 18 sessions in which they performed a book-reading task (henceforth: BOOK). In these sessions, the RITL task provoked a subjective experience of fog that lingered after the task into the second resting state scan, whereas the BOOK task did not provoke a subjective experience of fog (Fig. 1B).

Processing.

MRI data were minimally processed with fMRIprep version 23.2.3 via a singularity image run on the Princeton University high performance compute cluster5. Cortical vertices were parcellated into 100 regions using the Yan homotopic atlas6. Network assignments were determined based on the 17-network solution from Yeo et al7. We also applied subcortical8 and cerebellar9 atlases to altogether include 21 whole-brain, large-scale functional networks (Fig. 1F). Nuisance timeseries were removed from processed fMRI data using a combination of motion regression and aCompCor to remove physiologically-based noise10. 

Network based statistic (NBS).

For each session, initial functional connectivity (FC) patterns for each resting- and task-state run were estimated using the pairwise product-moment correlation between all region-to-region timeseries. As a first-pass test of the hypothesis that post-task modifications to resting-state connectivity patterns are significantly different between RITL- and BOOK-task fMRI sessions, we used the network based statistic (NBS)11. Further, we summarized significantly connected components identified with NBS via network-level degree strength (DS). 

Hidden semi-Markov model (HSMM). 

We used a hidden semi-Markov model (HSMM) to test the hypothesis that dynamic changes in intrinsic network organization, pre-to-post task, are linked to the provocation of cognitive fog. HSMMs approximate a state-space – the set of all possible hidden states that underlie time-varied data – more flexibly than standard HMMs. The HSMM was fit on a training set that included all resting-state timeseries, with a nonparametric (data driven) sojourn distribution3, and k-means initialized parameters for state means and covariances. Following prior work, we used a k=5 state solution. Model-fit state means, covariances (dynamic FC estimates), fractional occupancies, and dynamic FC properties were examined.

Results

Our analyses revealed significant pre-to-post task changes in intrinsic connectivity between sessions with (RITL) and without (BOOK) fog provocation (p<0.001) (Fig. 1C-D). At the network level, connected components were preferentially exhibited across temporal parietal, somato/motor A, medial temporal, thalamic, and striatal systems (Fig. 1D-E). These patterns indicate broad subcortical involvement in network-level signatures of cognitive fog, along with strong contributions from task-relevant and integrative cortical brain networks. Next, applying recent methodological advances in dynamic connectivity analyses3 (Fig. 2A-B), we established that fog-linked neural processes were specifically dominated by a single dynamic state (state 4 in Fig. 2C). Changes in the fractional occupancy (FO) of this state from pre- to post-task were significantly greater in RITL than in BOOK sessions  (p<0.0001) (Fig. 2D-E). Notably, state 4 exhibited the lowest system segregation12 amongst all 5 dynamic FC states (Fig. 2F), suggesting that this “fog state” broadly reflects de-differentiated, or flattened, network dynamics. 

Conclusion

These data provide novel evidence for the view that cognitive fog in patients with long COVID is rooted in disruptions to brain network dynamics. Pre-task brain network dynamics were similar across RITL and BOOK sessions. After the participant performed a fog-provoking task (RITL), a distinct and highly structured shift in dynamic connectivity emerged – dominated by a single state that was not evident during the non-fog-provoking BOOK-task sessions. Importantly, this indicates the presence of a sustained alteration to intrinsic network organization that follows fog provocation. Together, these results suggest that cognitive fog involves coordinated, state-level disruptions to neural processing that propagate across functional network interactions. Identifying this brain-network-based signature of cognitive fog lays the groundwork for translational efforts aimed at monitoring, predicting, and ultimately alleviating long COVID symptoms. Importantly, these analyses are readily adaptable to datasets with multiple participants, which will allow future work to characterize individual differences in symptom expression – a known but under-examined aspect of long COVID13.
