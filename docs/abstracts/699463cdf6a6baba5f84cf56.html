Introduction

Brain age estimation from neuroimaging has become an important approach for detecting deviations from typical aging trajectories. The discrepancy between estimated brain age and chronological age, termed the brain age gap, has been associated with mortality risk and neurodegenerative or psychiatric conditions.1 T1-weighted MRI remains the most widely used modality owing to its availability and rich anatomical information.2 While conventional morphometric approaches focus on volumetric measures such as gray matter volume and cortical thickness, radiomics offers complementary information by quantifying higher-order features including intensity distributions, textural patterns, and spatial heterogeneity that may reflect tissue-level characteristics not captured by volumetric measures.3

Despite increasing interest in radiomics-based brain age estimation, previous studies have employed varied subsets of radiomic features without systematic evaluation, yielding inconsistent predictive performance across studies.4,5 This variability likely stems from arbitrary feature selection without empirical guidance on which feature categories are most informative. Fundamental questions remain unaddressed regarding the comparative performance of different radiomic feature families and their optimal combination. The absence of systematic benchmarking has impeded establishment of evidence-based feature selection guidelines, limiting progress toward reproducible and clinically applicable methods.

This study addresses these gaps through systematic benchmarking of 91 radiomic features across four machine learning algorithms to identify categories with robust predictive performance. Building on these findings, we applied Multiple Kernel Learning with data-driven optimization to establish a parsimonious feature set. Our objectives are to provide empirical guidance for feature selection and deliver a validated, clinically translatable framework for radiomics-based brain age estimation.

Methods

We analyzed T1-weighted MRI data from 1,690 cognitively normal participants (786 males, 904 females; age 20–92 years) across five imaging centers, excluding individuals with neurological or psychiatric disorders. Figure 1 illustrates the overall analytical framework. T1-weighted structural images underwent standardized preprocessing via the Computational Anatomy Toolbox (CAT12 r2170) in Statistical Parametric Mapping 12, including denoising, bias field correction, tissue segmentation, and spatial normalization to Montreal Neurological Institute space using geodesic shooting registration (1.5 mm isotropic resolution). This preprocessing generated spatially normalized images for radiomics analysis and modulated gray matter maps for constructing a conventional volumetric baseline, consistent with established T1-based brain age prediction approaches.

Radiomic feature extraction was performed using PyRadiomics v3.1.0 following Min-Max intensity normalization. We employed a comprehensive composite atlas encompassing 442 brain regions, including 400 cortical parcels (Schaefer 7-network atlas), 14 subcortical structures (Harvard-Oxford atlas), and 28 cerebellar regions (SUIT atlas). Within each region, 91 quantitative descriptors were calculated across six feature families, comprising first-order statistics (18 features), Gray Level Co-occurrence Matrix (GLCM, 22 features), Gray Level Run Length Matrix (GLRLM, 16 features), Gray Level Size Zone Matrix (GLSZM, 16 features), Gray Level Dependence Matrix (GLDM, 14 features), and Neighbouring Gray Tone Difference Matrix (NGTDM, 5 features).

To systematically benchmark radiomic features in predicting individual brain age, we compared four machine learning algorithms with distinct learning mechanisms, comprising Support Vector Regression (SVR), Kernel Ridge Regression (KRR), Elastic Net, and eXtreme Gradient Boosting (XGBoost). Model evaluation employed nested 5-fold cross-validation with 100 repetitions, wherein the outer loop assessed generalization performance and the inner loop optimized hyperparameters via grid search. Z-score standardization was applied within each fold using training-derived parameters to prevent data leakage. Each of the 91 radiomic feature types was independently evaluated across all algorithms. For comparison, we constructed a morphometric baseline model using regional gray matter volumes from the same 442 regions, employing SVR to match conventional approaches in the literature. All model development and evaluation were implemented using scikit-learn (version 0.23.2; https://scikit-learn.org/stable/).

Following individual feature benchmarking, we performed optimal feature integration using Multiple Kernel Learning (MKL) with forward selection and L1-norm regularization. This approach was chosen to systematically combine information from multiple feature types while maintaining interpretability. Each kernel corresponded to one radiomic feature type computed across all 442 brain regions, enabling the model to learn optimal weights for different feature categories. Forward selection iteratively added kernels based on cross-validation performance. The optimal feature subset was determined using the elbow method applied to the mean absolute error (MAE) curve, identifying the inflection point beyond which additional features yielded diminishing returns. This data-driven strategy balanced predictive accuracy with model parsimony.

Results

Systematic benchmarking across 91 radiomic features and four machine learning algorithms revealed substantial performance heterogeneity (Figure 2A), with mean absolute errors spanning 5.39 to 12.86 years depending on feature type and algorithm choice. This variability provides empirical evidence for the inconsistent results reported in prior studies employing different feature subsets. Among algorithms, SVR demonstrated the highest overall accuracy, while XGBoost showed relatively lower performance. Notably, feature category exerted stronger influence on predictive power than algorithm selection, with first-order statistics and GLCM features consistently outperforming other categories across all algorithms.

Within feature categories, first-order statistics demonstrated robust performance, with SVR models achieving MAEs of 5.39–6.16 years (R²: 0.72–0.87) across the 18 individual descriptors. GLCM features showed comparable accuracy, yielding MAEs of 5.70–7.12 years (R²: 0.79–0.86) across 22 texture descriptors. In contrast, GLSZM features exhibited marked instability, with MAEs ranging from 6.73 to 11.62 years (R²: 0.46–0.81), suggesting that higher-order spatial zone characteristics are less reliably associated with age-related changes. Compared to the conventional morphometric baseline (MAE: 6.42 years, R²: 0.82 using regional gray matter volumes), the best-performing individual radiomic features achieved superior accuracy, demonstrating that voxel-level intensity distributions and textural patterns capture age-sensitive information beyond what is reflected in aggregate regional volumes.

Following systematic benchmarking, MKL-based feature selection identified an optimal 14-feature combination through elbow analysis (Figure 2B), where additional features beyond this subset provided minimal performance gain. This compact model comprised 6 first-order statistics, 7 GLCM features, and 1 GLRLM features, reflecting the predominance of intensity distribution and local co-occurrence patterns identified in individual feature evaluation. The integrated model achieved an MAE of 4.57 years and R² of 0.91, representing a 29% reduction in MAE compared to conventional volumetric methods and outperforming any single radiomic feature. Beyond improved accuracy, this 14-feature set offers practical advantages for clinical translation, reducing computational complexity while maintaining robust predictive performance. The feature composition (Figure 2C) suggests that age-related brain changes are optimally characterized through complementary information from voxel-level intensity patterns and short-range spatial relationships, rather than higher-order textural complexity.

Conclusion

This study addresses a fundamental question regarding the inconsistent performance reported across radiomics-based brain age studies. Our systematic evaluation of 91 features across four algorithms demonstrates that performance varies substantially depending on feature selection, with mean absolute errors spanning 5.39 to 12.86 years. This heterogeneity provides empirical evidence that prior inconsistencies stem primarily from arbitrary feature choices rather than algorithmic differences. The comprehensive benchmarking presented here establishes an evidence base to guide feature selection, advancing the field from exploratory approaches toward standardized, reproducible methodology.

Feature optimization revealed that brain aging is most accurately characterized by relatively simple descriptors. The optimal 14-feature model predominantly comprises first-order statistics and GLCM features, suggesting that age-related changes are primarily reflected in tissue intensity distributions and local spatial patterns. This finding implicates fundamental processes such as myelin degradation, iron accumulation, and microstructural alterations that affect voxel-level signal characteristics. The limited contribution of higher-order spatial features challenges prevailing assumptions regarding the necessity of complex descriptors for aging biomarkers.

Beyond methodological contributions, this compact framework offers practical advantages for clinical translation. The 14-feature model achieves 29% improvement over conventional volumetric approaches while reducing computational demands, providing a feasible implementation pathway for clinical research settings. This validated framework can facilitate investigations of accelerated aging in neurodegenerative and psychiatric populations, where subtle tissue alterations may precede volumetric changes. The standardized feature set addresses methodological heterogeneity that has limited cross-study comparisons and meta-analyses in this domain.
