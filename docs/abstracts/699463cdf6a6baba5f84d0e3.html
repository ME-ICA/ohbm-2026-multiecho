Introduction

The hippocampus has long been central to understanding brain-behaviour relationships. Converging studies from both rodents and humans have demonstrated that hippocampal neurons encode environmental locations, underscoring its role in spatial navigation. In parallel, clinical and neuroimaging research has revealed its vital contribution to declarative memory, particularly the retrieval of autobiographical/episodic memory with rich spatiotemporal context. While some theoretical accounts attempt to reconcile these functions by proposing that the hippocampus organizes experience within a unified spatiotemporal framework1, others argue for partially independent mechanisms embedded within its anatomical organization2.

Despite theoretical progress, the anatomical basis linking hippocampal morphology to individual differences in hippocampal memory function remains unclear. Existing studies largely rely on total hippocampal volume, which is a coarse measure yielding inconsistent findings. Although expert London taxi drivers show enlarged posterior hippocampi, large-sample studies reveal only weak correlations between hippocampal size and wayfinding ability3. Such discrepancies suggest that global volumetry may obscure finer anatomical variations relevant to hippocampal function.

Recent methodological advances now enable extraction of fine-grained morphometric features from unfolded hippocampal surfaces4, allowing exploration of how individual variations in hippocampal function map onto its anatomy. These enriched structural markers, combined with large-scale behavioral assessment and multivariate analytic techniques, may potentially provide a new opportunity to dissect distinct anatomical correlates of memory abilities. In this study, we therefore aimed to examine how fine-grained hippocampal anatomical profiles, contribute to individual variability across the foundational components of hippocampal function, namely dissociable types of long-term memory abilities.

Methods

With the aim of identifying robust components of memory abilities, we first employed the self-report Survey of Autobiographical Memory (SAM), which contains questionnaire items related to semantic, episodic memory, future prospection and spatial memory (Fig. 1). To obtain robust and generalizable decomposition, ratings from the in-lab administration of SAM (n=139) was combined with an independent, publicly available dataset (n=217)5. Dimensionality reduction was performed using Orthogonal Projective Non-negative Matrix Factorization (OPNMF), a machine learning method previously applied to other questionnaire data to identify latent interpretable components. Four complementary indices within a comprehensive cross-validation framework were used to identify optimal trait decomposition that jointly maximizes stability and generalizability. This was operationalized as higher Adjusted Rank Index (aRI) and Concordance Index (CI), as well as lower Variation of Information (VI) and increased Reconstruction Error (iRE), with low item variability (IV).

Neuroimaging data were acquired across 128 participants (mean age = 26.02 years old, SD = 3.04, F/M = 88/40) using high-quality HCP-compliant protocols on a 3T Siemens Prisma MRI scanner. In particular, whole-brain anatomical images were obtained using a T1-weighted MPRAGE sequence (0.7-mm isotropic resolution, TR = 2400 ms, TE = 2.02 ms, TI = 1,000 ms, flip angle = 8°, bandwidth = 270 Hz per pixel, no partial Fourier, in-plane acceleration factor (iPAT) = 2, TA = 7.4 min perscan) and a T2-weighted SPACE sequence (0.7-mm isotropic resolution, TR = 3200 ms, TE = 564 ms, BW = 744 Hz per pixel, no partial Fourier, iPAT = 2, TA = 8.2 min per scan).

HippUnfold was used to segment the hippocampus and generate high-resolution 0.5 mm unfolded surfaces for each participant. Morphometric features including thickness, gyrification, curvature were computed based on the surface geometry in T1w space. These surface metrics were then used to investigate their association with self-report components of memory abilities. For this purpose, we used multivariate predictive modelling to identify morphometric features of the hippocampus that were significantly predictive of component scores obtained from the decomposition of self-reported SAM ratings.  Morphometric features consisted of vertex-wise values for thickness, gyrification and curvature for the bilateral hippocampus. The neural predictive model was then constructed using Support Vector Regression (SVR). A comprehensive validation framework was used to systematically evaluate model performance across accuracy, robustness, generalizability, and specificity: (1) Predictive accuracy was evaluated using nested 2-fold cross-validation with Pearson's correlation (r), mean squared error (MSE) metrics and coefficient of determination (R2); (2) a permutation test (5000 iterations) was conducted to evaluate predicting accuracy and determine the p-value; (3) hippocampal feature importance was then determined through bootstrap resampling (5,000 iterations) with z-statistics.

Results

Using OPNMF and a comprehensive cross-validation framework, dimensionality reduction of the self-report SAM questionnaire ratings revealed a stable two-component solution (Fig. 2a). Although the original questionnaire included items across four broad labels (i.e. semantic, episodic, future, spatial), cross-validated model stability indicated that participants’ responses primarily reflected two dominant latent dimensions. In particular, items originally categorized as semantic, episodic memory and future prospection loaded strongly onto a single component, which we collectively labelled as “declarative memory”. Conversely, spatial memory items were isolated exclusively onto a second component, suggesting that self-assessed spatial memory forms a distinct behavioural construct relative to declarative memory facets (Fig. 2b).

At the neural level, multivariate prediction analyses demonstrated domain-specific associations between anatomical profiles of the hippocampus and the identified components of long-term memory. Among the surface-based morphometric features, thickness and gyrification exhibited selective predictive power. While hippocampal thickness significantly predicted individual component scores from the declarative memory component (r = 0.1800, p = 0.0465), gyrification provided the strongest prediction for the spatial memory component (r = 0.2748, p = 0.0055) (Fig. 2c). Permutation testing confirmed that both predictive relationships exceeded chance levels. In contrast, curvature did not reliably predict either memory dimension.

With the aim of further characterizing the spatial organization of these predictive effects, vertex-wise z-statistics from the bootstrap analysis were visualized on the unfolded hippocampal surfaces and summarized across subfields using ridge plots (Fig. 2d). For the declarative memory component, predictive patterns displayed marked subfield heterogeneity: thinner CA3 regions were consistently associated with higher self-reported declarative memory ability, while CA4 displayed an opposite effect. This divergence suggests differentiated contributions of hippocampal subfields to declarative memory-related processes. In contrast, the effects for gyrification showed greater homogeneity across the hippocampal subfields. Nevertheless, the results indicated that greater gyrification of the dentate gyrus and CA3 were associated with higher scores on self-reported spatial memory ability, while CA1 and subiculum showed an opposite effect. Collectively, these results indicate partially dissociable links between morphometric features of the hippocampus and declarative versus spatial components of hippocampal memory function.

Conclusion

In this study, optimal decomposition of self-report memory ability identified two stable and generalisable components, indicating that declarative memory, including semantic, episodic memory and future prospection, versus spatial memory are best represented by two separable latent dimensions. Contrary to theoretical proposals that declarative memory and spatial navigation might arise from a unified process, our findings indicate that these memory abilities, at least at the self-reported experiential level, display a degree of separability that may rely on distinct anatomical substrates within the hippocampus.

To this end, surface-based multivariate predictive modelling further revealed that self-report abilities for declarative and spatial memory are associated with distinct morphometric features: hippocampal thickness selectively predicted declarative memory, while gyrification predicted spatial memory. Moreover, the declarative memory-related predictive pattern demonstrated coarse subfield specificity, most notably within CA3 and CA4. However, the prediction of spatial memory largely illustrated a pattern of uniformity across different subfields, indicating that navigation-related morphometric information may be encoded at a finer spatial granularity (e.g., within-subfield vertex-level variation) rather than at the level of canonical subfield boundaries.

Collectively, these findings highlight that fine-grained hippocampal surface features capture individual variability in components of hippocampal function more precisely than traditional volumetric measures. They also suggest that the structural organization supporting spatial memory may be more homogeneous, or encoded at a more granular spatial scale than that supporting declarative memory. Together, the present results provide new evidence that declarative memory and spatial navigation, though both hippocampal-dependent, might be supported by distinct anatomical signatures, offering a refined perspective on how hippocampal architecture maps onto core human memory functions.
