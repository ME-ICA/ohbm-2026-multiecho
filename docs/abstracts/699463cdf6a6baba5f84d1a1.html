Introduction

Requirements for a reliable hippocampal complex (HC) activation task for presurgical clinical use include directions that are easy to understand and follow, minimal pre-scan preparation, relatively brief task duration, and standard post-processing.1 Ideally, the task would consistently show bilateral hippocampal activity to better interpret a lack of activity in either HC prior to hippocampal resection. While the HC engages numerous computational functions during memory processing, most research imaging studies focus on a single aspect of this complex system. Requiring engagement of multiple memory functions for task performance may increase the robustness and reliability needed for a clinical tool. Here we compare bilateral HC engagement in a series of three memory recall tasks, compatible with clinical use from a time/ease of delivery perspective, that include components of novelty, updating information/reconsolidation, and spatial or emotional stimuli to maximize bilateral HC engagement.

Methods

The memory recall tasks were developed in a stepwise manner, with each stage extending the one before it within an IRB-approved study. Cognitively healthy right-handed subjects underwent 3T imaging and a brief cognitive screening. Encoding of memory stimuli occurred outside of the scanner prior to 2 runs of the fMRI memory recall task. For the first location (L) task, subjects first viewed “baseline” movies of house rooms containing common items (couch, chairs, etc.). During the test fMRI task, subjects pressed a button when seeing any previously learned items that had changed color or location (thereby “updating memory”) 2 or when they viewed a new object (“novelty”).3 Previously learned, unchanged stimuli were intermixed. The next task changed the stimuli to those typically evoking positive emotion (PE). Baseline learning was viewing slides of puppies or babies in naturalistic settings. During the test fMRI, subjects responded if the baby/puppy was in a new background setting (updating) or was novel, intermixed with previously learned stimuli. The final “Positive and Negative Emotion (“EM”) task was the same as the PE task but included babies, puppies, disgusting, and scary images. All tasks’ baseline condition response was a simple decision-making task of pressing a button for a target digit.4 All tasks had 9 target blocks (L: 20”; E: 24”, PE: 20”) and baseline (L: 20”; E: 16”; PE: 20”) for task length of 6:06 with two dummy scans. Two runs were performed in addition to structural scanning. NordicNeurolab goggles were used for stimulus presentation. T2* parameters: TR = 2000ms, TE = 27ms, FOV 64x64, voxel 3mm3, scanned in hippocampal plane. Data analyzed with standard SPM12 protocol and 4mm3 smoothing, normalized to the ICBM space template. Results were masked using neuromorphometrics atlas to include left and right HC, and a threshold of p = 0.01, 10 voxel extent was used to evaluate individual activation maps of the combined 2 runs.

Results

Each task was run on separate subjects; L=16, PE=13, EM=17. Demographics across the tasks were (M±SD) age: 27±5 yrs; education: 16±1.7 yrs; sex: 19M/28F; memory retention (%): 87.5±13. Demographics did not differ among tasks. While motion tended to be subvoxel size, if motion trends appeared to be present, motion parameters were included. All subjects showed significant bilateral HC activity exceeding p < 0.01, uncorrected which was focused primarily within the posterior/body of the HC. The number of subjects who also showed anterior HC activity differed among tasks; L task = 7/16 (43%), PE = 5/13 (38%), EM = 15/17 (88%) (FIG 1.) For the EM group, 82% had bilateral anterior HC activity (14/17; 1 showed no anterior HC activity, 1 left anterior HC only, 1 right anterior HC only). Of those EM subjects with bilateral anterior activity, 8 subjects (57%) had <10% lateralization to the right or left anterior HC, and 6 (42%) were within a 10-32% hemispheric difference based on SPM(T) scores. As is common in clinical fMRI tasks designed to elicit robust activation across patients with either intact or impaired cognition, the ease of the task resulted in no consistent correlation between HC activity and performance, which was generally high across subjects.

Conclusion

In an effort to design an fMRI paradigm that elicits hippocampal activation and is feasible for clinical patients, we combined several computational memory processing functions. The first task utilizing both novelty and memory updating with spatial stimuli reliably showed bilateral posterior, but not anterior, hippocampal activity.  Incorporating emotional processing more reliably activated the anterior and posterior hippocampus, but positive stimuli alone were inadequate. Using both positive and negative stimuli markedly improved anterior, as well as posterior, hippocampal engagement. Negative stimuli may be best at increasing reliable anterior hippocampal activity5 but also risks inducing anxiety and task noncompliance in distressed patients, which may decrease successful mapping. This effect was potentially offset by the intermingled positive stimuli. Combining multiple memory-relevant computation processes may be more effective for producing maximal HC activity than engaging a single memory processing function.
