Introduction

Gradient-based optimization enables efficient parameter estimation in brain network models, scaling to thousands of free parameters where simulation-based approaches become computationally prohibitive.¹ However, these methods tend to fail near bifurcations, where dynamics can become chaotic and gradients explode or vanish. This is particularly problematic because many neuroscientifically relevant operating points lie precisely in these regimes. Standard automatic differentiation through the forward simulation yields unusable gradients in these cases, limiting the applicability of otherwise powerful optimization techniques. We systematically compare strategies for stable gradient computation in these challenging regions.

Methods

We use TVB-Optim, an open-source JAX-based Python library for differentiable whole-brain network simulation.¹ The framework supports standard neural mass models coupled via subject-specific structural connectivity and provides documented workflows for gradient-based parameter estimation (https://github.com/virtual-twin/tvboptim). We fit neural mass models to empirical functional connectivity features in parameter regimes spanning stable, critical, and chaotic dynamics. We compare three approaches for gradient stabilization. First, we evaluate implicit numerical solvers that improve integration stability at higher computational cost by solving nonlinear systems at each time step. Second, we test gradient flossing that adds Lyapunov exponent regularization to the loss function, dynamically guiding optimization toward non-chaotic regimes where gradients remain well-behaved.² Third, we apply least-squares shadowing that estimates gradients not along the simulated trajectory but along nearby bounded shadow trajectories, yielding meaningful sensitivity information even in chaotic systems.³ Each method is evaluated on parameter recovery accuracy, computational cost, and the range of dynamical regimes where optimization succeeds.

Results

All three methods extend the range of parameter space where gradient optimization remains viable, with distinct trade-offs in applicability and computational cost. Implicit solvers are most robust across dynamical regimes but substantially slower than explicit integration schemes. Gradient flossing is computationally efficient but biases solutions away from critical regimes. This bias may be acceptable when criticality is not the phenomenon of interest, but is problematic when studying critical dynamics. Shadowing preserves access to chaotic dynamics without biasing the solution space but requires careful tuning and is only applicable for time-averaged quantities over sufficiently long integration periods. The relative performance of each method depends on the specific neural mass model, the target features being fitted, and the proximity to bifurcation boundaries in parameter space.

Conclusion

The choice of stabilization strategy depends on whether critical or chaotic dynamics are scientifically essential to the modeling question or merely incidental to reaching a desired parameter regime. When fitting models where criticality is the object of study, shadowing methods preserve access to these dynamics despite their complexity. When critical regimes are simply obstacles to reaching stable operating points, gradient flossing offers an efficient solution. Implicit solvers provide a robust default when dealing with stiff dynamics that are non-chaotic. We provide practical guidance and documented implementations for selecting among these approaches within the TVB-Optim framework.
