Introduction

Sleep is a fundamental physiological process essential for cognitive function, emotional regulation, and overall health. Accurate characterization of sleep architecture, including Wake, Rapid Eye Movement (REM), and Non-Rapid Eye Movement (NREM; N1–N3) stages, is critical for diagnosing sleep disorders, assessing treatment efficacy, and studying sleep-related health outcomes. Clinical polysomnography (PSG) remains the gold standard for sleep assessment, offering comprehensive multi-modal recordings. Despite its high accuracy, PSG is time-consuming, costly, and inherently intrusive, severely limiting its practical application for continuous, at-home, or large-scale population sleep studies1. Advances in wearable technology allow comfortable, user-friendly collection of physiological signals for continuous sleep assessment. However, wearable data are often noisy and affected by motion artifacts, requiring robust algorithms for accurate sleep stage detection. While machine learning models show promising performance, models are still needed that both extract meaningful features and capture the sequential structure of sleep dynamics. 

In this study, we proposed a hybrid framework that integrates handcrafted feature extraction from wearable signals with tree-based feature classifiers and deep sequence models. The feature classifiers effectively capture discriminative, non-linear interactions within the handcrafted feature space, while the deep sequence models are well suited for modeling long-range temporal dependencies in wearable signal sequences. We evaluate the framework on the DREAMT2 dataset to develop a lightweight, accurate solution for home-based sleep monitoring. The dataset includes overnight PSG and Empatica E4 recordings from 100 adults, with 30-second epoch sleep stage annotations and multiple biosignals, including blood volume pulse, accelerometry (ACC), electrodermal activity, skin temperature, inter-beat intervals, and heart rate (HR).

Methods

Model framework. We propose a hybrid framework composed of two primary components: a feature classifier and a sequence classifier. The overall model architecture is illustrated in Fig.1. The input to the model includes handcrafted features extracted from preprocessed wearable-device signals, such as HR and three-axis ACC data. In the first stage, a decision-tree based feature classifier, such as Gaussian Process Boosting (GPBoost), Light Gradient Boosting Machine (LightGBM), or other decision-tree based algorithms, processes these feature vectors. This component generates initial predictions and identifies the most informative features based on the input distribution.

The outputs of the feature classifier, including predicted probabilities and selected important features (e.g., IMFs as shown in Fig.1), are subsequently fed into the sequence classifier. This second component employs models such as Bidirectional Long Short-Term Memory (BiLSTM), Transformer architectures, or other deep sequential models to capture temporal dependencies across consecutive time steps. By integrating the strong feature-level discrimination of tree-based methods with the temporal modeling capabilities of deep sequential networks, the hybrid framework effectively captures both static and dynamic information in the data, yielding improved classification performance.

Feature Extraction. We extract statistical features from HR and three-axis ACC signals. Each signal is first smoothed using a Gaussian filter, after which we compute a comprehensive set of features. For HR, we extract time-domain, frequency-domain, nonlinear, and basic statistical measures. For ACC signals, we compute both axis-specific statistics and overall magnitude-based measures to capture movement intensity and variability across the three axes3. 

Results

We evaluated generalization in a cross-subject setting, splitting the subjects into training, validation, and test sets (64%–16%–20%). Class imbalance was addressed using random undersampling to balance the training data. Additionally, we assessed the proposed framework across different architectural configurations using 5-fold cross-validation to identify the most effective combination of feature and sequence classifiers. Four tree-based methods (GPBoost, LightGBM, Random Forest, and Extreme Gradient Boosting (XGBoost)4) were used as feature classifiers, and four sequential models (Bidirectional Gated Recurrent Unit (BiGRU), BiLSTM, Temporal Convolutional Network (TCN), and Transformer5) were employed as sequence classifiers. Given the dataset imbalance, results are reported using the Weighted F1 score. 

The results show that among all evaluated configurations, GPBoost achieved its highest performance when combined with the Transformer, reaching a Weighted F1 score of 0.736 ± 0.324, which represents the best result across all model combinations. RandomForest also reached its peak performance with the Transformer, achieving 0.732 ± 0.412, which is very close to the best overall score. LightGBM likewise obtained its strongest result with the Transformer, reaching 0.705 ± 0.242. In contrast, XGBoost performed best when paired with BiGRU, achieving 0.701 ± 0.314.

These findings highlight the Transformer as the most effective sequence classifier, consistently yielding the top performance for three of the four feature classifiers. Among feature models, GPBoost and RandomForest demonstrated the strongest overall results, especially when combined with the Transformer. Conclusion

We presented a lightweight hybrid framework combining tree-based feature classifiers and deep sequence models for wearable-based sleep stage detection. The approach leverages handcrafted HR and ACC features while capturing temporal dependencies through sequential models. Experimental results on the DREAMT dataset demonstrate that the hybrid framework, particularly the GPBoost–Transformer configuration, achieves superior classification performance, effectively handling class imbalance and diverse sleep patterns. These findings highlight the potential of integrating interpretable feature-level models with temporal deep learning for accurate, home-based sleep monitoring.
