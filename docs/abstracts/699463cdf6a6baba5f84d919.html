Introduction

Command-line neuroimaging tools remain essential for brain imaging research but present significant barriers to discovery, accessibility, and integration into modern workflows. Researchers face challenges finding appropriate tools among thousands of options across fragmented packages, understanding complex command-line interfaces, and building reproducible analyses. Traditional approaches require extensive documentation review, trial-and-error configuration, and manual wrapper development. As AI agents emerge as potential research assistants, these tools additionally lack the structured, programmatic interfaces needed for agent interaction. We present the NiWrap Hub: an open web platform providing comprehensive access to 2,000+ neuroimaging tools across 20+ packages. Built on Styx (a compiler for type-safe wrapper generation) and NiWrap (comprehensive tool metadata), the Hub enables interactive visual configuration, multi-language code generation, and AI-ready programmatic access via Model Context Protocol (MCP), establishing infrastructure that serves both current interactive research and emerging AI-assisted workflows.

Methods

NiWrap Metadata Collection: Generated comprehensive Boutiques-format descriptions for 2,000+ tools across major neuroimaging packages (AFNI, ANTs, Convert3D, FSL, FreeSurfer, MRTrix3, NiftyReg, Workbench). Used direct source code extraction for well-structured packages and LLM-assisted approaches for traditionally documented software. Implemented continuous metadata refinement pipeline using LLM analysis of usage patterns and community feedback to improve descriptor accuracy and completeness.

Styx Compiler Architecture: Three-phase compilation processes Boutiques descriptors through intermediate representation to generate type-safe native interfaces in Python, R, and TypeScript. Generated wrappers provide IDE integration with autocompletion, runtime parameter validation, and container orchestration support (Docker/Singularity). Extended descriptor format to capture complex command-line patterns including hierarchy, alternation, and repetition using formal language concepts.

NiWrap Hub - Interactive Platform: Developed fully client-side web application leveraging Styx-generated TypeScript wrappers for browser-based tool interaction. Features include comprehensive search across packages, tools, and parameters; automatic visual GUI generation for even highly complex command-line interfaces; URL-based configuration sharing; and validated multi-language code generation. Client-side architecture ensures data privacy without requiring software installation, user authentication, or data upload. Critical for sensitive neuroimaging research.

AI Integration via MCP: Implemented Model Context Protocol server exposing tool metadata and capabilities to AI agents through standardized interface. MCP integration enables programmatic tool discovery based on capability queries, automated parameter configuration with validation, and integration into agent-driven workflow construction. Designed for language model integration where agents recommend tools, configure parameters, and generate execution code based on research objectives described in natural language.

Results

The NiWrap Hub provides end-to-end tool access embodying FAIR principles: Findable through semantic search and URL-based configuration sharing; Accessible via zero-installation browser interface with visual GUI generation for all tools; Interoperable through multi-language code generation based on open standards (Boutiques, JSON Schema, OCI containers); Reusable via static typing, runtime validation, tool versioning, and cross-platform deployment (Windows/Linux/macOS). The platform serves as a resource for pipeline development, teaching, and tool exploration across experience levels from students to expert developers.

MCP integration successfully exposes tool ecosystem to AI agents with demonstrated capabilities including: semantic tool discovery where agents query by research objective or capability (e.g., "cortical surface reconstruction tools"); detailed capability inspection retrieving parameter specifications and constraints; automated configuration assistance generating validated parameter combinations; and type-safe code generation in target languages. Preliminary evaluation with large language models shows successful agent-driven tool selection and parameter configuration for standard neuroimaging analyses including preprocessing pipelines, registration workflows, and statistical modeling.

LLM-assisted metadata refinement improved descriptor quality by identifying missing parameters, ambiguous documentation, and constraint inconsistencies. Community feedback loops enable continuous improvement of tool descriptions. Generated wrappers integrate with existing workflow frameworks (Nipype, Snakemake) while remaining framework-agnostic, usable with any parallel processing solution. Container integration ensures reproducible execution across computing environments. Citation metadata integration enables direct export to reference managers for proper tool attribution. The complete ecosystem is open-source, ensuring transparency and community extensibility.

Conclusion

The NiWrap Hub transforms neuroimaging tool access from manual documentation parsing and scripting to interactive discovery and AI-ready programmatic interfaces. By providing comprehensive metadata, compiler-generated wrappers, and a unified platform serving both human researchers and AI agents, we establish infrastructure for current research practices while enabling emerging AI-assisted workflows. The platform democratizes access to sophisticated neuroimaging software, eliminating installation barriers and reducing the learning curve for complex interfaces. MCP integration positions neuroimaging tools for evolving research paradigms where AI agents assist with tool selection, parameter optimization, and workflow construction based on high-level scientific objectives. LLM-assisted metadata refinement creates sustainable quality improvement cycles, leveraging AI to continuously enhance tool descriptions based on usage patterns. This open ecosystem invites community participation in shaping how researchers, both human and AI, access and utilize neuroimaging computational tools, providing a sustainable path forward for modernizing neuroimaging infrastructure while preserving battle-tested tool implementations.
