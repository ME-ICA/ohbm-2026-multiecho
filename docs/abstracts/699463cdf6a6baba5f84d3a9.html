Introduction

Traditional fMRI analysis typically utilizes predefined brain atlases to extract functional connectivity (FC) features. Although this method is widely used, it has several inherent limitations. First, FC features are usually derived from a single static correlation metric (such as the Pearson correlation coefficient), which does not adequately capture the complexity and temporal dynamics of brain activity. Second, FC features emphasize inter-regional relationships, potentially missing information present in the local context. Third, the traditional pipeline depends on atlas definitions that are based on prior assumptions about brain organization, which may obscure individual differences.

In our work, we aim to address these limitations by developing a novel approach, called TIMBER (TIMe series eMBedded Representation), which leverages transformer architectures to extract more informative features from fMRI time series with minimal prior assumptions. The key idea, similar to autoencoder models, is to learn a low-dimensional representation of the fMRI time series that captures the spatial-temporal structure of brain activity and filters out non-neural variability sources, such as sampling errors or physiological artifacts.

We proved that:

- The TIMBER model effectively learns low-dimensional representations of fMRI time-series, segmenting the cortex into spatial clusters that correspond to distinct functional networks.

- The learned representations serve as effective features for predicting individual behavioral measures, outperforming the traditional FC-based features. Notably, we observed substantial improvements in predicting fluid intelligence scores, a measure sensitive to brain dynamics ^1.

- The embedding space produced by TIMBER offers a flexible framework for incorporating prior knowledge, such as phenotypic information, into the model.

Methods

The TIMBER architecture, as depicted in Figure 1, consists of 4 blocks. First, the raw fMRI signal is split into patches by a tokenizer. These patches are preprocessed to inject a spatio-temporal context into each of them, then compressed by an encoder into a latent array of fixed size. By randomly masking the patches before encoding, we force the model to infer high-level structures in the brain organisation. We finally use the latent array as context and a pre-processed patch as query to predict, via a decoder, the next patch in time. This forecasting task aims to make the model, and therefore its representations, sensitive to the dynamics of the signal.

Here, we detail the 4 blocks:

- Tokenizer: this module divides the fMRI time-series into non-overlapping windows (patches), analogous to tokens in large language models. Each patch covers a short time interval (60 timepoints). A learned positional embedding indicating the vertex location is concatenated to each patch. To reduce input size, we randomly sample 1,024 vertices from the cortex (out of 59,412 total) for each run. Additionally, a random window of 900 timepoints is selected from the full 1,200 timepoints to prevent the model from memorizing the data.

 - Preprocessor: Based on the PatchTST architecture ^2, this block extracts features from each patch (intra-patch level) and introduces spatial and temporal context by applying self-attention across patches (inter-patch level). Instead of using positional encoding for time, we apply a causal mask in the self-attention layers to prevent the model from accessing future time points, thereby making the forecasting task more challenging.

 - Encoder: Using the Perceiver IO architecture ^3, the encoder aggregates information from the preprocessed patches into a fixed-size latent array (512 vectors of size 256 in our experiments). Cross-attention layers enable the encoder to focus on relevant spatial and temporal features, compressing the high-dimensional input while retaining essential information. To encourage the encoder to infer brain structures, we mask 70\% of the patches during training, requiring it to predict missing data from the observed context. 

 - Decoder: The decoder is designed for the self-supervised pretext task, specifically forecasting in our case. It receives the latent array from the encoder (context) and the preprocessed patches (queries), and utilizes cross-attention layers to reconstruct the next 60 time points from the previous 60. The output is a set of predicted patches, which are compared to the ground truth using L2 loss for training.

We pre-train the model using resting-state fMRI data from 200 subjects in the HCP dataset (accounting for about 20% of the total data). After this pre-training phase, we extract the encoder's latent array for every run of the test set (750 HCP subjects). Each of these latent arrays can be seen as a compact representation of the fMRI time series. The preprocessed patches are also retained as input features. Both of these representations are then utilized for downstream tasks, specifically for predicting or classifying individual phenotypic measures. We emphasize that the model training is self-supervised, meaning that no phenotypic labels were used during this process.

Results

The TIMBER model learns the functional organization of the brain.

As shown in Figure 2A, the TIMBER model effectively segments the cortex into spatial clusters that correspond to known functional networks. Each map is associated with one vector of the latent array embedding and represents the related attention weights in the first cross-attention layer of the encoder. We also proved that this structure exists upward in the preprocessed patches. This indicates that the model captures meaningful spatial patterns in the fMRI data, despite being trained solely on a forecasting task without explicit supervision regarding brain organization.

Extracted features from TIMBER demonstrate strong predictive performance for individual behavioral measures, surpassing most state-of-the-art methods in predicting fluid intelligence.

We assessed the predictive power of the learned features (preprocessed patches and latent arrays) on individual behavioral measures in the HCP test set. As illustrated in Figure 2B, TIMBER features consistently outperform traditional FC-based features across various measures. For fluid intelligence, a metric sensitive to brain dynamics ^1, the preprocessed patches achieved a Pearson correlation coefficient (PCC) of 0.37 and a Mean Absolute Error of 0.74 (for standardized measures), surpassing the performance of many leading methods. By comparison, BrainGNN^4, a model based on Graph Neural Networks, reaches a PCC of 0.28 and a MAE of 0.79. More recently, BrainMT^5, which utilizes the Mamba selective state space model, reported a higher PCC of 0.41 and a similar MAE of 0.74. Nevertheless, it is essential to note that BrainGNN and BrainMT are supervised models, whereas TIMBER is pre-trained in a self-supervised manner.

Incorporating phenotypic information during training enhances the model's ability to classify such attributes in the test set.

A logical next step is to incorporate phenotypic information—such as gender, age, or cognitive scores—into the TIMBER model during training. We tested this by introducing contrastive learning on a subset of the latent space for gender classification. Preliminary results on a reduced setting show that classification accuracy increased from 0.86 to 0.91. For comparison, the baseline using FC matrix features achieved an accuracy of 0.87. These findings indicate that the TIMBER embedding space can effectively integrate phenotypic information, improving classification performance.

Conclusion

TIMBER proves to be a promising self-supervised model, capable of providing richer representations of the fMRI signal than the traditional FC matrix. In particular, these representations demonstrate high predictive power on phenotypic measures sensitive to brain dynamics, surpassing or equaling state-of-the-art deep-learning models that are generally trained in a supervised manner.

Additionally, our results were obtained using a very limited training dataset comprising only 200 subjects. To handle this data scarcity without overfitting, we leveraged the richness of every run by subsampling a limited number of channels (1K out of 60K) each time, offering a different view of the recording at every training step. Moreover, by focusing only on a subsequence of the run each time (900 time points out of 1,200), all the patches are different across the training steps. This diversity of inputs extracted from a single run avoids the overfitting issue; however, as a drawback, it can cause the model to capture unwanted low-level information.

Finally, the modularity of the architecture, composed of simple sub-modules based on proven models (PatchTST^2 and PerceiverIO^3), enables scalability, making TIMBER suitable for future brain foundation models.
