Introduction

Gradient echo echo-planar imaging (GRE-EPI) is currently the most frequently used blood oxygenation level dependent (BOLD) scanning sequence for depth-dependent functional magnetic resonance imaging at ultra-high field strengths (>= 7 T). However, GRE-EPI faces challenges such as image distortion and a bias towards large draining veins located on the cortical surface.

Balanced steady-state free precession (bSSFP) offers a distortion-free alternative BOLD scanning sequence that can be considered less prone to macrovascular biases1, thus potentially reflecting neuronal activity more closely. However, bSSFP experiences lower functional contrast-to-noise ratio compared to GRE-EPI. As such, the choice of scanning sequence might affect the quantification of intricate functional signatures across cortical depths, such as visual population receptive fields (pRFs) – the region of visual space a population of neurons within a voxel is sensitive to.

In this pilot study, we therefore measured pRFs in the human primary visual cortex2 using both bSSFP and GRE-EPI at 9.4 T and submillimeter resolution, laying the foundation for future depth-dependent comparisons between these sequences.

Methods

Scanning: After giving written informed consent, one subject was scanned at a Siemens Magnetom Plus 9.4 T scanner and an in-house developed 16Tx/31Rx head coil. Two runs of each functional sequence, 3D bSSFP3 and segmented 3D GRE-EPI4, were acquired in each of the four sessions with 0.8 mm isotropic resolution and a static B1+ shim using the vendor’s implementation. The sequence parameters are listed in Figure 1A. Moreover, in each session, a short functional run (11 volumes) using a reversed phase-encoded (posterior to anterior) version of the segmented 3D GRE-EPI sequence was performed for distortion correction. For all functional runs, the imaging slab was oriented parallel to the calcarine sulcus (see Figure 1B). Lastly, one T1-weighted anatomical scan was performed in each session using a magnetization-prepared rapid acquisition with gradient echoes (MPRAGE) sequence with 0.6 mm isotropic resolution (matrix size = 352x352x320 px, CAIPIRINHA = 2x2Δ1, FA = 7.4°, TI = 1480 ms).

Experimental paradigm: The pRF mapping paradigm2 used a flickering checkerboard bar that swept across the visual field (1 step/TR) with an attention task on a central fixation dot. See Figure 1C for a detailed description of the stimulus paradigm.

Data analysis: For cortical surface reconstruction in FreeSurfer, an anatomical template was created from bias-field corrected and skull-stripped MPRAGE scans of all four sessions via ANTs. Each functional run underwent motion correction using SPM and additionally in the case of GRE-EPI, distortion correction using TopUp in FSL. Next, each functional run was co-registered to the anatomical template via boundary-based registration and projected onto the cortical surface without smoothing using FreeSurfer (projection fraction = 0.5), before undergoing linear detrending and z-standardization. Subsequently, the noise ceiling (NC) was calculated via the Spearman-Brown prophecy formula using these preprocessed  functional runs5 in three ways. First, using all 8 runs for GRE-EPI. Second, using all 8 runs for bSSFP. Third, using only the 2  runs of the first session for GRE-EPI to increase comparability to 8 runs bSSFP. Next, pRF modelling was performed for these 3 datasets after averaging across the respective set of runs. For this, a 2D Gaussian pRF model (see Figure 1D) in SamSrf X was used, estimating pRF position (x0, y0, eccentricity, and polar angles) and pRF size (sigma) in degrees of visual angle (dva), as well as determining the goodness-of-fit (R2). 

Results

Figure 2 shows the eccentricity, polar angle, sigma, R2 and NC maps for all three datasets (bSSFP 8 runs, GRE-EPI 2 runs, GRE-EPI 8 runs) on the inflated cortical surface of the left hemisphere. The delineation of V1 is shown by the colored lines.

The NC maps revealed much higher positive values for GRE-EPI 8 runs compared to bSSFP 8 runs, suggesting that the corresponding pRF parameter maps are not directly comparable, which we attribute to the lower functional contrast-to-noise ratio of bSSFP. This was also reflected in the R2 maps. However, when comparing bSSFP 8 runs to GRE-EPI 2 runs, both the NC and R2 maps became more comparable, although slight differences remained. As such, we based all further comparisons on these two datasets.

For both GRE-EPI 2 runs and bSSFP 8 runs, the eccentricity map showed that the central visual field is represented more posteriorly, while the peripheral visual field is represented more anteriorly in V1. Similarly, in both cases, the polar angle maps revealed that the upper visual field is represented more ventrally, and the lower visual field more dorsally, and that polar angle reversals are located at the border of V1. These topographic gradients reflect expected retinotopic patterns. Moreover, for both GRE-EPI 2 runs and bSSFP 8 runs, the eccentricity and polar angle maps appeared relatively comparable, suggesting that more fine grained analyses are necessary to reveal putative differences in pRF parameters. The only marked difference occurred for larger eccentricities, particularly in more superior portions of V1 (blue circles in Figure 2), which we attribute to the smaller imaging slab and poorer excitation profile of bSSFP (see Figure 1B).

When it comes to the sigma maps, no clear topographic gradient was evident in V1 for either GRE-EPI 2 runs or bSSFP 8 runs, which we attribute to the limited extent of our pRF mapping stimulus (maximum eccentricity: 4.36 dva). Moreover, the comparability of the sigma maps for the two datasets appeared limited, suggesting that more runs are required for quantifying the sigma parameter robustly.

Conclusion

Our results demonstrate the feasibility of visual pRF mapping at submillimeter resolution and 9.4 T for both GRE-EPI and bSSFP, whilst highlighting challenges when it comes to comparing pRF parameters between these sequences. To address these challenges, we made the NC and R2 maps more comparable by reducing the number of runs for GRE-EPI to two. After this adjustment, the pRF position maps reflected expected retinotopic gradients and seemed relatively comparable between both sequences. However, the number of runs used for either sequence appeared insufficient for quantifying pRF size robustly. As such, future work will involve more runs for bSSFP and conduct test-retest reliability analyses, before comparing pRF parameters in different cortical depths.
