Introduction

Over the past few decades, the study of the brain as a complex network has advanced significantly, driven by progress in neuroimaging techniques. Functional magnetic resonance imaging (fMRI) has enabled an increasing range of methods to capture the spatiotemporal properties of brain signals. In this context, we highlight recent advances in whole-brain effective connectivity (EC) estimation, which can isolate subject-, task-, and condition-specific signatures of brain dynamics. Once fitted, the brain network model can be used to simulate in-silico stimulation and quantify the activity propagation as a proxy measure of integration across the the brain, with a view to understanding information processing in cognitive tasks and neuropathological conditions.

Methods

The EC estimation relies on the fitting of simulated blood-oxygen-level dependent (BOLD) signals to empirical signals by adjusting the pair-wise EC weights (or strengths) between the regions in a dynamic network model. EC thus governs the propagation of fluctuating BOLD activity in the network model. In our case, we use a multivariate Ornstein-Uhlenbeck process as a linear-feedback generative model for the BOLD signals [Gilson 2020]. This approaches is closely related to model design choices for the regression dynamic causal model (DCM). We stress the importance of robust model inference to apply this framework at the whole brain level, consisting of a dynamic network model of hundreds of regions whose EC is optimized. To that end, we provide recent results that compare various EC estimation methods, in line with recent Bayesian methods [Ziaeemehr 2025].
The complexity is defined built from stimulating the model fitted to data and measures the network response to any given node (see figure). Importantly, this approach can be applied to a model tuned using ongoing fMRI data without experimental stimulation and can be framed in the perspective of transposing network theory to dynamic systems [Zamora-López 2024]. We also bridge the theory to account for spontaneous activity seen as a perturbation that propagates in the network, following recent work on entropy production in this dynamic framework [Gilson 2023].

Results

We apply this framework on the Human Connectome Project to show how task-evoked fMRI provides a testbench for this new definition of complexity. In line with previous work (see figure), we compare the complexity of brain dynamics in different brain conditions, both at the whole network level and more finely at the regional level. We show how the reconfiguration of EC across cognitive tasks changes the propagation of activity. We compare our approach to established approaches like the perturbation complexity index and  control theory applied to dynamic functional connectivity.
We also compare different estimation methods to estimation whole-brain effective connectivity in a brain network model of hundreds of regions, yielding thousands of parameters to estimate for each fMRI session. We show the importance of the estimation method on decoding, based on cognitive tasks as different conditions. We explain why the robust estimation is crucial for the subsequent in-silico experiment that underlies the quandification of complexity for brain dynamics.

Conclusion

Our recent development of complexity for network dynamics offers a suitable framework for application to fMRI data. Pursuing efforts to incorporate in a single framework several key aspects to analyze brain dynamics, we discuss how whole-brain EC can be useful for pathological biomarkers, in line with recent publications on the study of consciousness disorder or stroke. In particular, we stress the importance of the network approach to uncover and disentangle alterations related to nodes in the network from those concerning subnetworks.
