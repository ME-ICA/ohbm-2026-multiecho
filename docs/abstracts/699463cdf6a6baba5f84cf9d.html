Introduction

Blood oxygen level dependent (BOLD) fMRI is inherently blind to the cellular and molecular mechanisms that give rise to it1. Novel methods such as Receptor-Enriched Analysis of functional Connectivity by Targets (REACT) aim to bridge this gap by linking neurotransmitter distributions to systems-level dynamics2. 

 

The standard REACT pipeline employs a multivariate (“together”) dual-regression model to weight fMRI data against multiple normative positron emission tomography (PET) maps simultaneously2. Theoretically, this isolates unique contributions and avoids omitted variable bias1. However, this also assumes molecular distributions are spatially distinct. In reality, neurotransmitter systems exhibit high intrinsic spatial correlation both between (e.g. 5HT vs. dopamine) and within systems (e.g. 5HT-2A vs. 5HT-1A). Recent work demonstrates that highly collinear receptor combinations cannot be disentangled using the conventional “together” model3,4. Moreover, the competition of PET maps for variance renders the topology of molecular-enriched networks arbitrarily conditional on the specific input set, distorting downstream analyses and hindering reproducibility. 

Here, we critically evaluate the impact of PET map collinearity on molecular-enriched network estimation using REACT. We compare the standard multivariate (“together”) implementation against a univariate (“separate”) approach which shifts disentangling receptor contributions from the subject- to the group-level. Leveraging a pharmacoimaging dataset comparing Lysergic Acid Diethylamide (LSD) to placebo, we benchmark these approaches using: (1) collinearity metrics; (2) test-retest reliability; and (3) the ability to disentangle receptor contributions to the pharmacological and phenomenological facets of the psychedelic state.

Methods

Fifteen healthy volunteers (mean age = 30.5 ± 8.0 years, 11 females) underwent two scanning sessions in a balanced within-subjects design. Participants received either LSD (75 μg in 10 mL saline) or placebo (10 mL saline). ~70 min post-dosing, two resting-state fMRI runs (7 min each, TR = 2s) were acquired on a 3T GE HDx system. Data underwent standard preprocessing (motion correction, registration, nuisance regression, 0.01-0.08 Hz bandpass filtering, 6mm smoothing).

We utilized high-resolution normative PET data from neuromaps (github.com/netneurolab/neuromaps) for LSD's main receptor targets5: serotonergic 5HT-1A, 5HT-2A, and transporter 5HTT, alongside dopaminergic D1 and D2. All fMRI and PET data were resampled to 2mm (ANTs resampleImage) and parcellated using a Schaefer-400 cortical plus Tian-32 subcortical atlas, ensuring representation of subcortical regions densely innervated by monoaminergic systems implicated in psychedelic action.

Subject-specific receptor-enriched functional networks were estimated using two implementations of the REACT dual regression framework (github.com/timlawn/parcellated-REACT). The standard multivariate “together” pipeline entered all five PET maps as simultaneous regressors in the first step (spatial regression), extracting dominant fluctuations associated with each system. The resulting time series were entered into a single multivariate GLM for the second step (temporal regression) where they were regressed against every brain region's time series. Thus, receptor systems compete for variance to isolate unique contributions to connectivity2. In contrast, the univariate “separate” pipeline treated each receptor independently in both steps, generating molecular-enriched connectivity maps unconditioned on other receptor systems' dynamics. Molecular-enriched networks were averaged across runs within subject except for reliability analyses. 

We evaluated these pipelines across multiple dimensions. First, we quantified multicollinearity using variance inflation factors (VIF) for the “together” model. Second, we examined similarity (Spearman's ρ) between networks derived from the two pipelines. Third, test-retest reliability (Spearman's ρ) was evaluated by correlating repeated runs (Run 1 vs. Run 3) within each condition and compared between models using paired permutation tests (10,000 permutations). Fourth, we examined LSD's pharmacodynamic specificity and effect size differences between pipelines. LSD-induced connectivity changes (LSD > Placebo) were tested at each parcel using paired permutation tests (10,000 permutations), with FDR correction and a Bonferroni-adjusted threshold across receptors (q < 0.01). We then computed parcel-wise effect sizes (Cohen's d) and compared global mean effect sizes between pipelines using paired permutation tests at the subject level (10,000 permutations). Finally, reproducibility of Cohen's d effect maps was evaluated by correlating (Spearman's ρ) drug effects from each run at the group level, with pipeline differences tested using subject-level bootstrap resampling (10,000 iterations). Finally, we performed Connectome-Based Predictive Modelling (CPM) to establish behavioural relevance. Factor Analysis (promax rotation) of the Altered States of Consciousness (ASC) questionnaire identified latent phenomenological factors. Leave-One-Out Cross-Validation (LOOCV) predicted factor scores from drug-induced connectivity changes. Within each fold, parcels correlating with behaviour (p < 0.1) were summed separately by sign (positive minus negative) to create model features. Model performance was quantified as Spearman's ρ between observed and predicted values, with significance tested via permutation (10,000 iterations).

Results

The “separate” and “together” pipelines produced similar but visually divergent molecular-enriched networks associated with each receptor system (Fig. 1a). Evaluation of the PET maps revealed severe spatial multicollinearity with VIFs exceeding the problematic collinearity rule of thumb cutoff (>5) for all receptors except 5HTT (VIF = 4.0) in the “together” model (Fig 1b). The competition for variance in the “together model systematically altered network estimation pipelines showing imperfect spatial correspondence which varied by receptor (Fig 1c, Spearman's ρ ranging 0.48-0.94). These differences reflect the destabilizing effects of collinearity on network estimation, with “together” models yielding significantly lower test-retest reliability compared to “separate” models across most receptor systems (Fig. 1d): 5HT-2A and D1 (both p < 0.001), 5HTT (p = 0.007), and 5HT-1A (p = 0.024). Only the D2 network showed similar reliability between pipelines (p = 0.17).

The choice of pipeline also altered characterization of LSD's pharmacodynamics. “Separate” models successfully recovered LSD's known receptor specificity3, showing robust connectivity changes (LSD > Placebo) predominantly within the 5HT-2A network (84 parcels, FDR-corrected q < 0.01), with minimal effects at other receptors. In contrast, “together” models showed diminished results (9 parcels in 5HT-2A networks; Fig 2a). Scatterplots comparing t-statistics across receptor systems revealed that “separate” models that these were also more strongly selective (biased towards x-axis, Fig 2a) for the 5HT-2a receptor compared to all other systems. Bootstrapping confirmed that “separate” models produced significantly larger mean effect sizes (Cohen's d) for 5HT-2A (p = 0.022) and D1 (p = 0.029), with all receptors showing numerically larger effects in “separate” versus “together” models (Fig 2b, left). Test-retest reliability of effect sizes was numerically higher for “separate” models across all receptors (separate: ρ = 0.39-0.76; together: ρ = 0.24-0.61), though differences did not reach statistical significance (Fig 2b, right).

Factor analysis of the ASC questionnaire identified three latent dimensions of the psychedelic experience (Fig 2c): Positive (F1; spiritual experience, blissful state, changed meaning of percepts, experience of unity, and insightfulness), Negative (F2; disembodiment, anxiety, and impaired control and cognition), and Perceptual (F3; complex imagery, audio-visual synaesthesia, and elemental imagery). Connectome-Based Predictive Modelling (CPM) demonstrated superior behavioural prediction from “separate” networks (Fig 2d). The 5HT-2A network specifically predicted Perceptual alterations (F3; ρ = 0.52, p = 0.030), while D1 networks predicted both Positive experiences (F1; ρ = 0.51, p = 0.028) and Negative (F2; ρ = 0.65, p = 0.005), with 5HTT also predicting Positive experiences (F1; ρ = 0.51, p = 0.028). Predictive models included parcels with both positive relationships (increased connectivity associated with stronger phenomenology) and negative relationships (decreased connectivity associated with stronger phenomenology). Positive predictive parcels were anatomically concentrated in default mode network whilst negative predictive parcels were distributed across frontal, temporal, insular, opercular amygdala, and hippocampal regions (Fig 2d, bottom). In contrast, "together" models yielded only a single significant prediction (D1 → F2; ρ = 0.50, p = 0.027), which was weaker than for the “separate” model and demonstrates markedly reduced behavioural validity.

Conclusion

Collinearity among PET receptor maps fundamentally compromises conventional multivariate REACT models. The “together” implementation introduces an arbitrary dependence problem where results for any given receptor become contingent on which other receptors are included in the model. Moreover, when these molecular systems exhibit high spatial correlation, multicollinearity destabilizes network estimates, undermines reliability, and obscures established pharmacology. 

Network topology differed between pipelines, reflecting the intended competition among PET maps for variance in the “together” model. However, this competition creates instability rather than specificity. When receptor distributions spatially overlap, multivariate models cannot distinguish genuine receptor-specific signals from arbitrary repartitioning of shared variance. This results in reduced reliability, attenuated effect sizes, and diminished behavioural prediction. Thus, the “together” approach performs poorly in its intended purpose of disentangling receptor contributions in the presence of high multicollinearity. 

The recovery of 5HT-2A specificity within the “separate” models provides crucial pharmacological validation and refines our prior findings3. The 5HT-2a receptor has long been established as the main target of serotonergic psychedelics, with ketanserin (a 5HT-2a partial agonist) blocking both subjective and neural effects5. Previously, using multivariate voxelwise REACT, we demonstrated differential contributions of serotonergic versus dopaminergic systems to LSD’s phenomenology². The current “separate” models both replicate this serotonergic-dopaminergic dissociation while revealing 5HT-2A receptor specificity that was previously obscured by collinearity with other serotonergic receptors. Moreover, the strength, specificity, and reproducibility of these effects was greater in the “separate” compared to together models, although the latter did not reach significance. Crucially, despite high collinearity between 5HT-1A and 5HT-2A receptor maps, “separate” models show clear 5HT-2A but not 5-HT1a effects, demonstrating the ability to disentangle contributions at the group level. Moreover, behavioural predictions were stronger using “separate” models, suggesting the original pharmacological insights were genuine but attenuated by collinearity-induced instability. 

Spatial collinearity among PET receptor maps fundamentally undermines multivariate REACT by introducing arbitrary analytic dependencies that can destabilize network estimates and obscure established pharmacology. Univariate models circumvent this limitation by shifting receptor disentanglement from subject- to group-level, successfully recovering LSD's known 5HT-2A specificity with superior reliability and behavioural prediction. We therefore contend that univariate approaches provide a more principled foundation for linking receptor systems to network dynamics, offering robust multi-scale insights into mechanisms of drugs and disease.
