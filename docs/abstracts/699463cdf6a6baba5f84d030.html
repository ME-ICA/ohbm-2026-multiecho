Introduction

Neurofeedback (NFB) systems rely on real-time feedback to help users learn to self-regulate their brain activity 1. While substantial progress has been made in signal processing and machine-learning approaches for estimating neural states, the design and implementation of complete NFB pipelines remain fragmented. In particular, real-time feature extraction, artifact handling, and the translation of neural signals into intuitive and engaging feedback are often implemented ad hoc, limiting reproducibility and slowing down methodological innovation. As NFB studies increasingly emphasize transparency and replicability, there is a critical need for open-source, user-friendly tools that support standardized workflows while remaining flexible enough for advanced research. Such frameworks should enable researchers with diverse levels of experience to prototype, test, and deploy real-time paradigms efficiently. Optional integration with established platforms such as MNE-Python 2—a widely used, beginner-friendly library for electrophysiological data analysis further strengthens accessibility and promotes consistent analytical pipelines across laboratories.

We introduce ANT (https://payamsash.github.io/ANT/), an open-source Python package that provides a unified, user-centered framework for real-time M/EEG neurofeedback research. ANT integrates robust artifact-rejection modules, flexible pipelines for real-time neural feature extraction, and visualization tools for online signal monitoring. Moreover, ANT includes visual feedback modules intentionally designed around the known properties that shape user experience—incorporating aesthetic quality, clarity, and semantic representation to support engaging and effective neurofeedback. By combining methodological rigor, MNE-Python compatibility and accessible design, ANT facilitates the development and deployment of scalable, reproducible, and user-centered NFB paradigms.

Methods

The ANT workflow consists of two stages: an optional baseline session followed by the main real-time neurofeedback session. In the baseline stage, a short M/EEG recording is acquired to prepare subject-specific models for online processing. When available, each participant’s structural MRI is used to compute the forward model and inverse operator; otherwise, a FreeSurfer template anatomy is used. These operators are stored to enable rapid real-time transformation of sensor-level activity into source space during the main session. In this stage, ANT also extracts a topographic template of blink-related activity for subsequent ocular artifact suppression. During the main session, data are streamed through the lab streaming layer 3 (LSL) into ANT’s processing pipeline, where optional preprocessing steps can be applied depending on modality and experimental needs, including average referencing, Signal Space Projection for MEG, homogeneous field correction for OPM-MEG, or Online Recursive ICA (ORICA) in which. components highly correlated with the blink template are automatically removed. ANT provides a broad suite of algorithms for real-time neural feature extraction: at the sensor level, users can compute band-limited power, band-ratio metrics (e.g., alpha/theta), entropy measures such as Approximate, Sample, Spectral, and SVD entropy, connectivity metrics including Phase Lag Index (PLI), Phase Locking Value (PLV), coherence, and related measures, as well as tracking metrics such as argmax_freq (frequency of maximal power), individual_peak_power (power around the subject-specific peak frequency), and cross-frequency coupling between user-defined bands. At the source level, ANT computes band-limited power and connectivity between cortical parcels defined by the “aparc” and “aparc.a2009s” FreeSurfer atlases. The package also implements graph-learning methods at both sensor and source levels, estimating a graph structure that best represents the spatial organization of ongoing neural activity following 4, from which users may select connections as neurofeedback features. Real-time visualization modules allow continuous inspection of raw and preprocessed signals, extracted neural features, and online source-level activations. Features are temporally smoothed using band-limited filtering to avoid abrupt fluctuations before being passed to the visual feedback engine, which drives real-time stimuli presented to participants. For each subject, ANT automatically creates an output directory storing raw and preprocessed signals, extracted features, method-specific delays, inverse operators, and all metadata required for reproducibility and subsequent offline analysis.

Results

Figure 1 illustrates the overall architecture of the ANT neurofeedback pipeline. In the initial baseline phase, short M/EEG recordings are used to generate a subject-specific forward model and inverse operator based on the channel montage and the participant’s sMRI. During this phase, ANT also extracts a blink-related topographic template that is later used for online ICA-based artifact removal. In the main session, streamed data undergo preprocessing such as average referencing or modality-specific corrections before real-time computation of the selected neurofeedback (NF) features. These features are then routed to custom visual feedback modules while all intermediate and final outputs—raw data, preprocessed data, extracted features, model operators, and metadata—are automatically stored in the subject directory.

Figure 2a presents an example of ANT’s real-time feature extraction pipeline using simulated M/EEG data containing artificial alpha band activation restricted to the left pericalcarine cortex. Six neural features including (from top to bottom) individual peak power, sensor level graph learning, sensor level connectivity (PLI), Spectral entropy, band ratio and sensor level power were computed in parallel. On the right (Figure 2b), a real-time visualization of cortical activation is shown using a PyVista-rendered cortical surface. Figure 2c showcases several of the visual feedback designs implemented in ANT. These designs are driven directly by the extracted neural features and are crafted to align with established principles of effective NF visualization, emphasizing aesthetic quality, clarity, and meaningful semantic representation. This ensures that the feedback is not only accurate but also engaging and intuitive for participants, thereby supporting more effective self-regulation. To quantify ANT’s performance across modalities, we benchmarked computation delays for each feature type using 64-channel EEG data at a sampling rate of 500 Hz. As shown in Figure 2d, simple metrics such as band-power computation exhibit extremely low latency (~25 µs), while computationally intensive methods—such as source-space graph learning—reach delays on the order of ~500 ms. These results demonstrate that ANT can reliably support fast-responding NF paradigms while providing flexibility for more complex feature-based designs when higher latencies are acceptable.

Conclusion

ANT provides a flexible and extensible framework for real-time neural signal analysis, bridging advanced computational neuroscience methods with practical Brain–Computer Interface (BCI) and neurofeedback applications. By combining multimodal compatibility, a broad library of neural feature extraction methods, and adaptive visual feedback designs grounded in principles of aesthetic quality, clarity, and semantic representation, ANT has the potential to enhance user engagement, support more effective learning, and streamline the development of reproducible closed-loop experiments. Its modular architecture enables researchers to deploy complex real-time pipelines with minimal overhead while maintaining full transparency and customizability.

Although already fully functional, ANT remains open for continued development and community-driven extension. Possible improvements include integrating advanced real-time artifact correction tools such as Generalized Eigenvalue De-Artifacting Instrument (GEDAI) 5, incorporating normative models of healthy controls to enable individualized and deviation-based feature selection, expanding the library of visual feedback designs using frameworks such as py5, and enhancing user-friendliness through tighter integrations with widely used tools like MNE-Python. By remaining open-source and inviting contributions from the broader neuroscience community, ANT aims to accelerate the translation of state-of-the-art signal processing and computational methods into applied neurofeedback and BCI research.
