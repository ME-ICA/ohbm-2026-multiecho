Introduction

The hMRI toolbox is an internationally developed open-source software project hosted on GitHub and built on SPM, designed to enable the generation of quantitative MRI (qMRI) maps including R1, R2*, PD, and MTsat [1]. The major public release v1.0.0 of the toolbox has recently been officially pre-released (https://github.com/hMRI-group/hMRI-toolbox/releases) on GitHub, introducing a range of important new features. These include new modules that implement advanced image denoising with two state-of-the-art methods as options, the quantification of errors on qMRI maps, and a correction for motion-related image degradation in statistical analyses through the QUIQI framework [2,3,4]. Additional improvements such as refined mask creation and tissue-weighted smoothing further enhance the accuracy and robustness of analyses. In this work, we present these new features, which form the foundation of the major public release and mark a significant step forward in the development of the hMRI toolbox.

Methods

The toolbox features a configurable denoising module accessible through a dedicated GUI that applies state-of-the-art techniques. Both the LCPCA and MPPCA denoising methods (Fig.1) have been added as options to the denoising module, embedded with comprehensive pre- and post-processing pipelines that include NIfTI and metadata handling with JSON sidecar outputs and the capability to be flexibly pipelined with other modules. In addition, the LCPCA option is seamlessly integrated via a custom-built Java-MATLAB interface, ensuring smooth interoperability across platforms. Error Maps provide voxelwise error estimates of quantitative maps for quality assurance and an additional module enables these error maps to be used as weights to robustly combine quantitative maps from successive acquisitions. The QUIQI module enhances motion-robust group analysis by implementing a data-driven solution that accounts for subject-specific motion, assigning weights to each map based on an index of image quality when performing group-level GLM estimations. 

Results

The newly developed denoising module demonstrates configurability and integration with other core processing steps through SPM batch dependencies. Different denoising methods are available as user-friendly options within a dedicated GUI, supported by full NIfTI compatibility, metadata handling, JSON sidecar outputs and a seamless integration into the toolbox. These features enable the denoising methods to be flexibly chained with other modules, ensuring streamlined and reproducible workflows. Notably, the LCPCA implementation—originally developed in Java—has been implemented with a custom Java-MATLAB interface, providing smooth interoperability across platforms and highlighting the toolbox’s emphasis on cross-platform efforts. Error maps provide a powerful means of evaluating local data quality variations and artifacts without requiring additional acquisitions, and their use results in more robust MPM parameters that demonstrate reduced variability at the group level compared to single-repeat or averaged counterparts (Fig. 2a). The QUIQI module further enhances statistical analyses by mitigating the effects of head motion on group comparison and regression, ensuring more reliable outcomes in motion-sensitive datasets (Fig. 2b). 

Conclusion

The latest advances in the hMRI toolbox reinforce its commitment to delivering high-quality image processing through modern, cross-platform software development. The introduction of a configurable denoising module with two denoising methods—including LCPCA, seamlessly integrated via a custom Java-MATLAB interface, both embedded into the toolbox with comprehensive pre- and post-processing pipelines—marks a significant step forward in usability and workflow efficiency. By combining denoising, robust data handling (NIfTI support, metadata management, JSON sidecar outputs), error quantification, and motion mitigation within a coherent workflow, the toolbox delivers comprehensive data handling and ensures reproducibility across studies.

These enhancements not only establish the hMRI toolbox 1.0 as a self-sufficient, easily configurable, and well-documented resource but also provide reliable biomarkers for in vivo histology, making it ideally suited for investigations into development, aging, and neurodegenerative/neuroinflammatory conditions [5]. Collectively, these advances reinforce the toolbox’s pivotal role in driving open-source neuroimaging research and supporting the next generation of MRI-based in vivo histology.
