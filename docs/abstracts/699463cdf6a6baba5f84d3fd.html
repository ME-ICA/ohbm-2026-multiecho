Introduction

Neuroimaging researchers and clinicians require visualization and analysis tools like Freeview, the FreeSurfer neuroimaging viewer [1]. While the widely-used desktop tools play a crucial role in scientific research, they are a poor fit for modern web and cloud deployments. They are cumbersome to obtain and start using, have slow and rigid feature release schedules, do not naturally enable collaborative work that will be central in upcoming large scale annotation efforts, and do not integrate well with analysis tool development that requires specialized compute resources.

We introduce FreeBrowse: an open-source, browser-based 3D neuroimaging viewer that will serve as the web-native successor of the widely used FreeView tool, overcoming existing limitations. FreeBrowse enables researchers, clinicians, and tool developers to visualize and analyze 3D neuroimaging data quickly, easily, and collaboratively. Employing a browser-based implementation will enable its use with no startup overhead, and facilitate a continuous release model where new features are immediately available to users.

Methods

FreeBrowse uses NiiVue [2,3] as the rendering engine. NiiVue is an open-source, WebGL2-based neuroimaging visualization library capable of displaying volumetric data, surface meshes, tractography streamlines, and statistical overlays across more than 30 file formats.

The FreeBrowse architecture is based on the Fullstack NiiVue Architecture  (github.com/niivue/fullstack-niivue-demo), a reference architecture developed during Google Summer of Code 2025 [4] that demonstrates an end-to-end solution for web-based visualizations to interact with analysis programs and remote files. The architecture consists of a React frontend with NiiVue for browser-native WebGL2 rendering, a FastAPI Python backend for data transfer and analysis orchestration, and PostgreSQL for persistent storage of imaging metadata and NiiVue scene documents. This modular design supports image upload, server-side analysis pipelines, and browser-based result visualization. It will also be possible to run deep learning models directly on the frontend. An additional NiiVue reference repository (github.com/niivue/niivue-scribble-promt) demonstrates this principle.

We build on NiiVue documents to support a core component of FreeBrowse.  These JSON-based scene descriptors capture the complete state of a visualization session, including loaded volumes, surfaces, colormaps, opacity settings, and viewing parameters. The format supports two modes for referencing imaging data: URLs pointing to external files, or base64-encoded data embedded directly within the document. This flexibility enables NiiVue documents to function either as lightweight scene metadata (referencing server-hosted imaging files) or as self-contained portable packages. Because the format is pure JSON, NiiVue documents integrate naturally with databases, REST APIs, and web-based workflows.

FreeBrowse supports two modes of operation. In its default cloud-based mode, a backend server provides persistent storage for loading and saving data. In ‘serverless’ edge-based mode, there is no backend server, and users can load and save data directly to their local machine. This mode enables lightweight static deployments and eliminates PHI exposure risk, since imaging data does not leave the user’s device.

Results

FreeBrowse is currently under active development.  Our existing prototype already enables users to:

  - Load NiiVue documents or volumetric imaging data from the backend or their local machine

  - Manipulate the view (e.g. change the contrast, opacity, colormap etc. of various volumetric layers)

  - Create and edit annotations using a pen or magic wand tool

  - Save all changes, either locally or to the backend server

  - Create URLs that will automatically load a NiiVue document to enable frictionless collaboration

We make the FreeBrowse source code available at github.com/freesurfer/freebrowse, and provide an edge-based ‘serverless’ usable tool at freesurfer.github.io/freebrowse.

Conclusion

FreeBrowse provides a modern, browser-based alternative to traditional neuroimaging viewers, eliminating installation barriers and enabling immediate access to new features through continuous deployment. Its dual-mode architecture balances the needs of collaborative research environments (with backend storage and shareable URLs) against privacy-sensitive clinical contexts (with fully client-side serverless operation).

In future work we plan to include 4D volume support, surface support, user authentication, and integration with important AI neuroimaging tools, like ScribblePrompt [5], to enable AI-assisted interactive segmentation directly in the browser.
