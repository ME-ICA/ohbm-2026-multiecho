Introduction

The challenge of aggregating large multi-site neuroimaging cohorts for joint analysis is primarily driven by strict governance constraints that prohibit the sharing of sensitive raw data. While the centralized Label-noise filtering-based dimensional prediction (LAMP)1 method is highly effective at handling label noise and refining clinical labels to create cleaner cohorts for downstream analyses, such as those involving functional network connectivity (FNC), its requirement for raw data aggregation limits its real-world, multi-institutional application. This work introduces Federated LAMP (Fed-LAMP), a privacy-preserving adaptation of LAMP. Fed-LAMP's core design allows sites to perform typical-subject selection, confidence calibration, and prototype updates locally, thereby coordinating multi-site efforts while sharing only aggregated statistics or model parameters without ever transmitting the original raw data.

Methods

Fed-LAMP reformulates the original centralized LAMP workflow into a series of iterative local and remote steps.

  • Local Identification and Summary: Each participating site first identifies "typical subjects"—those with reliable labels—using complete random forest (CRF) models to measure label stability. Simple feature selection is applied using two-sample t-tests to create a reduced feature set. The site then computes the average feature vector (local summaries) for its healthy control (HC) and patient groups, and only these summaries are shared with the remote aggregator.

  • Global Model Aggregation: The aggregator receives and aggregates the local summaries across all sites to form global centroids (prototypes) for the HC and patient groups. These global references are then sent back to every site, ensuring all sites work with the same, shared global information while preserving privacy.

  • Dimensional Scoring and Relabeling: Each site computes a dimensional score for every subject by measuring its distance from the global healthy and patient centroids. This score reduces thousands of imaging features to a single, interpretable value. The aggregator combines all scores to compute one global threshold, which is returned to the sites. Each site then applies this threshold consistently to relabel subjects as strongly healthy, strongly patient, or boundary cases, with the new labels being used in the next iteration.

Results

Fed-LAMP is evaluated using two separate datasets, COBRE2 (157 subjects) and FBIRN3 (311 subjects), which function as two collaborating sites containing Schizophrenia (SZ) patients and HC. The CRF step identifies 103 typical subjects in COBRE and 191 in FBIRN. Group differences are compared using edge-wise two-sample t-tests on FNC matrices before and after relabeling. The relabeled data produces significantly sharper t-maps with stronger magnitudes and fewer isolated noise edges, demonstrating that the groups are cleaner and more separable post-relabeling. Crucially, the functional network connectivity patterns derived from the federated approach are confirmed to be almost identical to those from the centralized LAMP method (Fig. 2). A scatter plot confirms this strong agreement, validating that the Fed-LAMP implementation preserves the original centralized behavior while protecting data privacy.

Conclusion

Fed-LAMP successfully introduces a federated algorithm for relabeling neuroimaging data that eliminates the need for any raw data sharing to perform a combined multi-site analysis. By sharing only aggregated summaries, the federated model delivers identical results when compared to its centralized counterpart. This approach effectively reduces label noise and yields stronger, more robust group differences than the original, un-relabeled setup. Fed-LAMP thus offers a practical, scalable, and privacy-compliant framework for robust discovery in large-scale neuroimaging studies.
