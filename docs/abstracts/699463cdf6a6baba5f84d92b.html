Introduction

Large-scale brain simulation is a key tool for integrating multimodal neuroimaging data, testing mechanistic hypotheses, and linking micro- to macro-scale brain dynamics. Platforms such as The Virtual Brain (TVB) enable biologically grounded simulations driven by subject-specific connectivity, but constructing complete simulation pipelines remains complex, fragile, and difficult to reproduce. These workflows require expert knowledge and are highly sensitive to changes in data resolution, parcellation, and modeling choices.A more fundamental limitation is scalability. High-resolution datasets such as BigBrain provide surface meshes with tens of thousands of vertices per hemisphere. Although TVB supports surface-based models, its reliance on dense geodesic kernel operators leads to superlinear memory growth, effectively limiting stable surface simulations. As a result, high-resolution multimodal simulations aligned with BigBrain surfaces or vertex-level EEG/MEG projections are infeasible in standard TVB workflows. To address this, we employ a Region-Specific Brain Network Model (RSBNM) simulator that replaces geodesic diffusion with a sparse graph Laplacian defined on mesh adjacency. This yields linear memory scaling, enables efficient GPU execution, and supports full-resolution surface meshes. This shift fundamentally enables high-resolution, multimodal simulations that are not tractable with existing TVB surface methods. . However, increased resolution also amplifies workflow complexity. To manage this, we introduce NeuroAgents, an agentic framework that converts natural language instructions into fully configured, validated, and reproducible brain simulation pipelines. NeuroAgents acts as a workflow compiler, orchestrating typed tool calls, enforcing validation, recording full provenance, and handling errors. We demonstrate NeuroAgents on an end-to-end pipeline combining siibra/TVB connectivity extraction with high-resolution RSBNM simulations.

Methods

Agentic Workflow Framework (NeuroAgents)

NeuroAgents is an agentic workflow framework that translates natural language instructions into validated, reproducible brain simulation pipelines. Rather than executing free-form actions, the agent operates as a workflow compiler that maps user intent to typed tool invocations with explicit schemas, artifact validators, and provenance tracking. Each tool exposes a strict input/output contract, enabling deterministic execution, automatic parameter extraction, and structured error handling. The agent coordinates two domain-specific tools: (i) structural connectivity preprocessing and (ii) high-resolution brain simulation. Decision rules constrain the agent to minimal tool calls (one or two per request) and enforce safe behavior under ambiguity or malformed inputs. When validation fails, the agent applies recovery policies (e.g., parameter correction, re-execution, or safe failure) rather than producing corrupted artifacts.

Structural Connectivity Processing

Subject-specific structural connectivity is retrieved from the siibra / Ebrains knowledge graph. Connectivity matrices are filtered to the right hemisphere and mapped from fine-grained atlas labels to a fixed target label set that includes cortical and hippocampal regions. We aggregate weights, tract lengths, and node centers while preserving all target regions to maintain TVB compatibility.

Processed connectomes are exported as TVB-compatible connectivity ZIP archives containing weights, tract lengths, region labels, node centers, cortical masks, and default dipole orientations, alongside CSV/NPY sidecar files. Validators ensure matrix consistency, label alignment, and successful TVB loading.

High-Resolution RSBNM Simulator

We employ a Region-Specific Brain Network Model (RSBNM) simulator to enable vertex-level brain dynamics on high-resolution surfaces. RSBNM uses a normalized graph Laplacian defined on sparse mesh adjacency. This formulation requires only local 1-ring neighborhood information, yielding linear memory scaling and efficient GPU execution.

Simulations are performed on stitched cortex–hippocampus surface meshes (~81k vertices) using a Zetterberg–Jansen neural mass model. The simulator integrates local graph-based diffusion with long-range structural connectivity, stochastic noise, and region-to-vertex mapping. Sparse adjacency is constructed directly from surface triangles, enabling fast GPU diffusion without storing large geodesic neighborhoods.

Multimodal Outputs

During simulation, we record vertex-level snapshots at fixed intervals and project activity to EEG sensors using a precomputed vertex-to-sensor gain matrix. Outputs include time-stamped vertex snapshots (NPZ), EEG time series (NPZ), interactive 3D visualizations (HTML), and rendered animations (MP4). Validators ensure numerical stability (no NaNs/Infs), expected array shapes, and biologically plausible parameter ranges.

Benchmark Design

We evaluate NeuroAgents using a task suite spanning connectivity-only, simulation-only, chained, and ambiguous/malformed instructions across 10 subjects. Success is defined as producing all required artifacts with all validators passing. Reproducibility is measured via artifact hash consistency for deterministic outputs and tolerance-based agreement for floating-point results across repeated runs.

Baselines and Comparison

We compare against (i) a manual expert pipeline, (ii) a monolithic scripted pipeline, and (iii) a naïve agent without schemas or validators. To contextualize scalability and fidelity, we benchmark RSBNM vertex-level simulations against standard TVB regional (mean-field) simulations, comparing runtime, memory usage, and neurodynamics plausibility metrics (power spectral density, functional connectivity, temporal autocorrelation).

Results

End-to-end agentic execution.
Across the full task suite, NeuroAgents successfully translated natural language instructions into executable brain simulation pipelines, producing validated structural connectivity files, simulations, and multimodal outputs without manual intervention. For well-specified requests, the instruction-to-artifact success rate exceeded 95%, with failures occurring primarily in intentionally malformed or biologically implausible queries, which were safely rejected or corrected.

High-resolution brain dynamics.
Figure A shows a representative vertex-level activity map generated by the RSBNM simulator on a stitched cortex–hippocampus surface (~81k vertices). RSBNM successfully executed full-resolution simulations using sparse graph-Laplacian diffusion on the GPU. This enabled stable, high-fidelity spatial dynamics directly on BigBrain-scale meshes.

Multimodal signal generation.
Figure B illustrates EEG time series obtained via vertex-to-sensor projection during the same simulation. The signals exhibit structured temporal fluctuations with realistic amplitude variability and inter-channel diversity. Power spectral density analysis (not shown) revealed characteristic 1/f-like decay and physiologically plausible frequency content, supporting the neurodynamical plausibility of the simulated activity.

Spatiotemporal evolution.
Figure C presents time-resolved snapshots of vertex activity over a 10-second simulation window. Activity patterns evolve smoothly over time, preserving spatial coherence while exhibiting non-stationary dynamics. These snapshots highlight the ability of RSBNM to capture fine-grained spatiotemporal structure that is inaccessible to regional mean-field simulations.

Comparison with TVB regional mode.
When benchmarked against TVB regional simulations, RSBNM demonstrated comparable temporal dynamics while providing orders-of-magnitude higher spatial resolution. GPU execution enabled practical runtimes within the experimental budget, confirming RSBNM as a scalable alternative for high-resolution multimodal brain simulation.

Conclusion

We introduced NeuroAgents, an agentic framework that enables natural language interaction with high-resolution brain simulation pipelines while preserving reproducibility, scalability, and scientific rigor. By abstracting complex multi-script workflows into typed, validated tool calls, NeuroAgents transforms brittle expert-driven procedures into reliable, end-to-end computational workflows that can be executed autonomously from natural language instructions.

A key contribution of this work is the integration of a GPU-accelerated Region-Specific Brain Network Model (RSBNM) capable of vertex-level simulations on full-resolution cortical and hippocampal surface meshes (~81k vertices). In contrast to existing TVB surface simulations, which rely on dense geodesic kernels and become intractable beyond ~40k nodes, RSBNM leverages sparse graph-Laplacian diffusion defined directly on mesh adjacency, enabling linear memory scaling and efficient execution. This allows NeuroAgents to operate on multimodal, high-resolution datasets such as BigBrain, which are inaccessible to standard TVB surface models.

Through systematic benchmarking, we demonstrated that NeuroAgents reliably converts natural language requests into validated simulation artifacts, robustly handles ambiguous or malformed instructions, and produces reproducible outputs with full provenance tracking. Comparisons with TVB regional simulations show that RSBNM preserves biologically plausible temporal dynamics while providing substantially richer spatial detail, enabling the study of fine-scale spatiotemporal patterns and multimodal signal generation (e.g., EEG projections).

Beyond neuroscience, this work illustrates a general paradigm for agentic scientific computing, where large language models coordinate domain-specific tools rather than generate unverifiable code or results. By embedding constraints, validators, and explicit artifact generation into the agent loop, NeuroAgents bridges the gap between interactive AI systems and trustworthy scientific workflows.

All components of NeuroAgents—including code, benchmarks, and evaluation protocols—are released openly to support reproducibility and community adoption. We believe this approach represents a significant step toward scalable, accessible, and high-resolution computational neuroscience, and provides a blueprint for deploying agentic systems in other data- and simulation-intensive scientific domains.
