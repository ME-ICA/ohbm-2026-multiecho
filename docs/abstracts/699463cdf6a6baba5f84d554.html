Introduction

The cerebral cortex is often studied using surface-based methods, where the cortical mantle is represented as a mesh made up of vertices with morphological properties (e.g. thickness, gyrification). Working with these brain representations is often technically challenging, as it requires specialised software and complex command-line pipelines (e.g. FreeSurfer).

Methods

We introduce verywise, an R package specifically developed for running advanced vertex-wise statistical analyses in a way that is both user-friendly and computationally efficient. The goal of this open-source software is to streamline the full workflow (from reading pre-processed surface data, through model fitting and multiple-comparison correction, to visualisation and functional interpretation of the results) so that users can focus on scientific questions rather than the technical plumbing.

verywise supports several vertex-wise (univariate) statistical models, including linear mixed models (lmm). In short, lmm contain both fixed effects, which are constant across samples (e.g. age, sex), and random effects, which are not (e.g. measurement time, or scanner), allowing users to address complex study designs, including longitudinal and/or multi-site studies.

Results

verywise is an open-source R package under active development (https://seredef.github.io/verywise/; source code: https://github.com/SereDef/verywise). Some key features of verywise (version 1.2) include: 

1) flexible model specification using familiar R formula notations; 

2) extensive support for confounding and selection bias correction (e.g. missing data handling, inverse-probability weighting); 

3) fast and memory-safe computations (i.e. leveraging out-memory, parallel processing); 

4) modular design (e.g. general model object handling, so the software can easily be extended to new methods); 

5) interactive 3- and 2-D visualization of the resulting brain maps (with verywise-WIZard extension: https://seredef-verywise-wizard.share.connect.posit.cloud/; source code: https://github.com/SereDef/verywise-wizard)

Conclusion

We introduce verywise: a new R package developed for running advanced vertex-wise statistical analyses in a way that is both user-friendly and computationally efficient.
