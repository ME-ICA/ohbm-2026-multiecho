Introduction

Data visualization is paramount to neuroimaging, as implied by its name. Neuroimaging research is also a heavily computational discipline, by nature of how image processing algorithms facilitate data analysis. Atlas-type brain datasets, produced by modern computational processing techniques, have potential usefulness to clinicians for education and reference. They are used to teach and learn neuroanatomy. Furthermore, when paired with advanced data visualization tools, atlas datasets can provide measurements for normal brain development. The usefulness of brain atlas datasets is contingent upon the capabilities of data visualization software.
Both visualization and analysis software typically require sophisticated installation procedures and are sometimes exclusive to Linux-based operating systems. The complexity of scientific software, as well as their demanding hardware requirements, have motivated the development of HPC and cloud-based computing platforms. While non-interactive data pipelines are relatively easy to port to platform-based computing, interactive visual software poses unique challenges. Brainlife.io1, a science gateway specialized for neuroscience research, has pioneered an approach where desktop visualizer software run server-side and are video-streamed to a client web browser. This solution leverages existing popular neuroimaging software. However, recent trends and innovations in web development create the opportunity to conceive web native solutions with better features and greater performance. The integration of open-source computing platforms with web visualization technologies and clinically useful brain atlases could enable new applications of existing research outputs by creating a bridge between compute, visualization, and clinical use.

Methods

We developed a NiiVue2 applet within the ChRIS Research Integration Service3. NiiVue is a web component for 3D dataset visualization, supporting a plethora of neuroimaging file formats such as NIFTI. It uses WebGL2 and offers a TypeScript API making it highly performant and customizable. To integrate NiiVue with ChRIS we developed niivue-react, a software library wrapper which facilitates how NiiVue is used in the React.js front-end framework.

ChRIS is an open-source neuroscience computing platform. In contrast to centralized web applications (e.g. BrainLife.io), ChRIS embraces a “federated” architecture, independent control, and ownership of data. We deployed a dedicated ChRIS backend on the New England Research Cloud’s OpenShift cluster. To this instance we uploaded two publicly available fetal brain MRI datasets, one by Gholipour et al.4 and Serag et al.5 This instance of ChRIS is publicly accessible at the website http://fetalmri.org.

Results

While the fetalmri.org website is a public resource, the ideal of open science was in fact a secondary objective of this project. Fetalmri.org was developed for use by residents and practicing clinicians at the Fetal Care and Surgery Center of Boston Children’s Hospital. Our minimal and 100% anonymous telemetry reveals that fetalmri.org is used daily by 10–20 users for an average duration of 3m58s. The most commonly used feature is the measurement tool, which is used to inform clinicians on normative values for the size of cortical and sub-cortical brain regions during healthy development.
We reported and solved several bugs in NiiVue in collaboration with their development team. In particular, recent development has greatly enhanced NiiVue’s functionality with responsive design. As such, fetalmri.org works well on tablet and phone screens. Furthermore, these improvements have benefited the development of JuPyTer and VSCode plugins for NiiVue as well as the NiiVue iOS app.

Conclusion

The multiple facets of medical research: basic science, computational analysis, and clinical application, are traditionally pursued independently. Fetalmri.org demonstrates the capacity for open-source web technology to help these avenues converge. Brain atlas datasets, a cornerstone of computational research and brain data processing, have found use in the clinic and directly contribute to patient care. Fetalmri.org and ChRIS uniquely enable datasets to become online interactive educational tools, even for niche sub-specialties such as fetal MRI. Furthermore, fetalmri.org showcases the modernization of research and science engagement in general by transforming the literal practice of computational neuroscience from computer work at a desk to something that can be done on the phone.

Additionally, there is potential in how fetalmri.org is the integration between data visualization and science gateway technologies. Although the atlas datasets uploaded to fetalmri.org were not meaningfully post-processed, the underlying ChRIS platform nonetheless manages the data provenance—in this case, the renaming and reorganization of data. This pipeline instance, albeit menial, is fully reproducible. We anticipate that the colocalization of a dataset with visualization software, a computing platform, and built-in features for data provenance tracking, will contribute to motivating the implementation of best practices such as data sharing and reproducibility in computational neuroimaging research, all while forming a trustworthy hub for promoting software and data as valuable tools for patient care.
