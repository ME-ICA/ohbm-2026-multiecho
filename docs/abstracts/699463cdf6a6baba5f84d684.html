Introduction

A large body of fMRI studies has focused on associating brain activity with specific tasks, with the goal of identifying brain regions engaged during task performance. However, most experimental tasks recruit multiple cognitive processes simultaneously, making it difficult to disentangle individual functions. For example, tasks involving visual stimuli may engage visual perception, attention, and memory retrieval. Can we disentangle these functions and map them onto distinct neural substrates? If so, could we then study how different cognitive functions contribute to the observed brain activity during task execution?

In this study, we aimed to characterize brain function from a cognitive perspective by mapping cognitive processes onto voxel-level networks using fMRI data. Our work moved beyond predefined tasks and contrasts toward a representation of brain function based on a comprehensive cognitive ontology.

We used the Individual Brain Charting (IBC) project^1,leveraging its annotations of cognitive functions derived from the Cognitive Atlas^2. These annotations were used to create a “concept space”; an occurrence matrix that links cognitive terms to brain activation patterns.

Using an adaptation of sparse representation framework based on dictionary learning, we then estimated the contribution of each cognitive function to the observed neural activity. This approach produced individualized cognitive maps, offering a fine-grained view of how cognitive processes are localized and distributed across the brain.

Methods

For this study, we used two publicly available resources: the Cognitive Atlas^2 and the Individual Brain Charting (IBC) dataset^1. The Cognitive Atlas is a collaborative knowledge base that provides a structured ontology of cognitive concepts and their relationships. The IBC dataset is a deep-phenotyping resource in which 12 participants performed more than 80 cognitive tasks, yielding over 300 statistical contrast maps per subject. Each contrast map was annotated with cognitive functions from the Cognitive Atlas, indicating the processes engaged by each task.

Based on these annotations, we built a binary occurrence matrix in which rows correspond to contrast maps and columns to cognitive terms. Matrix entries indicated whether a term was associated with a given contrast.

To map cognitive functions to brain activity, we used the occurrence matrix as a design matrix in a general linear model (GLM), with the fMRI contrast maps as the dependent variables. This approach allowed us to estimate the contribution of each cognitive function to the observed activation patterns, producing one beta map per cognitive term, which we call cognitive maps. The cognitive maps reflect the spatial distribution of activity linked to each cognitive function, thereby mapping cognitive processes onto voxel-level brain networks.

We then hypothesized that the binary occurrence matrix could be relaxed to allow continuous weights for each cognitive term, reflecting the degree to which a cognitive function contributes to each contrast map. To estimate these weights, we adapted a sparse coding framework^3, which decomposes a signal as a sparse linear combination of dictionary elements. In our case, the contrast maps form the signal Y, and the initial occurrence matrix serves as the initial sparse code A.

For each subject, the procedure was as follows:

  • Dictionary Estimation: We estimated the dictionary D by regressing Y onto the initial sparse code A, and normalized each row to unit l2-norm.
  • Sparse Code Update: Using D, we updated the sparse code A by solving a non-negative sparse coding problem with l1-regularization, enforcing non-negativity constraints.
  • Objective Evaluation: We monitored convergence by computing the reconstruction error using a l1-regularized loss.

Using the updated sparse code as our design matrix, we ran a new GLM to estimate maps for each cognitive function. To ensure robustness, each subject's GLM used the average sparse code computed from all other subjects as the design matrix. We also computed a null model by randomly permuting the correspondences between cognitive terms and contrasts in the design matrix.  All implementations of the GLM procedures were performed using the Nilearn Python package^4.

With the new set of maps derived from the weighted sparse code, we assessed improvements in the cognitive mappings by calculating the Pearson correlation between these maps and meta-analytic maps from Neurosynth^5.

Results

The binary occurrence matrix included 200 contrasts (rows) and 102 cognitive terms (columns), where a value of 1 indicated that a term was associated with a contrast, and 0 indicated no association. The construction of the binary occurrence matrix is depicted in Figure 1 (A), showing the process with three cognitive terms: emotional expression, face perception, and facial age recognition; assigned to two IBC contrasts: angry faces (emotion recognition task) and faces vs. others (category localizer).

In this simplified example, both contrasts included face perception, while angry faces alone included emotional expression and faces vs. others alone included facial age recognition. These term–contrast relationships are reflected in the binary occurrence matrix, where the column for face perception contains two entries of 1, and the other two terms appear only once.

Using the occurrence matrix, we estimated cognitive maps for each term. The resulting cognitive maps represent the spatial distribution of brain activity associated with each cognitive function. Figure 2 (left column) shows representative group-averaged maps obtained with this procedure.

Next, we adapted a sparse coding framework to estimate continuous weights for each cognitive term, replacing the binary occurrence matrix with a weighted representation. In Figure 1 (A), we illustrate the face perception example, showing that the corresponding column of the matrix no longer contains binary entries but continuous weights. Figure 1 (B) shows the same process applied to a larger subset of contrasts: the initial binary matrix (left) was progressively transformed into a weighted sparse code (right).

Using this weighted sparse code as the design matrix, we then fitted a new GLM and obtained a second set of cognitive maps, shown in Figure 2 (A, right column).

The ordering of maps, in Figure 2 (A-B), reflects the gain in similarity to meta-analytic maps from Neurosynth when using the weighted sparse code versus the binary occurrence matrix. For the term with the largest improvement (language processing), the weighted approach produced a more focal map with a stronger and slightly broader effect. In the median example (visual place recognition), the differences were more modest but still visible as a mild expansion of the effect. Finally, for hand side recognition, where the gain in correlation was near zero, the maps from both methods were nearly identical, with only minor differences in intensity.

Lastly, we evaluated the explanatory power of both models by computing the explained variance (R^2) across all voxels for each subject. Figure 2 (B) shows the distribution of R^2 values obtained using the binary occurrence matrix (blue) and the weighted sparse code (orange). We also computed a null model by randomly permuting the weighted design matrix and refitting the GLM; the median R^2 across voxels for this null model is shown as the red line. Both models substantially outperformed the null model, with the weighted sparse code consistently achieving higher explained variance than the binary matrix for nearly all subjects. This demonstrates that allowing continuous weights for cognitive terms improved the model’s ability to account for variance in brain activation patterns.

Conclusion

This study presented a novel framework for cognitive brain mapping by integrating a cognitive ontology and deep-phenotyping fMRI dataset from the IBC project. We hypothesized that each task (e.g., face recognition) engaged multiple cognitive components with varying degrees of contribution. Using a data-driven approach, we estimated weights for these components and used them to decompose fMRI contrast maps.

The resulting cognitive maps aligned with well-established findings in the literature:functions such as motor responses and visual processing appeared in expected regions of motor and visual cortex. The richness of the IBC dataset allowed us to go further, revealing fine-grained distinctions within cognitive domains. For example, we obtained separate maps for auditory recognition and auditory word recognition, highlighting distinct regions associated with general auditory processing versus language-specific auditory functions.

Although our method remained constrained by the quality and specificity of the annotations, it provided a principled way to quantify how cognitive terms contributed to brain activity patterns. This work provides a foundation for deeper exploration of spaces that represent cognitive processes, and highlights the value of cognitive ontologies and semantic definitions in fMRI analysis. 

We showed that introducing continuous weights for cognitive terms improved the model’s explanatory power and led to more precise cognitive maps, regarding the binary occurrence matrix baseline. Our data-driven weighting procedure, based on sparse coding, allowed us to assign differentiated coefficients to cognitive terms without imposing strong assumptions about their relationships.

Finally, comparison with maps from meta-analyses demonstrated that we could recover known population-level effects at the individual level. These results showed the potential of our framework for personalized cognitive brain mapping, while mitigating the impact of inter-subject variability on cognitive function localization.
