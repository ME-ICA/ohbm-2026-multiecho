Introduction

Multimodal brain maps derived from nuclear imaging, structural and functional MRI, spatial transcriptomics, and histology are increasingly used as reference for spatial inference methods, aiming to better understand MRI-based neuroimaging findings1. Yet these resources are typically distributed in heterogeneous formats, imaging spaces, and parcellations, which complicates analysis and reproducibility.  

NiSpace (NeuroImaging Spatial Colocalization Environment; https://github.com/leondlotter/nispace) is a Python-based toolbox to assess spatial correlations ("colocalizations") between brain maps2. It aims to be the most comprehensive, yet easy-to-use and flexible framework for reference data retrieval, colocalization estimation, and significance testing to date. NiSpace extends the widely used neuromaps toolbox3 in that it provides high-level workflow functionalities and advanced statistical methods, condensing, for example, a spatial correlation analysis with 48 different PET maps or an imaging-based gene-set enrichment analysis using the Allen Human Brain Atlas (AHBA) in a single command each.  

Here, we introduce the curated library of reference datasets currently included with NiSpace. We describe how the data are collected, standardized, and distributed, together with an exemplary validation of the standardization procedure.

Methods

We aim to include any publicly available dataset of group-level brain maps that is of interest to a broad range of users. To be included, a dataset has to have a license permitting modification and redistribution, provide a whole‑brain or whole-cortex coverage at the group level, and must be available in at least one of the currently supported standard imaging spaces (MNI152, fsaverage, fsLR) or in at least one of the currently supported brain parcellations (see Fig. 1). From the source dataset, we generate NiSpace reference datasets in as many of the currently supported imaging spaces as possible (MNI152NLin6Asym, MNI152NLin2009cAsym, fsaverage, fsLR). All data are stored in a GitHub repository separate to the library's main repository, referenced through stable identifiers, and accessed via the NiSpace Python API as either imaging files or parcellated table data. To ease straight-forward retrieval and analysis of data according to user preferences, and to facilitate set enrichment analyses, we additionally provide "collections" of maps within a given dataset. A collection subsets and/or groups maps into reasonable categories. This design aims to minimize manual handling of file formats, imaging spaces, and lookup tables. 

The nuclear imaging map collection ("pet") represents a special case in that the included maps are both the most used4,5 but also the most heterogenous. Extending the nuclear imaging data provided with the neuromaps toolbox, NiSpace includes standardized versions of all maps, which were non-linearly co-registered with a deep learning assisted procedure (https://martinos.org/malte/synthmorph/), scaled, and masked. To demonstrate the advantage of our standardization procedure, we show how the voxel-wise correlation between three PET maps using the same tracer (ABP688, binding to the mGluR5 receptor) but obtained from independent samples improves after standardization.

Results

Fig. 1 summarizes the datasets included with the current NiSpace release, integrating multimodal molecular, structural, functional, and transcriptomic datasets across imaging spaces. The library includes 48 different PET maps, transcriptomic resources derived from the Allen Human Brain Atlas, meta‑analytic functional maps, resting‑state network probability maps, cortical topology and function from MRI, MEG, and histology, tissue probability maps, and large collections of spatially structured null maps for methods development. During retrieval of parcellated data, tables are flexibly combined between cortical and subcortical parcellations to achieve whole-brain coverage.  

Our preliminary validation of the PET map standardization procedure showed (1) that the voxel-wise spatial correspondence between independent PET maps using the same tracer was generally very strong and (2) that this spatial correlation increased furthermore after standardization, speaking in favor of our approach (Fig. 2).

Conclusion

By distributing a curated library of standardized reference datasets, NiSpace lowers the barrier to reproducible multimodal spatial inference on brain maps. Users can combine PET, MRI‑derived features, transcriptomics, meta‑analytic functional maps, histological gradients, and spatial null models within a single framework, without manually managing template spaces, parcellations, or file formats. With its library, NiSpace enables applications such as testing spatial correspondence between new experimental data and established molecular or transcriptomic spatial distributions, functionally decoding MRI-based effect maps, or performing neuroimaging gene-set enrichment analyses in both volumetric and surface spaces.  

The resource is designed to be extensible and will be continuously advanced, with user requests for new datasets handled via GitHub issues (https://github.com/LeonDLotter/NiSpace/issues).
