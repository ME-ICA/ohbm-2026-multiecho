Introduction

Whole-brain patterns of brain activity–i.e., brain states–change over time. These changes help support ongoing behavior. The connectome–the network of physical wires between neural elements–is thought to play a central role in shaping and constraining brain activity. Understanding how the wiring supports brain state changes remains a central aim of neuroscience.

Network control theory (NCT) represents a potentially useful framework for addressing these questions. NCT, and specifically optimal control, can be used to quantify the ease with which a networked dynamical system transitions from one state to another (so-called “control energy”). To date, the overwhelming majority of NCT applications have been applied to non-invasive human neuroimaging datasets. These studies have provided significant insight into the role played by the connectome in supporting state transitions. A key limitation, however, is that human structural networks reconstructed from diffusion MRI are undirected by construction. Consequently, it is unclear what role directed edges and connectome asymmetry might play in state transitions.

We address this question directly, leveraging two non-human animal datasets: whole-brain two-photon calcium imaging (2PCI) of the larval zebrafish brain (n=36), and functional magnetic resonance imaging (fMRI) in C57BL/6J mice (n=18). For both, we use group-representative, invasively reconstructed connectomes to constrain our optimal control simulations: a zebrafish connectome reconstructed from 4,327 single-cell morphologies1, and a mouse connectome derived from 428 viral microinjection experiments2.

We use optimal control theory and network models to quantify the minimum energetic cost of observed state transitions when preserving, to varying extents, different structural aspects of the connectome. We also investigate the impact of directionality by calculating control energies in directed and transposed connectomes.

Methods

Datasets. No additional processing was performed on either dataset:

  1. Zebrafish 2PCI data were acquired as previously described by Légaré et al., 20243.

  2. Mouse fMRI data is publicly available4.

States. We z-scored individual timeseries for all nodes (i.e., ROIs). For a range of k (2-20), we performed k-means clustering (100 iterations per k) on the timepoints of z-scored activity to identify an optimal number of states. To measure the similarity of clustered solutions, we calculated the adjusted Rand Index and obtained consensus labels using agglomerative clustering We define a state as a 1-dimensional vector of nodes, where each entry corresponds to the mean z-scored activity across the clustered time points for that node. 

SC. Each entry in the adjacency matrix is the total number of structural connections between two nodes. We zeroed out the diagonals to exclude self-connections. We normalize the adjacency matrix by dividing it by the largest eigenvalue and subtracting the identity matrix to prevent explosive growth.

Control. We consider a linear time-invariant dynamical system whose state at time t can be described as a differential equation. We use optimal control theory to calculate the minimal control signals associated with each state transition. We calculate the energies for the intact connectome for both datasets. Additionally, we transposed the intact connectome and compared the resulting control energies to those of the untransposed connectome.

Null Models. We use four null-network models, each preserving a different aspect of the intact connectome. To enable an effective comparison of results to the intact connectome, we maintain the number of nodes and edges for all null models. In addition to these,: 1) The Erdos-Renyi generative model keeps no geometric features. 2) The Maslov-Sneppen model iteratively swaps weights at random while only preserving the degree of each node. 3) The geometric randomized model generates edges probabilistically, with nodes that are farther apart having a lower probability of being connected (i.e., e(-β * distance)). 4) The minimally wired model is a deterministic geometric generative model that only connects nodes with the shortest distances.

Results

We found 6 to be the optimal number of states for both zebrafish (Fig. 1A) and mice (not shown). We observed this result for each combination of approach and distance metric across all levels of parcellation (not shown) for data collected from both animal models. We found that the control energies for 86.11% of all state transitions were lower in the empirical connectome compared to the transpose (Fig. 1B). With few notable exceptions, the intact connectome is associated with lower-energy state transitions compared to all four null-network models that preserve unique structural features (Fig. 1C). More specifically, the intact connectome outperformed randomly generated connectomes with randomized weights (p=0.02 for 1/36 transitions and p<0.01 for 4/36 transitions). Rewiring the connectome to preserve shorter distances probabilistically also outperformed the intact connectome 88.89% of the time (p<0.01 for 4/36 transitions). When only preserving the nodal degree distributions, the energetic cost for 94.46% of state transitions was lower for the intact connectome (p=0.03 for 1/36 transitions and p<0.01 for 1/36 transitions).

Similarly, by preserving selected aspects of structural connectivity in mice, we found that the intact connectome outperforms all four null-network models for all state transitions (not shown). This suggests that the connectome's structural architecture has evolved to minimize energetic costs for most global state transitions.

In the zebrafish connectome, the most notable exceptions common to all null-network models concern state transitions out of the high-activation state (Fig. 1D). Transitions from the high-activation state to the mirrored hemisphere-specific tectal/hindbrain states require less energy in a randomized network. For these state-specific transitions, connectomes generated to preserve shorter distances (geometric and minimally wired) also outperform the intact connectome. However, the opposite is true for the reversed state transitions. This suggests that shorter connections alone are more energetically favorable for transitions from high-global-activity to high-hindbrain-activity, but are costly for transitions in the reversed order.

Unlike in zebrafish, we did not identify a single high-global-activity state in mouse fMRI data (likely because mice are anesthetized during fMRI acquisition). We did, however, find three sets of mirrored states (akin to zebrafish hindbrain states) (not shown). The intact mouse connectome outperformed the null-network models for all state transitions (not shown).

Conclusion

The intact zebrafish and mouse connectomes generally outperform four null-network models that preserve different features of structural connectivity. Furthermore, directed edges and connectome asymmetry facilitate low-energy state transitions.
