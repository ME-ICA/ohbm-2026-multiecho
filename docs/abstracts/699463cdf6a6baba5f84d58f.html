Introduction

Understanding how brain activity unfolds over time and how these dynamics relate to behaviour, physiology, remains a major challenge in human neuroscience. Advances in neuroimaging have enabled increasingly sophisticated models of time-varying brain activity yet principled statistical inference on brain dynamics is still limited. In particular, many existing approaches lack a unified framework for hypothesis testing that generalises across experimental paradigms, accommodates different study designs, and provides robust control of confounds and multiple comparisons.

Here, we present a general statistical framework for testing hypotheses about brain dynamics derived from functional neural data. The framework is designed to support both resting-state and task-based experiments and enables inference on relationships between dynamic brain patterns and non-imaging variables. Statistical significance is assessed using permutation-based testing and structured Monte Carlo resampling, allowing handling of hierarchical data structures and minimal reliance on parametric assumptions.

Importantly, the framework prioritises accessibility and reproducibility. It is implemented as an open-source Python toolbox with both graphical and scripting interfaces, making advanced analyses of brain dynamics available to researchers with diverse technical backgrounds. Through illustrative examples, we demonstrate how statistical inference on brain dynamics can be performed in practice across different experimental settings.

Methods

We describe a statistical framework for hypothesis testing of brain dynamics derived from functional neural data. The framework operates on time-resolved representations of brain activity obtained from standard preprocessing pipelines and can be applied to both resting-state and task-based experiments.

Brain dynamics are characterised using statistical models that capture temporal structure in the data and summarise activity into a set of dynamic brain patterns. For each participant, these patterns are summarised using time-resolved or aggregate measures that reflect their expression over time. These measures are used as inputs to subsequent statistical analyses. The framework does not depend on a specific dynamic model and supports application across different data types and experimental paradigms.

Statistical inference is performed using permutation-based testing and structured Monte Carlo resampling. This allows testing of relationships between brain dynamics and non-imaging variables, such as behavioural or physiological measures, while controlling for confounding variables. Hierarchical dependencies in the data are handled using constrained permutation schemes, including family relationships between subjects. Multiple comparisons are addressed using established procedures, including family-wise error correction, false discovery rate control, and cluster-based permutation testing, with minimal reliance on parametric assumptions.

All analyses are implemented in an open-source Python toolbox with both graphical and scripting interfaces. The toolbox allows users to specify hypotheses, define confounds, select appropriate permutation schemes and exchangeability constraints, and visualise results without requiring custom statistical code.

Results

We demonstrate the proposed framework on multiple functional neuroimaging datasets to illustrate its applicability across experimental paradigms and analysis settings. The results show that the framework enables statistical inference on brain dynamics while accounting for confounding variables, dependency structures, and multiple comparisons.

Across both resting-state and task-based datasets, statistically significant associations are observed between dynamic brain patterns and non-imaging variables, including behavioural and physiological measures. Constrained permutation schemes account for dependency structures in the data, including family relationships between subjects, ensuring valid group-level inference.

Results obtained using the software implementation are reproducible across datasets and analysis configurations. Analyses yield consistent statistical results when the same hypotheses and permutation settings are applied.

Conclusion

We present a general statistical framework for hypothesis testing of brain dynamics derived from functional neural data. The approach provides a unified method for performing statistically valid inference on time-varying brain activity across both resting-state and task-based experiments, while accounting for confounding variables, dependency structures, and multiple comparisons.

By combining permutation-based testing with structured Monte Carlo resampling, the proposed approach enables flexible and assumption-light statistical inference in settings commonly encountered in neuroimaging studies, including datasets with family relationships between subjects. The results show that statistically significant associations between brain dynamics and non-imaging variables can be identified across experimental paradigms.

The approach is implemented in an open-source Python toolbox that supports reproducible analyses and practical application without requiring custom statistical code. This work contributes a principled and accessible solution for statistical testing of brain dynamics and supports more rigorous inference in studies of time-varying brain activity
