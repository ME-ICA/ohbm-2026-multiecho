Introduction

Traditional network analysis of resting-state fMRI in posttraumatic stress disorder (PTSD) examines direct pairwise connectivity, failing to capture how brain regions communicate indirectly through intermediate hubs. Mediation network analysis overcomes this limitation by identifying connections where information flow is relayed through third-party mediator nodes 1. We hypothesized that key brain hubs—particularly the posterior cingulate cortex and medial prefrontal cortex of the default mode network—serve as critical mediators integrating information across large-scale networks 2. We predicted that PTSD would exhibit disrupted mediated connectivity between limbic, attentional, and sensory networks routed through these default mode hubs, alterations that would be invisible to traditional connectivity analysis. Furthermore, we hypothesized sex-specific patterns of mediated connectivity alterations, given well-documented sex differences in PTSD prevalence and symptomatology 3. 

Methods

Resting-state functional magnetic resonance images were obtained from trauma-exposed controls (N=126, 39.5±10.3 years) and individuals with PTSD (N=37, 41.1±10.8 years) and preprocessed using standard pipelines through HALFpipe. The preprocessing steps included spatial smoothing with a 6.0 mm FWHM Gaussian kernel, slice timing correction, grand mean scaling, temporal filtering, and ICA-based confound regression. Time courses were extracted from the Schaefer 400-parcel atlas and averaged within Yeo's 17 functional networks, with each network serving as a node. For each of 17 mediation networks, one node was designated as the mediator while mediated connections between all remaining 16 node pairs were quantified using upsilon (υ), a stable effect size measure of indirect effects 4, see Fig. 1. PTSD-related alterations in mediated and traditional connectivity were examined using linear regression models controlling for sex, age, and age-squared, implemented via the IBMMA package for multi-site neuroimaging analysis 5. Sex-by-diagnosis interaction effects were tested to identify sex-specific patterns. All findings survived false discovery rate (FDR) correction (p<0.05, two-tailed) across all connections and mediators (for mediation network analysis only).

Results

Significant PTSD diagnosis-by-sex interactions emerged for mediated pathways in two mediators’ networks (p_FDR<0.001), with no significant main effects of PTSD diagnosis. Sex-stratified post-hoc analyses revealed effects exclusively in females. When the default-A network (medial prefrontal cortex/precuneus) served as mediator (Fig. 2 left), females with PTSD exhibited stronger mediated connectivity from the dorsal attention-B network (postcentral gyrus/frontal eye fields) to the visual-peripheral network compared to female controls (t=3.713, p_FDR<0.001). When the visual-central network served as mediator (Fig. 2 right), females with PTSD showed elevated mediated connectivity from the limbic-B network (orbitofrontal cortex) to both the visual-peripheral network (t=4.987, p_FDR<0.001) and the control-C network (posterior precuneus/posterior cingulate cortex; t=3.929, p_FDR<0.001). Males showed no significant case-control differences for either mediated pathway (all p_FDR>0.05). Importantly, traditional functional connectivity analyses between these same node pairs revealed no significant effects of PTSD diagnosis or PTSD-by-sex interactions (all p_FDR>0.05).

Conclusion

This study identified female-specific alterations in mediated functional connectivity in PTSD, with the default-A and visual-central networks serving as key mediators linking limbic, attentional, and visual systems, potentially reflecting symptoms of heightened vigilance and sensory re-experiencing seen in PTSD. These alterations were undetectable through traditional functional connectivity analyses, demonstrating the value of mediation network approaches. The sex-specific patterns may contribute to well-documented sex differences in PTSD prevalence and symptomatology, highlighting distinct neurobiological mechanisms between males and females. The identified mediator nodes represent potential targets for sex-specific neuromodulation interventions.
