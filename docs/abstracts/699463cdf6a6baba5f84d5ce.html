Introduction

Digital MRI phantoms are essential for validating and benchmarking neuroimaging methods in a controlled environment. The widely used BrainWeb phantom (https://brainweb.bic.mni.mcgill.ca/brainweb/) provides realistic tissue contrast, but is limited in the representation of highly complex structures, as the hippocampus and cerebellum, but also by the availability and accuracy of extended tissue classes, such as blood vessels, skull, dura mater, and bone marrow. Additionally, it is restricted to a small number of cases where these labels are available. These limitations constrain the applicability of this method for validation tasks, especially for algorithms that are sensitive background tissue, such as sequences with high-intensity backgrounds (e.g., MP2RAGE).

Recent advances in digital brain phantoms have improved anatomical realism and image synthesis quality. However, many existing approaches use ground-truth labels defined as hard tissue classes ^1. This limits their suitability for the quantitative validation of voxel-wise measures because these labels do not reflect partial volume effects at tissue boundaries. 

Meanwhile, there is an increasing need for robust benchmarking frameworks for segmentation approaches, especially novel deep learning–based methods, whose performance is strongly influenced by the characteristics and implicit biases of training data.  Furthermore, no publicly available MRI phantom currently allows for the explicit simulation of cortical thickness variations, which is a prerequisite for validating the accuracy and sensitivity of cortical thickness estimation pipelines.

To address these limitations, we developed T1-MRI-Phantom (https://github.com/ChristianGaser/T1-MRI-Phantom), a framework for generating anatomically realistic T1-weighted MRI volumes with controllable artifacts, pathology, and cortical thickness while providing  explicit ground-truth label images.

Methods

The pipeline begins with a high-quality T1-weighted MRI volume that is segmented into six tissue classes: gray matter, white matter, cerebrospinal fluid, and three background classes. This segmentation is performed using the default SPM25 unified segmentation approach ^2. This segmentation is not used for ground-truth labeling but rather as an initialization to locally normalize tissue intensities using the Local Adaptive Segmentation (LAS) approach implemented in CAT12 ^3. Intensities are scaled independently for CSF, gray matter (GM), and white matter (WM) to predefined canonical values (CSF = 1, GM = 2, and WM = 3). This yields a partial-volume-like label image that serves as the basis for all subsequent simulations.

Since tissue boundaries are derived from intensity-normalized images rather than discrete segmentation labels, this approach minimizes dependency on the initial segmentation algorithm while preserving realistic tissue topology. Residual noise in the scaled label image is reduced using spatially adaptive non-local means (SANLM) filtering. Optionally, WM holes can be closed to remove native white matter hyperintensities (WMHs) prior to inserting synthetic lesions. Then, user-defined anatomical modifications can be introduced, including region-specific atrophy based on atlas-defined regions of interest (e.g., the Hammers atlas ^4) and the addition of white matter hyperintensities using a probabilistic WMH atlas.

Image synthesis reuses the Gaussian mixture model parameters from the SPM forward model, replacing the tissue probability maps (and the optional white matter hyperintensity [WMH] class). This produces a realistic T1-weighted MRI volume derived exclusively from the modified label image. This image serves as an explicit ground truth for subsequent validation analyses. The synthesized image can be further modulated by radiofrequency bias fields using either a predefined MNI-space field or a simulated, smooth, three-dimensional field. Rician noise can be added, and parameters such as the contrast-to-noise ratio and the output voxel size can be specified (see Fig. 1).

To validate cortical thickness estimates, the framework can simulate predefined cortical thickness values directly in the label image (Fig. 2a). Cortical thickness is geometrically defined by applying morphological closing to the WM segmentation, followed by GM growth using Euclidean distance maps. Thickness values can be varied across anatomical regions (e.g., frontal, occipital, and remaining cortex) using the Hammers atlas. Although this approach does not model the biological processes of cortical development, it allows for precise control of the ground-truth thickness values necessary for quantitative validation. To approximate partial volume effects, tissue boundaries are jittered across multiple subvoxel offsets and hard labels are averaged to generate a segmentation resembling partial volume that replaces the original SPM labels.

All outputs follow BIDS-like naming conventions, and accompanying JSON files store the complete set of simulation parameters to ensure reproducibility.

Results

The proposed synthesis approach produces T1-weighted MRI volumes that closely resemble real anatomical images. Representative examples illustrate the impact of different noise levels, RF bias fields, and simulated white matter hyperintensities (see Fig. 2b). The framework also enables the systematic manipulation of image contrast, spatial resolution, and region-specific atrophy. This allows for controlled benchmarking of segmentation and cortical thickness algorithms.

Conclusion

Unlike existing digital brain phantoms that rely on a limited set of predefined anatomies ^5, this framework can generate realistic T1-weighted MRI data from any high-quality input image. Only six-class Gaussian mixture segmentation is required, which substantially lowers dependency on detailed manual tissue annotations. By synthesizing images exclusively from modified label images that serve as explicit ground truth, confounding influences and circularity introduced by downstream segmentation or thickness estimation algorithms are reduced significantly.

Beyond the traditional validation of segmentation pipelines, the proposed phantom offers a controlled testing environment for evaluating deep learning–based approaches and their susceptibility to imaging artifacts, domain shifts, and training-data biases. The ability to explicitly manipulate anatomy, pathology, and image acquisition parameters enables the systematic stress-testing of model robustness under conditions that are difficult to obtain in real-world datasets. This capability can also be extended using existing augmentation approaches, such as PyTorch (https://pytorch.org). Notably, the ability to simulate predefined cortical thickness values provides a novel, publicly accessible phantom-based method for validating the accuracy of cortical thickness.
