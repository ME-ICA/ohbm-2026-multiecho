Introduction

Florzolotau (18F) is one of the tau PET tracers capable of visualizing all tau isoforms, including those found not only in Alzheimer’s disease but also in other tauopathies such as progressive supranuclear palsy and corticobasal degeneration.1 In these diseases, cerebellar tau retention may occur, which might lead to the underestimation of cortical tau burden to regard the cerebellum as a reference region. To address this issue, a histogram-based semi-quantification using bi-modal curve fitting of gray-matter intensity distributions has been proposed to estimate a reference value without assuming the presence of an intact region.2 It has been demonstrated that this method is effective for assessing florzolotau uptake in various tauopathies.3 However, the practical usability and reproducibility of this approach have been limited by the lack of standardized methodological implementation. To overcome this limitation, we previously released tame-q, an open-source pipeline providing standardized preprocessing with histogram-based semi-quantification.4,5 Although the initial release of tame-q offered fully packaged end-to-end processing, it constrained its use to a fixed workflow and prevented researchers from easily accessing individual components that could be repurposed for alternative protocols. Therefore, we developed a major update to tame-q that modularizes all core functions and exposes them as independent utilities.

Methods

Prior to development, we defined three major requirements for the updated tame-q system: (1) the pipeline should remain capable of performing automated registration, segmentation, and semi-quantification as a single integrated workflow, (2) all major processes should be executable as independent utility commands that can be used flexibly for use in different research scenarios, and (3) preprocessing parameters, such as registration options and histogram-fitting settings, should be easily modifiable without editing source code. To meet these requirements, we adopted a software-engineering approach emphasizing structured modularity, parameter-driven design, and standardized input and output specifications.

The overall architecture was organized into three primary modules (registration, segmentation, and semi-quantification). Each module was further decomposed into sub-modules according to detailed functional roles. Implementation was carried out using multiple neuroimaging tools, including FMRIB Software Library, FreeSurfer, and Statistical Parametric Mapping 12. Mathematical procedures such as bi-modal curve fitting, Gaussian mixture modeling, and histogram visualization were implemented using Python libraries (NiBabel, NumPy, SciPy, Matplotlib). Shell scripts, MATLAB scripts, and Python utilities were combined to create orchestrated processes. A set of unit tests was conducted for each module to verify correct functionality under a variety of input conditions.

To ensure reproducibility, pipeline parameters were externalized to human-readable text files. The updated system also generates quality-control outputs, including registration overlays, histogram plots, and processing logs. Integration tests were conducted using both Docker-based and VirtualBox-based distributions of Lin4Neuro (Ubuntu 22.04), the officially supported execution environment for tame-q.

For validation, we processed a dataset consisting of 110 paired T1-weighted MR images and florzolotau PET scans, all acquired at the University of Tsukuba Hospital. Dynamic PET acquisition consisted of 4 × 5-min frames beginning 90 min after injection.　These data were used solely to confirm processing stability and correctness of the pipeline. The study was approved by the Ethics Committee of the University of Tsukuba Hospital (R02-328).

Results

Each module was individually validated through unit testing. After completing these tests, the modules were integrated into a unified workflow. When applied to all test datasets, the updated pipeline completed all processes successfully without any errors. The modularization of tame-q provided several practical advantages. Users can execute specific modules independently, enabling a broader range of applications. For example, researchers testing alternative reference-region strategies or exploring semi-quantification of other tracers can bypass unnecessary stages and iteratively evaluate different parameter settings. Moreover, the separation of modules also facilitated reusing intermediate outputs such as registration results or segmentation masks, reducing computation time during repeated analyses. In addition, parameter configuration proved particularly beneficial for rapid prototyping. Adjusting histogram fitting parameters requires only editing a text file, allowing investigators to perform analyses without modifying code. Furthermore, the enhanced logging system improved traceability of analysis outcomes. Structured logs documented processing parameters and runtime statistics, providing a foundation for reproducible multi-center data analysis. Taken together, these results demonstrate that the updated tame-q achieves both stability and flexibility.

Conclusion

The updated tame-q pipeline provides a more flexible and extensible framework for PET preprocessing and semi-quantification while preserving the reproducibility and standardization of the initial release. By eliminating the assumption of an intact cerebellar reference region, tame-q offers a generalizable semi-quantification strategy suitable for tauopathy research. Beyond its direct application to florzolotau, the updated pipeline has broader implications for neuroimaging research.
