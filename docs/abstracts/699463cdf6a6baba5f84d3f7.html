Introduction

Age-related differences in the ability to encode, store, and retrieve past experiences with rich contextual detail (episodic memory), start at midlife1. Episodic memory relies on the structural integrity of the hippocampus and surrounding medial temporal lobe cortex. Additionally, studies have shown that different aspects of episodic memory are associated with specific hippocampal subfields. For example, the ability to store similar memories as distinct representations (referred to as pattern separation) is associated with subfields CA3 and DG, whereas the ability to generalize across degraded or incomplete memories (pattern completion) may rely more heavily on CA12.

Of relevance here, midlife is also the timepoint at which most females with ovaries will transition through premenopausal to perimenopausal and lastly, postmenopausal stages. Perimenopause is defined as the period of time between irregular menstrual cycles and the complete cessations of menses. This life period is characterized by hormonal fluctuations and increases in subjective complaints of brain fog and memory dysfunction3. However, it remains unclear if perimenopausal middle-aged females exhibit objective evidence of episodic memory decline, compared to middle-aged premenopausal females; and if individual differences in hippocampal subfields may mediate any observed memory differences at perimenopause. 

The goals of the current study are to determine if: (1) there is an objective decline in face-location spatial source memory and correct rejections of new faces in middle-aged perimenopausal vs. premenopausal females (2) if there are differences in hippocampal subfield volumes between middle-aged perimenopausal vs. premenopausal females and (3) if hippocampal subfield volumes predict correct source memory and/or correct rejections in either perimenopausal and/or premenopausal females.

Methods

This study used previously collected data from the Brain Health at Midlife and Menopause (BHAMM) Study. In this study 83 cognitively unimpaired middle-aged females (48 premenopausal, 35 perimenopausal; aged 39.55–56.68 years; education 11 - 20 years) performed easy and hard versions of a face-location source memory event-related task fMRI paradigm4. We used the behavioural accuracy data for correct source memory and correct rejection measures from the event-related task fMRI paradigms as our primary  outcome measures of episodic memory in the current study. During the easy task participants were required to memorise 6 face-location associations. During the hard task participants were required to memorise 12 face-location associations. In addition, we collected ultra-high resolution T2-weighted MRI (TR 2500ms, TE 198 ms, 320 slices of 0.60 mm thickness, voxel size = 0.6 x 0.6 x 0.6 mm3, FOV = 206 mm, acquisition time = 13 min) on a 3T Siemens Prisma-FIT scanner to calculate hippocampal subfield volumes for CA1, CA2/3/DG, and subiculum. Hippocampal segmentation was conducted using a machine learning model, Automated Segmentation of Hippocampal Subfields5 (ASHS). Initially, an established atlas based on the OAP protocol was applied and then manually corrected with adjustments for differences in MRI image dimensions. The ASHS atlas was then retrained on the manually corrected images, which was then applied on the full T2 sample. This pipeline is outlined in Figure 1. Final volumes were corrected for intracranial volume (ICV) using the residual method. 

Analyses: We conducted separate linear mixed effects regressions using R v4.4.3 to test for (1) menopause group (pre vs peri) and task difficulty (easy vs hard) differences in (a) correct source memory and (b) correct rejection; and (2) menopause group differences in subfield volumes. Age was entered as an independent predictor in all models, in addition to an age by menopause interaction term. If significant menopause group differences in memory and subfield volumes were observed, a mediation analysis would be conducted to determine if menopause group differences in memory performance were mediated by specific subfield volumes.

Results

    The regression model for correct source memory identified a significant task 𝗑 menopause group interaction effect, such that premenopausal females had higher correct source accuracy than the perimenopausal females on easy tasks only (see Figure 2). The regression model predicting correct rejection identified a main effect of task difficulty, where performance was higher in the easy condition than in the hard condition. No other significant effects emerged. Lastly, the regression model for hippocampal subfields identified no significant menopause group differences. Because we did not find any volume differences between menopause groups, we did not conduct mediation analyses. 

Conclusion

    This study provides evidence that perimenopause females exhibit lower source memory compared to premenopausal females, however only at low task demands. This suggests that while both groups found the hard version more difficult than the easy version, the females in the perimenopause group were more challenged than the premenopause group by the easy version. Interestingly, there were no significant group differences in hippocampal subfield volumes between pre- and perimenopausal females. However, this finding is consistent with past adult lifespan studies that have noted age-related hippocampal volume declines arise at an older average age, between 50 and 60 years of age, than the current sample, which had an average age of 47.25 years. Thus, the lower spatial context memory observed in perimenopausal females may be related to differences in other neurocognitive systems, e.g. the prefrontal cortex. This explanation is consistent with previous reports of menopause status effects on cognitive control. Future research should examine whether group differences in lateral PFC volume or function mediates source memory deficits observed in some perimenopausal females.
