Introduction

Human brain mapping typically registers functional signals (e.g., BOLD fMRI) to a common reference space using anatomical alignment: structural images are diffeomorphically warped to a template and the resulting transforms are applied to functional data. However, anatomical correspondence is a poor proxy for functional correspondence, as functional features vary idiosyncratically across individuals and are only weakly constrained by anatomy. This mismatch limits localization accuracy and statistical power in population studies.

Functional alignment methods address this problem and have been used in large open-access datasets such as the Human Connectome Project (HCP), but their adoption has been limited by implementation complexity and poor data interoperability. Here we present an accessible diffeomorphic functional alignment pipeline modeled on the HCP approach (Glasser et al. 2016), designed for minimal user overhead and compatibility with both volumetric and grayordinate data. We evaluate its ability to improve interindividual functional correspondence relative to standard anatomical preprocessing (fMRIprep).

Methods

The pipeline reconstructs individualized resting-state networks and estimates smooth multivariate diffeomorphic warps that align these networks to a reference functional template. Reference templates were obtained from the HCP. Individualized networks were derived using a lightly modified iterative dual regression procedure similar to that used in HCP MSMAll alignment. Unlike MSMAll, which relied on unpublished templates and myelin maps, our approach aligns data to a published 50-dimensional HCP network template (PTN, S1200 release; Smith et al. 2013) and omits myelin maps to reduce acquisition requirements.

Surface and volumetric transforms were estimated using multimodal surface matching (MSM) and ANTs, respectively. The full workflow was implemented in Nipype and supports both NIFTI and CIFTI data formats.

Performance was evaluated in two studies using out-of-participant task-condition decoding as a primary outcome. Heritability analysis of deformation models provided a secondary outcome. All data were initially processed with fMRIprep; decoding performance with and without functional alignment was compared using Wilcoxon signed-rank tests. Linear SVMs were used throughout. Data were unsmoothed except where noted.

Results

Study 1 (HCP, n = 256; 17 conditions).
Using grayordinate data, functional alignment improved cross-participant decoding relative to anatomical alignment (fMRIprep F1 = 0.286; chance = 0.05). With 15 minutes of resting-state data, F1 increased to 0.331 (+20%; p = 3e-17); with 60 minutes, to 0.339 (+24%; p = 5e-19). Performance with 60 minutes modestly exceeded MSMAll alignment (MSMAll F1 = 0.331; +5%; p = 0.009).

Using volumetric data, functional alignment also improved decoding (fMRIprep F1 = 0.068; aligned F1 = 0.114; p = 2.4e-20). After Gaussian smoothing (σ = 2 mm), aligned data continued to outperform smoothed anatomical alignment (+15%; p = 5.7e-17), indicating that gains were not driven by interpolation-related smoothing.

Across surface and volumetric representations, deformation fields were more similar in identical than fraternal twins (grayordinate: r = 0.48 vs 0.38; volumetric: r = 0.42 vs 0.33; all p < 10e-19), consistent with heritable idiosyncrasies in functional topography (Dworetsky et al. 2024).

Study 2.
Using 5 minutes of resting-state data, functional alignment improved group-level decoding of noxious heat vs mechanical stimulation (fMRIprep F1 = 0.744; aligned F1 = 0.762; +2%; p = 0.01).

Conclusion

We present an easy-to-use Nipype pipeline for diffeomorphic functional alignment that improves interindividual functional correspondence relative to standard anatomical preprocessing and matches or exceeds MSMAll performance in several settings. By supporting both surface and volumetric data and avoiding specialized acquisition requirements, the pipeline enables functional alignment in contemporary and legacy datasets. These results demonstrate that modeling individual functional idiosyncrasies yields robust gains in cross-participant decoding and can be made broadly accessible for population neuroimaging studies.
