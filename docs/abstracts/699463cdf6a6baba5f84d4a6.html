Introduction

How the brain generates predictions during naturalistic language comprehension remains a central challenge in cognitive neuroscience. Although prediction is often assumed to be hierarchical, isolating its constituent scales is difficult because language is continuous, neural responses overlap in time, and predictive structure is latent. We address this problem by reframing hierarchical prediction in information-theoretic terms: rather than imposing linguistic levels, we define prediction by how uncertainty is reduced as context accumulates. Because both the stimulus (spoken language) and neural responses (MEG) are observed, this approach allows predictive structure to be inferred from data without committing to a particular representational scheme.

We operationalise predictive uncertainty using word-level surprisal derived from a large language model, treated purely as a probabilistic estimator of word-sequence likelihoods. No architectural correspondence between the model and the brain is assumed. Instead, we exploit how surprisal depends on context length, motivating a hierarchical factorisation in which increasing depth corresponds to exponentially expanding context windows. These components are related to neural activity by modelling overlapping word-evoked responses and localising effects in source space. Using this, we ask where predictive uncertainty at different depths is integrated during naturalistic language comprehension.

Our results show that predictive uncertainty is organised across a small number of context-dependent scales. Effects linked to shorter context windows are concentrated in temporal and inferior frontal regions, while effects linked to longer context windows extend into the frontal, parietal, and midline cortex.

Importantly, this work provides a framework for probing hierarchical prediction in the brain using probabilistic models of naturalistic stimuli without assuming any specific linguistic, cognitive, or neural architecture. 

Methods

Dataset. We used a high-resolution MEG dataset comprising approximately 30 hours of MEG recordings from three native English speakers, each recorded across ten sessions while listening to The Adventures of Sherlock Holmes1. Stimuli were presented binaurally through in-ear headphones, and neural activity was recorded using a 275-channel axial gradiometer system at 1200 Hz. To minimise motion artefacts and ensure anatomical consistency across sessions, participants wore individualised MEG-compatible headcasts. Structural MRI scans were obtained to support source localisation and anatomical co-registration. Word-level timing information was extracted using the Penn Forced Aligner2, enabling precise alignment between linguistic input and neural responses. 

Defining surprisal.  Surprisal was quantified as inference over the next word wt given its preceding context w<t,

St(k) = -log p(wt | wt-k:t-1),

where k denotes context length. Surprisal provides a model-agnostic measure of how unexpected a word is under a probabilistic model of natural language, without assuming any specific linguistic representation. Importantly,  while the joint distribution p(w1:T) is unknown and its factorisation underdetermined, empirical surprisal decreases monotonically with increasing context length. We exploit this property to define a hierarchy of predictive depths based on how uncertainty is resolved as context expands.

We approximate the decay of surprisal contributions with increasing context using an exponential partition of history3. Context is decomposed into non-overlapping windows whose size doubles at each level: level k captures information contributed by words wt-2^{k}:t-2^{k-1}-1. The surprisal contribution of level k is defined as :

ΔSt(k) = St(2k-1) - St(2k),

giving an additive factorisation of total surprisal across hierarchical depths. 

Computing surprisal. Word-level surprisal was quantified using Gemma-2B, a pretrained large language model. For each context window, token-level surprisal was computed as the negative log-probability assigned to the next token given preceding k tokens. Word-level surprise was computed by taking the maximum surprisal value across all subword tokens comprising a given word. This aggregation captures the peak predictive uncertainty per word. Word-level onsets from the MEG dataset were used to temporally align these estimates with neural responses, enabling time-locked analyses of lexical prediction in the brain. 

Modelling word responses. Linguistic input is continuous, thus the brain’s evoked responses to each word can temporally overlap. Traditional event-related potential (ERP) averaging approaches fail to resolve these overlapping contributions. We use convolutional general linear model (cGLM), which enables deconvolution of overlapping responses and isolation of word-level surprisal effects on evoked activity. For each context length k, we construct two sets of regressors: a baseline evoked response and a surprisal-modulated response. Each word onset is represented as a delta function and convolved with a set of m=12 cosine basis functions {Bj(t)}j=112 spanning a peristimulus window of [-100, 1100] ms:

Xbase,i(k)(t) = ∑j=112 Δ(t - ti) * Bj(t), 

Xsurprise,i(k)(t) = si(k) • Xbase,i(k)(t)

where ti is the onset of word i, and si(k) is its surprisal under context length k. This produces a design matrix containing 24 regressors per context level: 12 capturing the average response and 12 modeling the surprisal-modulated deviation. We fit these estimated responses to the continuous MEG signal using linear regression. Then, we project the sensor-level responses into source space using Bayesian source localisation4, as implemented in SPM5. 

Results

Hierarchical decomposition of surprisal reveals structured predictive scales. 

We first asked whether word-level surprisal in natural language exhibits structure beyond sequential integration of context. To evaluate this, we constructed context–surprisal transition matrices under two integration schemes: a sequential scheme, in which context is accumulated linearly one token at a time, and a hierarchical scheme, in which context is sampled at exponentially increasing intervals (power-law spacing of order 2), capturing both local and long-range dependencies. 

In both cases, surprisal decreases as a function of context length (Fig. 2B). However, the structure of these reductions differs across integration paths. Hierarchical integration produces smoother and more globally consistent changes in surprisal with increasing context, whereas sequential integration gives irregular, locally varying updates. Correspondingly, the effective dimensionality of the context–surprisal transition matrix, quantified by its rank, increases under sequential integration but remains low under hierarchical integration, stabilising at approximately rank 8 (Fig. 2C). 

To quantify this difference, we defined an efficiency metric as the ratio of representational rank to the norm of surprisal change. Hierarchical integration achieves higher efficiency, particularly at longer context lengths, reflecting larger surprisal reductions per representational degree of freedom (Fig. 2D).

Word-evoked neural responses increase monotonically with context length. 

We next examined whether word-evoked neural responses vary systematically with context length. At the sensor level, word-evoked power increases monotonically with context length across a broad set of cortical regions (Fig. 2E). For nearly all regions, power is lowest for short contexts and increases gradually as context length increases. This pattern is observed bilaterally, with consistently larger effects in left-hemisphere regions.

The magnitude of context-related increases differs across regions (Fig. 2F). Early auditory cortex shows relatively small changes, whereas temporal, frontal, and ventromedial prefrontal regions show larger increases at longer context lengths. Consistent with this pattern, direct contrasts between high- and low-context conditions reveal region-specific power differences that are present in both hemispheres and more pronounced in the left hemisphere (Fig. 2G).

Regional power analyses show a spatial cortical gradient. 

Regional analyses further characterise how baseline activation and context-related effects are distributed across cortex (Fig. 2H). Overall activation averaged across all contexts differs systematically across regions, with higher baseline power in temporal, frontal, and midline areas relative to early sensory regions.

When examining incremental context effects via successive k → k−1 contrasts, the spatial pattern varies with context length (Fig. 2I). Short context increments produce relatively focal effects in temporal and inferior frontal regions, whereas longer context increments gives more spatially distributed effects extending into the frontal, parietal, and midline cortex. This pattern is observed bilaterally and is consistently stronger in the left hemisphere.

Conclusion

We examined how predictive uncertainty during naturalistic language comprehension can be decomposed across context-dependent scales and how these scales relate to cortical responses. By defining prediction in information-theoretic terms and factorising word-level surprisal according to expanding context windows, we identified a small number of structured predictive components without imposing linguistic categories or assuming correspondence between model architecture and neural organisation.

At the computational level, hierarchical context integration gives a low-dimensional and efficient organisation of surprisal changes, whereas sequential integration produces higher-dimensional and locally variable structure. At the neural level, word-evoked responses increase monotonically with context length across widespread cortical regions, with consistently larger effects in the left hemisphere. Regional analyses further show that incremental context effects vary systematically across cortex: shorter context increments are associated with relatively focal effects in temporal and inferior frontal regions, while longer context increments are associated with more spatially distributed effects extending into frontal, parietal, and midline cortex. Across regions, response magnitude varies as a function of context length, with different regions showing maximal sensitivity at different ranges. Beyond these ranges, further increases in context length are associated with changes that are distributed across multiple regions rather than concentrated within a single area. Taken together, these results show that increasing context length is accompanied by progressively broader engagement across cortex, rather than selective amplification within isolated regions.

A central contribution of this work is methodological. Large language models were used solely as probabilistic estimators of word-sequence statistics, not as mechanistic models of neural computation. This allowed us to exploit the statistical structure of naturalistic language while avoiding assumptions about correspondence between artificial model architectures and the brain. More generally, these results illustrate how probabilistic models can be used to characterise neural responses to naturalistic stimuli in a way that remains agnostic to specific linguistic or cognitive theories.

Together, these findings demonstrate that predictive uncertainty during language comprehension admits a hierarchical decomposition across a limited number of context scales, and that these scales are reflected in the spatial organisation of word-evoked neural responses. By focusing on information scales rather than representational levels, this approach provides a general framework for studying prediction in naturalistic settings where hierarchical structure is present but difficult to define a priori.
