Introduction

Insomnia is a prevalent sleep disorder. In recent years, wearable electroencephalography (EEG) devices have demonstrated great potential as alternatives to polysomnography (PSG) and for enabling home-based sleep monitoring.1 Machine learning (ML) techniques, capable of integrating multi-dimensional data and efficiently processing large datasets, have been widely used for the automated identification of sleep disorders.2 In this study, we systematically compared the predictive value of sleep macroscopic and micro-structural features (including spectral and aperiodic features) derived from the wearable forehead EEG (UMindSleep, UMS) in predicting insomnia using ML approaches.

Methods

We recruited 132 patients with insomnia disorder (ID) and 126 age- and sex-matched healthy controls (HC) from hospital sleep clinics and the community. All participants wore forehead EEG overnight. For each subject, macro-sleep metrics as well as EEG-derived features, including spectral and aperiodic features were extracted. To predict the binary classification variable (HC and ID), we constructed predictive models based on three feature categories as well as their combinations. Specifically, we trained five machine learning models, namely Logistic Regression (LR), Elastic Net, Support Vector Machine (SVM), Random Forest (RF), and Extreme Gradient Boosting (XGBoost). Finally, the best-performing model was interpreted using SHapley Additive exPlanations (SHAP) analysis.

Results

The results of the statistical test are shown in Table 1. There were no significant differences in demographic variables (age, gender) and macro sleep structure variables between the ID and HC group (p > .05), while the scores of PSQI, ISI and PHQ-9 in the ID group were significantly higher than those in the HC group (p < .001). 

In the machine learning analysis, the Random Forest model yielded the best performance among the five algorithms evaluated. Permutation tests indicated that all three feature categories and their combinations could significantly differentiate between insomnia patients and healthy controls, with the spectral feature model performing the best (AUC = 0.7, Fig. 1A). 

Further SHAP analysis revealed that spectral features contributed more substantially to the classification than macroscopic and aperiodic features (Fig. 1B, left). Additionally, a supplementary SHAP analysis conducted on the all-feature model confirmed that all three feature categories contributed to insomnia prediction (Fig. 1B, right). These findings suggest that, based on objective data from wearable sleep EEG, including macrostructural, spectral, and aperiodic features all hold valuable potential for predicting insomnia.

Conclusion

Our findings reveal the value of objective measures from wearable sleep devices, particularly EEG-based indicators, in assessing insomnia, which advances the understanding of the pathophysiological mechanisms underlying insomnia and promotes the application of wearable sleep monitoring technology.
