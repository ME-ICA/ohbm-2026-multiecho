Introduction

Paired associate learning is a classic learning paradigm that one learns to associate pairs of stimuli, such as words and their pronunciations, faces and names, or items based on predefined rules. When implementing a paired associate task, a subject is presented with one stimulus (the “cue”) and must identify the associated stimulus. This method is considered as a simple strategy to research associative memory, a crucial type of long-term memory that allows contextual and structured learning, language acquisition, spatial navigation, and many other aspects of high-level cognition. 

Visual-visual associative memory has been studied extensively among all types of associative memory. Miyashita1 demonstrated the possible microcircuits in macaques. In the study a macaque was trained using paired abstract images, which shows that it is possible for associations to be learned for two previously unrelated items. They located the perirhinal cortex (PRC) as the convergent regions where visual-visual associative memory is coded. Most strikingly, two types of neurons have been identified in PRC as “pair-encoding” and “pair-decoding” neurons. 

The idea of associative memory has also inspired many influential concepts and studies in computer science and AI, e.g., content-addressable memory and Hopfield network. However, in computational neuroscience, head-on efforts of modeling the mechanisms underlying associative memory are largely limited to theoretical proposals on different stages of memory function. A unified framework is still lacking that can implement long-term memory tasks with biologically plausible network settings. In the present study, we demonstrate a large-scale neural network that can perform visual recognition, working memory tasks, and associative learning.

Methods

Large-scale neural network modeling with The Virtual Brain (TVB)

We developed a model with visual recognition system: visual cortices (V1/V2, V4) and inferior temporal cortex (IT); associative memory system: perirhinal cortex (PRC) and temporopolar cortex (TPC); working memory and decision-making system: prefrontal cortex. In the present study, only semantic-like visual associative memory is considered. The model structure is illustrated in Figure 1A.

The visual recognition system adopts a ResNet-18 structure with brain-like topographical constraints, modified from a previously published framework of ventral visual cortex2. The model was trained on ImageNet minimizing both task errors and metabolic energy cost.

The associative memory component resembles PRC and TPC. The PRC and TPC were initiated as randomly connected recurrent neural networks (RNN). The outputs of visual recognition system (VTC activation maps) are served as the inputs to associative memory system. The outputs of associative memory system project to both visual cortices and working memory system based on anatomical literature.

We then embed the model into a human connectome using The Virtual Brain (TVB) platform3,4. The corresponding nodes in the connectome representing visual cortices, PRC, TPC, PFC were replaced by our detailed modules. The TVB connectome allows brain-like noise and feedback into our model and observation of the global dynamics during memory tasks.

Equilibrium Propagation

In our study, the association between pairs of stimuli were determined arbitrarily. The associative memory system was trained to learn the associations through Equilibrium Propagation (EP)5. 

Learning of associative memory is generally considered as a Hebbian process, where neurons activated for items in a pre-defined pair are linked together (“fire together, wire together”). However, classic Hebbian scheme lacks a clear -defined objective function, which makes training neural networks for tasks difficult. EP is an adapted Hebbian style algorithm that is optimized to minimize a global energy function. EP backpropagates errors implicitly by making “nudges”, local small perturbations, on its energy-based loss function. EP is viewed as a biologically plausible learning framework while computing gradient on a defined objective function.

Experiment design

Experimental designs are illustrated in Figure 1B and described in detail in the following.

Delayed match-to-sample (DMS) task

In a delayed match-to-sample (DMS) task, two stimuli are presented to the model separated by a delay period (2 s). The model needs to determine whether the two stimuli match each other. DMS task is a classical method for working-memory research. In our study, DMS task is first implemented without the associative memory system to train and test the working memory and decision-making system. We also implemented DMS task with distractions, i.e., during the delay period one distraction stimulus is presented to the model.

Paired associate task

Stimuli are grouped into pairs based on predefined rules. In our case, images were grouped arbitrarily. The model was trained to memorize the associations. When performing the task, one stimulus is presented as cue and a second stimulus is presented after a short delay. The model needs to respond if the second stimulus is the correct pair of the cue.

Paired associate task with context

Similar to paired associate task, stimuli are grouped into pairs, but one item may be paired twice with different items. We added a special context, namely another item, to each of the pairs. For example, A is paired with B when B’ is presented, while A is paired with C when C’ is presented. This task imitates that in real world semantic memory one item can be associated with different concepts and emotions within different contexts (e.g., the etymon ‘dog’ in ‘hotdog’). 

Results

Working memory and associative memory tasks

The model first implemented DMS task without the long-term memory system (with only visual recognition system and working memory system). The representations of stimuli are maintained through persistent activation of two reciprocally connected clusters in PFC. The model successfully performed basic DMS task and DMS task with distractions with high accuracy.

The model successfully implemented visual-visual paired associate task with high accuracy. We tested different pairing schemes, e.g., face-face, face-grating, etc., and the model showed consistent performance on difference schemes. We then implemented visual-visual paired associate task with contexts. We show that when the contextual images similarity increases, the model performance decreases. 

Spatial representations of memory categories

We then analyzed the spatial representations of items from different image types (faces, gratings, etc.) in the associative memory system. In general, images from the same category share a significant number of units that are selectively active. Units with high selectivity for the same image category tend to cluster together spatially, due to optimizing the metabolic energy cost. This organization reflects human cortical topographic motifs of visual processing, which indicates energy optimization may be the underlying cause for human cortical topography.

Emerged encoding and decoding neuronal clusters

As illustrated in Figure 1c, we noticed that within the associative memory layers, two functional clusters of neuronal units emerged after training for paired associate task. One neuronal population show more selectivity to both stimuli of the pair but not stimuli from other pairs, which we termed as pair-encoding units. On the other hand, one group of units show more selectivity to one stimulus when the paired item is presented as the cue, which we interpreted as pair decoding units. These findings are consistent with experimental findings in macaques reported in Miyashita’s studies1.

Distinct global dynamics driven by memory tasks

We embed the model into a human connectome network using the Virtual Brain (TVB) to study the global dynamics while performing a memory task. The model activity projects to rest of the brain regions in TVB based on structural connectivity and the model receives noise and feedback from TVB. Network analysis metrics (global efficiency, cluster coefficient, centrality of hub nodes, etc.) are calculated to illustrate the effects caused by working-memory tasks and associative memory tasks. We show that different types of memory tasks drive distinct global dynamics.

Conclusion

We present a computational model that predicts functional and structural organizations of associative memory. We show that spatial organizations of the memory of object categories emerge from training the model to perform paired associate task. We also show that functional clusters of neuronal units can emerge from training for paired associate task within the associative memory system.

Our model successfully performed working-memory tasks (DMS task, DMS task with distractions) and long-term memory tasks (paired associate task, paired associate task with contexts) with biologically plausible network structures. Currently, as experimental results accumulating from various species and modalities, a more comprehensive perspective is needed for human associative memory, taking topography, microcircuitry, and computational principles into one model. Our approach is such a proof-of-concept trial for a unified framework for visual recognition and long-term associative memory of visual stimuli.
