Introduction

The hippocampal episodic memory system is implicated in the learning of new semantic representations 1. To understand how this system operates, it is important to know how the hippocampal memory system connects to semantic cortical regions in for example the anterior temporal lobe, and to produce a theory of how the hippocampal episodic memory system may help in the learning of new semantic representations 1, 2.

Methods

To analyse the pathways involved, diffusion tractography, and resting state functional connectivity, and effective connectivity were measured in 171 Human Connectome Project Participants and analysed in the HCP-Multimodal Parcellation 3 using methods described previously 4.

Results

The lateral parahippocampal cortex region TF (which connects via the perirhinal and entorhinal cortex with the hippocampus) has connectivity with the inferior temporal visual cortex involved in object and face representations, TE2p, TE1p and FFC; with the orbitofrontal cortex (47m), which provides a route for reward value to be incorporated into memories; with the anterior temporal lobe semantic network including STSda, STSva, TE2a, and temporal pole TGd; with temporo-parieto-occipital junction regions TPOJ2 and TPOJ3 that are implicated in language; and with inferior frontal cortex regions IFSp and IFJa, which are highly connected with Broca's area regions 44 and 45. 

The medial parahippocampal cortex regions PHA1-3 (which connect via the entorhinal cortex with the hippocampus and which represent spatial scenes with spatial view cells) have connectivity with the ventromedial cortical visual pathway regions VMV1-3 and ProStriate Cortex (ProS); with TPOJ3, which is a semantic region in the temporo-parietal region; with inferior parietal PGs (adjacent to and connected with PGi), which is connected with anterior temporal lobe semantic regions, and which may encode information about actions which is an important part of semantic representations; with some area 7 parietal and related regions involved in visuo-motor actions in space; and with reward-related ventromedial prefrontal cortex region 10r. 

These resting state results have been extended to task-related functional and effective connectivity, which confirm and extend the results.

Conclusion

It is proposed that some of these connectivities provide for the ‘What’ object or face, ‘Where’ spatial scene, and reward representations to reach the hippocampus to be combined into episodic memories. It is also proposed that connectivity from the hippocampal system to semantic anterior temporal lobe and inferior parietal semantic cortical regions provides a route for the already chunked components based on temporal and spatial contiguity used for each episodic memory by the hippocampus 5 to provide useful building blocks to form new semantic memories using slow semantic learning when related episodes are recalled close together in time.
