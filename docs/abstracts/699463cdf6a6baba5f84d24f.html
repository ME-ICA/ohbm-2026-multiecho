Introduction

In recent years, functional magnetic resonance imaging (fMRI) has emerged as a crucial tool for exploring the neural mechanisms of substance addiction. With the continuous development of fMRI technology, the significance of white matter function has increasingly gained attention. However, traditional addiction research has predominantly focused on gray matter functional networks, often treating white matter functional signals as noise and regressing them out, thereby overlooking the potential role of white matter in brain functional activities. Notably, white matter functional signals exhibit similar pathological patterns across numerous psychiatric disorders, suggesting that research into white matter function holds promise for offering a novel perspective on the neurobiological mechanisms of addiction.

This study will take smoking addiction as an illustrative example. For the first time, within a unified framework for node parcellation and network construction, we will systematically compare the global topological characteristics of white matter and gray matter functional networks under the same criteria. We will assess their sensitivity and specificity in identifying addiction states and severity, and validate the robustness of these findings in independent samples. Furthermore, using cocaine addiction as another research subject, we will introduce machine learning models to validate the application value of functional topological indicators in disease classification and core symptom grading. This will be followed by external validation using independent cocaine samples to enhance the generalizability and clinical translational potential of our research.

Methods

2.1 Clinical Classification Model for Nicotine Addiction Based on Global Network Topology

We employed an XGBoost classifier, utilizing five-fold cross-validation, to differentiate nicotine-dependent individuals from healthy controls based on significantly altered small-world metrics (γ and σ) of the white-matter functional network. Statistical significance of classification performance was assessed via 10,000 permutation tests (p < 0.05). Specificity was further examined using non-significant white-matter network metrics and gray-matter functional network small-world metrics.

2.2 Severity Classification Model for Nicotine Addiction Based on Global Network Topology

(1) Data Preprocessing: All threshold-specific white-matter small-world metrics (γ and σ) were used as features and normalized with PowerTransformer. K-means clustering, performed 50 times, binarized FTND scores into low-FTND (centroid 2.9343) and high-FTND (centroid 6.4483) groups.

(2) Model Construction: A Logistic Regression (LR) model was trained using five-fold cross-validation in the discovery sample and subsequently evaluated in an independent validation sample to classify smokers into low- vs. high-FTND groups.

2.3 Clinical Classification Using Global Topological Properties in Cocaine Addiction

An XGBoost classifier was built to distinguish cocaine users from healthy controls, using local efficiency (Eloc) values across all sparsity thresholds in the white-matter functional network as features. Model training and testing involved 10-fold cross-validation. Statistical significance was evaluated through 10,000 permutation tests (p < 0.05). Specificity was assessed by repeating the procedure with other white-matter and gray-matter network topological metrics.

2.4 Identifying Impulsivity Severity Using Global Topological Properties in Cocaine Addiction

(1) Preprocessing: Eloc values across all sparsity thresholds in the white-matter functional network were transformed using wavelet analysis, and the resulting coefficients were used for feature learning. Cocaine users were categorized into high (>62) and low (≤62) impulsivity groups based on a BIS score cutoff of 62.

(2) Model Training and Evaluation in Dataset 1: An XGBoost classifier was trained in Dataset 1 to discriminate high vs. low BIS groups using wavelet-derived white-matter Eloc features across all sparsity thresholds, evaluated with 10-fold cross-validation. Significance was assessed via 10,000 permutation tests (p < 0.05).

(3) Validation in Dataset 2: Hyperparameters optimized in Dataset 1 were applied to Dataset 2 to identify impulsivity severity. Due to a smaller sample size, performance was estimated with 5-fold cross-validation, and significance was tested with 10,000 permutations (p < 0.05).

(4) Specificity Analyses: Analogous models were trained using other white-matter topological metrics from Dataset 1 and validated in Dataset 2. Similarly, models using gray-matter network topological metrics from Dataset 1 were trained and validated in Dataset 2.

Results

At the network level, the nicotine addiction group exhibited significantly reduced small-world index (σ) and normalized clustering coefficient (γ), suggesting impaired topological organization of their white-matter functional network. Further analysis revealed that these abnormally altered small-world topological properties effectively distinguished nicotine-addicted individuals from healthy controls (accuracy = 0.5942, p = 0.0402) and could identify addiction severity, maintaining stable classification performance in the validation sample (accuracy = 0.6250, p = 0.0301). Analysis of confounding factors like age and education showed that σ and γ were not useful for distinguishing these factors, supporting their potential specific value in nicotine addiction applications. Using the same methodology for the gray-matter functional network, we found that its small-world topological metrics could neither differentiate nicotine-addicted individuals from healthy controls nor identify addiction severity.

In cocaine addiction, machine learning results indicated that only abnormal white-matter functional metrics effectively distinguished cocaine users from healthy controls (accuracy = 0.6909, p = 0.0016) and identified impulsivity levels in cocaine users (accuracy = 0.6810, p = 0.0131), further validated in an independent cocaine sample (accuracy = 0.7467, p = 0.0170). Gray-matter functional topological metrics were ineffective for both cocaine addiction identification and impulsivity severity differentiation.

Conclusion

This study, using nicotine and cocaine addiction as examples, highlights the white-matter specificity of addiction-related brain functional abnormalities.

In nicotine addiction, a decrease in the small-world properties of the white-matter functional network indicates an imbalance in brain integration and segregation. This abnormality not only effectively distinguishes addicted individuals from healthy controls but is also closely linked to addiction severity, demonstrating excellent performance in classification models. In contrast, the gray-matter functional network did not show similar sensitivity.

Cocaine addiction research further corroborated this finding: despite microstructural damage in both gray and white matter in addicted individuals, only the white-matter network exhibited significant topological abnormalities at the functional level. This change accurately differentiated cocaine users from healthy controls and effectively distinguished impulsivity severity, validated in independent samples. The gray-matter functional network failed to provide equally effective classification information.

Collectively, these findings emphasize that the white-matter functional network may be more sensitive to addiction-related brain functional abnormalities than gray matter, potentially changing earlier in disease progression, and thus holds significant clinical biomarker value.
