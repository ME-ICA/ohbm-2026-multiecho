Introduction

Caffeine is a widely used psychoactive compound with central vasoconstrictive properties, known to reduce cerebral blood flow by 20–30% and potentially reset the coupling between flow and metabolism.^1 While these global effects are well-documented, their impact on the magnitude of task-evoked BOLD activation remains complex. Early literature proposed caffeine as a "contrast booster" that could enhance BOLD sensitivity by increasing baseline deoxyhemoglobin.^2 However, it remains unclear whether this boosting effect is uniform across cognitive networks or if it interacts with task demand. Furthermore, caffeine may alter metabolic demands during cognitive load, potentially promoting "neural efficiency" (reduced metabolic cost for the same performance).^3

Addressing these questions requires precise anatomical specificity to separate vascular confounds from neural modulation.^4 In this study, we utilized a surface-based fMRI pipeline to quantify hemodynamic changes during an arithmetic task. We targeted four networks: Visual, Intraparietal Sulcus (IPS), Salience (Insula, Anterior Cingulate Cortex), and the Default Mode Network (DMN). We hypothesized that caffeine would modulate activation in high-demand attentional regions while sparing primary sensory cortices.

Methods

We investigated the impact of caffeine intake on cortical activation during an arithmetic task using surface-based fMRI analysis in AFNI/SUMA. Fourteen healthy subjects (N=14) completed two fMRI runs in a fixed order: Run-01 (pre-caffeine) and Run-02 (post-caffeine). The paradigm utilized a block design alternating between fixation and active arithmetic calculation blocks. fMRI data were preprocessed using afni_proc.py, including slice-timing correction, motion correction, coregistration, and spatial smoothing. Physiological noise was modeled and regressed using RETROICOR to isolate neural signals from vascular confounds. Functional data were projected onto the MNI152_2009 cortical surface to improve spatial specificity for Region of Interest (ROI) extraction.

First-level GLMs were estimated using 3dREMLfit (with motion and physiological regressors) to account for temporal autocorrelation. Task regressors were convolved with a canonical hemodynamic response function (HRF). For group-level analysis, paired t-tests are performed on the estimated beta coefficients. Results were projected to the cortical surface for visualization, and quantitative hypothesis testing was performed using surface-based ROIs (Visual, IPS, Salience, DMN) to calculate Cohen’s dz effect sizes. This approach allowed us to determine whether caffeine effects are region-specific when physiological noise is explicitly modeled.

Results

Task Validation: In both conditions, the arithmetic task elicited robust bilateral activation in the visual cortex and IPS, along with characteristic deactivation of the DMN, confirming participant engagement and protocol validity.

Effect Size Analysis: ROI analysis revealed that caffeine did not produce statistically significant changes in BOLD signal magnitude in any network (p > 0.05). However, effect size analysis demonstrated that caffeine modulated cortical responses in a region-dependent manner, revealing opposing trends between attentional and conflict-monitoring systems (Figure 2A):

Anterior Cingulate Cortex (ACC): This region showed the strongest modulation with a medium-sized reduction in activity (t(13) = -1.79,  dz ≈ -0.48).This negative shift implies that less ACC activation was required to perform the task under caffeine.

Intraparietal Sulcus: In contrast, the dorsal attention network showed a small-to-medium increase in activation (dz ≈ 0.35), suggesting a dissociation where caffeine enhances parietal engagement while reducing frontal metabolic cost.

Default Mode Network: The DMN core regions exhibited high stability (dz ≈ 0). These effects remained consistent after accounting for physiological confounds via RETROICOR, suggesting that observed differences are not driven solely by vascular or respiratory effects.


Conclusion

Our findings suggest that while caffeine exerts global vascular effects, it does not significantly bias the magnitude of task-evoked BOLD responses in primary visual or default mode networks. The high stability of the DMN (dz ≈ 0) provides reassurance for fMRI studies involving caffeinated participants. Critically, the dissociation between the IPS (increased signal) and ACC (decreased signal) demonstrates that caffeine alters cortical dynamics in a region-specific manner. The medium effect size in the ACC points toward a potential neural efficiency mechanism, where the brain requires fewer resources to monitor cognitive conflict. These findings highlight the importance of surface-based and physiology-aware modeling in pharmacological fMRI studies.
