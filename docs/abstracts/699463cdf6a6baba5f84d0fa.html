Introduction

Dynamic functional connectivity (dFC) captures how interactions between brain networks change over time. ^1 Most dFC analyses follow a sequential strategy: group-level functional networks are first constructed to define network nodes, and time series extracted from these nodes are then used to estimate dynamic models. An alternative approach is to construct individualised functional modes for node definition, raising the expectation that they could improve dFC modelling by providing more faithful spatial representations. However, such modes are estimated independently of dynamic models, and it remains unclear whether they help or hinder the recovery of temporal structure. Here, we use controlled simulations based on real data to test how spatial heterogeneity, temporal dynamics, and noise jointly affect dFC estimation, using an individualised functional mode mapping approach, Probabilistic Functional Modes (PROFUMO),^2 together with a Hidden Markov Model (HMM) ^3 for dFC. 

Methods

We simulated whole-cortex voxel-level fMRI time series using a linear mixing model that combines functional mode (functional network) spatial maps, corresponding mode time series, and additive noise (Fig. 1A). The simulation framework was designed to systematically vary three factors: spatial map structure, temporal dynamics, and noise level. 

Group independent component analysis (ICA; dimensionality = 50) followed by dual regression ^4 was applied to resting-state fMRI data from 1003 Human Connectome Project ^5 subjects to provide empirically grounded functional network spatial maps and time series used in the simulations. 

Spatial maps: The good_P condition used group-level ICA spatial maps shared across subjects, with only minimal individual-level perturbations, whereas real_P used individualised spatial maps obtained from dual regression. 

Temporal dynamics: We contrasted strongly structured time series generated using a generative Hidden Markov Model (good_A) with weaker, empirically derived time series obtained from dual regression (real_A). 

Noise: high-SNR vs. normal-SNR. 

These combinations yielded five scenarios from idealised to realistic conditions. For each simulated dataset, PROFUMO was applied to estimate individualised functional mode spatial maps and associated time series, after which an HMM was trained on the inferred time series. Recovery was quantified using spatial and temporal correlations to ground truth, state time course and state functional connectivity recovery, and bi-cross-validation, which provides a data-driven criterion for selecting the number of HMM states. An illustrative example of recovery performance under idealised conditions (good_P, good_A, high_SNR) is shown in Fig. 1B. 

Results

Across the five simulation scenarios, recovery depended strongly on the interplay between spatial map structure, temporal dynamics, and noise level (Fig. 2). Under idealised conditions (good_P, good_A, high_SNR), the sequential application of PROFUMO and HMM achieved near-perfect recovery across all metrics, and bi-cross-validation selected the five-state generative model. 

Under fully realistic conditions (real_P, real_A, normal_SNR), recovery declined across all metrics, and multi-state structure was no longer supported by the data. 

The three intermediate scenarios each differed from the fully realistic condition (real_P, real_A, normal_SNR) in only one factor, allowing the contribution of each factor to be assessed in isolation. Improving spatial maps (using good_P) enhanced spatial, temporal and state functional connectivity recovery. Strengthening temporal dynamics (using good_A) restored recovery of state time courses even in the presence of heterogeneous (real_P) spatial maps. Increasing SNR improved all recovery metrics and provided partial support for multi-state structure. 

Conclusion

Our results show that individualised functional mode mapping does not automatically improve dynamic functional connectivity (dFC) modelling. Using controlled simulations, we demonstrate that under realistic spatial variability, weak temporal dynamics, and normal noise levels, the sequential application of individualised functional mode mapping and dynamic functional connectivity modelling can blur multi-state structure rather than enhance it. This effect arises when functional mode spatial maps are estimated independently of temporal dynamics, as in commonly used sequential pipelines, and is illustrated here using Probabilistic Functional Modes (PROFUMO) as an example. Together, these findings indicate that reliable dFC modelling at the individual level will likely require methods that jointly estimate individualised spatial representations and dynamic states within an integrated modelling framework.
