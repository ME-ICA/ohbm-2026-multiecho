Introduction

Real-time functional magnetic resonance imaging (fMRI) is increasingly used in closed-loop and neurofeedback studies. Most real-time implementations rely on region-of-interest (ROI) averages or multivoxel pattern analysis. However, cortical computations are organized across layers, with feedforward and feedback pathways segregated.1 Access to depth-resolved signals in real-time would allow researchers to perturb and modulate laminar dynamics during cognition and could provide a basis for neurofeedback interventions targeting altered laminar processing. Achieving this, however, requires submillimeter spatial resolution, highly accurate anatomical–functional alignment, and rapid processing that keeps pace with the MRI repetition time, posing significant challenges for real-time laminar studies at ultra-high field.2 To address these constraints, we developed an open framework that combines gold-standard ultra-high-field offline processing with a low-latency real-time pipeline at 9.4 Tesla.

Methods

We designed a two-session protocol that separates computationally intensive preprocessing from real-time processing (Figure 1a). In session 1, we acquire a high-resolution MP2RAGE anatomical scan (0.75 mm isotropic resolution) and a whole-brain EPI scan (0.8 mm isotropic resolution): the latter serves as the reference for between-session registration. In addition, we acquire and analyze a functional localizer scan and use its activation pattern to position a GE-BOLD fMRI slab (0.8 mm isotropic resolution, TR = 2 s). Alternatively, ROIs can be defined without a functional localizer, for example by using anatomical features or atlas-derived regions. For all EPI acquisitions, matched reverse phase-encoded EPI scans are collected to enable susceptibility-distortion correction. 

After session 1, whole-brain EPI data are motion-corrected, averaged across repeated acquisitions to improve signal-to-noise ratio, distortion-corrected, and registered to the MP2RAGE using boundary-based registration. Anatomical surfaces are reconstructed using a custom FreeFurfer-based pipeline (Figure 1b), with optional manual refinements to correct skull-stripping errors or adjust surface boundaries. FreeSurfer surfaces are additionally registered to Human Connectome Project’s (HCP) fs_LR space using ciftify,3 providing a standardized representation, allowing the use of HCP-based atlases for ROI definition. 

In session 2, another whole-brain EPI scan is acquired, allowing  cross-session registration to session 11. Its registration to the session-1 whole-brain and slab data is used to determine the slab position that reproduces the same placement as in session 1. Once the slab is positioned, a reference slab image is acquired, and this image is defined as the reference for all subsequent real-time acquisitions. As in session 1, each EPI acquisition is accompanied by matched reverse phase-encoded images to enable susceptibility-distortion correction. After distortion and motion correction, the slab is registered to the MP2RAGE anatomy using the session-2 and session-1 whole-brain data as intermediate registration targets. The resulting combined transformation allows the anatomical surfaces reconstructed in session 1 to be projected into the session-2 slab space while avoiding multiple interpolations in volume space. Cortical depth is computed directly in the native slab space by assigning each voxel a normalized depth value between the white and pial surfaces, producing layer masks aligned to the acquisition grid (Figure 1c). 

These layer-constrained ROIs are passed to a real-time processing framework built on the open-source Pyneal library.4 During online processing, each incoming volume is motion-corrected to the slab reference, masked with the layer ROIs, and used to extract per-layer signals. To support low-latency analysis, we implemented a custom parallel processing system that executes analysis steps concurrently, minimizing the accumulation of processing delays. The system is fully integrated with a real-time monitoring interface, which displays laminar signals upon arrival for ongoing quality control. This interface is modular and can be extended for neurofeedback or other closed-loop paradigms.5

Results

Validation sessions confirmed that the full workflow from offline preparation after session 1 to rapid online processing in session 2 performed reliably within the required timing constraints. Session-1 anatomical processing produced high-quality cortical surfaces and well-defined gray–white boundaries, providing accurate anatomical references for subsequent laminar analyses (Figure 1b). In the first half of session 2, while the participant remained in the scanner, we validated the preprocessing steps: slab positioning completed in ~5 min, distortion correction and registration required ~15-20 min, and cortical layer computation finished in less than 5 minutes. To test functional sensitivity, we targeted the primary visual cortex (V1), with the ROI determined from FreeSurfer parcellation labels. We presented a checkerboard stimulus with varying spatial frequency and contrast to evoke layer-dependent activation. Online visualization confirmed that laminar responses were detectable in real-time and could be tracked dynamically across volumes. Across all 168 volumes, the processing duration was consistent, with an average of 2.19 s per volume (range: 2.16–2.23 s, SD ≈ 0.03 s). Although each volume exceeded the 2 s TR by approximately 0.19 s, the parallel processing architecture prevented cumulative latency, enabling the pipeline to maintain real-time performance throughout the run. Conclusion

This work introduces the first real-time laminar fMRI framework at ultra-high field, addressing longstanding barriers in resolution, alignment, and processing speed by combining state-of-the-art anatomical precision with real-time analysis. The framework incorporates dedicated modules for reproducible slab alignment, precise layer estimation, and depth-specific signal extraction in real-time, all implemented within an open-source codebase. Together, these components provide a robust platform for closed-loop experimental designs,5 neurofeedback applications, and mechanistic investigations of laminar computations in human cognition.
