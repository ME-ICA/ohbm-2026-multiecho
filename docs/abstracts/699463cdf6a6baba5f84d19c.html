Introduction

Personalized resting-state functional connectivity (FC) is a promising biomarker – able to identify individuals and predict behavior – but no generalizable and strongly predictive biomarkers have been found for complex traits or clinical outcomes. A potential explanation is that FC conflates coupling strength with network spatial variation, which introduces noise and reduces biomarker consistency. FC derived using fixed parcellations assumes that the network spatial topography does not change between individuals, which overestimates temporal correlations.1 Data-driven methods, like independent component analysis followed by dual-regression (ICA-DR), solve this problem by deriving networks that vary spatially across subjects. However, they also require networks to be spatially independent, which similarly overestimates FC temporal correlations.2 The Probabilistic Functional Modes (PROFUMO) algorithm estimates networks that can overlap spatially and capture subject-specific spatial variation, disentangling network spatial topography from FC.3 For resting-state networks, spatial topography changes capture subject variability more directly and uniquely than FC changes.1,2

Behaviors are predicted more accurately by both task and resting-state FC than by resting-state FC alone, and FC provides unique information not present in task activation maps.4 However, task FC matrices are normally calculated using traditional resting-state methods, which could lead to a similar temporal correlation bias, resulting in less consistent biomarkers if network spatial topography changes across tasks. Neither the effect of ongoing behavior (i.e. task paradigms) on network spatial topology nor the interaction of task and individual spatial reorganization have been examined. Here, we characterize the network spatial topography changes across both tasks and individuals using the PROFUMO method applied to the Human Connectome Project – Young Adult (HCP-YA) dataset.

Methods

PROFUMO model

PROFUMO is a Bayesian hierarchical matrix factorization method that estimates functional networks as Probabilistic Functional Modes (PFMs) on subject and group levels concurrently.3 Like ICA-DR, PROFUMO estimates a fixed number of networks (M) specified by the user. Each fMRI run is factorized into M PFMs, which are composed of timecourses, amplitudes, and spatial maps (SMAPs) (Figure 1). SMAPs represent the network spatial topography and are shared across all runs for a given PROFUMO subject (which we defined to be a participant-task pair). Subject-level SMAPs are estimated via Double Gaussian Mixture Modeling, using priors from group-level SMAPs. Group-level SMAPs are initialized from group-level ICA spatial maps, then updated using PROFUMO’s hierarchical Bayesian framework. When applied to ~1000 subjects, PROFUMO reliably estimates 40 PFMs and tends to eliminate additional networks,3 so we chose to derive 40 PFMs from the HCP-YA dataset (S1200 release). Significant dice overlap of each group SMAP (cortical regions only) with the AS400K17 (Schaefer 400 regions of interest assigned to the Kong17 functional networks) atlas was calculated using the Network Correspondence Toolbox, which provided network functional labels.

Preprocessing

Only participants with four resting-state fMRI runs (15:00 min each) and two fMRI runs for each of the other seven tasks – working memory task (5:01 min), language task (3:57 min), motor task (3:34 min), social cognition task (3:27 min), incentive processing [gambling] task (3:12 min), relational processing task (2:56 min), and emotion processing task (2:16 min) – were included, though runs with shorter durations were not excluded. The HCP minimal preprocessing pipeline (including artifact removal, motion correction, and MNI registration) was applied to all runs. Consistent with HCP data availability, only resting-state runs were FIX-cleaned. All runs were processed after MSM-All registration in CIFTI format and were spatially smoothed (FWHM 5mm).

PROFUMO Setup

Each participant-task pair was treated as a single PROFUMO subject, resulting in eight PFMs per person. PROFUMO is unsupervised and therefore was blind to participant and task labels. To accommodate the large number of PROFUMO subjects, we used stochastic PROFUMO (sPROFUMO), a scalable PROFUMO implementation.5 The large run duration differences across subjects prevented sPROFUMO from deriving group SMAP priors using MELODIC’s Incremental Group-PCA (MIGP), so sPROFUMO group SMAP priors were initialized using group-level variational ICA (implemented by PROFUMO) on a quarter of the participants.

Classification Analysis

To determine spatial topography reorganization across tasks and individuals for each of the 40 networks, two prediction pipelines were set up. For both pipelines, all steps were included in the cross-validation (CV) folds, preventing data leakage. The first two steps for both prediction pipelines were standardizing the participant-task SMAPs in the training set, then projecting them along their first 500 principal components. Task identity prediction accuracy for these dimensionally reduced SMAPs was determined using multinomial linear logistic regression (ElasticNet penalty, hyperparameters optimized during inner 5-fold CV) with a nested 5-fold CV. SMAPs from the same participant were kept in the same folds. Individual prediction accuracy for these dimensionally reduced SMAPs was determined using a multinomial linear logistic regression (ElasticNet penalty, C=1, l1ratio=0.5) with a stratified 8-fold CV (for each participant, seven tasks were included in the training set, and one was in the test set). Hyperparameter tuning with a nested CV was infeasible for eight SMAPs per individual. Task proportions were kept equal across folds. Significance of all prediction accuracies was determined using the multinomial test, after correcting for multiple comparisons using the Benjamini-Hochberg method.

Results

Cohort

A total of 954 HCP participants met the inclusion criteria, yielding 7632 participant-task spatial maps for each of the 40 PROFUMO networks.

Spatial Topography Reorganization

To visualize patterns of participant-task SMAPs for each network, we projected them along their first two principal components. Most SMAPs separated resting-state from other tasks, but several SMAPs clustered by multiple tasks along their first two principal components, demonstrating that the spatial topography of specific networks changed according to behavioral context. Somatomotor networks separated resting-state and motor tasks from the others, while auditory and language networks separated resting-state and language tasks from the others. 

Other networks, including the default mode network (DMN) spatially reorganized across more tasks (Figure 2A), clustering working memory, relational, and gambling task SMAPs. We visualized the corresponding topological shifts by averaging participant-task SMAPs across tasks. The working memory DMN included large portions of the rostral middle frontal gyrus and the inferior parietal lobe that were not included in the resting-state DMN, while the relational DMN included portions of the rostral middle frontal gyrus only.

Prediction Accuracies (Figure 2B)

Across all 40 networks, task and participant prediction significantly exceeded chance (Task: 53.7% ± 24.5%; Participant: 45.9% ± 31.0%; p < 0.001) and performed consistently across folds (Maximum Task SD: 1.7%, Maximum Participant SD: 1.8%). Though somatomotor, auditory, and language networks did not always achieve high task prediction accuracies (43.2% – 80.9%), confusion matrix analysis indicated that they were able to accurately distinguish their corresponding task from others (93.2% –  96.7%). Four networks predicted all tasks with high accuracy (89.7% – 94.6%), which were primarily composed of control network (CN), dorsal attention network (DAN), and DMN regions. A similar cluster of four networks with very high fingerprinting accuracy occurred (98.6% – 99.4%). 

Dual-Nature Networks (Figure 2C-D)

Three networks were able to predict both task and participant at high accuracy, indicating orthogonal spatial topography changes across task and participant. Network 1 (Task: 93.4%; Participant: 99.2%) was composed of CN and DAN regions. Network 2 (Task: 90.6%; Participant: 98.6%) was composed of DMN, CN, and Language regions. Network 3 (Task: 89.7%; Participant: 98.7%) was composed of DMN and CN regions.

Specificity

The highest-performing networks for both participant and task prediction reorganized preferentially for one over the other. The network with the highest task prediction accuracy (94.6%), composed of visual and DAN regions, achieved a participant prediction accuracy of 75.9%. The network with the highest participant prediction accuracy (99.4%), a global network, achieved a task prediction accuracy of 73.0%. 

Conclusion

Previous work established that network spatial topography changes across individuals.1 Our results demonstrate that spatial topography also changes across task paradigm: participant-task SMAPs cluster by task along their first principal components and they accurately predict task identity. Though all networks achieved significant predictive accuracy, individual network predictive power varied widely, implying a spectrum of spatial flexibility. Certain unimodal networks, including somatomotor, auditory, and language networks, remained static across most tasks, only reorganizing spatially during their corresponding tasks (i.e. motor or language). Conversely, transmodal networks, including the DMN, spatially reorganized uniquely for each task. Since the HCP task protocol follows a block design and the DMN deactivates during task, its spatial reorganization possibly supported context integration between blocks, incorporating regions to evaluate previous task performance or prepare for future tasks. This spatial reorganization occurred in a task-specific manner, indicating that context integration recruits different regions depending on behavioral context.

The high fingerprinting capabilities of networks that can also predict task state indicates that changes in spatial topography across behavior and individual are orthogonal: task-specific reorganization does not preclude individual reorganization. Some spatial reorganization captured task or individual preferentially, most noticeably for the networks with the highest corresponding prediction accuracies. The Visual-DAN network likely reorganized according to the varied visual stimuli (or lack of stimulus in the language task) and the attention needed (or not needed in resting-state) to complete the assigned task. Conversely, spatial topographical changes in the global network acted as excellent fingerprints, but less accurate task identifiers. This quality may be a result of structural differences driving the network spatial map, which are known to be strong fingerprints, but would not change according to behavior. 

Future Directions & Impact

The separation of resting state from other task conditions along the first two principal components for most networks likely reflects preprocessing differences (FIX-cleaning in rest vs minimally preprocessed task); however, preprocessing differences cannot account for the strong multinomial prediction accuracies across multiple tasks, indicating that spatial topography captures task signal in several networks. To definitively isolate signal from noise, future work should replicate these findings using the 2025 HCP release, which includes FIX-cleaned task and resting-state fMRI runs.

Our work demonstrates that spatial topography is sensitive to both individual and condition, highlighting several networks for biomarker consideration. To determine whether spatial topography captures more personalized variation than functional connectivity changes, we plan to quantify the ability of SMAPs to predict higher-order cognitive traits and compare their prediction accuracy with traditional FC changes during resting-state and task. 

Though future work is necessary to determine whether spatial topography captures more variance than functional connectivity between parcellated networks or ICA networks, our work provides evidence that current FC methods likely convolve task functional coupling with spatial topography. This signal mixing could explain reduced generalization of FC biomarkers to different populations. Methods, like PROFUMO, which can derive separate biomarkers for coupling and topography across both individual and task may identify more generalizable and reliable biomarkers, providing a new source for personalized disease markers and treatment outcomes.
