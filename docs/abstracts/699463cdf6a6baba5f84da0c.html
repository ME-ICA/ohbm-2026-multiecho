Introduction

Working memory and attention are key cognitive functions, where working memory is the temporary storage and manipulation of information, while attention maintains focus on certain stimuli avoiding distractions1. Impairments in these domains are linked to neurodevelopmental disorders such as ADHD2,3, highlighting the need for effective identification of biomarkers in early diagnosis. In recent years, multimodal neuroimaging facilitates a more comprehensive understanding of brain development and mental disorders4, however studies lack the incorporation of longitudinal information. In this study, we have investigated a longitudinal data from Adolescent Brain Cognitive Development (ABCD) which comprises baseline data (ages 9-10 years) and two-year follow-up (ages 11-12 years) from three different modalities: gray matter density (GM) images derived from T1-weighted structural MRI (sMRI), white matter fractional anisotropy (FA) images from diffusion MRI (DTI) and static functional network connectivity (sFNC) matrix derived from resting state fMRI (rsfMRI). The goal of this study is to evaluate the beneficial role of incorporating longitudinal data from multiple neuroimaging modalities on the predictive performance of working memory and attention, and to provide insights into the key structural, diffusion and functional brain features underlying these cognitive domains and their interrelationship. Brain features extracted from each modality and each time point were integrated using various fusion strategies to predict two-year follow-up working memory and attention scores. Model interpretability was achieved using Guided Grad-CAM for structural and diffusion, and input by gradient for functional connectivity, revealing the modality-specific significant brain features linked to the two cognitive domains. 

Methods

For our datasets, we used common subjects between the sMRI, DTI and fMRI in both baseline and year two, which is 3,302. The primary outcome measures in this study are the two-year follow-up working memory score and the attention score, both obtained from the Emotional N-back task. The working memory score corresponds to the 2-back accuracy (c2b), indicating participants correctly responded whether the current stimulus matched the one presented two trials earlier, whereas the attention score corresponds to the 0-back accuracy (c0b), indicating participants correctly identified whether the current stimulus matched that the one shown at the beginning of each trial5. As a preprocessing step, sMRI images were processed using Statistical Parametric Mapping 12, normalized to MNI space and smoothed. DTI was preprocessed using FMRIB Software Library (FSL) and Advanced Normalization Tools (ANTs) for correction and MNI registration. For rs-fMRI, data were analyzed using NeuroMark ICA to extract 53 intrinsic networks and Pearson correlation was performed between all pairs of IC time courses to generate a 53 by 53 sFNC matrix, which was flattened into a 1D vector. 

Our proposed deep learning framework includes three stages: (a) modality-specific feature extraction, (b) multimodal fusion and (c) final prediction. Feature extraction leveraged transfer learning technique with modality-specific pretrained models. We pretrained two Convolutional Neural Networks (CNNs) models for sMRI and DTI separately, and one Multilayer Perceptron (MLP) model for fMRI, using the baseline large data for the prediction of working memory. Each pretrained CNNs and MLP model was subsequently used for integration into the multimodal fusion stage.  After feature extraction from both baseline and year-two time points for each modality, the resulting six feature vectors were integrated using the multiple fusion strategy. Fusion 1 is direct concatenation. Fusion 2 strategy uses a multi-head self-attention where input features were linearly projected to query, key and value, and scale dot product attention was performed for each head and outputs were concatenated. Fusion 3 strategy employs a cascaded transformer where six multi-head attention blocks (two versions are compared as shown in Figure 1(d) and 1(e)) are designed, each for each feature set, the updated features were sequentially fused with the next feature set by a cross-attention module in the fixed order: sMRI baseline, sMRI year-two, DTI baseline, DTI year-two, fMRI baseline and fMRI year-two. After the fusion stage, we passed outputs to a fully connected layer that predicts working memory and/or attention. Additionally, in Fusion 4 strategy, we directly concatenated six features and passed them to a fully connected layer with two independent prediction heads, one for working memory and one for attention, forming a multitask fusionFi. The overall pipeline of architecture is shown in Figure 1. 

To interpret our results, we implemented Guided Grad-CAM approach for sMRI and DTI models and an input by gradient approach for fMRI model using the testing datasets. After obtaining the Guided Grad-CAM heatmaps for all testing samples, a voxel-wise one-sample t-test followed by false discovery rate (FDR) was performed to evaluate significant voxels. The mean importance scores of significant voxels were computed and the top voxels with scores exceeding the global mean were selected for interpretation. Similarly, for fMRI, we applied the input by gradient approach to compute the importance score and performed the one-sample t-test followed by FDR correction to select the significant features. Again, significant features were averaged across subjects, and the top 5% were selected for interpretation. 

Results

For each of our models’ pipelines that use different fusion strategies, we computed the Pearson correlation coefficient between the predicted and ground truth scores for both working memory and attention scores. Table 1 shows the models’ performance (correlation scores, r) for both cognitive processes. The result demonstrates that direct concatenation achieved a testing correlation of 0.38 for working memory and 0.16 for attention. While the multi-head attention and cascaded transformer underperformed, the multitask learning model matched the best working memory performance and achieved the highest attention prediction score of 0.21. 

We projected significant voxels identified using Guided Grad-CAM and Input × Gradient back onto the brain to visualize regions contributing to working memory and attention, including both cognitive process-shared and cognitive process-specific regions, as shown in Figure 2 (B). For working memory, prominent gray matter regions included the Middle Frontal Gyrus, Superior Temporal Gyrus, and Precentral Gyrus, while major contributing white matter tracts included the Anterior Thalamic Radiation, Superior Longitudinal Fasciculus, and Corticospinal Tract. For attention, significant gray matter regions were observed in the Superior and Middle Frontal Gyri, and Superior Temporal Gyrus, with white matter contributions primarily from the Anterior Thalamic Radiation, Forceps Minor, and Superior Longitudinal Fasciculus. Several regions were shared across both cognitive processes, including Superior Temporal Gyrus for gray matter and Anterior Thalamic Radiation, and Forceps Minor for white matter, while unique working memory regions involved frontal and temporal gray matter, with white-matter contributions from the anterior thalamic radiation, superior longitudinal fasciculus, and corticospinal tract. In contrast, attention specific regions were primarily frontal and temporal, with distinct involvement of the forceps minor and inferior fronto-occipital fasciculus. 

For sFNC data, we identified 18 unique features for working memory, 18 for attention, and 2 shared features. Figure 2 (C) showed the connectivity patterns, with cognitive-specific and shared connections. Each plot displays mean sFNC in the lower triangle and model-derived significant connectivity in the upper triangle, with each color indicating positive and blue for negative connections. The label abbreviations correspond to the Subcortical Network (SCN), Auditory Network (ADN), Sensorimotor Network (SMN), Visual Network (VSN), Cognitive Control Network (CON), Default Mode Network (DMN) and Cerebellar Network (CBN).

Conclusion

In this study, we focus on the longitudinal multimodal fusion of three neuroimaging modalities—sMRI, DTI, and fMRI—to predict working memory and attention. We evaluated several fusion strategies, including direct concatenation, cascaded transformers, and direct concatenation with multitask learning. Among them, direct concatenation and multitask learning achieved the highest prediction performance for working memory (r = 0.38), while multitask learning outperformed all other approaches for attention prediction (r = 0.21). Our multimodal fusion with multitask learning utilizes the shared representation of working memory and attention and performs better due to its joint optimization of both, which are closely related cognitive domains. The predictive performance achieved by our proposed model is driven by the combined contribution of both longitudinal and multimodal information. To assess the contribution of longitudinal information, we trained models using single time points only. Models trained on baseline data achieved correlations of 0.29 for working memory and 0.15 for attention, while year-two data yielded correlations of 0.31 and 0.15, respectively. These results demonstrate that incorporating longitudinal information improves overall predictive performance. For interpretation, using Guided Grad-CAM, we obtained the significant voxels associated with each cognitive domain, which help us to get the contributing brain regions for working memory and attention. Working memory and attention are closely related cognitive domains; therefore, we obtained common brain regions for working memory and attention. For the unique brain regions of working memory and attention, we found that although some brain regions are listed as both common and unique, MNI coordinates indicate that distinct subregions within the same anatomical area contribute uniquely to each cognitive function. Similarly, for fMRI, we implemented the Input × Gradient and obtained the significant features, which gave us significant functional connectivity for each of the working memory and attention. As shown in Figure 2(C), working memory was positively associated with stronger within-network connectivity and negatively associated with default mode and visual network interactions, whereas attention showed stronger inter-network connectivity and weaker within-network interactions. And for the common functional connectivity patterns for working memory and attention, both exhibiting strong positive relationships within visual network integration and visual–default mode network coupling. In sum, our proposed model utilizes both longitudinal and multimodal information and achieves high predictive performance compared with other fusion techniques. Also, the implementation of Guided Grad-CAM and input by gradient helped us to interpret the model and provide the contributing brain regions for working memory and attention. In the future, we can extend this by incorporating additional modalities, additional timepoints and the use of more advanced fusion techniques.
