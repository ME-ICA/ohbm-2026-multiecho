Introduction

Despite being well-researched and affordable, the multi-channel electroencephalogram (EEG) struggles to expand beyond controlled research and clinical settings. A major hurdle to broader EEG use is contamination by non-cerebral signals, known as artifacts. EEG artifact removal often requires the supervision of a trained operator, leading to reduced scalability and reliability. Hence, tackling artifacts has recently been rated by experts as the most important development needed in EEG research.

Current state-of-the-art methods present notable limitations. Independent component analysis (ICA) is effective for specific artifact types but is computationally demanding, relies on subjective or classifier-based component rejection, and struggles with Gaussian or distributed noise. Artifact subspace reconstruction (ASR) offers improved speed but requires clean reference data and depends on variance-based thresholds that cannot reliably distinguish signal from noise. Moreover, its reliance on orthogonal component separation limits performance in complex artifact mixtures.

Here, we present GEDAI (Generalized Eigenvalue De-Artifacting Instrument), a fully automated EEG denoising framework based on generalized eigenvalue decomposition (GEVD). GEDAI overcomes key limitations of prior GEVD approaches by introducing a theoretically derived reference covariance matrix based on EEG forward modeling via the leadfield matrix. This principled construction defines the expected brain signal subspace without requiring empirical clean or artifactual segments. Additionally, GEDAI employs an objective, data-driven criterion to separate signal and noise components based on subspace similarity.

Methods

GEDAI:

The GEDAI algorithm works as follow: a reference covariance matrix (refCOV) is derived from a precomputed leadfield matrix for standard 10-5 system electrode locations or, for non-standard electrode locations, from an interpolated leadfield matrix calculated ‘on-the-fly’ via spherical interpolation. Next, the whole input EEG signal (including artifacts) is epoched in circa 1-second windows, and an individual data covariance matrix (dataCOV) is generated for each epoch. Then, each data covariance matrix is decomposed with GEVD, using refCOV as a fixed reference matrix across all epochs. After, the output EEG data is reconstructed and evaluated using the Signal & Noise Subspace Alignment Index (SENSAI), in order to determine the optimal cutoff that separates brain from artifactual components, sweeping across a range of artifacting strengths. By respectively maximising and minimizing the subspace similarities of the retained and removed data with the refCOV, across different thresholding strengths, GEDAI estimates the optimal cutoff for component removal. For the final step, the denoised time-series of each epoch is then reconstructed by using only the GEVD components belonging to the brain-subspace.

EVALUATION:

We compared the GEDAI algorithm to 3 state-of-the-art denoising algorithms (ASR, MARA and ICLabel) in terms of ground-truth signal reconstruction on both synthetic and empirical EEG data. 

  • A synthetic datasets were generated by combining forward-modelled clean EEG signals with realistic artifact sources, allowing full access to ground-truth brain activity. Clean EEG was simulated using the SEREEGA toolbox with a realistic head model and leadfield, spanning diverse neural dynamics including colored noise, oscillatory activity, and epileptiform spikes. Artifacts were constructed from real EOG and EMG recordings and from synthetic and empirical noise sources, projected into sensor space using physiologically plausible spatial topographies. Multiple artifact categories were considered (EOG, EMG, noise, and mixtures), with varying signal-to-noise ratios, temporal contamination levels, and the inclusion of bad channels. This resulted in a large benchmark of 3,200 synthetic datasets.
  • Empirical simulations complemented the synthetic benchmark by mixing visually inspected clean resting-state EEG recordings with independently recorded artifact signals. This approach preserved realistic EEG structure while maintaining known ground truth for evaluation. Empirical datasets covered the same artifact categories and experimental manipulations, yielding an additional 6,400 datasets.

Algorithm performance was evaluated using three key metrics: correlation with ground-truth EEG, signal-to-noise ratio (SNRafter), and relative root mean square error (RRMSE). GEDAI was statistically compared against other algorithm using paired, non-parametric tests with a significance level set at α = 0.05. A Friedman test was used to identify overall differences in performance across algorithms under varying signal-to-noise ratios, temporal contamination levels, and artifact types. When significant effects were observed, post-hoc pairwise comparisons were conducted with Bonferroni correction to control for multiple comparisons. Effect sizes were quantified using standardized Z-score estimates to assess the magnitude of pairwise differences.

Results

Across all datasets and conditions (Friedman test χ²(3) = 4704, p < m.p.), GEDAI outperformed all algorithms in post-hoc pairwise comparisons (p < m.p.).

GEDAI significantly differed from MARA, the closest competitor in SNRafter (r = 0.59 ; GEDAI mean= 8.67 dB ; MARA mean = 6.14 dB) and RRMSE (r = -0.64 ; GEDAI mean = 0.38 ; MARA mean = 0.57). 

GEDAI significantly differed from ASR, the closest competitor, in Correlation Coefficient (r = 0.63 ; GEDAI mean= 0.92 ; ASR mean= 0.83).

Conclusion

Taken together, these findings position GEDAI as a state-of-the-art tool for EEG denoising, distinguished by its robust performance in heavily contaminated, low-SNR conditions and its particular strength in resolving complex mixtures of artifacts.
