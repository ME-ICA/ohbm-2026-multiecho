Introduction

The advent of generative artificial intelligence (AI) models for neuroimaging1 has enabled to model feature-to-feature mappings while taking into account the effects of demographic and clinical assessment variables via conditioning, instead of these variables being the primary predictors in traditional deep learning and machine learning architectures2,3. We introduce a multimodal methodological framework for generative modeling of structural and functional connectivity features for the human brain.   

We employ a graph-based version of the conditional variational autoencoder4 to encode static functional network connectivity (sFNC) and structural co-modulation (ScM) features into a common latent representation usingmultimodal fusion. These representations are used for creating synthetically generated features via a decoder andstudying the key patterns about the conditioning variable in the latent representation and generated data.  

By using this framework with biological sex as the conditioning variable on multimodal features from the Human Connectome Project (HCP) dataset5, we show that our model can achieve the tri-fold objective of generating high-quality synthetic multimodal neuroimaging features, retaining predictive patterns in the generated data, and meaningful associations in the latent space used for generation.  

Our framework is an important step towards developing interpretable generative AI models tailored to the context of neuroimaging features and clinical neuroscience applications. More specifically, such models can be extended to support the data-driven development of multimodal signatures for brain disorders, cognitive functions, and demographic variations in clinical neuroscience. 

Methods

We used structural MRI (sMRI) and functional MRI (fMRI) data from the Human Connectome Project (HCP) dataset5. The data were pre-processed using a standard pre-processing pipeline in SPM software. We used scans from a total of 833 subjects, aged 28.76 ± 3.6 yrs with 390 male and 443 female subjects.  

For functional connectivity features, Pearson correlation coefficients were computed between the time courses of53 Neuromark brain components extracted from each subject’s fMRI time series, resulting in a 53x53 sFNC matrix.For structural features, we used the mean gray matter volume (GMV) for the 53 Neuromark brain componentmasks. The outer product of the resulting mean GMV vector was then calculated, resulting in a 53x53 ScM matrix for each subject.  

The structural and functional connectivity feature matrices were then used as adjacency matrix inputs to the two parallel encoders based on the graph attention neural network4 (GATv2) model to create joint latent feature vectors. The multimodal latent feature vectors were then fused along with the conditioning variable according to a Gaussian mixture of experts (MoE) strategy. This was followed by variational sampling in the autoencoder and finally a decoding step based on a multi-layer perceptron (MLP) to create the generated features. The details of the overall pipeline are visualized in Figure 1.  

The analysis was done with 80% training, 10% validation,, and 10% held-out test data for training and testing the CG-VAE model, along with hyperparameter tuning. The generated features in the test data were then compared using performance metrics, which included mean squared error (MSE), Frobenius norm, and Pearson correlation between the real and generated samples.  

Additionally, the joint multimodal latent embedding vectors for each generated sample in the test set were analyzed for associations with the conditional variable (sex) using a two-sample t-test between the male and female labelled samples, to assess whether any latent embeddings captured significant differences between the two groups in the generated data.   

To test the predictive power of CG-VAE outputs, the generated and latent features from the test set were compared with real features based on their predictive performance in a sex-classification task. Classification was performed using a support vector machine (SVM) with repeated 5-fold cross-validation, in which the test set was further split into training, validation, and testing subsets in a 4:1:1 ratio. It should be noted that this secondary split was applied solely to assess the sex-classification performance within the test set defined by the primary CG-VAE data splits.  

Results

The multimodal CG-VAE model was trained on functional (sFNC) and structural (ScM) features from HCP data by randomly splitting into 80% train, 10% validation, and 10% test data. For the functional and structural encoders, a hidden dimension of 53 was used for the GATv2 model, thus keeping the 53x53 connectivity graph structure intact throughout the GATv2 layers. After hyperparameter tuning, the model with the lowest MSE-based reconstruction loss was selected as the optimal model. The selected parameters included a joint multimodal latent dimension of 32, two layers in the MLP decoder, a learning rate of 6e-4, a weight decay of 1e-4, and a batch size of 16. The model was trained for 100 to 1000 epochs with early stopping and comprised a total of 167,588 trainableparameters. 

Figure 2(a) shows the mean values of real and generated samples in the test set for structural and functional features. As can be seen, the model generates very similar features. To test this statistically, we compared the mean values for real and generated test samples using a two-sample t-test with FDR correction, and found no significant differences (at p-value threshold of 0.01) in all but one out of 3C2 = 1378 elements in the mean SFNC matrices and all elements of the mean ScM matrix. Secondly, we checked the generative performance usingsimilarity metrics, including mean squared error (MSE), Frobenius norm, and Pearson correlation, computedbetween real and generated test samples and summarized in Table 2(b) in the results figure. It can be observedthat all metrics yield very strong values, further indicating that the model successfully generates highly realistic multimodal samples when trained on functional and structural features.  

To study the joint multimodal latent space of the model, we performed an association analysis of the latent embeddings for the generated test samples. Figure 2(c) shows a bar plot of –sign(t) log(p) values from a two-sample t-test between male and female groups for the 32-dimensional joint latent embedding vectors for the test set. It can be observed that while the latent space embeddings encode generative information for the data in general, 3 out of 32 elements show statistically significant differences (p-value threshold of 0.05) between the male and female groups, as seen by the dotted-red threshold line in Figure 2(c). This indicates that, in addition to generic encodings, the latent space also has elements with significant condition-specific differences. Figure 2(d) shows t-SNE embeddings for the top elements of joint multimodal latent vectors. As can be seen, there are distinctly placed clusters for the male and female groups, further indicating that the model can encode distinct latent features corresponding to the conditioning variable.  

Finally, we also tested the predictive performance for real, generated, and joint latent features by using them for sex-classification (M vs. F) by creating second-level splits within the generated test samples. We used an SVM classifier with 5-fold cross- validation for this purpose, trained and tested independently for a total of 5 scenarios involving real sFNC, generated sFNC, real sCM, generated sCM, and joint latent features. Table 2(e) shows the predictive performance on different metrics for sex classification. As observed, the generated data either retains or slightly enhances the classification performance as compared to real features for each modality. However, the most observable result is that the joint latent features enhance the classification performance by a significant margin, indicating that the model is able to encode highly discernible latent embeddings for the conditional variable. 

Conclusion

This work introduces a novel multimodal generative AI framework for neuroimaging features based on a conditional graph-based variational autoencoder (CG-VAE). The framework enables the generation, and analysis of functional and structural connectivity features extracted from voxel-level fMRI and sMRI maps in the HCP dataset, using biological sex as the conditioning variable. By integrating features from both modalities into a common latent representation, and taking into account a conditioning variable at hand, the model is able to successfully achieve a three-fold objective.  

Firstly, the model can generate high quality realistic multimodal features which are strongly similar to real data on multiple performance metrics, with no significant differences between real and generated elements after robust statistical testing.  

Secondly, the model encodes strong associations between the conditioning variables and certain elements of the joint latent embeddings, while also encoding generic information to generate high-quality data. This is further verified by the distinctly placed clusters in the t-SNE visualizations of the top latent space elements.  

Lastly, the predictive patterns for the conditioning variable are not just retained in the generated data space, butalso enhanced in the joint latent embedding space. This further indicates that the CG-VAE model is able to capture discernible predictive patterns corresponding to the conditioning variable, which are preserved during the data generation process.  

In conclusion, this model is a very important stride towards generative AI models for neuroimaging. Our framework generates high quality neuroimaging features, enables the analysis of associations with non-neuroimaging variables, and enhances predictive power. With further extensions, this framework could support data-driven biomarker development for brain disorders.  

In the future, this work can be extended to include more datasets and clinically observed diagnostic ordemographic assessments as joint conditioning variables. This would allow the discovery of structural and functional brain signatures underlying behavioral and clinical changes in brain disorders, while accounting for demographic effects.
