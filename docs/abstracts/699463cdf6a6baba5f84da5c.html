Introduction

Workflows based on personalized virtual brain models offer a route to stratify subjects along healthy aging and neurodegenerative disease trajectories, but their practical usefulness relies on identifiability of the  disease‑relevant parameters from realistic data. We present a methodological framework to quantify parameter identifiability for virtual brain models using synthetic multi‑modal data that combines resting‑state dynamics with responses to non‑invasive brain stimulation (NIBS), and demonstrate its use on the Alzheimer's disease usecase.

Methods

The workflow consists of three components: stimulation modeling workbench based on preprocessed data of 100 healthy subjects, ready for NIBS modeling, scaffold for virtual brain simulations along a parametrized trajectory, and a systematic evaluation of the parameter identifiability using the simulation-based inference.

The NIBS simulation workbench incorporates previously published 100 realistic head models with variable tissue conductivity values and computational toolset for modeling of the NIBS effect (^1, ^2), and the virtual brain modeling pipelines (^3, ^4). In particular, for the virtual brain parameter estimation, we focus on modeling the TMS+EEG experimental paradigm.

Virtual brain models can be parametrized to capture progression of neurodegenerative diseases or psychiatric conditions (^5). In the other way around, the estimation of these parameters from empirical observations underlies the diagnostic application of the virtual brain models (^6). While the specific parameters, connectivity or spatial masks defining the progression trajectory differ, the methodology of validation of the model-based trajectory using synthetic datasets representing individual's progression is at heart of the model development workflow.

The parameter identifiability leverages the Simulation Based Inference (SBI, ^7, ^8) for parameter estimation. SBI is grounded Bayesian statistical inference, and uses state-of-the-art machine learning to establish the link between the selected parameters of the virtual brain model, and the functional data features of the simulated or empirical activity.  provides several diagnostics to assess the accuracy and reliability of the estimation. Coupled with known ground-truth simulated data, these allow us to perform the identifiability analysis.

Results

The resulting framework supports end-to-end workflows for developing and validating parameter inference for virtual brain models using responses to noninvasive stimulation as target data features.

As a demonstration, we evaluate the identifiability of the parameters of the Jansen Rit model implicated in the previously published trajectory for Alzheimer's disease (^9). Starting from the healthy baseline, the synaptic strength between the pyramidal cells and the inhibitory (C_ip) and excitatory (C_ep) interneurons is varied. While at the beginning of the trajectory, both resting state and the TMS response provide comparably precised estimates of both parameters (first row), the changed parameters in later stages of the progression trajectory are better identified with the stimulus response.

Conclusion

The presented framework provides a unique integration of realistic head model data, computational tools for stimulus effect modeling, virtual brain models of brain activity, and parameter estimation with simulation based inference. As such, it serves as a versatile workbench for development and validation of diagnostic applications of virtual brain models using responses to noninvasive stimulation as target data features.
