Introduction

Risk prediction models in neuroimaging often require large, diverse datasets, which are typically constructed by aggregating data across multiple clinical sites. However, pooling data in this manner can introduce site effects — systematic differences in imaging measurements attributable to scanner hardware, acquisition parameters, or site-specific protocols.1 Although a variety of harmonization methods have been proposed to mitigate these effects, best practices for incorporating harmonization into machine-learning workflows remain underdeveloped. For instance, while some studies have harmonized the full dataset before model training, others argue that this procedure risks data leakage and can lead to overly optimistic estimates of model accuracy.2 A further complication is that widely used approaches such as ComBat require inclusion of non-imaging covariates in the harmonization model to avoid biasing batch-effect estimation when covariate distributions vary across sites. In prediction settings, however, the outcome variable is not observed for the target data and therefore cannot be included in the harmonization model, which may attenuate genuine imaging–outcome associations when outcomes are imbalanced across sites. To address these challenges, we introduce an imputation-based framework in which batch-effect parameters are estimated exclusively within the training data and subsequently applied to the target data, with imputed outcomes incorporated during harmonization to help preserve imaging-outcome associations.

Methods

Figure 1 provides an overview of the proposed harmonization framework for machine-learning applications. First, a harmonization model (ComBat, CovBat, etc.) is fit using the training data, with the outcome included to preserve imaging–outcome associations during harmonization. Second, a prediction model is trained on the harmonized training data, and optimal hyperparameters are selected using k-fold cross-validation. Third, the outcome in the target dataset is imputed, and the resulting imputed values — together with the batch-effect estimates derived from the training data — are used to harmonize the target imaging data. Because the initial imputation is performed on unharmonized data, the harmonized target data are then used to re-impute the target outcome. This iterative procedure of outcome imputation followed by harmonization is repeated until convergence. Finally, the trained prediction model is applied to the harmonized target dataset to obtain the final predictions.

Although the framework is compatible with a wide range of imputation, harmonization, and prediction models, in this study we employ random forest algorithms for both imputation and prediction. Under multiple imputation, several harmonized target datasets are created using each imputed outcome, predictions are generated for each dataset, and final predictions are obtained by averaging (for continuous outcomes) or taking the mode (for categorical outcomes). Harmonization is performed using ComBat, an empirical Bayes method that removes both location and scale scanner effects.3

To evaluate the proposed approach, we used structural MRI data from the Alzheimer’s Disease Neuroimaging Initiative (ADNI) and the Baltimore Longitudinal Study of Aging (BLSA), aggregated through the Imaging-based coordinate SysTem for Aging and NeurodeGenerative diseases (iSTAGING) consortium (n = 3,477; participants aged 22–93 years; 49.3% female). Gray-matter volumes for 145 regions of interest were derived using a previously described multi-atlas label-fusion method.4 Prior to the primary analysis, we conducted a plasmode simulation in which imaging data were generated using the model 

                                                          yijv = αv + Xijβv + γiv + δivεijv

where i = 1,..., S indexes sites, j = 1,..., N indexes participants, v = 1,..., 145 indexes brain regions, and Xij = [x1, x2] contains a nuisance covariate and a binary outcome. The parameters γiv and δiv represent location and scale batch effects, respectively, and εijv is a residual term obtained by resampling rescaled volumetric data from the ADNI + BLSA data set to preserve the empirical spatial covariance in simulated imaging data. Batch-effect magnitudes and outcome prevalences were uniformly distributed across sites (γiv ∈ [-1, 1], δiv ∈ [1/3, 3], outcome prevalence ∈ [.05, .95]) to ensure the presence of both site effects and outcome imbalance. Here we report results from simulations with a sample size of N = 750 and the number of sites set to S = 10. We compare our method with: (1) no harmonization; (2) ComBat harmonization without including the outcome; (3) PrettYharmonize, a recently developed approach that harmonizes the target data pretending the outcome values are all from the same class (repeated across each outcome class to get multiple harmonized data sets from which an ensemble prediction can be generated)5, and (4) an oracle approach where the true outcome for the target data is used during harmonization.

Finally, we applied all methods to the ADNI + BLSA dataset using 100 random train–test splits (80% training). To examine how each harmonization method performed for unique outcome data types, we evaluated predictive accuracy using the area under the ROC curve (AUC) and residual mean squared error (RMSE) for predicting age, cognitive status (Alzheimer’s disease, mild cognitive impairment, cognitively normal), and sex. Reported AUC and RMSE values represent averages computed across the 100 repeated train–test splits.

Results

Figure 2a summarizes the results of the simulation analyses. As expected, omitting harmonization produced inflated predictive performance, yielding a moderate AUC (0.69) even when no association existed between the simulated imaging features and the outcome. PrettYharmonize also showed evidence of inflation in the absence of true imaging-outcome associations, exhibiting a higher AUC than the oracle method under null conditions (AUC = 0.59; Cohen’s d = 1.01). In contrast, ComBat applied without the outcome, both imputation-based harmonization strategies, and the oracle method all yielded comparable performance when no imaging–outcome associations were present (AUC = 0.53 – 0.54). As the effect size increased, the imputation-based harmonization approaches consistently achieved the highest predictive accuracy. For the largest effect size examined (βv = 1), multiple imputation yielded the highest mean AUC (0.921). Relative to the oracle approach, methods that did not incorporate imputed outcomes during harmonization — no harmonization (AUC = 0.84; Cohen’s d = –1.21), ComBat without the outcome (AUC = 0.87; Cohen’s d = –0.75), and PrettYharmonize (AUC = 0.85; Cohen’s d = –1.14) — showed moderately reduced predictive performance. 

Figure 2b presents results from repeated train–test splits of the combined ADNI + BLSA dataset. When predicting cognitive status, model performance was highest when no harmonization was performed (mean AUC = 0.82), followed by PrettYharmonize (AUC = 0.79). The single and multiple-imputation random forest approaches performed similarly (AUC = 0.76) and were nearly indistinguishable from the oracle method (AUC = 0.76). When predicting sex, performance was uniformly high and nearly identical across harmonization strategies (AUC = 0.90), likely reflecting the balanced distribution of sex across sites. For models predicting age, PrettYharmonize performed substantially worse than all other methods (RMSE = 60.3), whereas all remaining approaches performed comparably to the oracle method (Cohen’s d = –0.30 – .14).

Conclusion

Here we proposed a novel method for harmonizing imaging data for when the outcome is missing, which was motivated by predictive modeling settings. In the absence of any true imaging–outcome associations, applying currently available approaches produced inflated AUC estimates compared to both single and multiple imputation-based approaches. ComBat harmonization without the outcome performed comparably to the oracle when no true association was present but showed reduced predictive performance as the effect size increased. In contrast, the proposed imputation-based harmonization framework produced oracle level out-of-sample performance when true associations existed. These results indicate that incorporating imputed outcomes during harmonization is critical for preserving valid imaging-outcome relationships when the outcome is imbalanced across sites.

Results from the ADNI + BLSA dataset mostly corroborated the simulation findings. When predicting cognitive status, the imputation-based methods achieved predictive performance nearly equivalent to the oracle and exceeded the performance of ComBat without the outcome, whereas PrettYharmonize and no harmonization exhibited performance exceeding that of the oracle, indicating potentially over-optimistic predictions. Prediction of sex showed uniformly high performance across methods, consistent with the balanced distribution of sex across sites. Across outcomes, harmonization strategies that incorporated imputed outcomes produced predictions similar to the oracle method, while alternative harmonization approaches either attenuated true associations or displayed potentially inflated performance. Altogether, these findings demonstrate that imputation-based harmonization provides a robust method for integrating batch correction into predictive modeling pipelines for multi-site neuroimaging data.
