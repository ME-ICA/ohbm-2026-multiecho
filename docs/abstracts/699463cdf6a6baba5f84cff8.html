Introduction

Modern neuroimaging research demands fluency in a range of procedures across computing, analytics, and visualization. While specialized software packages exist to address individual challenges in acquisition, processing, and analysis, significant gaps remain between these tools. Trainees in network neuroscience frequently encounter seemingly basic tasks that prove surprisingly difficult to accomplish with existing software: importing brain atlases, parcellating data, constructing consensus networks, or visualizing results on cortical surfaces. This often results in a proliferation of ad hoc scripts and informal workarounds that are difficult to maintain and give rise to a range of methodological and reproducibility issues.

We present netneurotools (github.com/netneurolab/netneurotools), a Python package designed to fill precisely these gaps in the network neuroscience workflow. Born from the daily needs of trainees at the Network Neuroscience Lab, Montreal Neurological Institute, the toolkit embodies a “desire paths” philosophy: functionality grows organically with actual research demands, ensuring that the codebase reflects genuine needs. With over eight years of development since 2017, netneurotools has been battle-tested across more than 50 publications and has been adopted by researchers worldwide.

Methods

The netneurotools package is organized into nine modules that span the full lifecycle of a network neuroscience project. The datasets module provides programmatic access to cortical surface templates, brain parcellations, and published datasets with an efficient caching system. The networks module implements methods for generating consensus connectivity matrices and randomized surrogate networks that preserve topological or geometric properties. The metrics and modularity modules offer optimized implementations of classical and cutting-edge graph-theoretical measures, including communication models and community consensus workflows. The stats module provides efficient correlation metrics, permutation testing routines, and regression analyses including dominance statistics. A recently added spatial module implements geospatial statistics for studying the spatial embedding of neural patterns. The plotting module enables publication-ready visualization of volumetric, surface, and network-structured brain data with flexible 3D rendering. Finally, the interface module provides parsers for FreeSurfer, CIFTI, and GIfTI formats, while an experimental module serves as an incubator for community contributions.

The toolkit maintains minimal dependencies, building directly on backbone packages (NumPy, SciPy, Scikit-learn, NetworkX, NiBabel, Nilearn) to ensure stability and cross-platform compatibility. Performance-critical functions leverage Numba for just-in-time compilation and Joblib for parallelization. Continuous integration through GitHub Actions ensures code quality across multiple Python versions and operating systems, with automated documentation hosted on GitHub Pages. The package is openly available at https://github.com/netneurolab/netneurotools.

Results

Since its inception, netneurotools has supported diverse research applications in network neuroscience. The toolkit has enabled studies of assortative mixing in annotated connectomes, where functions for calculating assortativity coefficients and generating degree- and distance-preserving surrogate networks allowed rigorous statistical evaluation of whether connected brain regions share similar molecular or cellular properties. Structure-function coupling analyses have leveraged the metrics module’s communication measures alongside dominance analysis to quantify how structural connectivity predicts functional dynamics across magnetoencephalography frequency bands. Community detection workflows combining consensus modularity algorithms with surface visualization have facilitated comparisons of modular organization across multiple connectivity modes.

The package has attracted nearly 40 forks and 90 stars on GitHub and is under active development spanning new methods and dataset integrations. By standardizing atomic tasks and providing extensively documented, modular functions, netneurotools serves as a high-quality reference for routine procedures, offering contextualized, trustworthy implementations compared to isolated code snippets or generic outputs from large language models.

Conclusion

Netneurotools represents a necessary counterweight to monolithic, out-of-the-box software packages, highlighting the importance of smaller, no-barrier functions for implementing research pipelines. By opening a window into the inner workings of an active research lab, the toolkit also presents an opportunity for a new type of discourse among groups and establishes tangible links within the community. The trainee-centric design ensures that knowledge transfer transcends the typical graduate student lifecycle, with functions originally developed by early lab members now maintained and extended by newer generations.

As the field continues to evolve, we envision netneurotools as a living set of utilities that reflects the day-to-day needs of researchers at all career stages. Through research-driven, sustainable development and adherence to FAIR principles, netneurotools aims to lower barriers and raise rigor in network neuroscience: bridging gaps between specialized tools and empowering researchers to focus on scientific discovery rather than technical implementation.
