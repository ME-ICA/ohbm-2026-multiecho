Introduction

Studying neurodegeneration is difficult. Small, heterogeneous clinical samples yield unstable brain-trait predictions, and the disease process closely overlaps with natural ageing. Addressing these challenges requires integrating diverse data and improving feature generalizability. Foundation Models offer a potential technological solution. These models learn broad, transferable features from massive, self-supervised datasets, thus holding promises of mitigating the fMRI data heterogeneity problem. This research assesses BrainLM^1, an early fMRI foundation model, using the Prevent-AD cohort^2. We compare its generalizable features against the standard connectome baseline. The evaluation targets age, sex, and progression to Mild Cognitive Impairment (MCI).

Methods

FOUNDATION MODEL

We chose BrainLM as the evaluation target. Its architecture uses a transformer masked autoencoder to learn fMRI spatiotemporal dynamics. BrainLM is pretrained on UK Biobank. We downloaded the two pre-trained model sizes (111M and 650M parameters) from the public Hugging Face repository. To replicate the original downstream evaluations and feature extraction, we followed the instructions in the BrainLM GitHub repository. The original training data comprised fMRI time series extracted using the A424 atlas^3.

DATASET

The present study utilises data from the Prevent-AD (Pre-symptomatic Evaluation of Experimental or Novel Treatments for Alzheimer’s Disease), focusing on the baseline session and resting-state functional Magnetic Resonance Imaging (rs-fMRI). We preprocessed fMRI data using 20.2.8 LTS. 344 out of 382 subjects (255 females and 89 males; Mean Age (SD): 63.51 (5.09) years, range [55 84]) passed quality control based on motion and cerebellum coverage.

POST-FMRIPREP DENOISING AND TIME SERIES EXTRACTION

We adopted two time-series workflows: BrainLM's default and GigaConnectome (a Nilearn-based standard workflow) ^4. BrainLM's workflow uses hard-coded scaling and zero imputation for missing data. Since BrainLM only handles extraction and normalisation while GigaConnectome also performs denoising, we applied identical denoising to both: we regressed out six motion parameters, white matter, CSF, and global signals. For normalisation, GigaConnectome used the Scikit-learn implementation of the robust scalar, while the BrainLM pipeline used its customised robust scalar Subtract_Mean_Divide_Global_STD_Normalized_Recording.

Downstream evaluations

The original downstream task evaluation workflow of BrainLM is as follows:

  • Input Features: timeseries (baseline), CLS token, CLS embedding
  • Extract the top 5 PC from the input features
  • Classifier: SVM (sklearn default parameters)
  • 5-fold cross-validation
  • Scoring: 
    • Binary -accuracy
    • Regression - negative MSE

We modified the workflow and added connectome as an extra baseline to suit the properties of the Prevent-AD dataset better:

  • Features: timeseries (baseline), connectome (Pearson’s correlation; baseline), CLS token, CLS embedding
  • Extract the top 75 PC from the input features (top decompositions likely reflect the principal organisation of brain signals rather than individual differences)
  • Classifier: SVM (sklearn default parameters)
  • 100 iterations of StratifiedShuffleSplit (80% - training; 20% - testing; stablise smaller sample)
  • Scoring: 
    • Binary: Accuracy, ROC-AUC, F1 (including metrics that better reflect class difference)
    • Regression: negative MSE, MAE, R^2  (notes: we did not perform regression-based prediction)

Results

We performed three binary classification tasks as downstream evaluations: sex, age (split at the median), and progression to MCI status. We established the comparison baseline using two features (Figure 1.1): the raw time series (the baseline in the original report) and the connectome. We reported the original score (accuracy), alongside F1-score and AUC, which are more suitable for class-imbalanced targets (sex and MCI progression). The connectome consistently outperformed the time series in all tasks except MCI status prediction. Based on AUC and F1-scores, both baseline features performed poorly at predicting MCI status; consequently, the accuracy scores for MCI should not be interpreted due to severe class imbalance.

We executed a comprehensive benchmark comparing several core modelling choices (Figure 1.2): two data tokenization workflows, two Foundation Model sizes (111M and 650M parameters), two downstream application procedures (linear probing and fine-tuning), and two types of latent features (CLS token and CLS embedding).

The connectome baseline outperformed all BrainLM features in overall sex and age prediction. However, the BrainLM CLS embedding did exceed the connectome on both F1-score and ROC AUC in the clinical prediction task (MCI progression). Crucially, even with the best features, the overall performance on this clinical task remained poor.

Performance gain between the two data tokenization workflows was observed only with the GigaConnectome workflow. The CLS embedding consistently outperformed the CLS token during linear probing; however, under fine-tuning, this advantage held true only when using the original tokenization workflow.

Conclusion

Future fMRI foundation model development requires robust collaboration between computer scientists and neuroimagers to create rigorous benchmark evaluations. The community must abandon the raw time series baseline in favour of the functional connectome, which remains a simple, high-performing baseline. Furthermore, given the pervasive class imbalance in neuroimaging data, future work must report imbalance-aware scores, such as AUC and F1-score.

We found that many neuroimaging-specific investigations remain constrained by BrainLM's architectural and data processing choices, including atlas and denoising choices. While BrainLM showed a limited advantage in predicting future MCI status, it remains unclear if this benefit generalises to the broader foundation model approach. Despite these methodological limitations, future opportunities remain for researchers to develop foundation models for fMRI and trait predictions.
