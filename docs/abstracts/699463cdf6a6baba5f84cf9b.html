Introduction

Electron microscopy provides the resolution needed to study synaptic structure, yet manual vesicle annotation remains slow, variable, and difficult to scale. This limits the amount of morphometric data available for understanding synaptic function and constrains large-volume reconstruction efforts. Automated segmentation offers a practical alternative, but vesicle-level instance detection is challenging due to their small size, dense packing, and variable contrast across datasets.

Deep learning models have shown promise for membrane and organelle segmentation1,2, but performance can vary widely when applied across different EM volumes. Many approaches also rely on custom pipelines that are difficult to reproduce or deploy at scale. There is a need for evaluation of lightweight, generalizable workflows that support consistent vesicle detection across datasets and can be integrated into standard reconstruction tools3.

This project evaluates a two-stage vesicle segmentation workflow using a 2D affinity-based model trained on multiple EM datasets. The goal is to test cross-dataset generalization, quantify segmentation performance, and identify error patterns that affect downstream morphometric analysis. By combining a reproducible pipeline with high-performance computing resources, this work aims to provide a practical approach for generating vesicle-level annotations that reduce manual workload and support larger synaptic reconstruction studies.

Methods

We evaluated a deep learning pipeline for automated instance segmentation of synaptic vesicles in electron microscopy (EM) data. The analysis used four EM volumes from the Harris Lab, each containing manually annotated vesicles. These datasets were divided into four folds for cross-validation so that each volume served once as an independent test set.

Models were trained using a 2D affinity-based U-Net architecture1,3. The network predicted voxel-wise affinity maps, which were converted into instance labels using the Bootstrapper pipeline. This framework handled data loading, training loops, validation steps, and prediction export. All models were trained on TACC’s Lonestar6 high-performance computing system using NVIDIA A100 GPUs.

Training used data augmentations consistent with EM segmentation (random flips, rotations, and intensity jitter). Validation performance was monitored through TensorBoard logs to track loss curves, metric stability, and overfitting.

Segmentation quality was evaluated using the F1 score between predicted and manual vesicle masks, computed per test fold. Error inspection included visual comparison of predictions and annotations using Neuroglancer to examine missed vesicles, merged instances, and boundary errors.

Results

Across the four EM datasets, the affinity-based U-Net model produced consistent vesicle segmentation performance. Cross-validation showed F1 scores ranging from the mid-0.70s to low-0.80s across folds, indicating stable generalization despite structural variability between volumes. Models trained on one dataset transferred reliably to others without major degradation in accuracy.

Qualitative inspection in Neuroglancer showed that the model captured the major vesicle clusters within synaptic terminals. Predicted instances aligned with most manually annotated vesicles, including densely packed regions. Common errors included merged vesicles in tightly packed clusters and missed vesicles in low-contrast regions. These patterns were consistent across datasets and reflect typical challenges in EM segmentation.

False positives were infrequent and tended to occur near membrane-rich structures such as mitochondrial cristae. Manual review confirmed that the model maintained high precision in regions with well-defined vesicle morphology.

Training and inference on TACC’s Lonestar6 system enabled efficient processing of high-resolution volumes, supporting large-scale experimentation. The full pipeline, including affinity prediction and Bootstrapper instance-generation steps, produced reproducible vesicle segmentations suitable for downstream structural analysis.

Conclusion

The affinity-based U-Net model provided reliable instance segmentation of synaptic vesicles across multiple EM volumes, with stable F1 performance and consistent detection of vesicle clusters. Visual inspection showed strong agreement between predictions and manual annotations, with remaining errors in dense or low-contrast regions where boundaries are difficult to resolve.

The full workflow, deployed on high-performance computing resources, produced segmentations suitable for structural analysis and large-volume exploration of vesicle distributions. These findings show that deep learning methods support automated vesicle mapping in connectomics datasets and reduce the manual burden of annotating high-resolution EM data.

These results provide a foundation for scaling the pipeline to larger datasets and integrating vesicle-level instance segmentation into broader reconstruction and quantitative analysis workflows.
