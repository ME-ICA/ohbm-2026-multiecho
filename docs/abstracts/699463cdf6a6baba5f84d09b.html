Introduction

Naturalistic stimuli such as movies provide an ecologically valid framework for studying dynamic neural processes. However, features extracted from movies vary widely in temporal dynamics—from fast visual and auditory fluctuations to slower changes in physiology and subjective experience. Because the BOLD signal reflects neural activity with a several-second delay, accurate alignment between features and fMRI signals is critical. Standard analyses typically rely on a canonical hemodynamic response function (HRF), assuming a fixed delay across features and regions, which may be inappropriate for slower or more integrative signals. In this study, we examined feature-specific temporal delays between stimulus-derived signals and BOLD responses using three movie-watching datasets. We analyzed visual luminance and contrast, auditory pitch, pupil size, and theory-of-mind (ToM) ratings to quantify how their temporal relationships with BOLD responses vary across the brain. Our goal was to determine whether the canonical HRF is sufficient for naturalistic analyses and to evaluate data-driven approaches that better characterize BOLD timing during complex real-world viewing.

Methods

We analyzed three publicly available movie-watching datasets from the Healthy Brain Network (HBN; n = 83 and n = 87, ages 5–22)1 and the Partly Cloudy dataset (n = 82, ages 3.5–39)2. ToM ratings were collected from a separate group of 34 adults (ages 18–27). Eye tracking data were obtained from a separate session outside MRI scanner from a large sample (n = 1,312, age 5-21)3. 

For each movie, we extracted framewise luminance, visual contrast, auditory pitch, median pupil size, and continuous ToM ratings. All features were z-scored and temporally aligned to fMRI data. fMRI acquisition and preprocessing followed previously published pipelines 4,5, and preprocessed time series were extracted from cortical and subcortical regions of interest (ROIs).

We computed ROI-wise cross-correlations between each feature and BOLD activity to estimate the temporal lag that maximized correspondence. Analyses were performed using both canonical-HRF–convolved features and raw time series. Lag distributions were summarized using region-by-lag plots and compared across datasets.

To examine response dynamics beyond peak lags, we estimated BOLD response functions using finite impulse response (FIR) deconvolution with AR(1) pre-whitening and second-difference regularization. FIR kernels were computed for each participant and feature, and group-averaged responses were obtained. We also assessed whether continuous movie-derived features can serve as effective inputs for estimating region-specific HRFs.

Results

Sensory features (luminance, contrast, pitch) convolved with the canonical HRF showed peak correlations at zero lag, indicating that the canonical HRF appropriately captured their hemodynamic delays. Early visual and auditory regions showed the strongest and most temporally aligned responses.

Pupil size displayed very different timing. First, pupil responses lagged luminance by ~5 s—similar to the hemodynamic delay—raising questions about whether additional HRF convolution is appropriate (Figure 1A). Cross-correlation between pupil size and BOLD confirmed this: raw pupil signals produced more reasonable spatial correlation patterns than HRF-convolved versions (Figure 1B, 1C, and 1D).

Subjective ToM ratings showed even slower temporal dynamics. HRF convolution appeared to over-compensate the delay, and raw ratings yielded more consistent spatial patterns across all three datasets (Figure 2). FIR results showed that ToM-related responses were slower and more temporally dispersed, suggesting that the ratings themselves reflect temporally integrated cognitive processes rather than instantaneous events.

FIR deconvolution confirmed that canonical HRF models adequately captured responses to fast sensory features but showed greater variability in peak latency and shape for pupil and ToM signals. Continuous movie-derived features such as luminance produced reliable region-specific FIR curves, demonstrating the feasibility of naturalistic stimuli for large-scale HRF estimation.

Conclusion

This study demonstrates that temporal alignment is a critical factor when mapping naturalistic features to BOLD activity. While fast visual and auditory features are well modeled by the canonical HRF, slower physiological and cognitive signals—such as pupil-linked arousal and ToM judgments—show substantially shorter and more variable delays with the observed BOLD signals. Applying the same canonical HRF across all features can therefore distort estimates of feature–brain coupling.

Data-driven approaches such as cross-correlation and FIR deconvolution provide clearer insight into feature-specific timing and yield consistent patterns across datasets. Moreover, continuous movie-derived features can serve as effective inputs for estimating region-specific HRFs, highlighting new opportunities for naturalistic fMRI.

Overall, accounting for the temporal dynamics inherent to each feature will improve the accuracy, interpretability, and reproducibility of fMRI studies using complex real-world stimuli.
