Introduction

Parkinson’s Disease (PD) is a progressive neurodegenerative disorder characterized by the degeneration of dopaminergic neurons in the substantia nigra (SN).1 When PD is clinically suspected, confirmation often relies on invasive or specialized diagnostic procedures—such as dopamine transporter single-photon emission computed tomography (DAT-SPECT),2 skin biopsy,3 or dedicated nigrosome-focused magnetic resonance imaging (MRI) sequences4—all of which have limited sensitivity and specificity. Given these limitations, this study examined whether conventional T1-weighted (T1w) MRI could provide an alternative non-invasive source of diagnostic information for PD detection. If successful, this approach could allow standard T1w MRI to serve as a diagnostic aid for PD without introducing any additional risk, cost, or procedural burden to patients.

Methods

T1w MRI images were obtained from three independent cohorts: the Alzheimer’s Disease Neuroimaging Initiative (ADNI; n = 836; https://adni.loni.usc.edu/), the Parkinson’s Progression Markers Initiative (PPMI; n = 363; https://www.ppmi-info.org/), and Beijing Tiantan Hospital (n = 1055). The dataset comprised 1068 PD participants (438 female; mean age = 62 years, SD = 8.3) and 1186 control participants (594 female; mean age = 67 years, SD = 9.1) (Figure 1A). The control group included neurologically healthy individuals (n = 474) as well as subjects with non-PD neurological conditions, including Alzheimer’s Disease (n = 244), dystonia (n = 128), early (n = 84) and late (n = 139) mild cognitive impairment, epilepsy (n = 4), hemifacial spasm (n = 21), subjective memory complaints (n = 31), trigeminal neuralgia (n = 19), and tremor (n = 42). All images underwent preprocessing consisting of skull stripping followed by a two-stage registration using Advanced Normalization Tools (ANTs; https://github.com/ANTsX/ANTs): an initial whole-brain registration and a subsequent brainstem-focused masked registration. Subject-specific SN labels were propagated using antsApplyTransforms and then subdivided into anterior (Figure 1B, dark blue) and posterior SN subregions (Figure 1B, light blue). Radiomic features were then extracted using the open-source PyRadiomics framework (https://radiomics.github.io/pyradiomics.html),5 producing three feature sets (106 features each) from the whole SN and from each subregion. Feature extraction was performed without the application of additional PyRadiomics image filters.

Results

Across all three SN datasets, models were evaluated using an 80/20 train–test split. Base classification performance was slightly higher for features extracted from the posterior SN (test accuracy = 81.6%) compared to the whole SN (81.3%) and anterior SN (81.3%), motivating further analysis of this region. Among evaluated classifiers, including random forest, gradient boosting, and Light Gradient Boosting Machine (LightGBM), LightGBM achieved the strongest performance on posterior SN features. Following log-transformation of highly skewed features (|skew| > 1) and hyperparameter optimization using 5-fold stratified cross-validation, the LightGBM model achieved a mean cross-validated AUC of 0.88 (Figure 2A) and a test accuracy of 0.83 (Figure 2B). Model performance was stable across cross-validation folds (SD = 0.013).

Conclusion

This study demonstrates that radiomic features extracted from the posterior SN on T1w MRI contain discriminative information for PD prediction, supporting the potential to be used as a diagnostic aid. Future work will involve validating the model on an external dataset.
