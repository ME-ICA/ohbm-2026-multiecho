Introduction

Everyday experience is composed of rich, multimodal sensory information. The brain leverages certain features of incoming information to make meaning amidst this complexity. One approach for understanding how the brain processes this information is to define sets of “stimulus-computable” features and build forward models (e.g., encoding models) of these features to predict brain activity [1,2,3]. Yet, it is unclear how well this approach captures the full extent of stimulus-evoked cognitive processes. An alternative approach to understanding this information is intersubject correlation (ISC), in which brain activity to a time-locked stimulus is correlated across people to isolate stimulus-driven responses [1,4]. Importantly, ISC isolates shared, stimulus-driven responses of brain activity, therefore providing a “model-free” comparison for understanding how well forward models capture this activity. Here,, we introduce a methodology for isolating the unmodeled variance within these shared, stimulus driven signals, which presents an opportunity to identify novel features that drive brain activity. 

Methods

We leveraged three functional MRI (fMRI) datasets where subjects listened to either auditory stories (Narratives, N = 45 [5]; The Moth, N=8 [6]) or watched audiovisual movies  (AVID, N=43 [7]). We also used a subset of the HCP dataset (N=105, [8]) where subjects watched naturalistic movies and completed traditional task paradigms. 

First, we calculated “baseline” ISC using a voxel-wise, leave-one-subject-out approach. We identified voxels showing significant ISC using null distributions based on 1000 random time shifts.

Next, for all datasets, we extracted hypothesized features (e.g., luminance, loudness) and artificial neural network activations (e.g., AlexNet, GPT2) for each stimulus. We then used these features for training encoding models to predict the group-average brain activity time series (leave-one-stimulus-out). Following model fitting, we extracted the residual time series (the unmodeled signal) and used this time series to recalculate ISC (“residual ISC”).

Lastly, we contrasted baseline and residual ISC values to assess the extent to which the encoding models explained variance in brain activity attributable to the stimulus. 

Results

Across datasets and stimuli, we observed high stimulus-related activity (as measured by ISC) within unimodal cortices (i.e., early visual/auditory) that gradually declined in higher-order regions related to language and theory-of-mind (Figure 1; β = –0.23, SE = 0.05, t(137143) = –4.54, P < 0.001). While encoding models of stimulus-computable features captured some explainable variance in brain activity, the ability to model these shared responses declined moving from unimodal to heteromodal cortex (β = 0.03, SE = 1.42e-3, t(274293) = 23.55, P < 0.001). In turn, following our modeling of stimulus features, a significant amount of stimulus-related activity remained across cortex (residual ISC: r = -0.02 – 0.64).

Within the HCP dataset, task paradigms drove higher stimulus-related responses within early- and mid-visual cortex along with multiple-demand regions. In contrast, naturalistic movies drove greater shared signals within higher-order cortical areas such as high-visual cortex and theory-of-mind regions (Figure 2). Importantly, stimulus-based encoding models well-predicted brain activity for both naturalistic (r = -0.06 – 0.51) and task paradigms (r = -0.16 – 0.57). Interestingly, we were able to better model shared, stimulus-driven brain activity within task paradigms (average 19%) compared to naturalistic paradigms (average 10.5%).

Conclusion

Our results suggest that forward models built on “stimulus-computable” features have yet to capture the full extent of stimulus-driven cognitive processes. Together, these findings hint that stimulus-driven brain activity is more than the sum of its modelable parts and may carry emergent features of cognitive representation.
