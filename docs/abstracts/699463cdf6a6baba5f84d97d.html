Introduction

Improving signal-to-noise ratio (SNR) is a central goal in fMRI, particularly at high spatial resolution. NORDIC denoising1,2 has been shown to substantially increase detection sensitivity by suppressing thermal noise, with only minimal effect on spatial precision3. However, also changes in temporal properties are of particular interest, as frequency-dependent attenuation can systematically alter model estimates. Population receptive field (pRF) mapping provides a sensitive test case for such effects, as prior work has shown that low-pass filtering of fMRI time courses leads to an increase in pRF size estimates4. Here, we use pRF mapping as a diagnostic tool to investigate whether NORDIC induces systematic temporal filtering effects on fMRI data, whether these effects explain observed changes in model parameters, and whether they can be accounted for post-hoc while retaining gains in model fit.

Methods

We acquired fMRI data from eight healthy participants (one female, mean age 27.1a) at 7T (Siemens MAGNETOM) using a CMRR multiband EPI sequence5 (1.2 mm isotropic resolution, TE/TR=25/1000 ms) covering the occipital cortex. Each participant completed two pRF mapping runs using a moving bar stimulus, covering a 12° visual angle. NORDIC denoising was applied prior to standard preprocessing using fMRIPrep (fmriprep.org); all other preprocessing steps were identical across conditions. pRF parameters were estimated on the native surface, using GEM-pRF6. Analyses focused on vertices in V1 exceeding 10% variance explained in both conditions.

To characterize the temporal effects of NORDIC, we extracted preprocessed BOLD time series from V1 and computed vertex-wise power spectra after demeaning and linear detrending. Power spectra were pooled across vertices and runs, both at the group level and per subject. For each vertex, the ratio of power spectra from NORDIC-denoised and original data was computed, and these ratios were averaged to estimate an effective frequency-dependent filter associated with NORDIC. Temporal autocorrelation functions were additionally assessed to probe short-lag dependencies.

To test whether this filter explains pRF parameter changes, we applied a group-averaged frequency-domain filter to the original (non-denoised) data and repeated preprocessing and the pRF analysis. Finally, we examined the relationship between NORDIC-estimated noise suppression and pRF size inflation, and introduced the possibility for a post-hoc empirical correction of pRF size estimates.

Results

NORDIC denoising altered the temporal frequency content of fMRI time courses, with systematic attenuation of higher frequencies consistent with a low-pass filtering effect (Figure 2 top). This was accompanied by increased short-lag temporal autocorrelation (Figure 2 bottom left). When assessed via pRF mapping, eccentricity and polar-angle estimates remained largely unchanged, whereas pRF size (normalized difference +9.3%) and goodness-of-fit increased (ND 24.8%) following NORDIC denoising as shown in Figure 1.

Applying the estimated group-averaged temporal filter to the original data reproduced the pRF size increases observed with NORDIC, while leaving pRF position estimates unaffected. The magnitude of pRF size inflation was comparable to that induced by NORDIC, though gains in goodness-of-fit were smaller when using the explicit filter alone.

Across vertices, the increase in pRF size showed a linear relationship with the amount of noise suppression estimated by NORDIC (Figure 2 bottom right). Leveraging this relationship, a simple post-hoc empirical correction applied to vertex-wise pRF size estimates can mitigate the apparent size inflation while preserving the improvement in model fit through the denoising.

These findings are based on a single high-quality dataset with a limited range of noise-reduction values. Therefore, generalization to other acquisition protocols and noise regimes will require further validation.

Conclusion

Our results demonstrate that NORDIC denoising systematically alters the temporal structure of fMRI time courses in a manner comparable with low-pass filtering. Using pRF mapping as a sensitive readout, we show that this temporal filtering leads to predictable widening of model-estimated response profiles, increasing pRF size, while leaving spatial position estimates largely unaffected. This is consistent with prior work demonstrating that low-pass filtering inflates pRF size estimates4. This work suggests that the observed parameter changes are not specific to pRF modeling per se, but arise from frequency-dependent signal attenuation.

Importantly, reproducing these effects by explicitly applying an empirically derived temporal filter to the original data demonstrates that pRF size inflation can be explained by NORDIC-induced filtering, rather than by increased spatial smoothness or generic SNR changes. The accompanying increase in short-lag temporal autocorrelation further supports this interpretation. While explicit filtering reproduced pRF size effects, it did not fully reproduce the gains in goodness-of-fit achieved by NORDIC, indicating that denoising provides additional benefits beyond simple low-pass filtering.

The linear relationship between estimated noise magnitude and pRF size inflation enables a simple post-hoc empirical correction that reduces size bias while preserving improvements in model fit. This approach is intended as a practical correction rather than a general solution. As the present findings are based on a single dataset with a limited range of noise magnitude values, further work is required to assess generalizability across acquisition protocols, resolutions, and noise regimes. More broadly, our results highlight that denoising methods can introduce subtle but systematic temporal biases, emphasizing the need to consider frequency-domain effects when interpreting model-based fMRI analyses.
