Introduction

Conducting decoded neurofeedback studies is currently constrained by the limited availability of open-source software options. Most prominent software packages, such as Brain-Voyant (Cohen, Malach, Koppel, & Friedman, 2018), Turbo-BrainVoyager (Goebel, 2012), BrainIAK (Kumar et al., 2019), and OpenNFT (Koush et al., 2017), are either closed source or lack flexibility for the experimental customization. To address this gap, we introduce PyDecNef2.0, an open-source, Python-based real-time fMRI decoded neurofeedback framework that allows for extensive customization and personalization of experiments. In this version, we improved the structure of the framework to enhance the user-friendly vantage point of the project. The framework also includes new additions, featuring more machine learning techniques for brain activity decoding and co-adaptive decoding protocol.

Methods

PyDecNef2.0 includes an intuitive and efficient Python framework for real-time fMRI decoded neurofeedback, integrating various machine learning techniques including co-adaptation to improve the feedback signal provided to participants and enhance the learning curves during neurofeedback training.

Results

PyDecNef2.0 through the use of co-adaptation provides finer-grained and less binomial/overconfident neurofeedback signals compared to previous approaches that relied on logistic regression based classifiers [Margolles, P. et al. 2023]. Additionally, the introduction of co-adaptation techniques during neurofeedback training shows great potential to improve participant’s learning curves

Conclusion

PyDecNef2.0 is a free, open-source software solution for fMRI decoded neurofeedback, offering researchers flexibility, ease of use, and the capability to customize experiments to their specific needs. The framework promises more accessibility and adaptability to diverse research requirements.
