Introduction

Epilepsy is a network disorder affecting approximately 70 million people worldwide, with 25% of patients resistant to pharmaceutical therapy.1 Resective surgery remains the most effective treatment for drug-resistant epilepsy.2 Successful surgical outcomes depend on precise identification of the epileptogenic zone (EZ). Yet, current clinical workflows rely on fragmented, modality-specific approaches that fail to integrate multimodal neuroimaging data and, in particular, network-based approaches.2 Recently, biologically annotated connectomes have been suggested that fuse network topology with properties such as fMRI activation, structural data, lesions, and clinical biomarkers, all into one unified network representation.3 However, implementing annotated connectomes clinically requires integrating diverse neuroimaging sources through complex custom scripts. This fragmentation creates inconsistencies and limits reproducibility. We present a modular framework that serves as a proof of concept for constructing and visualizing biologically annotated connectomes from multiple imaging modalities tailored to epilepsy patients.

Methods

The framework was developed in Python 3.10.18 using Jupyter Notebook (v6.5.7) as the interactive computational environment and is designed to operate within containerized environments. Implementation relied on widely used open-source neuroimaging libraries and tools: ANTs and FSL for spatial transformations and registration; Nilearn for value extraction and Hyve, PyVista, and NetworkX for 3D network visualization.

The software design was driven by four architectural requirements: (1) modular and extensible architecture allowing flexible module execution and user-defined processing steps; (2) modality independence supporting diverse neuroimaging inputs; (3) spatial consistency ensuring all data align to a common anatomical reference frame; and (4) integration of established neuroimaging tools for standardized processing tasks. 

Three organizational packages were planned to structure the pipeline requirements: Initialization, Main, and Visualization. The final connectome visualization was based on three core processing layers: (1) spatial node coordinate definition computed from atlas parcellation in native T1-weighted space; (2) biological annotation extraction through spatial registration and Region of Interest (ROI) aggregation; (3) connectivity matrices for edge annotation. Specialized neuroimaging operations (atlas transformation, image resampling, spatial registration) were conducted using containerized tool calls (ANTs and FSL) via subprocess integration (cf. Figure 1). 

Within the framework, the subject’s T1-weighted (T1w) image was chosen to serve as the unified anatomical reference space for registering all additional modalities and annotations. Annotation inputs were abstracted into common mathematical formats (vectors and matrices) for connectome construction, regardless of the original data format of the source data. For storing and managing all provided metadata and intermediate outputs, a customized JSON-based subject dictionary was used as a central data store to ensure reproducibility and auditability.

To evaluate and validate the framework, two clinical patient datasets provided by the Medical University Vienna at different stages of preprocessing were used in three representative test cases: first test case was designed to annotate connectomes from a T1w image, task-fMRI data, and a 100-ROI atlas in individual subject space. Second test case was configured to show the influence of parcellation density with the same dataset but using a 400-ROI atlas parcellation. Third test case used fully preprocessed, atlas-based derivatives from XCP-D, where statistical inputs (ALFF values, 100-ROI centroids, Pearson correlation matrix) were already aligned to MNI space. 

Results

The framework successfully implements a modular architecture that meets all four core requirements. Each package consists of independent processing modules, which can be executed sequentially or selectively depending on the preprocessing stage of the input data and, therefore, the required processing tasks.

All three test cases produced correctly constructed annotated connectomes using two different rendering approaches. Spatial alignment of atlas and annotation data to the T1w reference image and spatial consistency were visually solid. 

The first test case validated the ability to process diverse preprocessing outputs and integrate them into the framework's standardized format. Test case 2 demonstrated extensibility by applying the identical pipeline to an alternative atlas granularity (400-ROI instead of 100-ROI), confirming that the framework supports multiple atlas choices without code modification. This test case validated the principle of modular node definition: users can select atlases post-hoc without reprocessing the upstream steps. The third test case demonstrated modularity by bypassing all internal preprocessing modules and directly adding precomputed derivatives from external pipelines. It processed all provided input data without executing preprocessing steps, validating the framework's ability to integrate results from diverse external preprocessing workflows.

Conclusion

We present a foundational, modular, open-source framework specifically designed to construct biologically annotated connectomes for clinical epilepsy applications. The framework successfully addresses key limitations of fragmented, network-based neuroimaging workflows by integrating multimodal data through standardized mathematical abstractions and maintaining spatial consistency across modalities. Its modular design enables flexible combination of processing steps, adaptation to diverse preprocessing pipelines, and future extensibility. While current implementation represents a proof-of-concept validated on limited illustrative clinical cases, future directions include validation on larger clinical cohorts, systematic sensitivity analyses across preprocessing parameters and atlas choices, integration of registration for patients with significant anatomical distortions, and extension to multidimensional node annotations. This framework provides a technical and conceptual foundation for precision connectomics to support the diagnosis and treatment of epilepsy.
