Introduction

We naturally recognize objects in our living environment through different levels of concepts, which are organized as a cognitive hierarchy. However, we rarely know that how we develop the cognitively hierarchical recognition behavior, especially the role of visual experience in this development.

Research has unraveled the object representational hierarchy underlying object recognition in the human higher visual cortex, with the arrangement of local category-selective areas embedded in the large-scale topology of abstract object conceptual dimensions. However, above two levels argued about the functional unit of object representations. Besides, visual input and linguistic semantics are entangled in the visual cortex, leaving the role of visual information alone unclear. Thus, whether representational hierarchy of visual system originate from learning of the visual data is still not clear. 

Trained exclusively on the visual data, self-supervised DNNs learn object representations convergent with the human visual stream. Simulation on these computational models could test the role of visual data without effect of the prior semantic experience. Category-selective areas exhibit specific selectivity for the abstract object dimensions, which suggests that neural clusters with similar dimension selectivity might be the new functional unit. These provide possible methods to address above challenges.

Methods

We mainly leveraged the THINGS datasets—a rich repository of human neuroimaging and ratings of object conceptual properties across a large-scale image set—and the Topographic Deep Artificial Neural Network (TDANN), a self-supervised visual DNN with better brain alignment, in our study.

To uncover unified representational hierarchy, we firstly constructed an object space using human ratings of 12 abstract object properties. These properties are proved to be critical in organizing object representations at conceptual dimension level. Then, we determined neural tuning maps to these properties through voxelwise encoding models. Therefore, brain areas were separated into clusters based on neural property tunings, and relations between traditional category-selective areas and these property-selective clusters were analyzed to try to uncover the full-scale representational hierarchy of human visual cortex. We expected those property-selective clusters as a new functional unit of object representations to link category and conceptual dimension representations.

To test whether this human representational hierarchy is mirrored in a DNN model trained by only visual input, we built connections between TDANN and human brain by projecting human property-selective clusters onto the TDANN through PLSR (Fig 1c). Based on this, property tuning profiles of the TDANN clusters were analyzed by independently voxelwise encoding models. And cluster-category relations were reflected by analyzing the effect of manipulations on the TDANN clusters on an object classification task (Fig 1d). The property-cluster-category hierarchies of human brain and TDANN were compared completely.

Results

Our results first found that large areas of human higher visual cortex are tuned by object dimensions, we use abstract object properties here, including traditional category-selective areas. Then, we revealed the property-cluster-category hierarchy in the human higher visual cortex by defining the property-selective brain clusters as new functional unit of object representations to link the large-scale property tunings and finer-scale category areas. 

Based on this, we further proved that TDANN learned brain-like hierarchical organization in the deep layer training solely on visual inputs. Brain property-selective clusters were projected on TDANN through PLSR. Brain-like property tuning and classification of corresponding object categories for each property-selective cluster were independently found  in TDANN. Interestingly, clusters in TDANN exhibited reduced selectivity for affective properties compared to human, likely because these subjective emotional dimensions are not directly embedded in visual inputs.

Conclusion

Our results support that naturally co-occurring patterns in the visual environment largely shape the topology of object representation, independent of prior conceptual knowledge. This work promotes our understanding of the visual system's computational principles, and offers insights into the way towards more human-aligned artificial visual systems.
