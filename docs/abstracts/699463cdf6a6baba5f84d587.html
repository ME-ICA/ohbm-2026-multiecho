Introduction

Temporal lobe epilepsy (TLE) is characterized by recurrent seizures originating in the temporal lobes. Often, patients with TLE report subjective memory complaint and experience deficits in memory ability. The neural underpinnings of these deficits is poorly understood. Research using naturalistic stimuli, such as movies and narratives, has shown that the hippocampus becomes particularly active at moments of change, when one event transitions to another1. In this study, we demonstrate evidence of hippocampal activity during movie viewing and demonstrate how it relates to memory ability in epilepsy.

Methods

Thirteen patients with epilepsy viewed an 8-minute video depicting a narrative during fMRI scanning. Following the viewing, they were asked questions about the video to test their memory. Functional images were realigned and unwarped using SPM12, and co-registered with the T1 structural scans. Hippocampal activity during contextual transitions called "event boundaries" was estimated. To do so, we used event boundary timepoints characterized in previous studies2 in which a group of 16 participants viewed the video and pressed a button to indicate when they felt that one meaningful ended and another had begun. This previous study, using healthy adults observed significant hippocampal modulation at these event boundary timepoints. Subject level general linear models were constructed using an event related design and used to contrast activity at event boundary timepoints against arithmetic middles of events. FreeSurfer was used to calculate individual subject hippocampal masks which were transformed into functional space and used to extract hippocampal activation. T-tests were used to test whether activity in the hippocampus was significantly higher at boundaries compared to middles. Patients were median split into high and low memory performance based on the post-scan memory test. T-test were used to test whether high memory performers were able to modulate hippocampal activity more effectively than low memory performers. 

Results

We observed significantly higher activity in the hippocampus at event boundaries compared to event middles in the patients. Those patients who had better memory for the video showed stronger differences in hippocampal event boundary activity and event middle activity.

Conclusion

This study presents preliminary evidence that hippocampal activity modulation at event boundaries may underscore everyday memory difficulties in epilepsy.
