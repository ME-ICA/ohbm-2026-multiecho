Introduction

Alzheimer's disease (AD) is the most prevalent form of dementia, is defined by severe neurodegeneration, impairment of memory, and other cognitive function declines [1].

Connectome-based studies have revealed widespread disruptions in large-scale brain network organisation in Alzheimer’s disease, including altered connectivity within the default mode, salience, and cognitive control networks, which are linked to cognitive decline [2].

Importantly, the coordination between within- and between-network connectivity supports general cognitive function [4].

Increasing evidence from multimodal neuroimaging approaches has demonstrated changes in functional integration and segregation in Alzheimer's disease [3].

Consistent with this, Alzheimer’s disease is associated with reduced system-level segregation, which relates to greater disease severity and poorer cognitive performance [5]. At the network level, reduced segregation within sensorimotor networks has also been linked to poorer cognitive performance in AD [5]. In contrast, higher functional segregation across large-scale networks has been linked to greater cognitive resilience in AD.

Therefore, we aimed to examine whether gradient metrics of functional integration and segregation can serve as biomarkers for early disease diagnosis and prognosis of cognitive decline in AD.

We hypothesised that reduced functional integration and segregation would be associated with poorer cognitive performance in Alzheimer’s disease.

Methods

Data

We used data from the Quantitative MRI of Brain Structure and Function in NHS Memory Clinics (QMIN-MC) dataset. 86 participants with Alzheimer’s disease (AD) underwent standard clinical and neurological assessments. Written informed consent was obtained from all participants. In addition, we recruited 46 control participants (functional/attentional group) who presented with symptoms of anxiety, depression, and attentional or memory complaints but showed no evidence of brain atrophy and did not meet diagnostic criteria for a neurodegenerative disorder.

Cognitive assessment

All participants completed the Addenbrooke’s Cognitive Examination–Revised (ACE-R), a brief and comprehensive cognitive assessment for neurodegenerative diseases. The ACE-R assesses five cognitive domains—attention, memory, verbal fluency, language, and visuospatial function—with total scores ranging from 0 to 100, where higher scores indicate better cognitive performance.

Functional connectivity gradients

Whole-brain functional connectivity (FC) matrices were constructed by parcellating the cortex into 300 regions using the Schaefer atlas and computing Pearson correlations between all parcel pairs. FC matrices were z-transformed, thresholded to retain the top 10% of connections per row and converted into affinity matrices using a cosine similarity kernel (sparsity threshold = 0.85).

Functional connectivity gradients were derived using diffusion map embedding, a non-linear dimensionality reduction technique. Individual gradients were aligned to the group average using Procrustes rotation. The first three gradients were retained, explaining >57% of variance, and corresponded to sensory–transmodal (G1), visual–insula (G2), and somatomotor–insula (G3) axes.

Gradient-based network analyses

Large-scale networks were defined using the Yeo-7 parcellation. Gradient values were first compared between Alzheimer’s disease (AD) and control participants using ANOVA. Network centroids were then computed as the median gradient coordinates of parcels within each network in three-dimensional gradient space. To quantify group differences in network organisation, Euclidean distances were calculated between AD and control network centroids and compared with within-group centroid distances in controls. ANOVA was applied to these distance measures to assess group differences in centroid positions.

Network integration

Network integration was quantified using a multi-dimensional node integration metric. Integration was defined as the summed squared Euclidean distance between each node and the median position of its corresponding network. Values were log transformed to deal with skewness of the data.

Network segregation

Network segregation was quantified computing centroid-to-centroid Euclidean distances between all pairs of Yeo networks, yielding 21 unique network-pair values per subject. Next, K-means clustering (k = 2) was applied to parcels from each network pair in gradient space, and overlap was defined as the proportion of misclassified parcels. Higher overlap indicates lower segregation. Together, these measures capture both separation between network centres and boundary blurring between networks.

Statistical analysis of network integration and segregation

Multiple linear regression models were used to examine the relationship between gradient-based metrics (integration and segregation) and ACE-R total and subdomain scores, adjusting for age, sex, and years of education. Network-specific relationships between integration and cognition were tested. Additional models assessed segregation–cognition relationships across all 21 network pairs. False discovery rate (FDR) correction was applied to account for multiple comparisons.

Results

Gradient differences between two groups

ANOVA revealed a significant group difference in Gradient 2 between Alzheimer’s disease (AD) participants and controls (Functional/attentional cohort) (p = 0.0029), (see Figure 1). This gradient differentiates brain regions along a modality axis, spanning visual to sensorimotor and auditory areas. In addition, a significant difference in somatomotor network centroid position was observed between the two groups (p = 0.0014, p_FDR = 0.0095).

Gradient integration and cognition in AD and Functional/attentional cohort

A significant association was observed between somatomotor network integration and ACE total score (p = 0.018, p_FDR = 0.129), as well as language (p = 0.007, p_FDR = 0.046) and memory (p = 0.001, p_FDR = 0.006) performance. In all cases, higher integration was associated with better cognitive performance in AD. No significant associations were found between gradient integration and ACE subdomain scores in control (Functional/attentional cohort) participants.

Network segregation and verbal fluency in AD

In AD, functional segregation between the visual and dorsal attention (p = 0.046, p_FDR = 0.600), visual and frontoparietal (p = 0.032, p_FDR = 0.532), and visual and limbic (p = 0.030, p_FDR = 0.053) networks was associated with verbal fluency performance, such that lower segregation was related to better fluency. These associations did not survive FDR correction. Additionally, Better memory performance was associated with lower segregation between the visual and dorsal attention networks (p = 0.042, p_FDR = 0.873), though this effect did not survive FDR correction.

Functional/attentional cohort – verbal fluency

In the functional/attentional cohort, poorer segregation between the visual and somatomotor networks was associated with better verbal fluency (p = 0.024, p_FDR = 0.308), as was poorer segregation between the somatomotor and ventral attention networks (p = 0.041, p_FDR = 0.308). These effects did not survive FDR correction.

Functional/attentional cohort – global cognition 

Higher segregation between the visual and dorsal attention networks (p = 0.016, p_FDR = 0.219) and between the ventral attention and limbic networks (p = 0.031, p_FDR = 0.219) was associated with better ACE total scores for Functional/attentional cohort. In contrast, lower segregation between the dorsal attention and frontoparietal networks was also associated with better ACE performance (p = 0.031, p_FDR = 0.219). None of these associations survived FDR correction.

Functional/attentional cohort – memory

Higher memory performance in Functional/attentional group was associated with greater segregation between the visual and dorsal attention networks (p = 0.023, p_FDR = 0.241) and between the ventral attention and limbic networks (p = 0.016, p_FDR = 0.241). Conversely, poorer segregation between the visual and frontoparietal networks was associated with better memory performance (p = 0.039, p_FDR = 0.271). These effects did not survive FDR correction.

Conclusion

In this study, we used functional connectivity gradients to investigate large-scale network organisation in Alzheimer’s disease (AD) and a functional/attentional cohort. We identified a significant group difference in Gradient 2, which captures a modality-related axis spanning visual to sensorimotor and auditory regions, indicating altered cortical organisation in AD. In addition, a significant difference in somatomotor network centroid position was observed between groups, suggesting network-specific reorganisation in gradient space.

Importantly, higher functional integration within the somatomotor network was significantly associated with better global cognition, language, and memory performance in AD, with associations for language and memory surviving correction for multiple comparisons. This highlights somatomotor integration as a sensitive marker of cognitive function in AD.

For network segregation, we observed several associations between segregation metrics and cognitive performance across visual, attentional, frontoparietal, and limbic networks in both AD and the functional/attentional cohort. Although these effects did not survive FDR correction, their consistent involvement of sensory and attention-related systems suggests that altered network differentiation may contribute to cognitive performance.

In AD group reduced segregation between visual and dorsal attention networks, as well as between visual and frontoparietal and visual and limbic networks, was associated with better verbal fluency and memory performance, potentially reflecting compensatory network reorganisation in response to disease-related changes. In contrast for functional/ attention subjects for other network pairs, including visual–dorsal attention and ventral attention–limbic interactions, higher segregation was associated with better cognitive performance, indicating that the functional relevance of segregation may depend on the specific network systems involved.
 
Notably, in the functional/attentional cohort—despite the absence of detectable structural brain atrophy—relationships between segregation measures and cognition were still observed. This indicates that changes in functional network organisation may be present even when structural imaging appears preserved.

Specifically, lower segregation between visual–somatomotor and somatomotor–ventral attention networks was associated with better verbal fluency, as well as reduced segregation between dorsal attention–frontoparietal and visual–frontoparietal networks was associated with better overall cognitive performance.

 Whereas higher segregation between visual–dorsal attention and ventral attention–limbic networks was related to better global cognition and memory performance. Although these effects did not survive FDR correction, they suggest that the functional relevance of segregation in functional/attentional presentations is network-dependent, with both increased and decreased segregation supporting cognition depending on the specific systems involved.

Together, these findings demonstrate that functional connectivity gradients are sensitive to both integration effects and more subtle segregation-related alterations, providing a network-level framework for linking large-scale brain organisation to cognitive performance across neurodegenerative and functional presentations.
