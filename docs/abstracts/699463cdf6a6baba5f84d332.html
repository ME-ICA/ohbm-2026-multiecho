Introduction

Diffusion MRI is a non-invasive tool for quantifying in-vivo tissue properties at the scale of micrometers. Numerous biophysical models are proposed to quantify microstructural properties from these images. For example, the diffusion tensor model is used to map axon orientation. The neurite orientation and dispersion density imaging (NODDI) model1 is utilized for density estimation of dendrites and axons.

Nonetheless, microstructure model fitting relies on solving the non-linear optimization problem using methods such as Markov Chain Monte Carlo sampling, Active-set algorithm which are usually iterative and computationally expensive. Deep learning techniques have been demonstrated to map diffusion data to diffusion model parameters efficiently and effectively2,3. Nevertheless, constructing training targets for supervised parameter mapping still requires solving the non-linear optimization problem for new imaging protocols, diffusion tables, diffusion models and even scanners. The fitting errors from specific optimization method may accumulate in the NN. Moreover, achieving good generalization across different gradient tables remains challenging.

We propose a self-supervised, physics-informed framework based on implicit neural representations (INRs) with diffusion signal embedding, called DIMONER (DIffusion Model Optimization using implicit NEural Representation). DIMONER uses an INR and a signal embedding to map voxel coordinates and diffusion signals to model parameter values, and trains the network by minimizing the mismatch between the measured signals and synthetic signals generated by a forward diffusion model using the estimated parameters. The INR compactly encodes voxel-specific properties with much lower storage cost than dense grids, while the signal embedding captures characteristic diffusion signal patterns. We evaluate the effectiveness and efficiency of DIMONER on the NODDI model using data from ten Human Connectome Project (HCP) subjects.

Methods

The proposed DIMONER framework accelerates self-supervised diffusion model parameter estimation by incorporating diffusion information, voxel-specific properties and spatial signal patterns jointly (Fig. 1).

Diffusion Pattern embeding

DIMONER utilizes a lightweight multilayer perceptron (MLP) to capture diffusion signal patterns among voxels. The MLP is consisted of three hidden layers (256, 256 and 64 hidden features) followed by the ReLU activation function. 

Voxel-specific properties storage

INR is utilized to storage voxel-specific properties, encompassing factors like noise, imaging artifacts and particularly signal compartments not adequately represented by the embedded diffusion pattern. INR utilizes an NN, essentially MLP, to map coordinates c with specific encoding to the target function  , where   is an encoding function. In this study, the hash grid encoding function is adopted (Fig. 1), which establishes a multi-resolution grid for feature calculation and a hash table for NN parameter storage. The single-resolution features for sampled coordinates are obtained through trilinear interpolation from its eight nearest feature grid points. Furthermore, 64 multi-resolution features of each voxel are obtained by concatenating features from all resolutions. Consequently, the optimization for each sampling voxel is only related to a subset of parameters, accelerating computation. The features for grid points at each resolution are stored in a hash table indexed linearly by coordinates. When the total number of grid features at fine resolution exceeds the capacity of the hash table, similar features will be indexed at the same hash table location during NN optimization. Due to the sparsity of high-dimensional fine features, this operation does not introduce many fitting errors.

Explicit local pattern modeling

The spatial convolutional explicitly models the local patterns in neighboring voxels. Nonetheless, the diffusion MRI data are usually volumetric and contains much more channels than the natural image, which requires 3D convolution and substantially increases the trainable parameters of the network, leading to slow convergence rate. Therefore, the spatial convolution is only utilized to process the integrated features at the decoder, consisting of a 3D convolution layer (kernel size=3, output channel=64), a ReLU activation function and a 3D convolution layer (kernel size=1, output channel=m), where m is the number of diffusion model parameters.

Self-supervised training

The self-supervised and physics-informed training optimizes NN parameters by minimizing the difference between the acquired data Si and the synthetic images Siest generated by the diffusion model parameterized by the NN's output. Specifically, NODDI model uses parameters P=[fiso,fic,μT,κ]  to quantify the isotropic volume fraction (fiso, ISOVF), intra-cellular volume fraction (fic, ICVF), mean orientation (μT) and orientation dispersion (OD=(2/π)arctan(1/κ)) with signal calculating as:  Si = S0((1 −fiso)(ficAic + (1 − fic)Aec) + fisoAiso) where  Aic, Aec and Aiso  are the function of P, diffusion encoding directions and b-values, S0 is the mean b=0 volumes. Synthetic data is generated through the above equation and the difference is measured over all voxels within the brain mask using the mean squared error.

Results

Dataset and Implementation details

Pre-processed diffusion data of 1.25 mm isotropic resolution of 10 healthy subjects from HCP WU-Minn-Ox Consortium were used4. 18 b=0 image volumes, 90 DWI volumes at b=1000, 2000 and 3000 s/mm2 were acquired for all subjects. The first 3 b=0 image volumes and 15 DWI volumes at three b-values were extracted as a 6-fold accelerated subset for each subject. The reference NODDI model parameters were generated by employing the NODDI-Toolbox shard by the inventors of NODDI to all b=0 and DWI volumes. 

 DIMONER and forward diffusion models were implemented using the PyTorch platform (https://pytorch.org/) using an NVIDIA A800 GPU. The training and inference were conducted on image blocks consisting of 64×64×64×n voxels due to the limited GPU memory. The network parameters were optimized using Adam optimizer with learning rate=0.001 for 140 epochs for each HCP subject.

Comparison of Efficacy and Efficiency

For comparison, the grid search and Active-set methods implemented in NODDI-Toolbox and Brute-Force approach implemented in Dmipy were used to generate NODDI model parameters on sub-sampled HCP data. These two methods were parallelized using 32 processes on Intel(R) Xeon(R) Platinum 8368Q CPU. The mean absolute errors (MAEs) of NODDI metrics (ISOVF, ICVF and OD) quantified the similarity compared to the reference.

DIMONER fitted NODDI model parameters effectively. The NODDI metric maps from DIMONDER were most similar to the reference and free of noise (Fig. 2Aiv vs. ii, iii). Quantitatively in Fig. 2B, DIMONER achieved substantially lower group mean MAEs than NODDI-Toolbox and Dmipy5 in terms of all NODDI metrics. The parameter estimation time was also substantially shorted from hours to 9.6 minutes.

Tract analysis

The parameter estimation performance was also evaluated over 42 major white-matter tracts in terms of the ICVF in Fig. 2C, since NODDI is an important tool for quantifying the restricted volume fraction in white matter. Tract masks were created by firstly calculating the warp field between FA maps of diffusion data and the template FA map in FSL-provided HCP tractography atlas, and then reversing and applying the warp field to the HCP tract template. A probability threshold of 0.5 was utilized to create the binary mask. The tracts from two hemispheres or the Cingulum were merged. 

DIMONER outperformed NODDI-Toolbox and Dmipy in predicting the ICVF of all major white matter tracts, especially from tract 5-10. The variations in prediction errors among different tracts (e.g., Forceps minor vs. Forceps major) stem from the failure of the sub-sampled protocol to capture the diffusion rates and directions of water molecules in certain voxels. The improved performance of DIMONER suggests that leveraging spatial information and signal patterns can compensate for these missing measurements.

Conclusion

This study proposes DIMONER as a fast and self-supervised diffusion model parameter optimization framework. By utilizing INR to storage voxel-specific properties and signal embedding to capture signal patterns, DIMONER achieved fast network convergence and improved NODDI metrics estimation. Experiments on HCP data showed that DIMONER achieved lowest MAE in terms of all NODDI metrics. Meanwhile the computation time was shortened from hours to 9.6 minutes. Fine-tuning the NN trained on tensor model to solving NODDI model parameters accelerates the network convergence. Future work will focus on disentangling the signals to model the noise, imaging artifact, etc. as the voxel-specific properties and the intrinsic signal pattern respectively with novel loss functions, regularization terms.
