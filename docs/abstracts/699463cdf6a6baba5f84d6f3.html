Introduction

Working memory and executive function impairment are common in Parkinson’s disease and thought to arise from frontostriatal dysfunction. Specifically, working memory operations with high executive demand (i.e. manipulation of working memory content) seem to be particularly vulnerable, even in early Parkinson’s disease. While task-related activation during working memory manipulation seems to depend on functional modulation within the caudate nucleus, the interplay between pathological, disease-related and functional changes remains insufficiently characterized in early disease stages. Building on previous work demonstrating frontoparietal and striatal contributions to working memory manipulation, we investigated whether caudate dopamine transporter (DaT) availability and iron content as measured by quantitative susceptibility mapping (QSM) may shape cognitive neural responses during working memory manipulation in early drug-naïve Parkinson’s disease. Given histopathological evidence that increased iron accumulation contributes to nigrostriatal degeneration and reduced DaT availability, we considered DaT loss as a downstream pathophysiological correlate of iron-related changes. We hypothesized that reduced striatal integrity - reflected by lower DaT availability and increased iron load in the caudate - would be associated with attenuated BOLD activation during high executive-demand working memory manipulation.

Methods

We studied 25 patients with early Parkinson’s disease (18 male; mean age: 64 years; disease duration<3 years;) in the medication-off state and 35 sex- and age-matched healthy controls (23 male; mean age: 63 years). Participants performed a validated working memory paradigm1 to identify neural activity specifically associated with working memory manipulation using SPM and a voxel-wise threshold of p < 0.05 FWE-corrected. A two-sample t-test was used to test for group differences. Performance in the working memory task(i.e. number of correct trials) was compared between patients with Parkinson’s disease and controls using a Mann-Whitney U Test. From DaT-SPECT imaging mean caudate specific binding ratios (SBRs) were computed to quantify the integrity of the dopaminergic system in patients. A subgroup of patients (n = 19) also underwent QSM MRI from which mean caudate susceptibility values were extracted to estimate iron load.

To investigate the specific relationship between BOLD activity and neuropathological disease-related changes, we created a binary mask from the FWE-corrected patient-group derived T-map during working memory manipulation. Using that group-based binary mask, mean BOLD values were extracted for each patient with early Parkinson’s disease. Finally, partial correlations between BOLD responses and DaT and QSM imaging markers were computed, while controlling for age and sex.

Results

Both groups showed robust widespread activation in the frontoparietal, cerebellar and anterior striatal regions (Figure 1). Despite visually stronger and more widespread activations in the control group, there were no statistically significant group differences. Performance in the working memory task did not differ between patients with Parkinson’s disease and controls (p = 0.493).

Within the Parkinson’s disease group, caudate integrity was associated with manipulation-related BOLD signal (Figure 2). Specifically, higher caudate DaT SBRs were trend associated with stronger BOLD responses (partial r = 0.342, one-sided p = 0.055), while higher caudate iron load as indexed via QSM correlated with reduced BOLD activity (partial r = –0.681, one-sided p = 0.003).

Conclusion

Patients with early Parkinson’s disease show working memory activation patterns similar to previous studies1 and comparable to controls. However, task-related BOLD modulation during manipulation of mnemonic content already relates to nigrostriatal integrity within the caudate nucleus. Reduced dopaminergic availability and increased iron deposition are associated with diminished manipulation-related BOLD activation pattern, suggesting that striatal microstructural and dopaminergic changes precede overt functional alterations at the group level. These results highlight caudate-dependent modulation of executive processes within working memory in early Parkinson’s disease.
