Introduction

Task-based fMRI is widely used to investigate how large-scale brain networks reconfigure to support specific cognitive demands, but acquiring multiple task runs per subject is often impractical1. Scan time, cost, and compliance issues become particularly problematic in large cohorts or clinical populations, where long task protocols are difficult to implement. To address this limitation, A prior study have proposed connectome-to-connectome (C2C) transformation approach that models the reorganization of the whole-brain functional connectome between different cognitive states (e.g., from rest to task-related states)2. The study showed that task-related functioanl connectivity (FC) can be successfully generated from resting-state FC and that the generated task FC better predicts behavioral performance compared to the empirical resting-state FC. 

However, rest-to-task reconfiguration is known to involve non-linear, task-specific changes in network organization, including shifts in integration and segregation across distributed systems3. It therefore remains unclear whether linear mappings are sufficient to capture individual-level task-related network reconfiguration. To capture complex rest-to-task mappings beyond linear transformations, we develop a deep learning–based approach, Connectome-GAN. By designing an FC-specific loss function and architecture that explicitly preserves node-wise connectivity profiles, we aimed to learn stable mapping of connectomes between cognitive states. In this study, we focused on three questions to evaluate whether Connectome-GAN improves rest-to-task FC prediction relative to the original C2C framework : (i) whether the GAN improves prediction of task FC at the edge level, (ii) whether it better reproduces task-related changes in large-scale network organization, and (iii) whether the generated task FCs retain behaviorally relevant information.

Methods

Dataset and preprocessing 

We used minimally preprocessed fMRI data from the Human Connectome Project (HCP) S1200 release. Each subject completed seven tasks (Emotion, Gambling, Language, Motor, Relational, Social, Working Memory) and two resting-state runs. We retained those who completed all fMRI conditions, satisfied stringent head-motion criteria for every run, and had a fluid intelligence score, then retained one randomly selected subject per family. The main analysis included 316 unrelated adults aged 22–36 years. 

We additionally preprocessed the minimally preprocssed data. The first 15 volumes of each run were discarded, and nuisance covariates were regressed out, including 24 motion parameters, three mean tissue signals (global, white matter, cerebrospinal fluid), and linear and quadratic trends. BOLD time series were averaged within a 268-node functional parcellation defined by the Shen atlas, and 268 × 268 FC matrices were computed as Pearson correlations between regional time series. 

Connectome-GAN model 

Connectome-GAN is a deep learning–based generative adversarial network that maps resting-state FC to task-specific FC. The generator is a shallow convolutional encoder–decoder that takes a 268 × 268 resting-state FC matrix as a single-channel 2D input and outputs a task FC matrix of the same size, designed to capture both local and distributed connectivity patterns while preserving node ordering. The discriminator follows a PatchGAN-style design and, given a concatenated pair of resting-state and task FC matrices, estimates whether the task FC is empirical or generated4. 

GAN training is often unstable, and this instability can be exacerbated when sample sizes are limited. To stabilize training of the GAN model under limited sample sizes and preserve node-wise connectivity structure, the generator was trained with an FC-tailored loss combining three terms: an adversarial binary cross-entropy loss, an L1 prediction loss between generated and empirical task FCs, and a Pearson correlation–based loss computed across rows and columns of the FC matrix. The discriminator was trained with binary cross-entropy and one-sided label smoothing for real samples. For the seven tasks, we trained and tested seven separate Connectome-GAN models, one per ta sk, using leave-one-out cross-validation (LOOCV): in each fold, the task-specific model was trained on N − 1 participants and then used to generate the held-out subject’s task FC from their resting-state FC. 

Original C2C transformation framework 

As a comparison method, we implemented the original connectome-to-connectome (C2C) framework. For each task, resting-state and task FC matrices were first reduced using PCA, the relationship between rest and task component scores was modeled using PLS regression, and task FCs were reconstructed in the original edge space via inverse PCA. C2C models were trained separately for each task using the same subjects and LOOCV folds as Connectome-GAN. 

Evaluation 

We evaluated both methods using three groups of metrics. First, accuracy of the task FC prediciton was assessed using the Pearson correlation between upper-triangular entries of generated and empirical task FCs and mean squared error (MSE) across all edges. Second, large-scale network organization was assessed using whole-brain modularity (Q) computed via the Louvain community detection algorithm, examining how well each method reproduced task-related changes in modular structure. Third, behavioral relevance was evaluated using connectome-based predictive modeling (CPM) to predict fluid intelligence (PMAT24_A_CR) from empirical rest FC, empirical task FC, C2C-generated task FC, and GAN-generated task FC5. For each FC type and task, CPM was performed using 10-fold cross-validation repeated 1,000 times, and predictive performance was summarized as the Pearson correlation between predicted and observed scores in held-out data. 

Results

Connectome-GAN improved rest-to-task prediction compared with the original C2C framework across all seven tasks. At the edge level, task functional connectomes generated by Connectome-GAN showed higher similarity to empirical task FCs than those generated by the original C2C models, with spatial correlations ranging from r = 0.70–0.74 for GAN-generated FCs and r = 0.64–0.72 for C2C-generated FCs (Cohen’s d = 0.46–0.69; p < 0.001 ), indicating more accurate recovery of task-related connectivity patterns. Mean squared error (MSE) analyses also revealed significant improvement by Connectome-GAN across tasks (Cohen’s d = 0.42–0.71; p < 0.05), suggesting systematic differences in how linear and non-linear mappings recover absolute edge weights. Notably, these effects were stable across LOOCV folds, suggesting that non-linear mapping better captures task-induced changes in functional connectivity beyond linear transformations. 

At the level of large-scale network organization, empirical task FCs generally showed higher modularity than resting-state FC (rest: Q = 0.14), consistent with stronger within-network coupling during task engagement. Across tasks, empirical task modularity ranged from Q = 0.16–0.21. C2C-generated task FCs showed lower modularity values (Q = 0.14–0.17) than the empirical estimates. In contrast, GAN-generated task FCs yielded modularity values (Q = 0.15–0.19) closer to those of empirical data , with significant differences between GAN- and C2C-generated FCs across all tasks (Cohen’s d = 0.43–0.61; p < 0.001 ), indicating that Connectome-GAN better captures task-induced shifts in modular organization beyond edge-wise similarity alone. 

Compared with C2C models, behavioral prediction analyses showed that CPM performance based on GAN-generated task FCs more closely approached that of empirical task FCs. CPM using empirical resting-state FC predicted fluid intelligence only weakly (r = 0.074), whereas CPM applied to generated task FCs yielded substantially higher prediction accuracy. Across tasks, CPM on C2C-generated task FCs achieved r = 0.158–0.212, while CPM on GAN-generated task FCs yielded slightly higher correlations overall (r = 0.159–0.239; p = 0.028–0.0036). Overall, these findings highlight the promise of non-linear generative approaches for capturing task-evoked reconfiguration from resting-state connectivity. 

Conclusion

We introduced Connectome-GAN, a non-linear generative model that predicts task FC from resting-state FC at the individual level. Using HCP data across seven task domains, we showed that Connectome-GAN improves edgewise reconstruction of empirical task FCs and more faithfully captures task-related changes in large-scale network organization compared with the original C2C framework. 

From a behavioral perspective, our findings align with prior C2C studies, demonstrating that linear rest-to-task transformations already provide a competitive baseline for predicting fluid intelligence. Beyond this baseline, Connectome-GAN yielded consistent, albeit modest, improvements in both reconstruction accuracy and behavioral prediction, particularly for cognitively demanding tasks. At the same time, given the data-hungry nature of deep learning models, it is plausible that the advantages of Connectome-GAN would become more pronounced as larger and more diverse training datasets become available. 

Overall, these results support the idea that resting-state FC encodes latent information about task-related network reconfiguration and that both linear and non-linear mappings can be used to uncover this information. Generative rest-to-task models such as Connectome-GAN may therefore be particularly useful in settings where extensive task fMRI data are difficult to acquire, including time-limited clinical protocols and large-scale population studies.
