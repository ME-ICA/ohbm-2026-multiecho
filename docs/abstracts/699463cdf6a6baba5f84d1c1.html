Introduction

Alpha-range (8–12 Hz) event-related desynchronization (ERD) has been widely interpreted as an index of attentional gating and visual cortical engagement during working memory. EEG–fMRI studies suggest that frontoparietal attention networks recruit visual cortex during encoding, and reduced alpha ERD has been associated with impaired suppression of irrelevant information, including in ADHD. However, most evidence comes from visuospatial paradigms, leaving unresolved whether alpha ERD reflects a domain-general suppression mechanism or task-dependent visual engagement.

Here, we tested whether alpha modulation is driven by visual input per se or by the functional relevance of visual information. Participants performed working memory tasks spanning visuospatial, visual non-spatial, and auditory domains, including a spatial working memory task with and without visual distractors. We hypothesized that robust alpha ERD would emerge selectively during the encoding of task-relevant visuospatial information. In contrast, conditions requiring suppression of external visual input—particularly the presence of distractors—would elicit increased alpha power during maintenance, reflecting protective inhibition rather than engagement.

Methods

EEG was recorded while participants (n = 25; mean age = 22.26 years) performed five working memory tasks that varied in stimulus modality and cognitive demands. These tasks included: (1) Spatial Working Memory, a paradigm that has consistently shown robust alpha ERD during encoding; (2) Spatial Working Memory with distractors during the maintenance period, designed to test whether alpha ERD reflects suppression of irrelevant information beyond encoding; (3) Faces, which rely on visual processing but additionally engage face-specific neural networks; (4) Fractals, a visually presented but non-spatial and semantically meaningless task; and (5) an Auditory Working Memory task, which primarily recruits non-visual processing networks. Each task was performed at two levels of difficulty (Low and High). Alpha ERD was computed separately for encoding, maintenance, and probe phases in each task, allowing us to examine whether alpha modulation differed across processing stages and stimulus domains.

Results

Time–frequency analyses revealed that alpha-band modulation differed markedly as a function of task demands and working memory load. Under low load, spatial working memory (SWM) elicited a clear reduction in alpha power during encoding, consistent with facilitation of task-relevant visual information. In contrast, visually presented non-spatial tasks (Faces and Fractals) showed comparatively weak and inconsistent alpha modulation, despite equivalent visual stimulation. Under high load, alpha dynamics diverged across task types. In SWM, and more prominently in the SWM with distractors condition (SWM-DS), alpha power increased during encoding and early maintenance, reflecting a shift from alpha desynchronization to synchronization. By contrast, Faces and Fractals did not show comparable alpha increases, nor did they exhibit robust alpha ERD with increasing load.

Across tasks, alpha modulation was therefore not determined by visual input per se, but by the functional relevance of visual information to task goals. Alpha ERD emerged selectively when visual-spatial information was actively encoded, whereas alpha synchronization emerged when visual input needed to be suppressed to protect internal representations.

Conclusion

Alpha-band modulation during working memory was governed by the functional relevance of visual information rather than stimulus modality alone. Alpha ERD emerged selectively during visuospatial encoding, whereas alpha synchronization was observed when external visual input needed to be actively suppressed, particularly under high load and in the presence of distractors. Visually non-spatial and auditory working memory tasks showed minimal alpha modulation, supporting a task-dependent gating account of alpha activity.
