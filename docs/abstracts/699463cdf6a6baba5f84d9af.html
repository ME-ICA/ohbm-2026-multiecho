Introduction

Maintenance of information in working memory is fundamental for higher-order cognition. Research in both non-human primates and humans includes evidence that the maintenance of task-relevant information comes from persistent neural activity in the lateral prefrontal cortex1. However, recent work has suggested that information can be maintained in the face of interruptions to this persistent activity, a phenomenon known as activity silent working memory (ASWM)2. Here, task-relevant information is held through persistent, recurrent activation in parietal and prefrontal regions. Information that is not currently task-relevant, but may later become so, is held in long-term memory state through sub-threshold patterns of reinforced synaptic weights, that are then brought into an active supra-threshold state by medial temporal lobe structures such as the hippocampus when they become task-relevant. Here, we seek to test the hypothesis that medial temporal lobe structures support working memory using a dual retrocue paradigm, which has previously been used to show evidence for ASWM in cortical regions3.

Methods

In the dual retrocue paradigm (Fig 1), participants are initially shown a face and a scene to maintain across a short delay period, after which they are cued that they will be tested on one of the two images after an additional delay. After the first test, a second cue indicates which of the two images will be tested after another short delay in the second half of the trial; critically, this second probe image is sometimes the same image category as the first probe (“stay” trials) and sometimes reflects the other image category (“switch” trials).

Functional MRI data from 5 participants (2 F, mean age = 25.43) were collected on a 7T Siemens Terra scanner (1.3mm3 voxels, TR=1s, TE=20ms). Data were denoised using NORDIC4 and preprocessed using AFNI. Bilateral hippocampal ROIs were extracted from a high resolution T1w image using hippunfold5 and split into anterior and posterior hippocampus segments using the uncal apex as an anatomical landmark.  

After preprocessing, a cross-validated regularized logistic regression decoder was trained to distinguish between faces, scenes and objects using independent task data (16 blocks of a 1-back task per image category; each block was comprised of 16 images each presented for 400ms with a 600ms ISI). Hyperparameters for regularization and number of voxels selected within each ROI were tuned within training sets and accuracy was measured by performance in held-out test sets comprised of 3 blocks (one per image category).

The trained decoder was subsequently applied to every time point of each trial, resulting in a predicted probability for the presence of each category over the course of the trial in each segment of the hippocampus. To increase the power of the analysis, and to distinguish memory effects from category effects, the predicted probability of each category was pooled by memory status (attended memory item [AMI]: first item tested vs unattended memory item [UMI]: item not initially tested) rather than image category (face vs scene).

Results

Preliminary analyses suggest that the category information can be decoded in both hemispheres of anterior and posterior hippocampus (decoding accuracy on held out folds: L anterior hippocampus: M = 0.408, SD = 0.052; R anterior hippocampus: M = 0.477, SD = 0.106; L posterior hippocampus: M = 0.544, SD = 0.066; R posterior hippocampus: M = 0.517, SD = 0.106). Applying the trained decoder to each time point of the dual retrocue task revealed that after the initial cue (when the participant is informed that they will be tested on the AMI), right posterior hippocampus showed increased evidence of the UMI relative to the AMI (Fig 2a). After the second cue, the left anterior and bilateral posterior hippocampus showed increased evidence for the UMI relative to the AMI on switch trials (where the UMI was tested) but not stay trials (where the AMI was tested twice instead of the UMI) (Fig 2b).

Conclusion

Taken together, these results suggest that the hippocampus supports working memory by storing information that is not immediately task relevant in a long-term memory state and subsequently returning it to an active suprathreshold state when it later becomes task relevant. Future work includes assessing hippocampal-cortical functional connectivity as well as hippocampal activation and decoding performance in a post-scan memory test.
