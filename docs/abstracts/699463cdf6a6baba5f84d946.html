Introduction

Across complex systems, network integrity is disproportionately supported by a small subset of nodes, commonly termed hubs1,2. In brain networks, identifying such critical nodes is essential for understanding vulnerability, resilience, and for informing presurgical planning3. While classical measures such as degree, betweenness, and PageRank identify hubs based on topology, an alternative approach defines hubs based on their functional impact, considering a node important if its removal leads to network collapse. However, exhaustively testing all node-removal orders is computationally intractable as network size increases. Here, we introduce Participation in Percolation (PiP), a scalable probabilistic framework that estimates the likelihood that a node’s removal at a given stage of an attack sequence contributes to network fragmentation, without relying on changes in any single network property. We evaluate PiP in MEG-derived human language networks as a proof of concept.

Methods

PiP was evaluated in individual functional language networks derived from MEG verb-generation data in 21 typically developing adolescents (ages 15–18). For each network, we generated 𝑆 random attack sequences, with 𝑆 set to 107 or terminated earlier if PiP estimates converged. During each simulated attack, network fragmentation was tracked by monitoring the sizes of the largest and second-largest connected components. The percolation point was defined as the attack depth at which the second-largest component reached its maximum. Nodes removed up to this point were labeled as having participated in percolation for that sequence. Across randomized attack sequences, node-wise PiP probabilities were computed as the proportion of simulations in which a node was removed at or before the percolation point at each attack depth. PiP convergence was determined when the Wilson 95% confidence interval half-width on node-level participation probabilities computed from stochastic attacks generated up to each iteration fell below 0.05. To assess efficiency, we compared the number of node removals required to reach the percolation point when attacks were ordered by PiP versus classical centrality measures (degree, betweenness, and PageRank).

Results

Across networks, high PiP values emerged at shallow attack depths in a small subset of nodes, defining a distinct hub population (Fig. 1A-B). When used to guide node removal, PiP reached the percolation point at 6.52 ± 3.70 node removals, significantly earlier than degree (15.78 ± 6.81), PageRank (15.14 ± 5.44), or betweenness (16.81 ± 8.46) (Fig. 1C; all p < 0.001), demonstrating greater efficiency in identifying nodes critical for network collapse.

Conclusion

PiP provides a probabilistic, data-driven estimate of node criticality grounded in functional impact rather than static topology. By identifying nodes that disproportionately contribute to network fragmentation, PiP offers a framework for assessing node criticality and studying network vulnerability and resilience. In clinical contexts, PiP could inform presurgical planning in epilepsy and other network disorders, while more broadly enabling scalable hub identification across diverse complex systems.
