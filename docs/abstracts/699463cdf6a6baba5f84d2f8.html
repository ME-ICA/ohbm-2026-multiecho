Introduction

Lesion studies have established medial temporal lobe (MTL) and subcortical circuits as critical for anterograde memory,1 whereas the networks supporting retrograde memory remain poorly defined because prior lesion cohorts rarely included standardized retrograde assessments.2 This has left unresolved whether anterograde amnesia (AA) and retrograde amnesia (RA) arise from disruption to a shared memory system or instead map onto dissociable large-scale circuits supporting encoding versus retrieval.3 Using a large lesion cohort with structured AA and RA ratings, we aimed (1) to replicate the recently described subiculum-centered human memory circuit,2 and (2) to test whether AA and RA correspond to separable brain networks.

Methods

We identified 118 lesion-associated amnesia cases with neuroimaging from published case reports and case series. Anterograde and retrograde amnesia (AA/RA) severity was assessed using a newly predefined rating scheme developed by the study authors to systematically evaluate AA and RA features described in the original reports.

Lesions were traced in MNI space and used as seeds for lesion network mapping (LNM) with a 1,000-subject normative connectome.4 Group differences in lesion-derived networks were tested using voxel-wise permutation analysis of linear models (PALM; family-wise error correction).5 Cortical involvement was quantified using cortical intersection scores. Directionality was assessed by extracting mean t-values from significant peak regions.

Results

Across all 118 lesions, 95% showed significant functional connectivity to the bilateral subiculum, with maximal convergence in the left posterior subiculum, replicating and extending a core human memory circuit.2 PALM analyses revealed dissociable circuits for AA versus RA.

RA > AA: stronger connectivity to lateral neocortical regions, including posterior middle temporal gyrus, temporal pole, frontal pole, and posterior supramarginal gyrus.

AA > RA: stronger connectivity to MTL–subcortical and midline structures, including posterior subiculum, frontal pole, thalamus, cerebellum, corpus callosum, and periaqueductal gray.

ROI analyses confirmed that these dissociations reflected stronger positive connectivity within each subtype’s network, not opposite-sign effects.

Conclusion

This work provides robust lesion-based evidence that human memory engages (1) a conserved subiculum-centered core circuit and (2) dissociable large-scale networks supporting anterograde versus retrograde memory. These findings clarify the neural architecture distinguishing encoding from retrieval deficits and establish a lesion-derived framework for understanding clinical amnesia and systems consolidation.
