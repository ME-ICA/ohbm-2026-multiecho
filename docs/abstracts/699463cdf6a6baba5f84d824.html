Introduction

Functional magnetic resonance imaging (fMRI) provides a way to study the dynamics of neural activations across distinct brain regions. This is useful for analyzing how different regions interact, as information about these interactions is reflected in patterns of co-activation. Extracting this information can be done in several ways, one of which is based on statistics for pairwise interactions. Relationship matrices derived as Pearson correlation coefficients between signals from different brain regions, referred to as functional network connectivity (FNC), have been used in neuroimaging analysis, e.g., to identify functionally similar brain networks or to compare clinical populations.

There exist various statistics for pairwise interactions (SPIs) based on correlation, spectral analysis, causality, and information theory that allow the derivation of relationship matrices for multivariate time series1. These techniques rely on different assumptions and describe interactions in distinct ways, leading to different results for the same data. Therefore, using multiple statistical tests for FNC estimation should allow a richer description of interactions.

In this work, we investigate the use of multiple SPIs for FNC derivation in the search for discriminative connectivity features predictive of schizophrenia. Using a preprocessed resting-state fMRI dataset, we derive FNC matrices using different SPIs and identify group predictive connectivity features. Aggregating results across SPIs yields a sparse map of high-confidence predictive features that survive permutation testing and are consistently important across methods. Further investigation of these features may reveal meaningful neurological insights into schizophrenia, as well as limitations and artifacts related to protocol design, data acquisition, or preprocessing.

The code associated with this project is available at https://github.com/neuroneural/brain-spi.

Methods

In this section, we describe the fMRI dataset used in this work, the statistics for pairwise interactions (SPIs) used to derive FNC matrices, the methods employed to identify group differences, and the aggregation of predictive features across multiple SPIs.

Dataset

We used resting-state fMRI images collected from FBIRN (Function Biomedical Informatics Research Network)2. All images in the dataset were preprocessed using statistical parametric mapping toolbox (SPM12). Rigid-body motion correction was applied to correct for subject head motion, and slice-timing correction was used to account for differences in slice acquisition timing. The fMRI images were subsequently warped into standard Montreal Neurological Institute (MNI) space using an echo planar imaging (EPI) template and resampled to 3x3x3 mm3 isotropic voxels. The resampled images were then smoothed using a Gaussian kernel with a full width at half maximum of 6 mm. Finally, images were parcellated using the Neuromark pipeline3, yielding 53 independent component time series per image.

The final dataset consisted of 311 multivariate time series, each containing 140 time points and 53 channels. Of these 311 images, 160 were acquired from healthy subjects (HC) and 151 from patients diagnosed with schizophrenia (SZ).

Statistics for pairwise interactions (SPIs)

We used pyspi4 to compute FNC matrices. From the available statistics, we selected covariance (measures the signals covariance), precision (based on the inverse of covariance), Spearman rank correlation (rank measure of monotonic dependence (whether signals are sorted the same way)), Kendall’s tau correlation (rank measure based on concordant and discordant observation pairs (whether signals go up or down synchronously)), mean cross-correlation (Pearson correlation between two time series with lags), distance correlation (general dependence measure based on signal distance correlation), multiscale graph correlation (generalization of distance correlation), Hilbert-Schmidt independence criterion (HSIC, non-linear correlation estimation method based on kernels), and power envelope correlation (PEC, compares signals by their amplitude oscillation similarity). This set of statistics was selected post hoc based on their ability to produce non-trivial relationship patterns and statistically significant group differences. Group analysis

To identify significant group differences between the FNC matrices, we employed two approaches, one based on Student's t-test and another based on Random Forest (RF) classifier.

In the statistical approach we used t-test to compare all 1378 unique connectivity features and obtain the corresponding p-values. To control for false discovery due to multiple comparisons, we applied Bonferroni correction, resulting in a significance threshold of p = 0.05/1378 = 3.6e-5.

For the RF approach we trained 1000 random trees to classify each set of FNC matrices. Feature importance was estimated as the mean decrease in entropy across trees. To select the most important features, we computed the proportion of statistically significant p-values k and retained the top-k% RF features. 1000 trees were used to ensure that this randomized approach converges to the same solution.

Feature aggregation

To aggregate predictive connectivity features found with statistical and RF approaches, we used an intersection of significant p-values and important RF features. As statistical and RF features turned to be positively correlated, this approach allows to additionally prune significant features without losing too much information. 

To aggregate features across SPIs we computed the frequency of each feature significance across SPIs and combined them into a map. This result was further validated on 20 random subsets containing 66% of the original images.

Results

Figure 2 summarizes the main steps and results of group comparisons across SPIs. Individual SPIs identified different sets of significant connectivity features, with varying levels of sparsity and overlap. Aggregating results across all SPIs revealed a sparse subset of features that were consistently identified as important by multiple tests. The frequency with which a feature was selected provides a natural criterion for thresholding significance, with higher frequencies indicating greater confidence in feature importance. Most significant features identified this way were reproduced in experiments on the random subsets of the FBIRN dataset.

Conclusion

In this work, we investigated the use of multiple statistics for pairwise interactions (SPIs) for group-level functional connectivity analysis. Using multiple SPIs allows probing the data for a broader range of possible interactions. While individual SPIs can identify many potentially important connectivity features, aggregating their results reveals a sparser set of features with higher confidence. The frequency with which a feature is identified as important across SPIs provides a natural way to control precision and to assess its credibility for further analysis.

It is worthy to note that the features identified this way are not exhaustive and do not cover the whole set of potentially significant features, as the results depend on many other variables and require additional consideration. For example, the higher concentration of identified features in the visual network may be influenced by the FBIRN non–eyes-closed acquisition protocol, which promotes activity in this network and makes the differences more visible.
