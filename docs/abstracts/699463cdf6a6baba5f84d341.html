Introduction

Approximately one third of people with temporal lobe epilepsy (TLE) cannot be treated adequately with antiseizure medication and therefore become candidates for resective epilepsy surgery. Memory impairment affects people with TLE pre- and postoperatively^1. Cognitive functional magnetic resonance imaging (fMRI) is a standard procedure in the presurgical workup of people with drug-resistant TLE. While language paradigms are well established in centers worldwide, many sites do not perform memory fMRI at all. This study aimed to characterize memory in TLE comparing a visuospatial and an episodic memory paradigm within individuals with TLE using BOLD activation and functional connectivity analyses. 

Methods

Forty-seven people with TLE (20 left-sided, 25 right-sided, 2 bilateral) underwent presurgical neuropsychological assessment and functional MRI (fMRI) on a 3 Tesla scanner. All participants completed two different memory paradigms to assess distinct memory domains. A 12-minute encoding task evaluated visual and verbal episodic memory^2, while a five minute hometown walking task^3 assessed visuospatial memory. Functional images were preprocessed using fMRIprep. For BOLD activation analyses, one sample t-tests and paired t-tests were performed in Statistical Parametric Mapping 12 (SPM12). Functional connectivity analyses were conducted using the CONN toolbox. We used 23 regions-of-interest (ROIs) in each hemisphere to perform ROI-to-ROI seed-based connectivity analyses.^4. 

Results

Preliminary findings revealed greater anterior mesiotemporal BOLD activation during visual and verbal episodic memory encoding compared to visuospatial memory retrieval (FWE corrected p<0.05). Furthermore, episodic memory encoding showed stronger connectivity in mesiotemporal regions of interest compared to visuospatial memory, as revealed by paired t-tests (Figure 1; FDR corrected p<0.05). Within-subject paired t-tests enabled classification of face, picture, and word encoding, with BOLD activation in more anterior hippocampal segments for face encoding and more posterior hippocampal segments for picture encoding (FWE corrected p<0.05).

Conclusion

Episodic encoding and visuospatial retrieval paradigms are widely used in the presurgical evaluation of people with epilepsy. Functional connectivity analyses, as well as simple BOLD activation analyses, help to characterize memory network differences in TLE. Better understanding of these networks could improve the prediction and mitigation of cognitive impairments in people with TLE pre- and postoperatively. Our preliminary findings suggest that relevant areas for resective epilepsy surgery can be addressed more precisely by episodic memory encoding than by visuospatial retrieval.
