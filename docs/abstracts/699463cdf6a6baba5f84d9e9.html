Introduction

Accurate and precise co-registration of stimulus onset with brain data acquisition is fundamental to M/EEG research. Temporal offsets between a recorded trigger and the true physical onset of a visual or auditory stimulus can bias latency-sensitive analyses ^1, including event-related responses, phase-locked measures, and time–frequency estimates. As multi-site collaborations become more common, small but systematic differences in stimulus timing across setups can accumulate into meaningful between-site variability. Recent work has highlighted this issue, offering specific software ^2 and hardware ^3 efforts to minimize delays. Despite this, in many laboratories the latency between a software trigger and the actual stimulus onset is often unknown. While commercial hardware exists to measure this latency, they are typically proprietary, high in price and may be tied to specific amplifiers. At the same time, building bespoke measurement systems can present a high technical barrier, requiring specialist electronics knowledge, embedded programming, custom enclosures, and analysis tooling.

Here, we present ElectroTime, an open-source, low-cost platform for measuring visual and auditory stimulus latencies across common experimental configurations. Using controlled bench validation and real-world recordings during PsychoPy-based stimulus presentation, we demonstrate that ElectroTime can quantify both device-level timing error and experimentally relevant stimulus latencies, providing an accessible route to standardised timing assessment in EEG/MEG research.

Methods

ElectroTime is a fully open-source system comprising hardware, firmware, host-side software, and analysis pipelines. All design files, source code, and documentation will be made available via a public repository and accompanying project website (electrotime.org). The hardware is built around a microcontroller platform mounted on a custom prototype shield incorporating an operational amplifier and supporting electronic components. Visual stimulus onset is detected using a photodiode circuit and auditory onset is captured via a standard 3.5 mm audio input. Trigger signals are received through a parallel port interface, allowing direct comparison between recorded triggers and physical stimulus onset. The device is housed in a filament-printed enclosure designed for reproducibility and ease of assembly (Figure 1).

Firmware for the device is written in Rust, selected for its emphasis on memory safety and performance in embedded systems. The device is controlled from a host computer using a graphical user application compatible with Windows, Linux, and macOS, developed in Dart. This application manages device connectivity, initiates recordings, and handles data transfer. Recorded data are processed using custom Python scripts that perform signal thresholding, artefact rejection, and extraction of summary latency statistics.

Validation was conducted in two scenarios. First, a controlled “gold-standard” setup was used in which a secondary microcontroller simultaneously generated a trigger signal and activated an LED. Given the negligible latency of LEDs and minimal software overhead, this configuration provided an estimate of the internal measurement error of the system. Second, ElectroTime was deployed in a realistic experimental context as part of the #EEGManyLabs ^4 consortium using a standard stimulus presentation computer running PsychoPy ^5.

Results

In the controlled validation scenario, ElectroTime demonstrated a mean measured latency of 0.24 ms (SD = 0.46 ms). This sub-millisecond measurement error is notably smaller than the sampling interval of typical EEG amplifiers (e.g., 1 ms at 1000 Hz), confirming that the device introduces negligible distortion to the recorded timing. The stability of these measurements indicates that the Rust-based firmware successfully minimizes interrupt latency and processing overhead, providing a deterministic timestamping floor.

In the real-world experimental setup using PsychoPy (60Hz Monitor), the mean visual stimulus latency was 18.03 ms (SD = 2.23 ms), This delay is consistent with a 1-frame buffer plus display input lag. These results highlight both the magnitude of uncorrected stimulus delays in typical laboratory environments and the degree of variability that can arise even within a single setup. 

Conclusion

ElectroTime provides an open, low-cost solution for measuring stimulus presentation in EEG and MEG experiments. By measuring the physical onset of stimuli relative to record trigger markers, it can enable accurate reporting, and where appropriate, correction of timing offsets in latency sensitive analysis. Because the system is fully open-source and designed to be easy to build and deploy, it lowers the technical and financial barrier to latency validation. Initial testing within the #EEGManyLabs consortium indicates that ElectroTime can support more consistent timing characterisation across laboratories and facilitate higher confidence in pooling and comparisons of datasets in collaborative studies.
