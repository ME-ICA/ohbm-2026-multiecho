Introduction

The hippocampus is traditionally associated with memory, yet functional neuroimaging and neuropsychological evidence suggests a broader role in processing scene information.1 Hippocampal activation has been observed during the perception of contextual, spatial, and navigation-related stimuli, as well as during scene imagination – processes thought to rely on internally maintained representations of a scene or place.2,3 However, it remains unclear whether this activity reflects perceptual scene processing or processes related to the successful encoding of information into long-term memory.

Methods

To examine whether hippocampal activation for scenes and objects during encoding relates to subsequent recognition memory, young healthy adults (N = 29; aged 18–35 years) underwent 3T fMRI while completing an implicit encoding task. In the scanner, participants viewed 120 colour images of real-world outdoor scenes and 120 greyscale images of everyday objects. Each image was displayed for 3000 ms, during which participants made property-based judgements (e.g., “Is the stimulus jagged or smooth?”). Outside the scanner, participants completed an old/new recognition test for all images and rated their confidence (120 old/120 new per category). Explanatory variables for each category and memory condition (scene hits, scene misses, object hits, object misses) were entered into a general linear model using FEAT in FSL. Parameter estimate images were computed for each condition relative to an active baseline. Percentage signal change was extracted from a probabilistic hippocampal region-of-interest, and category x memory interactions were assessed using a 2 x 2 repeated-measures ANOVA, conducted separately for each hemisphere.

Results

In the left hippocampus, there was a significant main effect of stimulus category (F = 8.58, p = 0.007), with greater activation for scenes than objects. There was no main effect of memory outcome (F = 0.65, p = 0.429) and no category x memory interaction (F = 2.10, p = 0.158). In the right hippocampus, there were no significant main effects of category (F = 3.56, p = 0.070) or memory (F = 0.08, p = 0.783), and no interaction (F = 2.32, p = 0.139). Behavioural performance showed both higher hit rates and memory discrimination for objects than scenes (p = 0.001), indicating that the preferential hippocampal activation was not driven by memory performance differences. 

Conclusion

These findings suggest that the hippocampal engagement during stimulus encoding is driven by category, with preferential engagement for scenes over objects, rather than by subsequent memory success. This effect was also only evident in the left hippocampus, in contrast to prior work suggesting a right hemispheric bias. Importantly, as memory performance was higher for objects, this effect cannot be attributed to overall memory performance. Together, these results highlight a role for the hippocampus in processing spatial scene information, rather than supporting memory encoding in a domain-general manner. Further work could investigate relationships with scene memory performance (e.g., confidence, item-level memorability) to further elucidate the relationship between scene perception and memory.
