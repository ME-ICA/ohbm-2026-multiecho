Introduction

Neural patterns in the human brain can encode a wide range of cognitive and behavioral variables.1 While most prior work has focused on the representation of isolated variables within localized regions – for example, object information in occipitotemporal cortex (OTC) and task-related information in prefrontal cortex (PFC) and posterior parietal cortex (PPC) – the human brain likely supports a richer representational architecture that extends beyond a simple one-to-one mapping between functions and regions. The discovery of mixed-selectivity neurons2 suggests that individual brain regions can simultaneously support the encoding of multiple variables. Moreover, extensive inter-regional communication may enable representations to be distributed across the cortex, giving rise to more widespread and potentially different representational formats.

In this study, we examined how three key variables in visual cognition—object category, selective attention, and task load—are represented across the brain. Using multivariate voxel pattern analysis (MVPA) on fMRI data, we showed that decoding is not confined to canonical regions but extends broadly across the cortical surface. Furthermore, with a novel functional connectivity based MVPA (fcMVPA) approach, we demonstrated that patterns of interaction between regions also reliably encode these variables, revealing a complementary representational format that further supports a brainwide account of visual and task-related processing.

Methods

In this project, we analyzed fMRI data from 12 participants while they performed an n-back working memory task. Using stimuli consisting of colored dots overlaid on object images, we manipulated object category, selective attention (object shape vs. colored dots), and task load (1-back vs. 2-back repetition detection) in an orthogonal design.

Minimal preprocessing was applied to each participant’s fMRI data, including motion correction, removal of linear and quadratic trends, and projection into native cortical space using each participant’s anatomical scan. The cortical surface was then parcellated into regions of interest (ROIs) using the Schaefer 200-region atlas3.

MVPA decoding of object category, attention, and task load was performed separately for each ROI and each participant using a linear support vector classifier (SVC). For each trial block, voxel patterns were constructed from the activity amplitude of each voxel derived from a general linear model. Leave-one-run-out cross-validation was used to assess decoding performance. Feature selection was performed on the training set by retaining the top 500 voxels ranked by their t-statistics of a paired t-test on normalized activity amplitudes between the two decoding conditions.

To explore the interdependency between the representation of different variables, we used a cross-decoding approach that followed the same procedure as above, except that the classifier was trained and tested on data from different conditions. For example, to decode attention across task load, an SVC was trained to classify attention using data from one load condition (e.g., 1-back) and tested on data from the other condition (e.g., 2-back). To remove directional bias, decoding accuracies from both train–test directions were averaged to yield the final cross-decoding performance.

Lastly, we applied fcMVPA analysis to test whether functional connectivity patterns also carry representational information about the key variables. Unlike conventional MVPA, which leverages voxel-wise activity patterns within a given ROI, fcMVPA is based on patterns of voxel-wise functional connectivity between pairs of ROIs. Specifically, for each ROI pair, we calculated the functional connectivity between the timecourses of all voxel pairs across the two regions for each trial. Rather than averaging these values, as is done in traditional functional connectivity analysis, we used the multivariate connectivity patterns directly as features to train and test the classifier. To reduce computational cost and maintain consistency with the standard MVPA procedure, we retained only the top 500 voxels from each ROI based on activity amplitude before performing fcMVPA. All other procedures followed the same pipeline as in the standard MVPA analysis.

Results

Using voxel patterns within each ROI, we first confirmed that object category, attention, and load are decodable in their respective canonical regions: object category in OTC, and attention and load in PPC and PFC. Importantly, however, these representations were not confined to their specialized regions (Figure 1a). Object category information was also reliably decodable in PFC, PPC, and across much of the cortical surface, particularly during the cognitively demanding shape-2back condition. Likewise, attention and load information were consistently represented across the entire cortex rather than restricted to a small set of regions.

Next, we examined the relationships among the neural representations of the three variables to determine whether they are orthogonally encoded or whether each exerts influence on the representation of the others. Using MVPA cross-decoding, we found that in most cortical regions, including PFC, PPC, and OTC, decoding object category across attention conditions (or vice versa) led to significant reductions in accuracy relative to within-condition decoding. This pattern indicates that object category and attention are interdependently encoded in these regions. In contrast, cross-decoding load with either object category or attention did not produce comparable performance drops in most regions, suggesting that load is represented in a more independent manner, invariant to other variables.

Lastly, we used a novel fcMVPA approach to probe inter-regional communication patterns and test whether functional connectivity serves as an additional representational substrate. Results from a subset of ROI pairs spanning PFC, PPC, and OTC (Figure 1b) indicate that all three types of information can be decoded from connectivity patterns. Object category information was not decodable in all ROI pairs, but was reliably coded in PFC–OTC, PPC–OTC, and within-OTC connections. Attention information, in contrast, was broadly represented across nearly all ROI pairs both within and between PFC, PPC, and OTC. Load information was primarily decodable from PFC-PPC connectivity, but was also evident in connections between frontoparietal regions and OTC.

Conclusion

Together, this study examined how three key components of visual processing—object category, selective attention, and task load—are represented across the brain. We not only confirmed that OTC, PPC, and PFC reliably encode object, attention, and load information, respectively, but also showed novel evidence that these representations are not confined to these regions. Instead, all three types of information are jointly encoded across all these ROIs and extend broadly across the cortical surface. This evidence suggests that the brain relies on a more integrated, whole-brain representational scheme that goes beyond traditional compartmentalized views of localized function. Moreover, the finding that object category coding becomes more widely distributed under high load and when attended indicates that this brainwise representation is task dependent, and the degree of its pervasiveness likely correlates with the perceptual and cognitive demands of the task.4

Examining the way different types of information are encoded, cross-decoding analysis revealed that some variables, such as object category and attention, exhibit dependent representational patterns, whereas others, like task load, are encoded largely independently from the rest. This unique representational mechanism suggests that the brain processes and organizes information in a dynamic and flexible manner, even when these inputs may appear orthogonal at the point of arrival.

Finally, with the help of a novel decoding method that we termed fcMVPA, we further discovered that all three key variables were encoded in patterns of functional connectivity between regions. In other words, in addition to the regional activity patterns that carry representational significance, connectivity patterns between pairs of brain regions also vary systematically across task conditions and stimulus types. These findings reinforce the idea that whole-brain information processing is widespread and can be instantiated through multiple complementary forms.
