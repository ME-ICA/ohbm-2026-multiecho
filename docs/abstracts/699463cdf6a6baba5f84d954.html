Introduction

Advances in neuroimaging technologies have enabled the collection of large-scale brain imaging datasets, which are essential for powerful statistical and predictive modeling. While such multi-site data increase sample sizes and improve generalizability, they also introduce site-specific biases due to differences in scanners, acquisition protocols, and preprocessing pipelines1. These biases, also known as Effect of Site (EoS), become particularly problematic when class distributions are imbalanced across sites2, for instance, when patients are primarily scanned at one site and controls at another. In such cases, machine learning (ML) models may learn to exploit spurious site-related signals rather than neurobiologically meaningful patterns3, leading to inflated performance estimates, poor feature interpretability, and reduced generalizability to new sites4.

To address this, we introduce Intra-Class Interpolation (ICI), a preprocessing strategy designed to remove site–target dependencies before model training. By upsampling within each site and class, ICI encourages downstream ML models to rely on target-relevant signals that generalize across sites, rather than site-specific confounds. Experiments on controlled simulations demonstrate the rationale and potential of this approach.

Methods

We propose Intra-Class Interpolation (ICI), a data-level strategy designed to limit the extent to which ML models can exploit site-target dependencies. ICI operates by balancing class proportions within each site, independently for each class. For a given site, samples from the minority class are used to generate synthetic observations via interpolation-based methods (e.g. SMOTE) until equal representation of all classes is achieved. By enforcing equal class representation at the site level, ICI disrupts the statistical coupling between site and target variables while preserving within-class structure and feature distributions.

To study the impact of site-target dependencies on ML models, we simulated multi-site datasets using an additive generative model, where the data is a mix of signal, noise and site effect.

All components were modelled as normally distributed random variables. The signal component encoded class-specific effects shared across sites; the site effect represented site-specific shifts affecting all samples within a site; and a noise component, unrelated to classes or sites. By controlling the relative strength of these components and the class balance within each site, this framework enabled the explicit manipulation of site-target associations.

In our experiments, 1000 samples with 10 features were simulated from 2 sites. Three scenarios were proposed. First, an Only EoS scenario was simulated without any True Signal. Secondly, an Only True Signal scenario was simulated, eliminating any EoS. Finally, the Combination of both signals was simulated. These scenarios were simulated in two ways: in a perfectly balanced scenario, where 0.5 of each class was presented at each site; and in a site-target dependent scenario, where 80% of one class was presented at one site and 20% at the other.  For the experiments presented here, interpolation was implemented using the Synthetic Minority Over-sampling Technique (SMOTE) with k = 10 nearest neighbours, although alternative interpolation schemes can be substituted. 

Logistic regression was used as the downstream classification model. To prevent information leakage, ICI was applied in a cross-validation-consistent manner: interpolation was performed only on the training data within each fold, while the test data remained unaltered. Model performance was evaluated on the test data using a stratified 10-times repeated 10-fold stratified cross-validation. This evaluation protocol ensured a robust performance estimate while preserving the original site and class structure in the held-out data. Random seed was fixed throughout the code to maximise reproducibility.

Results

When site and target were correlated (Figure 2-A), models trained using the unbalanced data in the Only EoS condition exploited this confound, yielding spuriously inflated AUCs (0.7–0.8). ICI successfully suppressed this site-driven bias, reducing AUC to chance level. In the Only True Signal condition, results were closely matched between unbalanced and ICI-balanced data, indicating that the proposed balanced strategy does not degrade the True signal. For the Combined Signal condition, unbalanced data achieved the highest AUC by leveraging both True Signal and EoS bias, whereas ICI systematically reduced AUC by removing the confound while retaining meaningful predictive information. Therefore, in the presence of site-target dependency, ICI selectively eliminates spurious, site-driven performance inflation without compromising sensitivity to the True signal.

When the site and target were independent (Figure 2-B), ICI did not degrade the performance. For the Only EoS condition, AUC remained at chance level (~0.5) both with and without ICI. In the Only True Signal condition, AUC distributions were nearly identical between unbalanced and ICI-balanced data, with overlapping medians and similar variance, demonstrating preservation of target-relevant information. For the combined signal condition, performance showed a slight increase over the real-signal-only baseline, with no systematic difference between processing pipelines. Thus, in the absence of site–target dependency, ICI has a neutral effect on model performance.

Collectively, these results demonstrate that ICI acts as a protective, data-level strategy: it attenuates site-driven predictions only when a site-target dependency exists, and remains inert otherwise. This supports its role not as a broad harmonisation or EoS-removal tool, but as a targeted safeguard against learning site-based confounds.

Conclusion

Intra-Class Interpolation (ICI) provides a targeted, data-level solution to a common pitfall in multi-site ML studies: the spurious inflation of performance by site–target confounds. Through controlled simulations, we demonstrate that ICI selectively mitigates site-driven bias in imbalanced data while preserving the True Signal and remaining inert when no such bias exists. Unlike broad harmonization methods, ICI does not assume site effects are always nuisance; instead, it removes only the dependency between site and label that leads to overfitting. This makes ICI a practical, safeguard-style preprocessing step for improving the validity and generalizability of ML models in heterogeneous neuroimaging datasets.
