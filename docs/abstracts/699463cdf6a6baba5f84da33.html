Introduction

Preclinical MRI is a cornerstone of translational neuroscience, providing mechanistic insights that complement human neuroimaging studies. Despite its importance, preclinical MRI data are typically stored in vendor-specific formats with limited standardization of metadata, spatial orientation, and coordinate systems. These inconsistencies hinder reproducibility, large-scale data integration, and direct reuse of animal MRI data within analysis pipelines developed for human connectome research.

In particular, preclinical MRI scanners often do not enforce explicit or standardized coordinate systems, and metadata required for reconstruction and interpretation are distributed across vendor-specific parameter files. As a result, substantial manual effort is required to convert, organize, and validate datasets before downstream analysis. Bridging preclinical and human neuroimaging workflows therefore requires tools that prioritize metadata transparency, coordinate system consistency, and compatibility with community standards such as the Brain Imaging Data Structure (BIDS).

Here, we present BrkRaw, a Python-based framework designed to provide standardized access to raw preclinical MRI data acquired on Bruker BioSpin systems, enabling BIDS-compliant data organization and streamlined integration into translational neuroimaging pipelines.

Methods

BrkRaw provides a modular Python application programming interface (API) and command-line tools for accessing, parsing, and managing raw Bruker preclinical MRI datasets. Metadata are parsed directly from JCAMP-DX parameter files using a robust and extensible parser that preserves sequence parameters and acquisition details required for reconstruction, spatial orientation resolution, and downstream analysis.

Raw image data are loaded as NumPy arrays and can be converted to NIfTI-1 format using nibabel, enabling seamless integration with standard neuroimaging software ecosystems. To address the lack of standardized spatial conventions in preclinical MRI, BrkRaw explicitly resolves scanner-specific axis definitions by unwrapping orientations expressed in human-based reference systems and remapping them to animal-centric coordinate systems. During conversion, image orientation is normalized according to species-specific anatomical conventions to ensure consistency across datasets and compatibility with BIDS and human neuroimaging pipelines. Animal species and acquisition position can be explicitly overridden via the command-line interface, allowing correction or standardization of orientation metadata when scanner-side configuration is incomplete or inconsistent.

To support large-scale and multi-study workflows, BrkRaw includes BIDS helper utilities and mapping templates that enable extraction of modality-specific metadata into JSON files and automated organization of multiple datasets into BIDS-compliant directory structures (Figure 1). By exposing sequence parameters and raw image data as Python objects, BrkRaw supports streamlined, end-to-end pipeline development directly from raw vendor data, facilitating custom reconstruction and preprocessing workflows with minimal manual intervention.

In addition, BrkRaw supports direct access to zip-compressed vendor-specific raw datasets, enabling inspection, metadata parsing, conversion, and dataset organization without manual extraction, thereby simplifying raw data management and archival workflows.

Results

BrkRaw was evaluated across multiple preclinical MRI projects at the Center for Animal MRI (CAMRI), University of North Carolina at Chapel Hill, encompassing structural and functional imaging datasets. The command-line interface enabled efficient inspection and batch processing of raw Bruker datasets, including direct access to acquisition parameters and image data from zip-compressed archives (Figure 2A,B). This capability substantially reduced manual handling of raw datasets and facilitated rapid verification of acquisition settings and data integrity.

The graphical user interface further supported interactive visualization of image data and associated sequence parameters directly from compressed vendor-specific archives without prior conversion (Figure 2C). This functionality enabled rapid quality assessment, protocol verification, and exploratory inspection of non-standard or newly developed imaging sequences not fully supported by vendor software.

Together, these interfaces supported reproducible and scalable handling of heterogeneous preclinical MRI datasets while minimizing user intervention during early-stage data inspection and validation.

Conclusion

BrkRaw provides a flexible, BIDS-oriented framework for preclinical MRI data management with a strong emphasis on translational compatibility. By enabling direct access to raw data and sequence metadata, resolving coordinate system ambiguities, and automating BIDS-compliant dataset generation across multiple studies, BrkRaw reduces technical barriers in preclinical neuroimaging workflows. This approach facilitates reproducible, scalable, and connectome-ready preclinical MRI research aligned with human neuroimaging standards.
