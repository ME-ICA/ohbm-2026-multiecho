Introduction

Neural responses to identical stimuli vary considerably across individuals despite similar behavioural outcomes. Aligning neural representations across subjects is essential for group-level neuroimaging analyses, building universal decoders that generalise to novel individuals, and understanding shared computational principles underlying human cognition.¹

Traditional alignment methods, e.g., Shared Response Model (SRM)² and Procrustes analysis suffer from two fundamental limitations. First, they require subjects to view identical stimuli to derive alignment transformations, rendering them inapplicable when shared stimulus presentations are unavailable. Second, even when shared stimuli exist, these methods derive transformations from the shared subset with the goal of generalising to all stimuli – yet they often exhibit degraded alignment performance on non-shared stimuli, undermining this very goal.

Inspired by compelling evidence that low-dimensional neural population dynamics are preserved across animals performing identical motor tasks,³ suggesting species-wide "neural landscapes" constraining possible activity patterns, we introduce MED-VAE (Multi-Encoder Multi-Decoder Variational Autoencoder), a framework for creating functionally aligned common spaces across subjects through task-guided latent organisation. The key insight is that artificial neural network (ANN) representations trained on visual recognition can serve as an alignment scaffold, defining task-relevant computational structure, e.g., hierarchical visual features, categorical boundaries, semantic relationships, that should be preserved across individuals. MED-VAE addresses both limitations of traditional methods: it eliminates the shared-stimulus requirement entirely, and by leveraging subjects' complete datasets including thousands of unique images per subject, it performs more stable alignment that generalises robustly to novel stimuli.

Methods

Architecture and Training Objective. MED-VAE (Figure 1B) comprises four pathway types operating through a shared latent space: (1) Subject-specific fMRI encoders mapping individual neural responses (~20,730 occipitotemporal cortex voxels per subject) to the shared latent space; (2) A shared ANN encoder mapping ResNet-50 activations (51,060 units after Sparse Random Projection) to the same space; (3) Subject-specific fMRI decoders reconstructing voxel-level activity; (4) A shared ANN decoder reconstructing ResNet-50 features from any encoder's latent representations. All pathways were trained simultaneously. 

Alignment emerges implicitly through bidirectional architectural constraints. The shared ANN decoder enforces that all subjects' latent representations must successfully reconstruct identical task-relevant features for each stimulus, creating pressure toward cross-subject representational compatibility. Simultaneously, subject-specific fMRI decoders must reconstruct neural activity from both same-subject and ANN-encoder latent representations. The shared ANN encoder output serves as a universal input that regularises decoders toward functionally equivalent transformations and enhances compatibility between each subject's decoder and other subjects' encoders, thus enabling cross-subject fMRI prediction where one subject's latent representation can be used to predict another subject’s fMRI activations.

Dataset and Experimental Design. We utilised the Natural Scenes Dataset (NSD):⁴ high-resolution 7T fMRI recordings from 8 subjects each viewing ~10,000 natural images across 30-40 scanning sessions. Each stimulus was presented three times, enabling cross-trial analyses. Cross-subject alignment was evaluated on two stimulus sets: 872 images viewed by all 8 subjects and 128 images viewed only by subjects 1, 2, 5, and 7 (Figure 1A). Critically, MED-VAE training excluded neural responses to all shared images from subjects 2-8, ensuring evaluation tests genuine cross-subject alignment rather than overfitting. In contrast, SRM and Procrustes derived alignment transformations using all subjects' responses to the 872 shared images, which is the standard protocol for these methods. The ANN activations were extracted from a pre-trained ResNet-50 model presented with the same images (Figure 1A).                                   

    

Evaluation Framework. We assessed performance across four dimensions: (1) Alignment quality via component-wise correlation (dimension-specific correspondence) and Representational Similarity Analysis (RSA; geometric structure preservation) between subjects' latent/common space representations; (2) Within-subject reconstruction via voxel correlation and explained variance R², evaluated both within-trial (correlating reconstruction with the same trial-averaged data) and cross-trial (correlating reconstruction with independent trials); (3) Behavioural relevance via multi-label category decoding accuracy and silhouette scores quantifying semantic clustering; (4) Cross-subject fMRI prediction, i.e, reconstructing Subject j's neural responses using Subject i's latent representations decoded through Subject j's decoder.

Cross-Trial Evaluation for Signal-Noise Decomposition. Trial-averaged fMRI data contains two noise types: Type A (trial-consistent, spatially-structured) arising from imaging physics, and Type B (trial-independent, random) including thermal noise and physiological fluctuations. Standard within-trial evaluation correlates reconstructions with the same trial-averaged data, potentially inflating performance if methods capture Type B noise patterns present in both input and target. To isolate genuine signal capture, we implemented cross-trial evaluation: correlating reconstructions from one trial with independent trials of the same stimuli. Since Type B noise is uncorrelated across trials, this metric reveals whether reconstructions capture stimulus-driven signal or exploit trial-specific artifacts.

Results

Superior Cross-Subject Alignment Without Shared Stimuli. MED-VAE achieved significantly higher alignment than both SRM and Procrustes across both Component correlation (Figure 2A, top) and RSA (Figure 2A, bottom). Crucially, this superior alignment was achieved despite MED-VAE never accessing shared stimuli during training, while baseline methods explicitly used these images for deriving alignment transformations.

Generalisation to Unseen Stimuli. The 128 images viewed only by subjects 1, 2, 5, 7 served as a critical generalisation test. MED-VAE maintained consistent performance across both stimulus sets (Figure 2A, lighter purple colour). In contrast, SRM and Procrustes (Figure 2A, lighter pink/green colour) showed pronounced generalisation degradation, with component correlation dropping substantially on unseen images, a pattern that became more severe at higher latent dimensionalities. This degradation confirms that traditional methods overfit to shared stimulus patterns rather than capturing genuinely transferable neural structure, undermining their core goal of aligning all stimuli including non-shared ones.

Within-Trial vs Cross-Trial Reconstruction: Distinguishing Signal from Noise. Traditional methods (SRM, Procrustes) achieve higher within-trial reconstruction compared to MED-VAE (Figure 2B, Reconstruction – within-trial). Within-trial evaluation correlates a reconstruction with the same trial-averaged data used as input. Because both share identical Type B noise realisations, methods capturing these noise patterns achieve inflated correlations. Cross-trial evaluation correlates a reconstruction with an independent trial, breaking the shared noise structure. Here, the correlation of raw trials is much lower (~0.18), reflecting how much raw trials correlate with each other due to shared stimulus-driven signal alone.

Under cross-trial evaluation, the performance pattern reverses (Figure 2B, Reconstruction – cross-trial). MED-VAE achieves cross-trial correlations that exceed the raw trials correlation. This indicates that MED-VAE effectively denoises individual trials: when correlating a denoised reconstruction with an independent raw trial, performance exceeds the raw trial-to-trial correlation. 

This slight performance reversal reveals that traditional methods' higher within-trial reconstruction derives substantially from capturing Type B noise patterns that are consistent within-trial but do not generalise to independent noise realisations. The within-trial advantage is therefore inflated by noise, not indicative of superior signal capture. MED-VAE's probabilistic regularisation appropriately suppresses these non-transferable noise patterns, achieving representations that are both more aligned across subjects and equally or even slightly more faithful to the underlying neural signal.

Superior Cross-Subject fMRI Prediction. Cross-subject neural prediction, i.e., using Subject i's latent representation with Subject j's decoder to reconstruct Subject j's voxel-level responses, provides the most direct assessment of whether common spaces capture genuinely shared neural structure. MED-VAE substantially outperformed both SRM and Procrustes (Figure 2B, Cross-subj. prediction), demonstrating that its common space captures transferable neural representations.

Preservation of Behaviourally Relevant Structure. MED-VAE latent spaces exhibited superior preservation of stimulus category information (Figure 2B, Category Encoding). UMAP visualisations of common subspaces revealed that MED-VAE produced tighter category clusters with clearer semantic organisation compared to the more diffuse representations from baseline methods (Figure 2C).

Conclusion

This work establishes MED-VAE as an effective framework for cross-subject neural alignment, demonstrating superior performance compared to conventional alignment methods across multiple evaluation dimensions. Our principal findings reveal three key insights with direct implications for neuroimaging methodology.

Cross-Subject Correspondence Without Shared Stimuli. The bidirectional pathway structure achieves cross-subject correspondence without requiring stimulus overlap during training. This fundamentally distinguishes MED-VAE from traditional methods in two respects. First, it eliminates the shared-stimulus requirement entirely, enabling alignment when matched stimulus presentations are impractical or unavailable, a common constraint in real-world neuroimaging scenarios. Second, by leveraging subjects' complete datasets including thousands of unique images per subject, MED-VAE performs more stable and informed alignment that generalises robustly to novel/unseen stimuli. Traditional methods, constrained to deriving transformations from limited shared stimulus sets, exhibit degraded generalisation to the majority of stimuli that cannot be used for alignment training, undermining their fundamental goal of creating universally aligned spaces.

Noise Suppression Rather Than Signal Loss. Cross-trial evaluation provides critical insight into the apparent reconstruction performance gap between methods. MED-VAE's lower within-trial reconstruction, that could be wrongly interpretable as a limitation, reflects principled suppression of trial-specific measurement noise rather than inferior signal capture. The key evidence is the performance reversal under cross-trial evaluation: traditional methods' substantial within-trial advantage disappears entirely, while MED-VAE achieves cross-trial correlations that exceed the raw trial-to-trial correlation ceiling.

This reversal has a clear interpretation. Within-trial evaluation conflates signal and noise because both reconstruction and target share identical Type B noise patterns, methods capturing these patterns achieve inflated correlations. Cross-trial evaluation isolates signal by correlating with independent noise realisations. Traditional methods' high within-trial performance derives substantially from noise capture; when this noise no longer correlates with the target, their advantage vanishes.

Superior Cross-Subject Neural Prediction. Cross-subject fMRI prediction, provides the most stringent assessment of whether alignment methods capture genuinely shared neural structure. MED-VAE's substantial superiority over traditional baselines demonstrates that bidirectional architectural constraints more effectively enforce representational universality than explicit correspondence matching approaches. The shared ANN decoder requires all subjects' representations to reconstruct identical task-relevant features, while fMRI decoders learning from shared ANN encoder outputs become mutually compatible, enabling effective cross-subject prediction.

Enhanced Category Encoding and Latent Organisation. Beyond alignment metrics, MED-VAE's common space exhibits superior preservation of behaviourally relevant structure, i.e., better semantic clustering and improved category decoding accuracy. This indicates that MED-VAE's task-guided alignment, produces common spaces that preserve the functional organisation of visual cortex rather than merely achieving geometric correspondence.

Implications. These findings have direct implications for: allowing group-level neuroimaging analyses; training universal decoders that generalise to new subjects with minimal calibration data; and advancing our theoretical understanding of shared computational principles in human visual cortex. The framework's applicability extends to any neural recording modality where cross-subject or cross-session alignment is required.
