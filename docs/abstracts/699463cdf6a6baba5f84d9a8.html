Introduction

Traditional fMRI experiments use static, narrowly defined hypothesis-driven designs with predefined conditions, limiting exploration of complex brain-task relationships and contributing to reproducibility challenges in cognitive neuroscience. Closed-loop neuroadaptive paradigms offer an alternative approach: analysing neural data in real-time during acquisition and dynamically adjusting experimental parameters based on ongoing brain activity. However, existing “neuroadaptive” implementations remain inaccessible, requiring bespoke technical setups without integrated open-source solutions. We present AutoNeuro, an open-source framework that integrates real-time fMRI acquisition, preprocessing, feature extraction, and Bayesian optimisation for adaptive experimental control. AutoNeuro connects directly to various neuroimaging modalities, processes reconstructed images with low-latency pipelines, computes neural features online, and uses a Gaussian Process (GP) to select subsequent task conditions that maximise user-defined objectives. This approach enables experiments where brain responses directly guide experimental trajectories, moving beyond static paradigms toward dynamic, data-driven neuroscience.

Methods

In this example we use the AutoNeuro pipeline for an fMRI task-based approach. AutoNeuro establishes persistent connections to MRI scanners via ISMRMRD-formatted image streams, receiving reconstructed slices in real-time and assembling complete volumes for immediate processing. Real-time preprocessing employs ANTs for rapid registration: the initial EPI volume is registered to MNI space using SyNRA, the inverse transform of which is applied to brain masks in MNI space for native-space analysis. Subsequent volumes undergo rigid-body registration and skull-stripping optimised for computational efficiency. 

Neural features are extracted online at TR resolution before a Bayesian optimisation agent models brain-task relationships using Gaussian Process regression with Matern kernels. This allows the system to select the next task based upon the known mapping between the task space and brain metric, and balances exploration and exploitation via Upper Confidence Bound (UCB) acquisition functions to select subsequent tasks.

We simulated an adaptive task-selection experiment using artificial data to demonstrate the utility of the approach. We define a task space, represented by axes along which the potential task can vary (Figure 1, top left). These axes can vary both the presented stimuli and task paradigm. Our simulation approach uses a task space with three dimensions, with 3 variations on each axis, meaning the intersection of task variants was 27 (3 axes with 3 task variations; 33). Each axis was represented by a number line with limits between -1 and 1. With three task variations on each axis, each axis would have a point at -1, 0 and 1 (Figure 2A).

We created an artificial brain metric that gave a weighted preference to the positive end of axes 1, 2 and 3. We tracked metrics including GP mean and uncertainty, acquisition function values, observed versus predicted responses, cumulative maximum response, exploration versus exploitation, and the sequence of task selections across trials. Once a threshold of certainty about the mapping is reached, the point in the task space at which the brain metric is largest is exploited, with more trials of this specific task being run.

This process was repeated across multiple independent batches of simulated data to demonstrate the robustness and repeatability of the approach. This setup demonstrates how adaptive sampling can efficiently navigate a discrete task space to identify high-response conditions while balancing exploration and exploitation.

Results

The three dimensional task space is visualised in Figure 2A. The “lattice” of possible combinations of task dimensions are indicated by points in the 3D space, with each axis representing a different component of the task. The connected line of red points indicates an example trajectory of tasks chosen by AutoNeuro. The exploration shows an efficient sampling of the task space across a total of 10 trials. Simulation of these trajectories was repeated 500 times with randomly chosen starting points. 

The brain metric values observed at each axis coordinate across all 500 folds is plotted in Figure 2B, each axis being denoted by a colour. For each pair of coordinates on each axis, t-tests yielded p-values < 0.05 except for values on axis one at coordinate -1 vs 0. This indicates that AutoNeuro reliably converges on tasks that yield a higher target brain metric. Additionally, all 500 repeats converged on the task space coordinate with the highest brain metric within 10 trials. Comparatively, a grid search of the same task space requires 27 individual trials. Conclusion

AutoNeuro provides the first integrated open-source platform for closed-loop neuroimaging, combining real-time acquisition, preprocessing, feature extraction, and adaptive control in a modular framework. It is worth noting that a key limitation shared by all neuroadaptive paradigms, lies in the choice of neural metric used to guide optimisation. The selected metric does not directly reflect brain activity but instead shapes the optimisation landscape through which brain-task relationships are inferred. As a result, convergence reflects properties imposed by the metric and task-space design rather than intrinsic neural dynamics. The interpretability of optimisation outcomes therefore depends on the researcher’s choice of task dimensions and neural metrics, which must be selected based upon the cognitive or clinical process of interest.

Even within these constraints, AutoNeuro enables neural responses to directly guide experimental design in real time, shifting experimental logic from testing predefined hypotheses to dynamically discovering brain–task relationships during acquisition. The framework efficiently explores multidimensional task spaces using Bayesian optimisation, supports a wide range of neural metrics from regional contrasts to network-level measures, and maintains stable performance under real-time constraints. By placing control of task and metric definition in the hands of the user, AutoNeuro establishes a flexible and extensible platform for next-generation neuroadaptive experiments in cognitive neuroscience and clinical applications.
