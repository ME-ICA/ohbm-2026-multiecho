Introduction

The effective visualization of data across brain structures is crucial for interpreting and communicating neuroimaging results. Frequently used options include volumetric slices (e.g., from NIFTI files), surface-mesh rendering, or two-dimensional (2D) vector plots. As reviewed in Chopra et al. (2023)1, many open-access tools now programmatically render reproducible brain figures across these formats, bolstering image quality and enabling interactive exploration. However, most tools target the cortex and far fewer support subcortical and cerebellar structures, leaving the field without a consistent, accessible way to depict non-cortical data.

We address this gap with a new Python package for flexible 2D visualization of subcortical and cerebellar data. The design was inspired by the ggseg package2 in R, which maps empirical data to cortical atlases in two dimensions. ggseg supports subcortical plotting via the FreeSurfer ‘aseg’ atlas, but no single mid-point coronal or sagittal view can simultaneously show all seven subcortical regions (accumbens, amygdala, caudate, hippocampus, pallidum, putamen, thalamus). Users can project subcortical data onto three-dimensional (3D) volumetric renderings in ggseg2 as well as in the ENIGMA toolbox3, though interpretation of empirical data is challenged by occlusion and lighting inhomogeneities and by limited atlas support beyond that of aseg, despite the increasing availability of alternative atlases for subcortex, brainstem, and cerebellum.

Our contribution is twofold: (1) a novel Python package that offers out-of-the-box, vectorized visualizations across nine popular subcortical and cerebellar atlases; and (2) a step-by-step guide for creating custom visualizations from any segmentation compatible with this package. While applicable to cortex and non-cortex alike, we focus here on the subcortex and cerebellum since cortical visualization already benefits from many established tools1.

Methods

To create 2D vector representations of a given non-cortical atlas, we first render the atlas as a 3D mesh, from which region outlines can be traced in two dimensions using vector graphic software. This overall workflow is depicted in Fig. 1, using the Melbourne Subcortex Atlas with the S1 resolution (i.e., eight regions per hemisphere) as an example. In Fig. 1A, this segmentation is overlaid in color atop the MNI152 atlas template using the MRIcroGL visualization software. 

To view just these subcortical structures in three dimensions, we rendered the atlas regions as a set of mesh surfaces forming one cohesive 3D object. There are several programmatic options for constructing a triangulated mesh surface from a voxel-based volume, many of which use the marching cubes algorithm. Indeed, we selected a Python-based solution using an enhanced marching cubes implementation from the lab of Professor Chris Rorden. This script, niiAtlas2mesh.py (which can be found among other useful Python-based neuroimaging scripts at https://github.com/rordenlab/pythonScripts/tree/main), utilizes the ‘niimath’ package that incorporates command-line tool functionality from FSL into Python. This functionality is adapted in our workflow to allow the user to specify a custom color map that assigns an RGBA value to each vertex, corresponding to one color per unique region index. The result is one final mesh file in .mz3 format, which can be viewed in multiple neuroimaging applications—though it is primarily designed for the Surf Ice graphical software. As depicted in Fig. 1B, Surf Ice renders all regions together with color coding, enabling rotation to view the merged mesh object from any angle. 

The next step is to capture still images at the desired angle(s) for the vectorized 2D representation. Fig. 1B shows selected medial and lateral angles of the left-hemisphere segmentation, from which we then traced regional outlines. While there are edge detection tools that could automate this process (such as the binary silhouette mesh shader in the NiiVue software package), we opted to manually trace each region to ensure consistent quality across atlases. This was performed using the freely available vector graphic editing software Inkscape (https://inkscape.org/), to create a traced object for each region (e.g., putamen) and face (medial and lateral), respectively. As shown in Fig. 1C, we added a solid-color fill to each traced object and stacked them along the z-axis to align with the corresponding still image of the 3D volumetric mesh in Fig. 1B. We then assigned a title to each region—face object in Fig. 1C in the Object Properties panel in Inkscape, which allows programmatic access to each object from Python for mapping empirical data (using the svgpath2mpl package; https://github.com/nvictus/svgpath2mpl). 

Our Python package, ‘subcortex_visualization’, was designed to use the nomenclature template [region]_[face]_[hemisphere], with the example of putamen_lateral_L indicating the lateral face of the left-hemisphere putamen. For the traced regions to be properly superimposed along the z-axis in the programmatic rendering, the region layering order is explicitly defined in a tabular data file for each hemisphere. This framework offers a flexible approach to customized data visualization for any segmentation volume, and users can tweak visual properties of both the 3D mesh rendering and 2D vectorized image. In the Results section, we discuss how this visualization pipeline interfaces with our Python package (subcortex_visualization) to depict empirical results across nine popular atlases for the subcortex and cerebellum.

Results

The 2D vector graphic representation of an example segmentation atlas in Fig. 1C forms the basis for our new Python package, ‘subcortex_visualization’. This package enables out-of-the-box empirical data visualization for nine popular subcortical and cerebellar atlases using 2D vector images that were constructed using the pipeline described in the Methods. These nine atlases are depicted in Fig. 2 and include the aseg subcortical atlas; the Melbourne subcortical atlas (resolutions S1 through S4); the AICHA subcortical atlas; the Brainnetome subcortical atlas; the thalamic nuclei HCP atlas; and the SUIT cerebellar lobule atlas.

For each atlas, we created the requisite vector graphic .SVG file and region-order CSV file that together allow Python to programmatically access each region—face object per hemisphere and assign a color based on either segmentation index (if no user data is provided) or a colormap anchored by empirical data values. The central workhorse function of this package is ‘plot_subcortical_data’, which takes a variety of parameters designed to maximize flexibility in data visualization. For example, users can specify a given atlas (any of the pre-constructed nine will work out of the box), an empirical dataset with values to plot for each region (and, optionally, each hemisphere), line color and thickness, and color map (for example, ‘viridis’ or ‘turbo’, or a custom Matplotlib color map). To maintain consistency across other visualizations, users can also set a fixed upper and lower bound and/or fixed midpoint for the colormap values.

Conclusion

In this work, we introduce the subcortex_visualization package with the aim of broadening the availability of non-cortical data visualization tools in a streamlined and accessible manner. This presents a unified two-dimensional subcortical and cerebellar visualization tool that complements existing software for two-dimensional cortical rendering (e.g.,  ggseg2, along with pycortex for cortical flatmap projections) as well as the projection of empirical data onto a three-dimensional surface for cortical and non-cortical structures alike (including ggseg2 as well as the ENIGMA toolbox3, fsbrain, and brainrender). We curated a set of nine existing atlases that are frequently used in human brain-mapping studies, including seven for the broader subcortex, one for thalamic nuclei specifically, and one for the cerebellum. Additionally, we developed an integrated tutorial pipeline for creating new vector-based visualizations for custom segmentations, paving the way for flexible incorporation of new atlases.

To our knowledge, this is the most comprehensive compilation of subcortical and cerebellar atlases for data visualization in one unified toolbox with standardized rendering conventions. The limited availability of programmatic data visualization tools for the subcortex and cerebellum reflects a historical ‘cortico-centric' bias in cognitive and computational neuroscience4, arising in part from physical difficulties in obtaining reliable signal from more deeply embedded structures relative to superficial cortical areas. However, in an era of increasing focus on the subcortex and cerebellum in health and disease, imaging resolution continues to improve, such that more studies can start to depict analytical results from the subcortex and cerebellum alongside those of the cortex. This package thus aims to facilitate accessible and interpretable data visualization across non-cortical parcellation atlases, which is particularly timely with the recent release of multimodal functional maps across cortex, subcortex, and cerebellum by Hansen and colleagues5.

We hope that this serves as an important step towards increasing the availability of open-source programmatic brain-imaging data visualization tools for non-cortical structures, which can be readily integrated with other Python-based imaging analysis workflows. Recognizing the importance of open science and community engagement, we have made this package available on GitHub at https://github.com/anniegbryant/subcortex_visualization. Additionally, documentation (including installation instructions and tutorial Jupyter notebooks) can be found at the project website at https://anniegbryant.github.io/subcortex_visualization/. As an open-source tool, we warmly welcome user contributions for new atlases to include in the library for the benefit of other researchers. For example, future work might also incorporate brainstem atlases and other thalamic nuclei parcellations. Altogether, in providing both out-of-the-box atlases and instructions with which users can generate such atlases, it is our hope that this provides a crucial resource for data visualization options below the cortical mantle.
