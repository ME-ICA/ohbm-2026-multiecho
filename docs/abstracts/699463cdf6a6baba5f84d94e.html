Introduction

The Enhancing Neuro Imaging Genetics through Meta Analysis (ENIGMA) consortium conducts some of the largest brain imaging studies in the world, involving over 1,000 institutions in 47 countries worldwide1. Ensuring consistent analysis procedures across the consortium projects presents a significant challenge, which has been a barrier to projects on functional magnetic resonance imaging (fMRI) in particular due to the complexity and diversity of analysis methods. To overcome these challenges, the consortium has developed the software HALFpipe2. 

The development of HALFpipe closely follows insights from other standardized protocols for cortical thickness, surface area, volume and diffusion imaging developed in ENIGMA1. In the consortium, any researcher can propose an analysis plan, after which collaborators with relevant data are invited to apply the analysis plan to their data and contribute resulting summary statistics. HALFpipe enables consistent execution of fMRI analysis plans for diverse datasets and across diverse compute infrastructures. Researchers then pool these outputs via meta- or mega-analysis to generate a single set of results, usually with sample sizes exceeding what can usually be collected by a single research project. 

Such collaborative projects represent one way of increasing statistical power and overcoming the reproducibility crisis in functional neuroimaging.

Methods

HALFpipe is distributed as a container that bundles fMRIPrep3 as well as other tools such as AFNI, FSL, ANTs, FreeSurfer and Nilearn that are necessary for data processing. Instructions for how to download and use the software are available at https://fmri.science/halfpipe.

When a user starts the container, they are prompted by a user interface to specify input data (which can be in BIDS format but does not have to be), preprocessing parameters and which brain maps and matrices should be derived. These inputs and configurations are used to run end-to-end automated data processing from raw image inputs to imaging features usable for statistical analyses. Preprocessing of images is standardized via fMRIPrep3, but available outputs can be configured flexibly to include functional connectivity maps and matrices, task-based models, network template regression, and metrics such as fractional amplitude of low frequency fluctuations (fALFF) and regional homogeneity (ReHo). 

HALFpipe includes efficient code for the calculation of multiverse analyses, so that outputs are re-used when possible across different analysis specifications, minimizing processing time. 

Results

HALFpipe has been used by researchers across 81 universities in 22 countries and is in use across 16 working groups of the ENIGMA consortium for collaborative meta-analyses. These working groups have so far published more than 12 studies on the neural correlates of mental health and brain disorders, with multiple other studies currently in progress.

For easier adoption by new projects and users, and to support more flexible configurations for multiverse analyses, we have updated the user interface of HALFpipe version 1.3.x. The terminal user interface library Textual enables improved usability, clickable buttons even in the terminal, and flexible navigation between different parts of the application. This includes a “duplicate” button that can create a copy of an analysis specification that can then be edited, which makes it easier to define sets of multiverse outputs.

HALFpipe has also incorporated novel functionality to support new kinds of research projects in the ENIGMA consortium. These include NeuroMark, which uses spatially constrained independent component analysis to derive brain maps and time series for brain networks using a template of pre-identified regions to enhance the reproducibility of data-driven network estimation between studies4. HALFpipe has also added support for estimating single-trial pattern maps for multi-voxel pattern analysis5. To increase spatial resolution and specificity in multi-voxel pattern analysis studies, as well as reduce computation time and storage requirements for other outputs, all outputs of HALFpipe can now optionally be calculated in native space.

Conclusion

These updates represent a significant step towards enabling consortium-scale fMRI studies to use state-of-the-art methods. HALFpipe is part of a broader infrastructure of manuals, guidelines, and analysis plans that are used across the ENIGMA consortium, but ensures that analysis methods and flexibility are standardized, version-controlled, and that outputs are generated alongside metadata containing provenance information. We will discuss these achievements and improvements alongside ongoing challenges, such as further reducing the computational and storage footprint and advancing the use of biobank-scale cohorts in the consortium.
