Introduction

The brain exhibits constant patterns of spontaneous activity, even in the absence of sensory input or tasks. The representation hypothesis 1 suggests that spontaneous activity underlies priors of generative models of the most common perceptual, motor, and cognitive patterns, which are used to predict future behavior. In line with this hypothesis, in previous work we showed that spontaneous activity patterns in visual regions reactivate category specific patterns in category specific regions (e.g., face patterns in fusiform face area 2). Moreover, spontaneous reactivations of natural hand movements occur in human primary motor cortex and parietal cortex 3. To further investigate cross-modal rest-task representational relationship, we measured the occurrence of visual patterns related to four evolutionarily salient visual categories, i.e., body parts, faces, places, and tools during resting state in motor cortex and attention networks. 

Methods

Using data from 100 healthy participants (56 females, 22-35 yrs) in the Human Connectome Project (HCP), we analyzed 3T resting-state and task fMRI data. Participants were instructed to complete an N-back working memory task, wherein images from four distinct stimulus categories (faces, body parts, places, and tools) were shown in separate blocks. These blocks comprised trials featuring pictures corresponding to each of the mentioned categories. 73% of Body parts stimuli included the hand. Each run included 8 task blocks (25 seconds) and 4 fixation blocks (15 seconds). Fifty percent of the task blocks used a 2-back design, while the other 50% used a 0-back design. At the beginning of the block, a 2.5 s cue indicated the task type (and also indicated the “target” stimulus for the 0-back design block). During the 2-back design block, participants were instructed to respond manually with a button press whenever the current stimulus matched the one presented two positions earlier, and during the 0-back design block, participants were instructed to manually respond with a button press whenever the target stimulus appeared during the block. On each trial, the stimulus was presented for 2 seconds, followed by a 500ms inter-task interval. A 15-minute resting-state fMRI scan was conducted. 

Hand region of motor cortex obtained from Gordon et al. 4, dorsal attention (DAN), and ventral attention (VAN) from Yeo’s atlas 5 were selected as regions of interest (ROI). Contrast maps obtained from the HCP processed working memory task data were included for the following analysis. Specifically, linear contrasts for each category type versus baseline were selected. Multi-voxel activation patterns in ROIs were measured and compared between each frame of preprocessed rest and task contrast map using Pearson Correlation. The U90 value (90th percentile of r-value distribution) represented the task-rest pattern similarity and served as the dependent variable in ANOVAs assessing interactions between regions, movements, and hemispheres. 

Results

We did not find a significant U90 three-way interaction between visual patterns, hemisphere, and ROI (F(6,594) = 0.42, p = 0.864), while we observed significant two-way interaction effects between visual patterns and ROIs (F(6,594) = 4.51, p < 0.001, ηp2 = 0.044) and between hemisphere and ROIs (F(2,594) = 11.86, p < 0.001, ηp2 = 0.107). The visual patterns × hemisphere interaction was non-significant (F(3, 594) = 0.73, p = 0.532). A second one-way ANOVA, aimed at investigating the associations between spontaneous and visual stimuli-evoked patterns, was separately performed for each ROI. We found a significant category effect in the left-hemisphere hand ROI (F(3,297)=3.93, p-FDR corrected=0.018, ηp2=0.038). A post-hoc analysis found that resting state spontaneous multi-voxel activity patterns showed higher similarity with the tool stimuli-evoked activity compared to the place stimuli-evoked patterns after Bonferroni multiple comparison correction (p-value corrected = 0.004, Tool U90=0.117, Place U90=0.109). In contrast, we did not observe a category effect in the right-hemisphere hand ROI (F(3,297)=0.69, p-FDR corrected =0.800).

In the higher-order cognitive networks, we found a significant category effect in the bilateral DAN (left: F(3,297)=9.57, p-FDR corrected<0.001, ηp2=0.088; right: F(3,297)=6.15, p-FDR corrected=0.001, ηp2=0.059). Specifically, within the left DAN, spontaneous multi-voxel activity patterns showed higher similarity with body parts (U90=0.075), place (U90=0.073), and tool (U90=0.075) evoked activity compared to face (U90=0.069)(body parts pattern-vs-face pattern: p-Bonferroni corrected < 0.001; place-vs-face pattern: p-Bonferroni corrected = 0.014; tool-vs-face pattern: p-Bonferroni corrected < 0.001). In the right DAN, we also observed higher similarity between resting state patterns and body parts (U90=0.077), place (U90=0.075) and tool (U90=0.076) evoked patterns compared to face-evoked patterns (U90=0.072)(body parts-vs-face pattern: p-Bonferroni corrected < 0.001, place-vs-face pattern: p-Bonferroni corrected = 0.030; tool-vs-face pattern: p-Bonferroni corrected = 0.012). Additionally, we did not find a category effect in the VAN (left: F(3,297)=0.10, p-FDR corrected=0.959; right: F(3,297)=0.52, p-FDR corrected= 0.800).

Conclusion

Resting-state patterns in the left hemisphere hand motor region showed significantly higher similarity to tool-evoked patterns than place-evoked patterns, indicating cross-modal encoding of tool-related visual information in motor cortex. In the bilateral dorsal attention network, resting-task similarity for body parts and tools significantly exceeded that for faces. These results demonstrate that resting-state activity in non-visual cortices (e.g., motor and association areas) represents visual information, supporting the theoretical framework that spontaneous neural dynamics reactivates ecologically salient stimuli through distributed networks.
