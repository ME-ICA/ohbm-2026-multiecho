Introduction

Aphasia is a language disorder that commonly develops after a stroke due to disruption of language areas. Estimated connectome-based approaches that use databases and only require lesion masks1 offer a way to represent stroke lesions’ disruptions at the network level when subject-specific diffusion or functional MRI data are not available; recent work has successfully used estimated structural connectivity (eSC) and estimated functional connectivity (eFC) for cognitive prediction in a cohort with Multiple Sclerosis.2 In this study, we used a post-stroke aphasia dataset to examine how eSC and eFC derived from lesion masks only relate to language performance. Our models achieved very good performance in predicting aphasia scores and provide a feature importance map for both structural and functional connections that are important in the aphasia predictions. Having a better understanding of the networks that underlie aphasia may allow personalized therapeutics and more accurate prognoses for better post-stroke care.

Methods

The open source Aphasia Recovery Cohort (ARC) dataset (N = 230, aged 55.7 +/- 11.6 years, 89 female, 141 male) consisted of native space T1/T2 lesion masks, basic demographics and aphasia scores.3  We first applied SynthSR to the T1s, which generates a synthetic T1-weighted version of a scan with a lesion inpainted. This step helps the accuracy of the subsequent MNI space transformation, which was calculated using ANTs. The same MNI space transformation was applied to the lesion masks.

The co-registered lesion masks were then put through the Network Modification Tool, which maps each lesion onto a normative tractography reference to generate subject-level estimated structural connectivity (eSC).1 Specifically, change in connectivity scores (ChaCo), which is the ratio of disrupted streamlines to total streamlines for each region of interest, were used for the predictions. Estimated functional connectivity (eFC) was generated from the NeMo Tool’s eSC using the Krakencoder, a deep learning framework trained on paired structural–functional connectivity data to learn a latent representation that supports estimating functional connectivity from the structural input.4 Note that the parcellation that this study uses is cococomppsuit439, with 439 ROIs. 

Ridge regression was used to assess the relationship between connectivity-derived features and Western Aphasia Battery (WAB) scores. Covariates included in the model were age, sex, days after stroke in which a subject took the WAB test, and days after stroke in which the MRI was taken. Lesion volume was included and excluded in certain models to determine whether it improved the predictions. Model performance was evaluated with 100 repeated train–test cross-validation splits, using Spearman’s correlation (r) between predicted and observed scores as the primary metric. Haufe-transformed weights were examined to characterize the distributions of connectivity features contributing to prediction. 

Results

Using lesion volume and covariates alone produced an average r = 0.70. Models based on ChaCo scores had an  r = 0.74 when including lesion volume, and r = 0.75 when excluding lesion volume. Haufe-transformed weights showed that eSC contributions were strongly left-lateralized and aligned with known language regions, whereas eFC contributions were more distributed and bilateral. This suggests that eSC captures focal lesion-related disconnection, while eFC reflects broader functional network involvement in language function.

Conclusion

This work demonstrates a practical framework for applying estimated structural (eSC) and functional connectivity (eFC) methods to brain-behavior mapping in post-stroke aphasia. By combining NeMo-derived eSC with Krakencoder-derived eFC, the approach enables network-level characterization of lesion effects and supports predictive modeling using only clinically acquired anatomical lesion input. The use of these models is two-fold: to create more accurate prognoses but to also understand how network disruptions in specific areas can impact language.
