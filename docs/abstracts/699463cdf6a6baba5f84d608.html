Introduction

Major depressive disorder (MDD) is a leading cause of global disability. While repetitive transcranial magnetic stimulation (rTMS) guided by functional connectivity (e.g., SNT) has improved outcomes1, substantial interindividual response heterogeneity persists. The neural mechanisms underlying this variability, particularly from a dynamic network perspective, remain poorly understood. We hypothesized that the therapeutic response depends on the intrinsic network control properties of personalized rTMS targets2,3,4. This study integrates brain network control theory2,4 and interpretable machine learning5 to elucidate the mechanistic basis of connectivity-guided rTMS and identify a novel, dynamic biomarker for predicting treatment response, moving beyond static regional metrics.

Methods

We analyzed a unique dataset comprising 182 participants from three clinical trials (two randomized controlled and one open-label) targeting distinct MDD symptom dimensions: suicidal ideation, anhedonia, and emotional blunting. All received personalized, connectivity-guided rTMS. Individualized functional brain networks were constructed from pre- and post-treatment resting-state fMRI. We quantified two key network controllability metrics—Average Controllability (AC, energy-efficient stabilization) and Modal Controllability (MC, high-energy state transitions)—for each participant's personalized “effect target” (the symptom-relevant region used for targeting)2. A linear Support Vector Machine (SVM) classifier was trained using baseline controllability features from all brain regions to predict treatment response. Model performance (accuracy, AUC) was rigorously validated and compared against models using only regional activity (fALFF). SHapley Additive exPlanations (SHAP) analysis identified the most contributory neural predictors.

Results

Three primary findings emerged: (1) Symptom-specific network reconfiguration: rTMS induced widespread, symptom-dependent changes in nodal AC and MC. These changes were largely antagonistic, reflecting a dynamic trade-off between stabilizing baseline states (AC) and facilitating large-scale state transitions (MC), consistent with network control theory. (2) Baseline controllability predicts outcome: Baseline AC and MC at the personalized effect target, but not the stimulation site, robustly distinguished responders from non-responders across all subgroups (p<0.05). The predictive direction was symptom-specific: higher AC predicted better response in suicidal ideation/anhedonia, whereas the opposite pattern held for emotional blunting. This predictive power significantly surpassed that of conventional fALFF and functional connectivity metrics. (3) Superior predictive model: The linear SVM model trained exclusively on baseline whole-brain controllability features achieved an accuracy of 80% and an AUC of 0.844 for classifying treatment response, outperforming models based on fALFF alone (accuracy: 65%, AUC: 0.65). SHAP analysis revealed that the most influential predictive features were localized within fronto-temporal-limbic circuits critical for emotion regulation and cognitive control.

Conclusion

This work demonstrates that connectivity-guided rTMS exerts its therapeutic effect by symptom-specifically reconfiguring the dynamic control landscape of large-scale brain networks. More importantly, we establish baseline brain network controllability—a metric quantifying a node’s capacity to influence global brain dynamics—as a superior and mechanistically grounded biomarker for predicting rTMS response across diverse MDD symptom dimensions. By integrating computational network control theory with interpretable machine learning, our findings provide a novel framework for understanding rTMS mechanisms and advance the field towards precision neuromodulation. This approach enables a paradigm shift from standardized targeting to pathophysiology-informed, individualized treatment strategies based on a patient’s unique brain control architecture.
