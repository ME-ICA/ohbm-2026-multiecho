Introduction

Physiological recordings such as ECG, photoplethysmography (PPG), and respiratory belts play a critical role in neuroimaging research, supporting analyses ranging from physiological noise correction to quantification of autonomic dynamics1,2. Although the latest algorithms now achieve high performance in event detection, residual noise, motion artifacts, and the MR environment continue to limit fully automated labeling. In many datasets, visually identifiable peaks or troughs are missed by detection algorithms, while other segments require exclusion because data quality is too poor for reliable detection. Existing tools offer limited solutions for manual curation: many are tied to a single signal type, require proprietary software, or lack flexible interfaces for editing, annotating, and exporting events.

PyPhysAnnot addresses this gap by providing an open-source, platform-independent Python toolbox designed for fast, flexible manual correction and quality annotation of physiological signals commonly acquired during neuroimaging studies. The tool can be used on any signal where identification of local maxima or minima is desired, and is optimized for cardiac and respiratory recordings collected during MRI. The main contribution of this work is the graphical interface designed with features to accelerate the curation of annotations, but convenient data loading, preprocessing, and signal metric extraction tools are also included. The toolbox aims to improve data quality, enhance reproducibility, and streamline workflows for physiological analyses in neuroimaging studies.

Methods

PyPhysAnnot is implemented as a modular Python package emphasizing flexibility and ease of use. The toolbox can be executed programmatically in python or via a command-line wrapper that automates data loading, annotation, and export steps, enabling flexible integration into existing workflows. The core functionality is built around an interactive annotation interface implemented using custom callback functions connected to the matplotlib canvas (using GTK backend) for rapid redrawing, efficient panning/zooming, and dynamic updates of event markers. The interface supports keyboard and mouse controls for rapid adding and deleting both peaks and troughs of the signal (left click to add, right click to delete, holding shift switches to troughs). The user can quickly advance through the data with left and right arrow keys and zoom in or out of the x-axis with the up and down arrow keys. The signal can also be stretched in the y-axis (shift + up or down) or rescaled automatically with the “r” key using limits of the data in that window. In a separate plot below the active annotation window, the inter-event intervals are plotted across the entire signal and updated in real-time, enabling visual identification of data segments requiring annotation adjustments. Clicking on this interval plot also allows the user to immediately jump to that window of data. Sections of the data that are likely missing or contain an erroneous extra annotation are automatically identified by cyan and orange highlighted patches based on median event intervals (Figure 1). These highlights are also updated in real time with annotation changes.

The interface also supports several features involving selecting segments of the data using the matplotlib Span Selector widget. Artifacts can be highlighted by pressing the “a” key, and then clicking and dragging to select a segment of data. The positions of these low-quality segments are stored and then fed into postprocessing functions to automatically return calculated metrics accounting for these missing annotations. Automatic correction of annotations in a desired window can also be performed through first pressing the “c” key and selecting a segment of the data with high quality annotations to calculate the average waveform around the peak. Then, pressing “m” and selecting a second window with improper annotations uses the calibrated average to fix the annotations. This procedure is performed by convolving the average waveform with the selected low quality data window and identifying maxima in the output. At each maximum, the local maximum in the original signal is identified, and troughs (if relevant for this signal) are identified as minima between the new peaks.

Data loading is handled through a custom module that has been designed to read many of the common formats used for storing physiological data. PyPhysAnnot natively supports MATLAB .mat files (structured or array-based), text-based formats (.txt, .csv, .tsv), BIDS physiological files with associated JSON metadata, and LabChart-exported files through a dedicated parser that reads channel labels and data. All imported data are internally converted to a common representation to ensure consistent processing and annotation logic across heterogeneous datasets. Signal cleaning and initial event detection are optionally performed using NeuroKit23, but users can supply their own preprocessed data or initial annotations.

Post-processing utilities are implemented as independent functions that operate on the corrected annotations and artifact segments. These utilities first identify the valid physiological cycles, accounting for artifacts, and then calculate relevant metrics (phase, duration, and amplitude-based) on a per cycle basis. Output metrics are returned both as a dictionary of the measures sampled at each annotation, and as a pandas data frame with values interpolated and resampled to the original signal sampling rate.

Results

PyPhysAnnot provides a comprehensive set of tools for manual curation of physiological annotations and for generating derived physiological measures compatible with neuroimaging analysis. Users can rapidly correct automated detections, annotate new events, identify segments with unreliable data quality, and export cleaned outputs suitable for downstream analysis. This tool has been used internally in our group by multiple users across several datasets, facilitating analyses of interactions between physiology and functional neuroimaging data. Example projects leveraging this tool include explorations of respiratory and cardiac-locked BOLD and cerebrospinal fluid signal fluctuations, and changes in autonomic variables across arousal transitions and global BOLD signal peaks. The annotation interface has easily handled densely sampled (1000Hz) long duration (> 20minute) physiological data without losing speed in annotation updating. The tool is currently in a beta-testing phase and will soon be released for public use according to open-source principles. Development of detailed documentation is ongoing and will accompany the release of the software.

The development of this toolbox has also yielded a novel method for manual correction of ECG R-peaks when finger pulse (e.g. photoplethysmography or piezo sensors) signals were simultaneously acquired. ECG signals are notoriously difficult to acquire in the MR environment, and the MR noise typically causes standard detection algorithms to fail. PyPhysAnnots supports simultaneous annotation of both signals, boosting confidence in peak detections across modalities (Figure 2). Furthermore, a calibration-based ECG annotation method uses the typically higher quality finger pulse signals to estimate R peaks. Using the calibration selector on window with good quality ECG R-waves and finger pulse peaks calculates the average pulse-transit delay, and then this delay is used to project estimates of R peak locations into the ECG signal. Candidate R-wave positions are estimated from PPG peaks and refined by selecting the nearest local maximum in the ECG signal. This procedure, as well as the more general average waveform calibration feature, dramatically reduces manual annotation correction time and is particularly useful when physiological rhythms change over the course of the session, causing algorithms that process the entire run to fail. Users may recalibrate as often as need and retain accuracy in automatic detections across changing signal features.

Conclusion

PyPhysAnnot provides a flexible, open-source solution for manual curation of physiological annotations, addressing persistent challenges in neuroimaging workflows that rely on accurate characterization of cardiac, respiratory, and other relevant signals. By enabling efficient correction of automated detections and post-processing to exclude low quality segments, PyPhysAnnot facilitates higher data quality and reduces the amount of discarded data runs. The tool also contributes features such as its PPG-based ECG reconstruction approach for MR-corrupted datasets. Modular incorporation into existing preprocessing streams in python as well as the command-line wrapper expands accessibility to users working in different environments. The toolbox is well suited for inclusion in pipelines for physiological noise modeling, autonomic metrics, and multimodal imaging studies.

The toolbox is designed for extensibility, and several future developments are planned. Support for additional signal types such as continuous blood pressure, electrodermal activity, and electrogastrography would enhance the tool’s reach. We also aim to include more features directly relevant for neuroimaging such as formatting outputs for common tools such as RETROICOR4 and generating respiratory volume and heart rate regressors used in fMRI denoising. We also seek to add a generic data segment labeling frameworks for marking data segments with labels beyond artifacts. PyPhysAnnot’s architecture facilitates the addition of these modules and contributions from the community will be encouraged following public release.
