Introduction

Mild traumatic brain injury (mTBI) and alcohol use disorder (AUD) frequently co-occur in Veterans, with AUD affecting over one-third of those with mTBI (1). This comorbidity is clinically consequential: individuals with both conditions show greater impairments in cognitive control, emotion regulation, and functional recovery than those with either condition alone. Emerging evidence suggests that co-occurring mTBI and AUD may non-additively amplify disruptions in large-scale intrinsic brain networks involved in salience detection, cognitive control, and internally oriented thought. The triple-network model provides a useful framework for understanding this effect. The salience network (SN)—anchored in the right anterior insula—supports dynamic coordination between the default mode network (DMN), which underlies self-referential processing, and the frontoparietal control network (FPCN), which supports cognitive control (2). When this coordination is disrupted, the brain may show prolonged DMN engagement and reduced FPCN recruitment, increasing sensitivity to internal cues such as alcohol craving while diminishing regulatory control.

Importantly, salience-related dynamics can be obscured by traditional neuroimaging approaches that rely on static connectivity summaries (3). Here, we test group differences between Veterans with mTBI+AUD and controls in resting-state connectivity across the triple networks, and examine how craving relates to these static features across participants. We then use right anterior insula–seeded co-activation pattern analysis to assess group differences in salience-linked network states and their temporal properties, followed by dimensional analyses relating these dynamic features to craving. Together, this approach evaluates how mTBI+AUD alters salience-centered network organization across static and dynamic timescales.

Methods

Forty-four Veterans (22 with comorbid mTBI+AUD, 22 matched controls without AUD) completed a 20-minute eyes-open resting-state fMRI scan on a 3T scanner (TR = 555 ms), along with the Penn Alcohol Craving Scale (PACS; 0–30) administered immediately post-scan. Resting-state data were preprocessed in CONN (realignment, normalization, aCompCor denoising, band-pass filtering) and parcellated with the SchaeferPlus-100 atlas with Yeo-17 network assignments. Static functional connectivity was defined as Fisher-z–transformed Pearson correlations averaged within three a priori salience-linked internetwork pairs per hemisphere (salience–FPCN and salience–DMN), restricted to within-hemisphere connections. A salience orientation index (θ) was computed as the inverse tangent of SN–FPCN relative to SN–DMN coupling. 

Dynamic salience-linked states were characterized using co-activation pattern (CAP) analysis. Using the right anterior insula (rAI) as a salience seed, we identified high-amplitude frames in the seed time series for each subject and extracted whole-brain BOLD volumes at those time points. Retained frames were clustered with k-means (k = 4), with multiple random initializations and consensus clustering used to obtain stable CAPs. For each CAP and subject, we calculated dwell time (total time spent in that CAP), number of entries (how often the CAP was entered), and fractional occupancy. CAP spatial maps were labeled by voxelwise overlap with canonical Yeo-17 networks (for example, DMN-like, SN-dominant, SN–FPCN, visual). The number of retained frames per subject was included as a covariate in all CAP models to control for differences in frame retention.

Group effects for all analyses were tested with linear mixed-effects models with subject-level random intercepts; predefined static contrasts were FDR-corrected. Craving was examined as a secondary, exploratory dimensional variable by relating PACS scores to static connectivity and CAP metrics.

Results

Veterans with mTBI + AUD exhibited a default mode–dominant pattern of salience network coupling, characterized by reduced left salience–frontoparietal control connectivity and increased right salience–default mode connectivity relative to controls (FDR-corrected p < 0.05 for both). These static effects were accompanied by a shift toward default mode–biased network orientation (θ), consistent with altered large-scale regulatory balance across the scan. In  exploratory analyses restricted to group-significant edges, higher alcohol craving was associated with weaker left salience–frontoparietal control coupling (r = −0.31, p = 0.037) and stronger right salience–default mode coupling (r = 0.33, p = 0.029), mirroring the direction of the categorical group effects.

Next, dynamic CAP analysis identified four recurring network states across all subjects: a DMN-dominant state (CAP1), a SN-dominant state (CAP2), a SN–FPCN state (CAP3), and a visual network state (CAP4). Compared to controls, Veterans with mTBI+AUD spent significantly more time in the DMN-dominant CAP1 (β = 3.54 s, p < 0.001) and exhibited fewer transitions into CAP1 (β = 1.87, p = 0.022), CAP2 (β = 1.82, p = 0.025), and CAP4 (β = 1.60, p = 0.049). A significant craving × CAP interaction further revealed that higher craving across all subjects was associated with a longer dwell time in CAP1 (β = 1.58 s, p < 0.001), even after controlling for group effects.

Conclusion

These findings suggest that Veterans with co-occurring mTBI and AUD show both static and moment-to-moment disruptions in salience network regulation, marked by a shift toward DMN-dominant connectivity, prolonged time spent in a DMN-centered brain state, and fewer state transitions overall. Clinically, this pattern may reflect reduced regulatory flexibility, in which internally focused processes, such as craving-related thoughts, become overly salient and difficult to disengage from. Importantly, both static connectivity measures and dynamic brain state metrics converged on DMN dominance, pointing to the DMN as a key circuit-level contributor to craving. Although preliminary, these results highlight salience network interactions with the DMN and FPCN as promising targets for targeted intervention. Future work is needed to determine causality, clarify specificity to mTBI+AUD, and test whether modulating these network dynamics can improve craving regulation and functional outcomes in this high-risk population.
