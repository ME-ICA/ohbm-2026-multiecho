Introduction

Learning about threats in the environment and when threatening cues no longer signal danger are two basic tasks for survival, often studied in the laboratory using Pavlovian fear learning and extinction. The neural circuitry underlying these adaptive learning processes is still not fully understood, particularly how large-scale function brain networks reconfigure from rest to fear acquisition and extinction. Intrinsic functional connectivity remains relatively stable during rest, but reconfigures with changing task demands. Other learning tasks, which recruit diverse systems for memory, attention, and cognitive control, are associated with increased global integration across networks, while motor tasks, which primarily rely on a sensorimotor network, preferentially increase local, within-network communication1. Changes in network reorganisation or transition to different cognitive states can be studied using system segregation2, which reflects how distinct functional networks are by comparing within-and between network connectivity strength, while reconfiguration3 captures how much this segregation changes between a baseline condition and task state. Flexibility4measures how often a node changes its community assignments across time in the functional layers, revealing which nodes are engaged during transitions to different cognitive states. Here, we aimed to investigate the reconfiguration of brain network organisation when switching from resting to fear learning and extinction. Using graph-theoretical analyses in healthy young adults, we quantified system segregation and reconfiguration for single-layer analysis and flexibility for multilayer reconfiguration.

Methods

Fifteen individuals (mean ±SD age 25 ± 5.2 years; 9 women, 6 men; 14 right-handed, 1 left-handed), recruited through local advertisements, participated in the study. All individuals were self-reported healthy, non-smokers and non-drug users. The study was approved by the regional ethics review board committee in Uppsala, Sweden, and all participants provided written informed consent prior to participation. 

The fear acquisition paradigm lasted 20 min and consisted of 20 presentations of each of two geometrical shapes (a brown arrow and a blue circle), which served as conditioned stimuli (CS). One stimulus (CS+) co-terminated with a 250 ms electric shock on 16 trials (80% reinforcement), whereas the other (CS−) was never paired with the shock. The assignment of shapes to CS+ and CS− was counterbalanced across participants. Each CS was presented for 6 s, followed by a fixation cross with a mean inter-trial interval of 24.3 s (range: 21.8–27 s). The fear extinction task was 20 min long and included 20 presentations of each of the CS+ and CS- without the US. All CS were presented for 6 s followed by a fixation cross during a mean inter-trial interval of 24.3 s (range: 21.8–27 s). Imaging data were acquired on a 3T Siemens scanner using T2*-weighted EPI and preprocessed, including motion correction, slice-timing correction, nuisance regression, registration and normalisation to standard space.

For 166 AAL3 nodes, regional time series were extracted, and whole-brain correlation matrices were computed for rest and each task and condition (fear acquisition CS+ and CS-, fear extinction CS+ and CS-). Time-series data were preprocessed in the CONN toolbox for resting state fMRI and in SPM12 and BASCO toolbox for task fMRI. For single-layer analysis, the network modules were partitioned by overlaying using the Yeo 7 network partition onto the AAL3 template and additionally mapping subcortical and cerebellar networks. We focused on the Somatomotor Network (SMN), Default Mode Network (DMN), Frontoparietal Network (FPN), Limbic Network (LIMB), Ventral Attention Network (VAN), Visual Network (VIS), Dorsal Attention Network (DAN), Subcortical Network (SUB), and Cerebellar Network (CB). These network modules were used to compute system segregation, which was evaluated using repeated measures ANOVA with Tukey post-hoc comparisons, while functional reconfiguration was tested against zero to determine whether network organisation shifted significantly between functional tasks. The multilayer reconfiguration measure flexibility was computed using the BRAPH2 Flexibility function applied to a multiplex network in which the resting state and task layers were coupled through inter-layer links (γ = 1 and ω = 0.5). The matrices were thresholded across sparsity levels from 2% to 40% in 2% increments, and summarised as the area under the curve. Flexibility was then compared with nodal null distributions using a paired t-test.

Results

System Segregation was significantly higher for rest than for other tasks, indicating a shift toward less segregated organisation from rest to both CS+ and CS- conditions of Fear Acquisition and Extinction (F(4,56)=211.217,  p_GG=3.87e-26). Post-hoc Tukey–Kramer comparisons showed that rest exhibited significantly higher segregation than CS+ Fear Acquisition, CS- Fear Acquisition, CS+ Fear Extinction, and  CS- Fear Extinction. However, the functional layers of the fear acquisition and extinction tasks did not differ significantly. Thus, segregation decreased primarily between rest and task layers, whereas segregation remained relatively stable within task layers. See Figure 2 A. This task-related decrease in system segregation was significant for each of the modules except DAN (Figure 2 B). Across participants, significant reconfiguration were observed  (mean±SEM[SD]) for specific layer transitions from rest to CS+ Fear Acquisition (0.845±0.026[0.104]; t(15) = 31.400; p < 0.001) and Rest to CS+ Fear Extinction (0.910±0.031[0.121], t(15) = 29.012 p < 0.001) indicating a robust task-related reduction in system segregation (Figure 2 C). This decrease in segregation was significant for each of the nine functional modules, reflecting task-evoked integration of the network. (Figure 2 D).  This indicates that the brain’s functional architecture shifts from a segregated, modular organisation at rest to a more integrated network state during task performance, and this was observed in all 9 modules. Flexibility, which is also a measure of reconfiguration, indicated less switching of nodes within  DMN, Ventral Attention Network, Dorsal Attention Network, Subcortical Network and Cerebellar networks (Figure 2 E).

Conclusion

Our findings demonstrate that brain’s functional architecture shifts from a segregated modular organisation at rest to a more integrated network state during task performance.  This is in line with findings from other learning tasks and demonstrates that global brain engagement and integration also characterizes human threat learning.
