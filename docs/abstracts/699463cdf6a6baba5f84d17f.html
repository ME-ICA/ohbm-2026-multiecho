Introduction

Aging reshapes large-scale neural dynamics that support cognitive and temporal functions. Resting-state EEG captures both static properties (oscillatory power, individual alpha peak frequency, aperiodic 1/f features) and dynamic spatiotemporal organization through travelling waves (TWs). TWs reflect coordinated propagation of oscillatory activity across cortex and contribute to predictive processing and long-range communication.^1 Spectral power identifies the cortical sources underlying these oscillatory dynamics, revealing how age-related alterations reshape neural communication patterns.^2 Aperiodic activity indexes broadband neural excitability and neural noise.^3 Understanding how these markers jointly vary with age is essential for explaining differences in temporal and mnemonic performance across adulthood.

Methods

27 young adults (mean age = 23.8 ± 2.72 years) and 23 old adults (mean age = 67.1 ± 4.79 years) completed four minutes of eyes-open resting-state EEG using a 128-channel EGI system (1000 Hz sampling rate). Data were cleaned with ICA-based artifact rejection, and analysed using individualized frequency bands derived from each participant’s intrinsic alpha peak frequency (iAPF). Static indices including aperiodic exponent and offset, and periodic α and β spectral power, were computed using specparam (1-45 Hz, knee mode, peak width 0.5-12 Hz) at source level (sLORETA, PCA within Destrieux atlas). Dynamic indices quantified forward (FW) and backward (BW) TWs using 2D-FFT, with surrogate-based normalization, median propagation velocity (phase gradients via Hilbert transform), and temporal variability of FW/BW power (standard deviation over time). Participants completed an episodic memory test (CVLT), an executive function assessment (STROOP), and the CHRONOS temporal cognition battery.

Results

Older adults showed higher BW waves to FW waves ratios in the Beta (t(47) = 4.534, p < 0.001) and Gamma bands (t(47) = 3.059, p = 0.004), and greater BW-waves temporal variability in Beta (t(47) = 3.007, p = 0.004). BW Beta waves emerged as the strongest functional marker: in older adults, increased BW Beta-waves power predicted better immediate recall on the CVLT (β = 4.41, p = .009), this relationship was absent in young adults. Alpha band propagation velocity was significantly reduced in older adults (t(47) = 2.420, p = 0.020), with no associations to temporal cognition or memory in either group. No significant differences were observed between age groups in aperiodic components or individual alpha peak frequency (all p > 0.27).

Conclusion

Aging alters the directionality and temporal organization of large-scale cortical communication. Beta-band backward waves, implicated in top-down integration and memory maintenance^4 showed increased power in older adults specifically associated with episodic memory performance. This suggests that dynamic travelling wave measures capture early age-related reorganization of brain communication more sensitively than static spectral indices.
