Introduction

Criticality is a state in which complex systems exhibit maximal information processing capacity, and has thus been proposed as a marker of optimal brain function. The cortex is thought to hover near criticality, which enables long-range integration and abstraction.1  Examining distance to criticality at rest may therefore index the functional capacity of these cortical networks, which has the potential to be a valuable clinical marker. Although supported by evidence in cellular and animal models,2 the reliability and validity of distance from criticality measures in human fMRI remain unclear. Criticality has been studied in the context of development, and children who born prematurely exhibit decreased proximity to criticality at rest compared to their at-term counterparts, and effect that holds into childhood.1 Notably, these premature children exhibit abnormal hierarchical organization, suggesting that criticality may have predictive value for neurological development. An emerging theoretical breakthrough (d2) holds promise as a spatially precise measure of distance to criticality that, unlike existing tools, operates on a timescale applicable to clinical fMRI. While this holds promise to allow rigorous application of criticality theory, fMRI signal is slow and noisy which requires multiple processing steps that may impact the absolute and relative d2 values calculated. Here, we assess the intermethod-agreement of fMRI-derived measurement of d2 across fMRI processing choices.

Methods

A subset of  data from 50 children (5-8 y) was selected from the  Healthy Brain Network Biobank.3 NIH toolbox percentile scores were collected for Card Sort, Flanker Inhibitory Control, List Sorting, and Pattern Comparison and averaged to create a composite score. Functional MRI data, collected during movie-watching, fixation, and eye-tracking task runs (1-6, 3–10-min runs from each, per participant), were processed using fMRIPrep and with one or more combinations of the following additional processing steps: motion regression, global signal regression, and bandpass filtering (0.008-0.1 Hz). A preliminary analysis of the minimally (fMRIPrep alone) and maximally processed (all processing steps) pipelines is presented here. Both pipelines were parcellated4 before computing parcel-wise and cognitive network-wise d2. d2 was calculated using a custom autoregressive script, with fourth order models.5

To test whether analytic pipelines produced consistent cognitive system–level estimates of distance to criticality, we calculated one-tailed Spearman correlations comparing system-level averages of each subject between pipelines. To test whether pipeline choice influenced brain–behavior associations, we performed linear regressions for systems-level d2 with mean cognitive scores. Then, to test whether the magnitude of brain–behavior associations differed between pipelines, we conducted one-tailed Wilcoxon matched-pairs tests comparing regression effect sizes. To test for systematic bias in the effect size of the brain-behavior associations, we generated Bland–Altman plots comparing the two pipeline-derived estimates.

Results

Subjects showed a wide range of scores across NIH Toolbox Card Sorting (mean=34.77± 24.73, range=1-95), Flanker Inhibitory Control (m=34.94±25.70, r=5-99), List Sorting (m=37.76±25.77, r=1-93), and Pattern Comparison (m=33.91±33.23, r=1-99).

We tested whether there was a consistent linear scale between the d2 values calculated from each pipeline.  Spearman rank correlations between d2 values from each pipeline for each system showed correlation values ranging from -0.6082 to 0.2654, indicating that there is no consistent bias when examining d2 scores directly at the cognitive-systems level in individuals and only emerge when looking at the strength of association between d2 and cognitive measures.

Linear regressions between d2 values and the NIH toolbox composite score showed a flat relationship for all cognitive systems in both the maximally and minimally processed d2. Regression of effect sizes between pipelines yielded a raw slope of 13.02, indicating that the magnitude of criticality-cognition associations differed on average by more than an order of magnitude depending on preprocessing choices. Bland–Altman analysis showed a strong linear trend in the difference-versus-average plot between the effect sizes from each pathway, indicating a systematic scaling bias between pipelines rather than random disagreement. This pattern reflects multiplicative divergence in effect size estimates and means that the preprocessing methods are not interchangeable.

Conclusion

This work demonstrates that analytic pipeline choices can meaningfully alter fMRI-derived measures of distance to criticality and their brain–behavior associations, as small, cumulative differences across preprocessing may be magnified.  Our data suggests that these small decisions can accumulate to produce differences in behavioral associations of an order of magnitude. These results highlight the need for transparency and standardization of processing pipelines when examining criticality. This also underscores the need for further examination of the basic properties for fMRI-based measures of proximity to criticality before they can be more fully applied to study regional differences in brain function or as a possible clinical biomarker.
