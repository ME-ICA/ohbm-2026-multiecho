Introduction

Analyses in network neuroscience rely on complex pipelines involving numerous interdependent methodological decisions. In the absence of ground truth, many of these choices (ranging from data preprocessing to network construction and statistical modelling) are equally defensible, yet can lead to substantial variation in results.¹ While concerns about analytical flexibility and researcher degrees of freedom are well documented in neuroimaging, tools for systematically mapping and evaluating this variability remain limited, particularly in network neuroscience. Multiverse analysis addresses this challenge by encouraging researchers to evaluate all defensible combinations of analytical decisions to assess the robustness of their findings.² In this context, we introduce the Comet toolbox, which integrates an extensive set of (dynamic) functional connectivity and network-based methods within a unified multiverse analysis framework.

Methods

Comet is an open-source Python toolbox designed to support multiverse analysis in functional connectomics. It integrates a broad range of static, continuous, and state-based connectivity methods with graph-theoretical and network-based analyses within a modular and extensible architecture. Multiverse analyses are defined by specifying forking paths at any stage of the analytical pipeline, which are automatically expanded into complete and executable analysis scripts representing distinct analytical universes. Comet supports both graphical user interface-based and script-based workflows, includes optimised implementations of computationally intensive network measures, and is compatible with common neuroimaging data formats, enabling flexible integration into existing analysis pipelines.

Results

The Comet toolbox enables researchers to implement multiverse analyses with minimal additional workload and independently of specific methods or research questions. Extensive online documentation provides tutorials and usage examples (https://comet-toolbox.readthedocs.io). An accompanying preprint further situates the toolbox within the methodological landscape.³ In the poster, we demonstrate the conceptual framework and functionality of the toolbox using an analysis of dynamic functional brain networks in association with individual differences in trait neuroticism in the Human Connectome Project dataset.⁴ Brain-behaviour associations are tested using latent variable modelling techniques, such as bifactor models based on estimators for polytomous and quantitative observed variables. These models may also include regularisation for nodal network measures. In addition, approaches for integrating and interpreting results across the multiverse, including recent proposals for multiverse aggregation,⁵ are discussed to provide initial guidance on how to handle potentially large decision spaces.

Conclusion

Comet enables researchers in network neuroscience to move beyond single-pipeline analyses by explicitly quantifying how methodological choices shape empirical results. By combining dynamic connectivity methods and network-based analyses with an efficient multiverse workflow, the toolbox supports transparent robustness assessment and principled exploration of analytical uncertainty when addressing brain-behavior associations. Comet is publicly available via the Python Package Index (https://pypi.org/project/comet-toolbox/) and on GitHub (https://github.com/mibur1/comet).
