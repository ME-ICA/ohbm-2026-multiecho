Introduction

The visual cortex and artificial neural networks both process images hierarchically through multiple computational stages. However, prior works comparing them lack standardized pipelines and focus predominantly on CNNs. We contribute three advances. First, we establish a standardized, fully reproducible pipeline for temporally comparing any visual processing system (biological or artificial). Second, we validate this pipeline across multiple CNNs (AlexNet, ResNet-50, VGG-19). Third, we extend our work to Vision Transformers (ViT) and two rapid-presentation EEG datasets (THINGS-EEG 1: 50 ms; THINGS-EEG 2: 100 ms). To the best of our knowledge, this is the first study to jointly compare CNNs and a transformer within a unified temporal framework across multiple rapid-presentation EEG datasets, while explicitly quantifying the shift from visual to semantic representations. Our analysis revealed a robust mapping for all neural networks: early EEG components correlated with activations from initial network layers and low-level visual features; later components aligned with deeper layers and semantic content. Moreover, semantic correlation increased in deeper layers with longer stimuli, suggesting more semantic information could be encoded in EEG. These findings have important implications for both neuroscience and computer vision, as they de-emphasize the importance of model-specific mechanisms such as convolutions and suggest that different ANNs ultimately converge to brain-like computations when trained for the same task. This correspondence appears primarily driven by the hierarchical transformation from visual to semantic representations rather than by architecture-specific computations, potentially reflecting an underlying efficient algorithm for visual processing that emerges in any architecture regardless of the computational substrate. 

Methods

We analyzed two rapid visual presentation EEG datasets from the THINGS-EEG project. THINGS-EEG 1 includes 50 participants viewing 1,854 object concepts for 50 ms each in an RSVP paradigm; THINGS-EEG 2 includes 10 participants viewing 1,654 concepts for 100 ms with 100 ms ISI. For both, we used a common subset of 200 images (200 distinct concepts).

EEG was filtered (0.1–100 Hz, Hamming FIR), re-referenced to the average, down-sampled to 250 Hz, and baseline-corrected using the pre-stimulus interval (all in MNE-Python v1.9.0). At each time point, we performed pairwise decoding of object identity with regularized LDA (scikit-learn; 70/30 stratified split; tol = 0.01). Classification accuracies for all image pairs (200×200) yielded time-resolved representational dissimilarity matrices (RDMs) per subject.

The same 200 images were then passed through multiple deep vision models to obtain layer-wise activations: AlexNet, MoCo, and ResNet-50 (as in Gifford et al.), plus VGG-19 and a Vision Transformer (ViT). All models were ImageNet-based: AlexNet/MoCo/ResNet-50 and VGG-19 trained on ILSVRC/ImageNet; ViT pre-trained on ImageNet-21k and fine-tuned on ImageNet-2012 at 224×224 resolution. For VGG-19, we used pool1–pool5 and fc2; for ViT, we extracted the class token from all 12 layers. Activations were flattened, scaled, reduced to 200 components via iterative polynomial-kernel PCA, and converted to 200×200 RDMs using cosine distance.

To quantify temporal correspondence, we correlated EEG RDMs at each time point with each ANN layer RDM using Spearman’s ρ, then related peak correlation times to layer order within each architecture and compared patterns across architectures (Wilcoxon tests). We also examined how the correlation between EEG-based decoding and model/semantic structure evolved with layer depth and tested dataset differences using Mann–Whitney U.

To characterize low-level visual structure, we followed Lützow Holm et al., combining image descriptors from Harrison with RGB channel statistics. A recursive feature selection identified 8 key variables (spectral, edge, luminance, and color features), which were reduced via PCA, and pairwise absolute differences in the first component produced 200×200 low-level RDMs.

Semantic distance between concepts was computed using 300-dimensional FastText embeddings trained on Common Crawl, with cosine distance yielding a 200×200 semantic RDM per dataset. This semantic structure was validated using RDMs derived from two state-of-the-art language model embedding spaces (NV-Embed-v2 and Stella).

In sumary:

We employed THINGS-EEG 1 (50 participants, 1,854 concepts, 50 ms with 50 ms ISI) and THINGS-EEG 2 (10 participants, 1,654 concepts, 100 ms with 100 ms ISI), using 200 shared images. At each time point we used a regularized linear discriminant analysis (70/30 split for train/test; tol = 0.01) to classify image pairs, forming 200×200 representational dissimilarity matrices (RDMs) per subject/time. Images (224×224) were fed to AlexNet, MoCo (with ResNet backbone), ResNet-50, VGG-19, and ViT (ImageNet-pretrained). Layer selection followed for AlexNet/MoCo/ResNet-50; for VGG-19 we used pool1–pool5 and fc2, and for ViT the class token from all 12 layers. Activations were flattened, scaled, reduced to 200 principal components (PCs), and converted to RDMs via cosine distance. We correlated EEG and layer RDMs over time (Spearman ρ), tested layer-order vs. peak-time relationships (Wilcoxon), and assessed dataset differences (Mann–Whitney U). Low-level visual features were computed following, with top 8 features via recursive selection and PC1 projection. Semantic RDMs used FastText embeddings (300-d) with cosine distances.

Results

We first assessed similarity structure within and between network representations. Across both datasets, layers within each CNN showed high representational similarity and similar ordering, while the final ViT layer was notably dissimilar from earlier ViT layers and from CNN layers. Across architectures, correlation with low-level image statistics decreased with depth, whereas correlation with semantic similarity increased, indicating a progressive shift from visual to semantic representations. For ViT, the decline in visual similarity was weaker and the semantic trend was flatter, suggesting more uniform layer representations. These patterns replicated on an independent validation image set.

We then quantified brain–model temporal correspondence. For each network and layer, we measured the time of maximum correlation between EEG and ANN representational dissimilarity matrices. In both datasets, this time systematically increased with layer depth, consistent with a hierarchical mapping in which early EEG components align with shallow layers and later components with deeper layers. Exceptions were mainly confined to the last layers of VGG-19, MoCo and ViT. In contrast, the peak correlation value tended to decrease with layer depth, again with ViT showing weaker monotonicity. Overall, correlations between layer order and time of maximum correlation were positive for all architectures, whereas correlations between layer order and peak correlation were negative, and these relationships were more stable in the longer-duration dataset.

To disentangle visual and semantic contributions to EEG, we compared EEG representational dissimilarity matrices with matrices derived from low-level image statistics and from semantic embeddings. In the shorter-duration dataset, EEG correlated robustly with low-level statistics but showed no reliable semantic effect, suggesting that discrimination was driven almost entirely by visual features. In the longer-duration dataset, EEG again showed an early peak related to image statistics, but subsequent time points also exhibited significant correlations with semantic similarity, indicating an increasing contribution of conceptual information over time. Correlations between visual and semantic dissimilarity matrices themselves were near zero, confirming that they captured largely independent structure.

Finally, we examined how semantic information predicts brain–ANN correspondence across layers. For each architecture and dataset, we regressed EEG–semantic correlations onto EEG–activation correlations across participants and extracted the slope per layer. For AlexNet, MoCo, ResNet-50 and VGG-19, slopes were significantly higher in the longer-duration dataset for subsets of layers, indicating that inter-individual variability in how semantic information is expressed in EEG helps explain variability in brain–model alignment when more time is available for semantic processing.

Conclusion

We demonstrated a robust and consistent temporal correspondence between the activation hierarchy of deep neural networks and human EEG responses during rapid visual perception. Across all convolutional architectures, early EEG components aligned with layers encoding low-level visual features, whereas later components corresponded to deeper layers that increasingly captured semantic content. This correspondence was strongly modulated by viewing duration: for very brief presentations, brain–ANN alignment was almost entirely explained by low-level visual statistics, while longer presentations revealed a clear contribution of semantic structure, especially in deeper layers. For longer durations, we also found that individual differences in brain–ANN correspondence were systematically predicted by how strongly semantic information contributed to EEG decoding, indicating that semantic abstraction is not only present but functionally relevant for explaining model–brain alignment.

Our findings support the view that, regardless of architecture-specific computations, ANNs operate by transforming visual input into semantic abstractions. Even architectures with limited biological plausibility, such as vision transformers, showed a clear temporal alignment with brain activity, despite exhibiting more uniform and less classically hierarchical internal representations. This suggests that temporal correspondence between brains and ANNs is driven primarily by representational hierarchy and task demands, rather than by specific mechanisms such as convolutions, spatial locality, or hand-crafted receptive fields. In other words, when very different models are trained to solve the same challenging visual recognition task, they converge toward brain-like representational dynamics.

We further showed that, as layer depth increases, similarity between ANN activations becomes progressively less constrained by low-level visual similarity and more tightly linked to semantic similarity. EEG responses exhibited a parallel progression: early time points were dominated by low-level visual statistics, whereas later time points increasingly reflected semantic structure, particularly when the brain had more time to process the stimulus. Taken together, these results support the idea that brain–ANN correspondence is primarily driven by a shared representational goal: the efficient transformation of visual input into abstract, semantically organized codes over time.

In conclusion, our work argues that artificial neural networks resemble the brain not because they replicate its microscopic operations, but because they implement similar high-level representational objectives. This perspective has important implications for both computer vision and neuroscience. For computer vision, it challenges the explanatory power of model-specific architectural motifs (e.g., convolutions) as primary reasons for brain-likeness, and instead highlights the central role of hierarchical representational learning. For neuroscience, it suggests that very different ANN families can serve as viable computational models of visual cortex, provided that they are trained to pursue comparable goals. Future work should explicitly probe the role of hierarchical organization in the emergence of brain-like representations by systematically comparing models with varying depths, degrees of recurrence, and even non-hierarchical or shallow architectures, thereby testing how far the principle of task-driven representational convergence can be pushed.
